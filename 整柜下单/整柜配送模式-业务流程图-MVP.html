统一主链路五步：下单 → 订舱 → 清关 → 派送 → 已完结，各节点对应系统页面；七种模式按业务责任裁剪环节（不涉及环节不进入我方流程）。

PRD · 配送模式流程

整柜七种配送模式 · 统一五步主链路

  • ① 下单 → 整柜下单页面（订单录入 / 提交预报）
  • ② 订舱 → 舱位管理页面（放舱签入 / 完善提单）
  • ③ 清关 → 清关管理页面（目的港清关状态）
  • ④ 派送 → 整柜尾端派送（直送 / 拆送 / 海外仓入仓）
  • ⑤ 已完结 → 整柜尾端派送（POD / 自提 / 海外仓自提结案）
  • 「不涉及」环节：客户或他方自理，不进入我方系统页面流转，流程图中以虚线节点标注。
  • 与结算节点配置、订单录入配送模式下拉一致。
