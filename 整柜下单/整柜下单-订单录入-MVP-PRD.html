整柜下单 · 订单录入

新增

额外服务 / 附加服务 · 关联费用与杂费包
  • 附加服务须关联费用（NEW）：整柜运单勾选的额外服务 / 附加服务，须绑定费用类型并落预估（业务数据统计可见）。勾选 ≠ 仅打标；无费用映射的项不可单独生效（配置侧先补齐映射）。
  • 杂费包 · 整柜（NEW）：杂费包主数据新增「整柜」杂费包（与散货等既有包并列维护）。包内配置整柜可用的附加服务项及其对应费用类型、默认金额/计费口径（读库价，不在下单页手改价目副本）。
  • 默认关联：业务类型=整柜（整柜下单 / 传统订单管理整柜票）时，运单默认挂「整柜」杂费包；附加服务勾选、批量修改附加服务均只从该包解析可选项与费用映射。非整柜票不默认挂此包。
  • 示意映射（以杂费包配置为准，可维护）：报关→报关费；拖车→拖车费；保险→保险费；带电→带电附加费（名称以费用字典为准）。金额取杂费包/附加服务库当时价写入运单预估。
  • 入口：下单页「额外服务」勾选；运单列表「附加服务 / 批量修改附加服务」变更时同步增删关联费用行（来源=附加服务）。取消勾选同步移除对应未确认费用行。
  • 测：新建整柜运单默认杂费包=整柜；勾「拖车」后预估出现拖车费；取消勾选后该拖车费行移除（未确认态）。散货票默认包≠整柜包。
基本信息区
  • 额外服务联动：额外服务含「报关」「拖车」勾选，与报关方式、拖车方式联动（费用落账见上节「关联费用与杂费包」）。
    • 勾选报关 → 报关方式固定「我司代理报关」并置灰；未勾选 → 固定「自行申报」并置灰。
    • 勾选拖车 → 拖车方式固定「我司统一安排拖车」并置灰；未勾选 → 固定「客户自拖车」并置灰。
  • 明细联动：报关方式为「我司代理报关」时展开报关行（选填）；拖车方式为「我司统一安排拖车」时展开装柜地址、计划装柜时间（拖车费、报关费、报关联系人等下单页不录，由询价/报价带入）。
  • 装柜地址（调）：与提单分配 · 工厂地址同交互（旁支① #5 合并）。拆省* / 市* / 详细地址*三字段，均可下拉或手输；详细地址旁「选择地址」从地址簿带回省/市/详细（可改）。未填完整时红字「请选择装柜地址」，提交预报拦截。
  • 选填字段：船公司、报关行非必填，下单时可留空，后续订舱/报关环节再补。
  • 总价*（NEW）：基本信息必填；口径同运单发票总价；提交预报后回写 业务数据统计 · 申报价值（金额+币种一并回显）。未填或 ≤0 拦住提交。页内提供申报价值回显预览。
  • 车架备注：是/否单选；保存后同步至 舱位管理「下单车架备注」，供订舱岗确认。
  • 中转标识：默认直航；切换为中转时须填写中转港，选项取目的港数据字典。
发货人 / 收货人信息区
  • 去掉：预计送货地点、期望 ETD。
  • 按原型分开展示发货人信息与收货人（收件人）信息；通知人仅下拉选择（默认同收货人）。
  • 选择发货人 / 收货人后，自动带出该主体的地址、联系人、电话、邮编（支持「新增」维护主体）。
  • 收件人区去掉税号、EORI；地址、联系人、电话取收货人（非通知人），选择收货人后自动回填。

调整

配送模式 · 卡派跟进

各配送模式结案后进入卡派跟进（新）；涉及派送的模式支持上传 POD，直送与拆送在轨迹上区分。

  • 整柜清关（PK2548）：前端订舱、尾端派送均非我司 — 下单 → 清关 → 已完结（进卡派跟进）
  • 整柜清关直送（PK2549）：前端订舱非我司，我司管到港清关+派送直送 — 下单 → 清关 → 派送(直送) → 已完结（进卡派跟进）
  • 整柜清关拆送（PK2550）：前端订舱非我司，我司管到港清关+派送拆送 — 下单 → 清关 → 派送(拆送) → 已完结（进卡派跟进）
  • 整柜直送（PK2551）：我司管前端订舱+到港清关+派送直送 — 下单 → 订舱(报关并行) → 清关 → 派送(直送) → 已完结（进卡派跟进）
  • 整柜拆送（PK2552）：我司管前端订舱+到港清关+派送拆送 — 下单 → 订舱(报关并行) → 清关 → 派送(拆送) → 已完结（进卡派跟进）
  • 整柜到港自提（PK2553）：我司管前端订舱+到港清关，不管派送 — 下单 → 订舱 → 清关 → 已完结（进卡派自提）
  • 整柜海外仓自提：我司管前端订舱+到港清关，送海外仓客户自提 — 下单 → 订舱 → 清关 → 海外仓 → 已完结（进卡派跟进）
  • 枚举与 传统订单管理「修改配送模式」弹窗对齐（7 项）。
  • 货物明细必填：柜型、柜量、毛重小计、体积小计、HSCODE、中英文品名；箱数选填。
  • 箱型在货物明细表录入；已去掉箱型组合、目的港派送方式(PK)、配送特殊操作要求、送货时间、结案日期等字段。
