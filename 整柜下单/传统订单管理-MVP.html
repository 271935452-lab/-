传统订单管理（整柜）

页面定位

  • 融合原系统「传统/分摊下单管理」列表 + 工具栏 + 筛选，与 整柜订单录入 字段对齐。
  • 整柜流程 7.2：本页为运单主视图；新建/编辑在「提交预报」→ 订单录入；放舱在「绑定仓位」→ 仓位信息。
  • 相对原系统移除：顶栏黄色流程说明条、筛选区「合同号」「货代商」、分摊录单及相关能力（本期不做）。

筛选区

  • 保留：运单号、提单号、柜号、船名/航次、业务员、客户、客户单号。
  • 整柜扩展：运单状态、配送模式、关联报价。
  • 辅助操作：更多筛选、数据配置、查询、重置搜索。

工具栏（18 个 · 对齐原系统截图 + 整柜扩展）

  • 顺序与配色：查询数据（蓝）· 提交预报（橙，链至订单录入）· 修改配送模式 · 绑定仓位 · 修改报关方式 · 取消订单（红）· 装柜完成（绿）· 修改拖车方式 · 附加服务 · 批量修改附加服务 · 发票 · 导入修改发票信息 · 批量修改备注 · 客户要求折扣（红）· 客户轨迹 · 轨迹 · 运单操作日志 · 修改收货体积。
  • 查询数据：按筛选区条件刷新列表（原型演示）。
  • 提交预报：跳转 整柜下单录入 新建运单。
  • 修改配送模式：弹窗批量修改，须先勾选运单；字段均为选填，留空不覆盖原值（见下「批量修改弹窗」）。
  • 修改报关方式 / 修改拖车方式：同上批量规则；枚举与订单录入对齐。
  • 绑定仓位：打开侧栏抽屉，须填海运费 + 合约有效期；确认后写入仓位信息页；可跳转仓位详情。
  • 装柜完成：运单状态 → 装柜完成；签出时触发装柜时间与海运费有效期校验（超期 → 仓位信息跳红）。
  • 取消订单：已预报/已订舱等未结案态可取消；已签收不可取消（业务规则待接口）。

批量修改弹窗（通用规则）

  • 适用：修改配送模式、修改报关方式、修改拖车方式。
  • 前置：至少勾选 1 条运单，否则提示「请先勾选需要修改的运单」。
  • 原则：弹窗内各字段均为选填；下拉选「— 不修改 —」或文本留空 → 该字段不覆盖原值。
  • 提交后写操作日志（操作人、时间、变更明细）。
修改配送模式 · 字段
  • 配送方式（7 项，与订单录入一致）：整柜清关 · 整柜清关直送 · 整柜清关拆送 · 整柜直送 · 整柜拆送 · 整柜到港自提 · 整柜海外仓自提--海运（第 7 项）。
  • 询价单：可改关联询价单号，留空不改。
  • 备注：配送相关备注，留空不改。
修改报关方式 · 字段
  • 报关方式：自行申报 · 我司代理报关。
  • 备注：留空不改。
修改拖车方式 · 字段
  • 拖车方式：客户自拖车 · 我司统一安排拖车。
  • 备注：留空不改。

绑定仓位抽屉

  • 入口：工具栏「绑定仓位」；须先勾选未绑定或待更新运单（原型直接打开）。
  • 必填：订舱代理、SO No、合约期内海运费(USD)、合约有效期起止。
  • 选填：船名航次、提单号、超出有效期调价、关联报价单（报价绑定后可带入）。
  • 保存 = 放舱签入，同步 仓位信息页；装柜签出时比对装柜完成时间与合约有效期。

列表状态页签

  • 工具栏下方快捷筛选：全部、已预报、已订舱、装柜完成、已签收、已退件（括号内为各状态运单数量）。
  • 与筛选区「运单状态」下拉联动；点击页签刷新列表计数。
  • 异常态 船期变更待确认 不在页签中单独列出，通过筛选区下拉查询。

运单状态（主流程）

  • 已预报：提交预报 / 录入完成，尚未绑定仓位。
  • 已订舱：绑定仓位（放舱）完成；仓位信息页已写入海运费 + 有效期。
  • 装柜完成：现场装柜结束；签出时记录时间并与海运费有效期比对。
  • 已签收：末端 POD / 签收完成，运单结案。
  • 已退件：退件/取消后结案，页签单独汇总。
  • 船期变更待确认：异常态，ETD/ETA 变更待订舱岗确认后恢复已订舱等正常态。

列表列（融合原系统横向滚动 · 整柜裁剪）

  • 列顺序：运单号 → 客户单号 → 客户名称 → 客户代码 → 业务员 → 所属客服 → 运单状态 → 提单状态 → 提单号 → SO → 柜号 → 柜型 → 船名航次 → 船司 → 重量(KG) → 体积(CBM) → 起运港 → 中转港 → 目的港 → 目的国 → 运输方式 → 配送模式 → 最新轨迹内容 → 轨迹状态 → 是否上传报关资料 → 报关单号 → 客户备注 → 关联报价 → 海外代理 → 签收时间 → 创建时间 → 修改时间。
  • 整柜移除（不合逻辑）：序号、客户类型、件数、收件邮编、附加服务费、业务类型/参考编号、关务分区、卖家、毛利/单价/成本、收货仓/收货件数、所属账套/网点、收件人/收货地址、托盘号、主品条数、货物类型(包裹)、进仓单、主单轨迹、指令状态/交易号、创建人/修改人/最新轨迹更新人等。
  • 海运费、合约有效期、绑定仓位状态等在「绑定仓位」抽屉及仓位信息页维护，列表不重复展示。

列表行样式

  • 蓝底选中行：当前勾选/聚焦行。
  • 橙底行：装柜完成时间超出海运费合约有效期等业务预警（如 RC266503）。
  • 红底行：船期变更待确认等异常态（如 RC266505）。
  • 进港时间标红（仓位信息页联动）：签出时登记进港时间；合约有效期内未登记或超有效期未补录调价 → 仓位列表标红，补录后恢复（详见 仓位管理 PRD）。
