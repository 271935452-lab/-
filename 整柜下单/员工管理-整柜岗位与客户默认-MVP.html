PRD · 员工整柜团队

员工管理 · 整柜岗位团队（业务员）

关系模型

  • 客户 → 业务员：客户主档系统信息中的「业务员」字段（已有）。
  • 业务员 → 岗位团队：本页新增，横向五岗，配置该业务员整柜单默认服务团队。
  • 客户 → 岗位默认：继承绑定业务员的团队；客户子表可单向覆盖。
  • 运单 → 权限：读取客户最终岗位配置（含客户侧修改），不直接读业务员团队。

表结构示意

  • fcl_salesperson_role_team：salesperson_emp_no + role + bind_emp_no
  • fcl_customer_role_binding：customer_code + role + bind_emp_no + bind_source(default/custom)

变更传播

  • 业务员团队变更 → 不自动覆盖客户 custom 格；可选批量刷新 default 格。
  • 客户换业务员 → 提示重新「从业务员团队带入」。
