订舱登记 + 完善提单 · 整合页

页面定位

  • 原「订舱登记」与「完善提单」合并为同一全屏单页；布局：订舱信息+运单基础信息、飞驼推荐+补充信息、仓位录入+海运费、完善提单+放舱确认。
  • 放舱 = 流程 7.2 签入 = 仓位信息绑定；须录海运费金额 + 合约有效期。
  • 新增须先选运单；编辑/完善通过列表提单号或「完善提单」入口打开。

新增 · 列表

  • 导出放舱 BC（模板）、导出预报模板（模板）、未放舱导出（模板）、批量导出（按筛选区+状态页签）、编辑备注（备注流转至卡派跟进（新）海外卡派总单）。
  • 编辑舱位 / 完善提单：同一页面，必填项因场景不同（见下「订舱编辑状态」）。
  • 甩柜换船、甩柜 BC 导出：已放舱记录换船，原舱作废、异人录入新舱。

新增 · 海运费异常标红

  • 无合约时间：不判断，不标红。
  • 有合约时间，关联运单无进港时间：标红；补录「超出有效期调价金额」（非 0 且非空）后恢复正常。
  • 有合约时间，进港时间超出合约止：标红；补充「超出有效期调价金额」后恢复正常。
  • 有合约时间，进港时间在合约期间内：正常。

调整 · 新增/编辑订舱

  • 飞驼船期：选起运港+目的港后查询；默认 ETD 参考日为当天；已选船司则带船司条件，未选查全部；勾选中转后带中转港条件筛选。
  • 中转：默认直航；勾选中转须填中转港，取值目的港字典。
  • 卸货港：下拉，取值目的港字典；修改目的港时自动同步。
  • 补充信息 · 航线：文本编辑框；飞驼选用时自动回填。
  • 放舱资料：上传后同步至关联运单，供客户与业务员下载。
  • 放舱状态 = 否：提单号、截单时间(SI)、SO No 均为非必填。
  • 放舱状态 = 是（编辑态）：提单号、放舱状态、仓位录入（箱型/数量/SO/增删行）不可修改。
  • 车架备注：下单页「车架备注」只读带入「下单车架备注」，订舱岗在放舱确认可再确认是否带车架。

订舱编辑状态

  • 未放舱：运单「已预报」· 提单「提单草稿」。
  • 已放舱：运单「已订舱」· 提单「待分配」。
  • 完善提单后：提单「已分配」· 运单可操作装柜完成。

放舱必填摘要

  • 放舱「是」：提单号、SO、截单 SI、船名航次、ETD/ETA、海运费+合约有效期必填；截关/截港/进港代码选填。
  • 新增订舱时分公司、海运费可选；完善提单/绑定仓位时海运费必填。
  • 选用飞驼船期可回填 ETD/ETA、截单/截关/开舱/开港/截港、免用箱天数、航线等，支持手动改。
