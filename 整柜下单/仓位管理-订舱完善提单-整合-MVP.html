  • 移除「未放舱导出」：与「批量导出」功能重复；需导出未放舱列表时，切换「未放舱」页签或使用「放舱状态=未放舱」筛选后点「批量导出」。
  • 移除状态页签「船期变更待确认」：异常态仍通过筛选区或列表橙底行识别，确认后回到已放舱等正常态。
  • 列表新增 甩柜BC导出；新增/编辑侧栏去掉 BC 导出按钮，仅保留关闭与保存。
  • 同步流程 7.2 · 四：询价报价绑定、放舱侧栏、导出放舱 BC / 甩柜BC导出、导出预报模板/按筛选批量导出。
  • 二程船期并入订舱与船期；进港代码（船司按需填写）；中转港与直航同一行；是否带车架、报关代理均为非必填。
  • PRD 明确：放舱=仓位信息·绑定仓位；绑定须填海运费+有效期；装柜完成签出超有效期跳红；进港时间×合约有效期标红规则。
  • 移除「分摊录单」。完整清单见 整柜本次更新说明 · 运单侧见 传统订单管理 PRD。

已移除功能

  • 未放舱导出：原独立按钮已去掉；统一走「批量导出」，按筛选区 + 状态页签（如未放舱）导出 Excel。
  • 分摊录单：流程文档无定义，待业务确认后再做。

整合原则

  • 原「订舱登记」抽屉与「完善提单」弹窗合并为同一侧栏，保存同步列表与提单草稿。
  • 字段修改留操作日志（操作人、时间、变更明细）。

已移除字段

  • 柜号、铅封号：改至签出环节录入（流程文档）。
  • 换单日期、国内/国外费用明细、提单附加费：非放舱核心字段，费用走海运费登记与额外服务。
  • 重复船名+航次：合并为「船名航次」单字段。

放舱 = 仓位信息 · 绑定仓位

  • 业务上「放舱」即流程 7.2 中的签入，对应系统仓位信息页面（本页列表 + 侧栏），与泳道图步骤 ③运单绑定舱位为同一环节。
  • 绑定仓位时须录入海运费金额（合约期内固定价）与合约有效期起止时间（必填）；报价绑定后可带入，订舱岗可据实调整。
  • 侧栏「海运费」区块即绑定仓位时的必填登记项；保存后写入仓位信息，供后续签出校验与列表标红。

进港时间 × 合约有效期（仓位信息标红）

  • 进港时间：客服在运单签出时登记柜子实际进港时间（流程 7.2 · 「签出时一并登记进港时间，反推海运费」）；订舱侧栏「开港时间」为船期计划参考，以签出登记的实际进港时间作为校验依据。
  • 标红条件：已绑定仓位且录入合约有效期后，若合约有效期 [起, 止] 内尚未登记进港时间（或进港时间不在有效期内且未补录调价），则仓位信息列表对应行 / 海运费相关列标红，提示订舱岗或客服处理。
  • 恢复正常：补录进港时间且时间在合约有效期内 → 标红消除；若进港时间超出合约有效期，须补录「超出有效期调价金额」（或更新合约有效期/海运费，开航前完成）→ 补录保存后标红消除（原型标注「填完正常」）。
  • 与「海运费异常」页签联动；与装柜完成签出校验并行，任一异常均触发标红直至补录完成。

海运费有效期 × 装柜完成时间（签出校验）

  • 装柜完成时间：货物装柜完成后，运单执行签出时由系统记录该时间戳（签出前置节点时间）。
  • 比对规则：签出时将装柜完成时间与绑定仓位时录入的海运费合约有效期 [起, 止]自动比对。
  • 不在有效期内：系统弹出提示；仓位信息列表对应行 / 海运费列跳红；推送订舱岗处理（补录「超出有效期调价金额」或更新合约有效期，开航前须完成，见流程 7.2）。
  • 本规则与列表「海运费异常」页签联动；原「进港超有效期跳红」以装柜完成时间作为签出环节的触发校验时点。

列表标红规则

  • 红底行：未放舱；海运费合约已过期；合约有效期内未登记进港时间；装柜完成时间不在合约有效期内；提单号/SO 等 P0 必填缺失。
  • 橙底行：海运费 7 天内过期；截关/截单 48h 内；船期变更待订舱确认。
  • 红字单元格：该行中具体异常字段（如缺失提单号、海运费金额/有效期、临近截关时间）。
  • 装柜完成签出时超出海运费有效期 → 海运费列标红；合约有效期内缺进港时间或超有效期未补录调价 → 同上，补录进港时间或「超出有效期调价金额」后恢复正常。

列表列调整

  • 保留截图列：航次/船名、提单号、业务员、订舱代理、SO、起运港/目的港、箱型、截关、截单、ETD、ETA、带车架、备注。
  • 新增：20GP/40HQ 汇总、放舱状态、海运费状态；供应商改名为订舱代理。
  • 页签快捷筛：未放舱、海运费异常、截单临近、已放舱。

完善提单 · 业务分配

  • 分公司为必填；拖车供应商、报关代理、装柜地址均为非必填，按实际港前配套服务勾选/填写。

带车架 · 下单与放舱

  • 下单：客服在运单录入页填写「车架备注」（是否带车架及说明），只读带入订舱侧栏。
  • 放舱：订舱岗在「放舱确认」可选填是否带车架（非必填）；列表「带车架」列展示结果。
  • 带车架=是：保存后任务流转尾端操作岗（派送预约、POD、尾端附加费如车架使用费等）。

流程 7.2 · 四、报价 & 订舱

4.1 询价阶段
  • 询价来源：合作代理询价 / 直客询价；报价员生成标准化对外报价单并留存报价台账（模板）。
  • 询价/报价录入页支持导出对外报价单；仓位列表支持导出放舱 BC、甩柜BC导出（勾选或按筛选）、导出预报模板、批量导出（含未放舱：切换页签或筛选后导出；不提供「未放舱导出」）；新增/编辑侧栏仅「关闭」「保存」，不提供 BC 导出。
  • 报价完成后：运单绑定报价 → 关联询价/报价单号带入订舱侧栏 → 关联提单及后续放舱。
4.2 放舱（业务定义：签入 = 仓位信息 · 绑定仓位）
  • 即仓位信息页面绑定仓位：须填海运费金额 + 合约有效期；订舱代理、是否锁价/是否保舱报价单有则带入。
  • 放舱核心：提单号、船名航次、一程/二程船期（有中转港时二程必填）、目的港 ETA、截单 SI、截关/截港/开舱/开港、进港代码（非必填）；甩柜可勾选通知+轨迹，BC 导出在列表操作。
  • 放舱 BC 系统生成可导出；EIR/箱单等附件可上传；舱位变更原记录作废、异人重录。
  • 签出校验：装柜完成 → 运单签出时比对装柜完成时间与海运费有效期；超期则仓位信息页跳红。签出时登记进港时间：合约有效期内未登记或超期未调价 → 仓位信息标红，补录后恢复。
  • 列表标红：未放舱、海运费过期、缺进港时间/超有效期未调价、装柜完成超有效期、必填缺失；船期变更推送订舱/操作/尾端对应人员。
