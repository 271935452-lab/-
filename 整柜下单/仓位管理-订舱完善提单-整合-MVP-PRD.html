订舱登记 + 完善提单 · 整合页

页面定位

  • 原「订舱登记」与「完善提单」合并为同一全屏单页；布局：订舱信息+运单基础信息、飞驼推荐+补充信息、仓位信息（含海运费，按 SO 行维护）、完善提单+放舱确认。
  • 仓位登记合并规则（2026-08-11）：原分散的「仓位录入」与「海运费/合约/锁价/保舱」等信息合并在「仓位信息」区块，按 SO 行（柜子维度）一行维护，不再拆成两个独立模块。
  • 放舱 = 流程 7.2 签入 = 仓位信息绑定；须按柜子维度录海运费金额 + 合约有效期。
  • 新增/编辑订舱登记：可先选运单，也可后选运单（保存前须关联有效运单）；编辑/完善通过列表提单号或「完善提单」入口打开。交互见下「关联运单」。

新增 · 多 SO 拆分列表（2026-08-11）

  • 生成规则：订舱登记保存时，「仓位信息」区若有多行 SO，系统在舱位管理列表生成多条数据，按 SO 号一一对应（1 个 SO = 1 条列表记录）。
  • 每条携带：该 SO 行的箱型、数量、SO No、柜号、铅封号、合约有效期起/止、固定海运费、超出有效期调价金额、是否锁价、是否保舱；公共订舱字段（船名航次、起运港/目的港、提单号、ETD/ETA 等）同步带入各条。
  • SO 唯一性校验：
    • 同一保存批次内，各 SO 行 SO No 不可重复（含一行内逗号分隔拆出的多个 SO）；重复时拦截并提示「SO No 不可重复」。
    • 与系统已有舱位 SO 冲突时拦截（全局 SO 不可重复占用）。
  • 编辑：从列表进入时，单条记录仅编辑对应 SO 行；若需整票多 SO 一并维护，仍通过订舱登记侧栏多行录入后按 SO 拆分落库。

新增 · 关联运单（新增/编辑订舱）

  • 交互顺序（2026-08-11）：支持先选运单或后选运单两种路径，保存前须关联有效运单；已绑定运单后切换须二次确认（避免误覆盖已填仓位信息）。
  • 路径 A · 先选运单：点击「选择运单」选定运单后，系统按运单预报自动带出：
    • 起运港、目的港 → 订舱信息区；
    • 柜型、数量 → 「仓位信息」SO 行（一票多柜按「+」拆成多行，如 40HQ×1 + 20GP×1 → 2 行）；
    • 运单号、客户代码、派送方式、柜量类型、货好时间、收货人、拖车方式、装柜地址、下单车架备注等 → 基础信息区只读回填。
  • 路径 B · 后选运单：可先手工维护订舱信息（起运港、目的港）及「仓位信息」箱型/数量，再通过「选择运单」弹窗按条件反向匹配可选运单。
  • 后选 · 匹配触发条件：打开运单选择弹窗时，须已填写起运港、目的港，且「仓位信息」区已填写箱型与数量，方可按组合条件筛出可选运单。
  • 匹配维度：起运港 + 目的港 + 箱型数量组合须与运单预报一致；仅展示已预报且未绑定仓位的运单。
  • 一票一柜：运单仅 1 个柜型 × 数量，须与仓位信息完全一致方可筛出。
    • 例：下单 40HQ×1，仓位信息 40HQ×1 → 可匹配。
  • 一票多柜：运单含多个柜型，仓位信息须箱型与数量全部一致方可筛出（缺一不可、不可多不可少）。
    • 例：运单预报 40HQ+20GP → 仓位信息自动生成 2 行（40HQ×1、20GP×1）；起运港/目的港同步填入订舱信息区。
    • 反例：下单 40HQ×1 + 20GP×1，仓位信息仅 40HQ×1 → 不匹配，不展示。
  • 双向同步：先选运单带出后，用户仍可手工改起运港/目的港/仓位信息，改后再选运单仍走路径 B 匹配；手工修改与运单预报不一致时，后选运单列表可能为空并提示核对。

新增 · 列表

  • 编辑舱位 / 完善提单：同一页面，必填项因场景不同（见下「订舱编辑状态」）。
  • 甩柜换船、甩柜 BC 导出：已放舱记录换船，原舱作废、异人录入新舱；甩柜 BC 导出规则同「导出放舱 BC」。
  • 编辑备注：备注流转至卡派跟进（新）海外卡派总单。
  • 进港时间：列表新增列，取自关联运单「装柜完成」登记的进港时间（多运单时展示首条或「—」）；供海运费异常判定与订舱岗核对。
  • 海运费（合并于仓位信息）：侧栏「仓位信息」按 SO 行（柜子）维护海运费、合约期、锁价/保舱及柜号/铅封号；保存后按 SO 拆成多条列表记录（见上「多 SO 拆分列表」）。列表同步展示合约有效期起 / 止、固定海运费、调价金额；「海运费」列仍为异常状态（正常 / 已过期）。

新增 · 导出功能

  • 1. 导出放舱 BC
    • 范围：已放舱（放舱状态=是）的舱位；优先导出列表已勾选记录，未勾选时取当前筛选区 + 状态页签条件下的已放舱数据。
    • 导出方式：点击后弹出「选择导出模板」弹窗。
      • 若放舱确认区已上传放舱资料附件 → 直接导出已上传的附件（原文件，不套模板）；
      • 若未上传附件 → 按放舱模板（导出模版/放舱模板.xlsx）依据订舱登记已录入项生成 Excel。
    • 联系人（模板字段）：联系人姓名、联系人手机号取本条订舱创建人在 员工管理 维护的姓名、手机号；未维护则留空。
  • 2. 导出预报模板（仓位预报表）
    • 范围：已放舱且尚未开船（开船时间 ETD > 当前时间）的舱位记录。
    • 导出方式：按开船时间（ETD）所在自然周汇总生成 Excel 标准模板（表头示例「WEEK xx 预报（起止日期）」），供订舱岗发送给订舱代理做周度舱位预报/对舱确认。
    • 模板字段：POL、POD、航线、船名航次、船司、开船时间（ETD）、柜量、备注；同一周内按船司+航线+船名航次聚合柜量；备注取各 SO 行是否保舱（多 SO 时拼接，如「S0892：否 · S0893：是」）。
    • 不含：未放舱记录、已开船（ETD≤当前）记录。
  • 3. 未放舱导出
    • 范围：全量未放舱（放舱状态=否）舱位记录；可叠加当前筛选区条件收窄（默认导出全部未放舱）。
    • 导出方式：按未放舱数据模板（导出模版/未放舱数据模板.xlsx）生成 Excel（表头「未放舱数据」）。
    • 字段映射：
      • 编码：绑定报价编码（BJ…）；未绑定留空；
      • 订舱时间：仓位创建时间；
      • 代理名称、船名航次、起运港、目的港、ETD：订舱登记/列表已录入项；
      • 备注：拼接各 SO 行是否保舱、是否 SOC/COC（如「保舱：S0892否/S0893是 · SOC/COC：COC」）。
  • 4. 批量导出
    • 范围：按当前查询条件（筛选区 + 状态页签 + 列表可见数据）导出，不限放舱状态。
    • 导出方式：直接导出列表当前结果集（列表列字段），不使用上述 1～3 项业务模板；用于运营/对账按条件拉全量列表数据。
    • 与「未放舱导出」区别：未放舱导出固定未放舱范围+专用模板；批量导出跟随查询条件、导出列表原始字段。
  • 导出区分摘要：放舱 BC = 单票放舱单据（客户/业务）；预报模板 = 未开船已放舱按周报代理；未放舱导出 = 未放舱专用模板；批量导出 = 列表查询结果；运单侧「提交预报」与海外仓预报非本页模板。

新增 · 状态页签

  • 全部：展示当前筛选条件下的全部舱位记录。
  • 未放舱：放舱状态为否的记录（含新增订舱登记且尚未放舱）；列表以红底行标识。
  • 海运费异常：「海运费」列状态为已过期的记录；该列枚举仅已过期、正常两种（无「即将过期」）。页签与筛选区「海运费异常状态」联动，判定规则见下「海运费异常」。
  • 截单/截关临近：满足下列任一条件时列表橙底行或相关时间单元格标橙，并归入本页签：
    • 截关时间为空（未抓取/未填写）；
    • 截关时间距 ETD ≤ 3 天；
    • 截单时间(SI) 距当前时间 ≤ 48 小时。
  • 已放舱：放舱状态为已放舱（是）的记录。
  • 页签计数随列表筛选结果动态更新；切换页签在原型中按 data-release / data-freight / data-cutoff 等属性过滤演示。

新增 · 列表行样式

  • 红底行：未放舱（放舱状态=否）/ 海运费已过期 / 装柜完成不在合约有效期内 / 必填缺失。
  • 橙底行：截关时间为空 / 截关距 ETD≤3 天 / 截单(SI) 距当前≤48h / 船期变更待确认。
  • 灰底删除线：甩柜换船后原舱作废。
  • 绿底行：甩柜换船后新生成舱位。

新增 · 海运费异常（两个节点触发）

  • 触发节点 ① · 装柜完成：关联运单在「装柜完成」确认后，系统按下列规则重算海运费异常状态；异常时列表行标红，「海运费」列显示已过期。
  • 触发节点 ② · 编辑超出有效调价金额：订舱岗在编辑舱位时补录「超出有效调价金额」后，海运费状态恢复正常（列表标红消除）。
  • 无合约时间：不判断。
  • 有合约时间，且没有运单的进港时间关联在内：标红，海运费状态已过期；「超出有效调价金额」不为 0 且不为空时，后正常（海运费状态正常）。
  • 有合约时间，且运单的进港时间超过合约止：标红，海运费状态已过期；补充「超出有效调价金额」后正常（海运费状态正常）。
  • 有合约时间，且运单的进港时间在合约期间内：正常（海运费状态正常）。
  • 进港时间来源：关联运单「装柜完成」时登记的进港时间（见 传统订单管理 PRD）。

调整 · 新增/编辑订舱

  • 飞驼船期：选起运港+目的港后查询；默认 ETD 参考日为当天；已选船司则带船司条件，未选查全部；勾选中转后带中转港条件筛选。
  • 中转：默认直航；勾选中转须填中转港，取值目的港字典。
  • 卸货港：下拉，取值目的港字典；修改目的港时自动同步。
  • 补充信息 · 航线：文本编辑框；飞驼选用时自动回填。
  • 放舱资料：放舱确认区上传放舱资料 / EIR 等附件；上传后同步至关联运单，供客户与业务员下载。导出规则见上「1. 导出放舱 BC」。
  • 放舱状态 = 否：提单号、截单时间(SI)、SO No 均为非必填。
  • 放舱状态 = 是（编辑态）：提单号、放舱状态、仓位录入（箱型/数量/SO/增删行）不可修改；海运费合约期与固定金额锁定，但超出有效期调价金额、柜号、铅封号仍可补录。
  • 超出有效调价金额（编辑区字段标签：超出有效期调价金额）：海运费状态为「已过期」时可补录；补录后由触发节点 ②将海运费状态恢复正常。
  • 装柜地址：完善提单区两列两行（分公司+车队供应商 / 报关代理+装柜地址）；关联运单拖车方式为「我司统一安排拖车」且已填装柜地址 → 只读带入；客户自拖车时占位提示「客户自拖车，无装柜地址」。基础信息区同步只读展示拖车方式。
  • 车队供应商：仅当装柜地址有值时可选；装柜地址为空（含客户自拖车、需拖车但未填地址）时置灰不可选并清空已选。
  • 车架备注：下单页「车架备注」只读带入「下单车架备注」，订舱岗在放舱确认可再确认是否带车架。

订舱编辑状态

  • 未放舱：运单「已预报」· 提单「提单草稿」。
  • 已放舱：运单「已订舱」· 提单「待分配」。
  • 完善提单后：提单「已分配」· 运单可操作装柜完成。

放舱必填摘要

  • 放舱「是」：提单号、SO、截单 SI、船名航次、ETD/ETA、各 SO 行海运费+合约有效期必填；截关/截港/进港代码选填。
  • 新增订舱时分公司、海运费可选；完善提单/绑定仓位时海运费（柜子维度）必填。
  • 选用飞驼船期可回填 ETD/ETA、截单/截关/开舱/开港/截港、免用箱天数、航线等，支持手动改。
