舱位管理（订舱登记 + 完善提单）

按功能点：筛选条件 → 列表字段 → 功能逻辑。每条说明带原型链接。订舱登记与完善提单合并为同一全屏页。　本页原型　整柜导航

筛选条件 列表字段 功能逻辑 工具栏 弹窗 订舱编辑 导出

一、筛选条件

查询在筛选区。默认首行 4 项；「更多筛选」展开业务员 / 订舱员 / 创建时间。状态页签与筛选叠加。

条件位置说明原型
航次/船名/SO/提单号首行
  1. 模糊搜索，匹配列表船名航次、SO、提单号
  2. 测：输入 SO 片段能筛出对应行
筛选
订舱代理首行
  1. 下拉全部 / 具体代理
筛选
放舱状态首行
  1. 全部 / 未放舱 / 已放舱
  2. 与状态页签「未放舱」「已放舱」口径一致
筛选
海运费异常状态首行
  1. 全部 / 正常 / 已过期
  2. 与「海运费」列、页签「海运费异常」联动
筛选
更多筛选按钮
  1. 默认收起。展开：业务员、订舱员、创建时间起止
更多筛选
状态页签列表上
  1. 全部 / 未放舱 / 海运费异常 / 截单·截关临近 / 已放舱（无「已退仓」；2026-09-10 取消仓位退运）
  2. 计数随当前筛选动态更新
  3. 未放舱=红底行；海运费异常=海运费列已过期；截单临近见逻辑说明
状态页签

二、列表字段

多 SO 订舱保存后按 SO 拆成多条列表记录（1 SO = 1 行）。行样式见功能逻辑。

字段说明原型
提单号
  1. 可点打开侧栏编辑。未放舱无号显示 —
  2. 放舱=是后提单号锁定不可改
列表
放舱
  1. 未放舱红标 / 已放舱绿标
  2. 甩柜作废旧舱灰标删除线（CABIN=3）
放舱
海运费
  1. 仅正常 / 已过期两种（无即将过期）
  2. 判定规则见「海运费异常」
海运费
合约有效期起/止
  1. 按 SO 行维护，列表只读展示
  2. 过期或装柜不在有效期内参与红底行
合约期
固定海运费 / 调价金额
  1. 固定海运费放舱必填；调价金额=超出有效期调价，补录后可恢复海运费正常
列表
截关 / 截单(SI) / ETD / ETA
  1. 飞驼可选用回填，可手改
  2. 截关空、截关距 ETD≤3 天、截单距当前≤48h → 橙底或橙标
船期
进港时间
  1. 取自关联运单装柜完成登记的进港时间；多运单取首条或 —
  2. 供海运费异常判定
进港时间
关联报价
  1. 绑定报价编码可链至报价详情；未绑定 —
列表
现网字段
  1. 序号、航次/船名、业务员、订舱代理、SO No、起运港、目的港、箱型、20GP/40HQ、带车架、备注等：本期展示口径不变
列表

行样式：红底=未放舱/海运费过期/合约外装柜/必填缺失；橙底=截关·截单预警；灰底删除线=甩柜作废旧舱；绿底=甩柜新生成舱。

三、功能逻辑说明

3.1 工具栏 / 勾选

功能点说明原型
新增订舱登记
  1. 不用勾列表。打开全屏侧栏订舱登记
  2. 可先选运单或后选运单，保存前须关联有效运单
新增
完善提单 / 编辑舱位
  1. 勾 1 条或点提单号。同一页，放舱前后必填不同
  2. 已放舱：提单号、放舱状态、仓位录入（箱型/SO 增删）锁定；调价金额、柜号、铅封可补
编辑
甩柜换船
  1. 勾已放舱记录。原舱灰底作废，异人录入新舱绿底
  2. 弹窗可录亏舱费（金额/币种/说明选填；费用类型定死销售费用 · 退运费 A87）→ 挂提单预估；不填也可确认甩柜
  3. 甩柜 BC 导出规则同「导出放舱 BC」
甩柜换船
退运
  1. 本期取消（2026-09-10）：工具栏无「退运」按钮；不做已退仓；不在仓位侧录亏舱费
  2. 未放舱清理改走删除规则（见下）
—
导出系列
  1. 导出放舱 BC / 导出预报模板 / 未放舱导出 / 批量导出 — 规则见 §3.4
导出
编辑备注
  1. 备注流转至卡派跟进（新）海外卡派总单
备注
批量删除
  1. 勾 ≥1。无正式提单号可删（不录亏舱费）；有正式提单号禁止删除（接口/前端拦住）
  2. 已放舱仍按线上拦截或提示走甩柜换船
删除

3.2 弹窗 · 关联运单 / 甩柜 / 导出模板

功能点说明原型
选择运单
  1. 先选运单：带出起运港/目的港、柜型数量拆 SO 行、运单基础信息只读
  2. 后选运单：须已填起运港、目的港及仓位信息箱型数量，反向匹配已预报未绑定运单
  3. 一票多柜须箱型数量完全一致；切换已绑运单须二次确认
选运单
多 SO 拆分
  1. 保存时仓位信息多行 SO → 列表按 SO 一一对应生成多条
  2. 同批 SO 不可重复；与系统已有 SO 冲突拦截
订舱侧栏
退运弹窗
  1. 本期取消：无退运弹窗
—
甩柜换船弹窗
  1. 展示原舱信息；新船名航次/SO/ETD 等；关联运单可勾选是否随甩
  2. 底部增加亏舱费录入（选填）：金额/币种/说明；费用类型只读销售费用 · 退运费 A87；确认后写提单预估
甩柜
选择导出模板
  1. 放舱 BC：有上传附件则导原文件，否则套放舱模板 Excel
  2. 联系人取订舱创建人在员工管理的姓名/手机，未维护留空
导出模板

3.3 订舱编辑 · 放舱 / 海运费 / 飞驼

功能点说明原型
页面定位
  1. 订舱登记 + 完善提单同一全屏页；仓位信息（含海运费）按 SO 行维护
  2. 放舱=流程签入=仓位绑定；须柜子维度录海运费+合约有效期
侧栏
飞驼船期
  1. 选起运港+目的港查询；默认 ETD 参考当天；可带船司/中转港条件
  2. 选用回填 ETD/ETA、截单/截关/航线等，支持手改
飞驼
放舱必填
  1. 放舱=否：提单号、截单、SO 非必填
  2. 放舱=是：提单号、SO、截单 SI、船名、航次、普提/快提、ETD/ETA、各 SO 行海运费+合约期必填
  3. 船名/航次拆两格；普提/快提下拉必填
完善提单
订舱编辑状态
  1. 未放舱：运单已预报 · 提单草稿
  2. 已放舱：运单已订舱 · 提单待分配
  3. 完善提单后：提单已分配 · 运单可装柜完成
状态
海运费异常
  1. 触发①装柜完成：按进港时间与合约期重算；异常→海运费列已过期、红底
  2. 触发②补录超出有效期调价金额：海运费恢复正常
  3. 无合约时间不判断；有合约无进港→过期；进港超合约止→过期；进港在合约内→正常
海运费
装柜地址 / 车队
  1. 完善提单区两列两行：分公司+车队 / 报关代理+装柜地址
  2. 我司拖车且运单有装柜地址→只读带入；客户自拖车提示无地址
  3. 车队供应商仅装柜地址有值可选，否则置灰清空
完善提单
放舱资料
  1. 放舱确认区上传附件；同步关联运单供下载；导出 BC 优先用附件
放舱资料
改单同步运单
  1. 已绑定运单后，侧栏修改提单/订舱信息（港、船期、柜型等）点保存
  2. 弹窗询问「是否同步修改关联运单」；确认才回写运单，取消则只保存舱位/提单
  3. 测：有绑定运单且改了起运港，保存弹同步窗；点取消运单不变、舱位仍保存
  4. 测：点确认后 toast 含「已同步运单」
完善提单

3.4 导出功能

功能点说明原型
导出放舱 BC
  1. 范围：已放舱；优先勾选行，未勾取当前筛选+页签下已放舱
  2. 有放舱附件→导原文件；无→套放舱模板 Excel
放舱 BC
导出预报模板
  1. 已放舱且 ETD>当前；按 ETD 自然周汇总 Excel 给订舱代理
  2. 字段：POL/POD/航线/船名航次/船司/ETD/柜量/备注（保舱拼接）
  3. 不含未放舱、已开船记录
预报模板
未放舱导出
  1. 全量未放舱，可叠筛选；专用未放舱模板 Excel
  2. 编码=报价编码；订舱时间=创建时间；备注拼保舱/SOC/COC
未放舱
批量导出
  1. 按当前查询+页签导出列表字段，不限放舱状态，不用 1～3 业务模板
批量导出
