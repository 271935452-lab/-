各相关原型页顶部黄色/绿色提示条已同步标注「本次更新」要点；按 P 打开 PRD 面板可查看页面级变更说明。

一、流程 7.2 · 四、报价 & 订舱

  • 调整询价/报价/运单/订舱链路打通：XJ → BJ → RC → 仓位放舱（示例单号已对齐）。
  • 调整询价详情、报价编辑、报价详情：询价来源、锁价/保舱、绑定运单、导出对外报价单、跳转订舱放舱。
  • 调整订单录入：关联询价/报价只读 + 跳转链接；车架备注 → 放舱确认带车架；报关方式置于柜量类型之前；配送模式新增第 7 项「整柜海外仓自提」。
  • 调整仓位管理 · 订舱整合页：列表甩柜BC导出；新增/编辑侧栏去掉 BC 导出，仅保留关闭与保存。

二、仓位信息 / 放舱侧栏

  • 新增二程船名航次 / 开船 / 到港（有中转港时必填），并入「订舱与船期」。
  • 调整进港代码标签：进港代码（船司按需填写），标注非必填。
  • 调整中转港输入框与「直航」勾选同一行，不再单独占一行。
  • 移除工具栏「未放舱导出」：与「批量导出」重复；切换「未放舱」页签或筛选后批量导出即可。
  • 移除状态页签「船期变更待确认」；移除侧栏 BC 导出按钮；是否带车架、报关代理改为非必填。
  • 移除工具栏「分摊录单」按钮（流程文档无定义，待业务确认后再做）。

三、PRD 规则补充

  • 新增放舱 = 仓位信息页面 = 绑定仓位（即流程签入 / 泳道图步骤 ③）。
