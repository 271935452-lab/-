自动识别规则

扫子单号 → 逐件签入
识别为箱条码：反查主运单 → 预填子单号 → 直接进入录入尺寸页 → 保存即签入该箱。
扫运单号 → 批量签入
识别为主单条码：加载运单信息 → 停留主单页 → 逐箱扫子单录尺寸 → 全部录齐后一次性签入。

识别逻辑（条码规则）

  • 子单号：主运单号 + 3 位子序号（如 …746001）
  • 运单号：无子序号后缀的标准主单格式
  • 同规格运单：运单标记为同规格时，跳转旧版「尺寸+件数」页（见演示码 …99999）

流程对比

扫子单（逐件）
扫子单 → 识别逐件 → 录尺寸 → 签入 → 继续扫下一箱

扫运单（批量）
扫运单 → 识别批量 → [扫子单 → 录尺寸 → 保存]×N → 全部签入

补充规则

  • 模式由首次扫描自动决定，同一会话内保持一致，界面不提供手动切换。
  • 已加载运单后再扫子单，不再改变模式，仅追加录入。
  • 子单号需归属当前运单；重复扫描提示已录入。
