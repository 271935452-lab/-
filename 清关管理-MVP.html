产品说明 · 清关管理增量

进口商 / 清关行（绑定后展示）

  • 船务在提单管理绑定进口商时一并选定已授权清关行并落库。本页与做资料只展示，不在本页改绑。
  • 列表列名用「清关行」（目录：精准 / 02B / 赛因 / 关关通 / 人人数智 / 帝成），不再用「清关供应商」。
  • 未绑定进口商时进口商、清关行均显示 —。筛选支持名称/编码、清关行、未绑定。

取消 IT（只读协同）

  • 「取消IT」仅在船务 提单管理 操作；清关管理不设取消IT工具栏入口。
  • 本页列表「取消IT」列只读：已取消标取消IT，未取消显示无。不展示有IT / 无IT。
  • 筛选项仅「取消IT / 无」，与列展示一致。

查验消息推送

  • 文案口径：只同步目的港查验进度，不写「请转发客户 / 无需转发客户 / 无需操作回复」。渠道仍为业务员/客服站内待办 + 企微；不发邮件、不建客户待办。
  • 列表工具栏常驻消息推送：勾选清关查验/查验放行提单 → 预览站内/企微文案 → 发送或复制（事后补发）。渠道无邮件；收件对象仅业务员/客服。
  • 「清关查验」弹窗（轨迹登记）下方直接铺开消息推送：渠道、对象、说明、文案预览、复制/发送，不必再点页脚按钮。

海外清关品名

  • 清关详情中出口报关品名与海外清关品名分字段维护；目的港清关资料以海外清关品名为准。

现网筛选项 / 列补齐

  • 筛选对齐现网两行：提单号、运单号、柜号、运输方式、柜型、出发港、目的港、船名航次、船公司、订舱供应商、国内拖车供应商、报关供应商；右侧保留更多筛选 / 查询 / 重置。
  • 列表在增量列之外补现网列：提单/报关/查验状态、清关备注与查验/放行时间、件毛体、计划/业务 ETA、出发港·中转港、供应商、创建人、最新阶段等。清关供应商列名仍用「清关行」。
  • 「更多筛选」放现网列头常见条件：提单状态、报关状态、清关查验状态、创建人。
