产品说明 · 清关管理增量

进口商 / 清关行（绑定后展示）

  • 船务在提单管理绑定进口商时一并选定已授权清关行并落库。本页与做资料只展示，不在本页改绑。
  • 列表列名用「清关行」（目录：精准 / 02B / 赛因 / 关关通 / 人人数智 / 帝成），不再用「清关供应商」。
  • 未绑定进口商时进口商、清关行均显示 —。筛选支持名称/编码、清关行、未绑定。

IT 状态（只读协同）

  • 「取消IT」仅在船务 提单管理 操作；清关管理不设取消IT工具栏入口。
  • 本页列表「IT标记」列只读展示有IT / 已取消IT / 无IT，供清关协同与筛选。

查验页一键通知客户

  • 仅在「清关查验」页签展示「一键通知客户」按钮。
  • 勾选查验中记录 → 生成含提单/柜号/目的港/查验说明的消息 → 发送或复制。
  • 对齐关务「查验一键通知 + 处置状态」能力，减少口头转告。

海外清关品名

  • 清关详情中出口报关品名与海外清关品名分字段维护；目的港清关资料以海外清关品名为准。

查验 · 改港费占位

  • 清关查验页签详情区展示「清关过久 · 改港费」占位按钮；金额待业务固化。
  • 示例查验行可带「费用异常」标记，便于后续费用对账。
