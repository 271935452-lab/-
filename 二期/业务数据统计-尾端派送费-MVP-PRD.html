二-附、整柜字段（旁支计划二 #1）

业务数据统计与业务数据统计财务同一字段。总册见 旁支计划二 #1。

字段说明原型
整柜配送模式
  1. NEW。取运单配送模式；枚举对齐整柜下单 7 项（整柜清关 / 清关直送 / 清关拆送 / 直送 / 拆送 / 到港自提 / 海外仓自提）
  2. 非整柜票可显示「—」或空
  3. 测：整柜直送票本列显示「整柜直送」
 列表
收货计费重
  1. 改。= 下单重（下单录入毛重/计费重口径）
  2. 测：下单重 12500 → 收货计费重 12500
 列表
出货计费重
  1. 改。= 过磅重；无过磅重时取下单重（与收货计费重同值）
  2. 测：有过磅 13000 → 出货 13000；无过磅 → 出货=下单重
 列表

三、功能逻辑

场景说明原型
私卡绑运单写入
  1. 私卡组（报价员确认台）绑运单时，把已登记尾端派送费写入运单，并进入业务数据统计 · 财务侧该运单的预估 / 业务成本「尾端派送费」字段（来源=绑单同步）
  2. 与手工「新增业务成本」同一字段，不另开列；柜子计划导出取该字段
  3. 测：列表 ICBU88291001 显示 USD 186 · 绑单同步；财务入口打开该运单预估可见同值
 绑运单
无绑单手工补录
  1. 没有绑定询价/运单时，仍须在业务数据统计「新增业务成本」录入尾端派送费
  2. 保存后字段有值，来源=手工补录；业务 / 财务入口均可操作（权限以现网为准）
  3. 测：TXZG…01781 补录后列表来源变手工补录，明细汇总有值
 新增业务成本

四、柜子计划取数

点说明原型
导出取值
  1. 柜子计划导出对应柜/票时，取业务数据统计上的「尾端派送费」字段（绑单同步与手工补录同一字段，不另开列）
  2. 私卡且字段为空：导出预览标缺值（实现侧可拦导出或标红，以评审为准）
  3. 测：勾选含绑单同步 + 待补录票点「导出柜子计划」，预览行能看到取值与缺值提示
