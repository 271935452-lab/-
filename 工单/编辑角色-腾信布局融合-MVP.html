PRD · 弹窗外侧说明（不占弹窗内宽度）

1. 文档目的与布局

本页为「编辑角色」融合原型：弹窗内左侧维护角色基础信息（编号、名称、状态、终端、备注）；弹窗内右侧配置该角色在对应终端内的功能权限与业务数据范围。本 PRD 固定在弹窗右侧外侧，不进入 modal 内容区，避免挤压弹窗内的左右分栏与表格。随 HTML 交付，不另附独立 Markdown。

2. 弹窗内右侧信息结构（自上而下）

  • 菜单管理：树形勾选可访问菜单/功能入口。
  • 字段管理：按模块配置字段级权限（本原型为折叠占位）。
  • 查询条件管理：按列表配置可见筛选项（本原型为折叠占位）。
  • 业务数据范围：本 MVP 重点——客户类型、分公司、销售产品多选及筛选。

3. 菜单管理

  • 表头区提供「全选菜单」示意；子节点可单独勾选。
  • 落库与鉴权与既有「菜单-功能点」模型对齐；本页仅做交互示意。

4. 字段管理 / 查询条件管理

默认折叠。正式版本需对接：按模块/列表维护可读写字段、可见筛选项；保存粒度与缓存策略由技术方案定义。本原型不演示具体矩阵。

5. 业务数据范围

5.1 客户类型：下拉单选，含「不限」与业务枚举（示意：直客、同行）。用于约束角色默认可见的客户分类维度。

5.2 分公司（多选）：选项取自「大区分公司」页面维护的分公司主数据（展示名称、提交编码与该平台列表一致，本原型勾选项为示意）。单行触发器展开面板；支持全选、清空、完成；点击面板外关闭。未勾选任何分公司视为不限。保存时应提交已选分公司编码列表（value），与组织/数据权限策略叠加时以企业权限引擎为准。

5.3 销售产品（多选）：候选数据仅包含状态为「已启用」的销售产品（已停用或未启用的产品不出现在查询列表，亦不可新勾选绑定）。表格字段与主数据一致：产品编号、产品名称、产品组、业务类型。

  • 四项条件填好后点击查询才刷新列表；产品编号 / 名称框内支持回车等同查询；重置清空条件并刷新。
  • 产品编号 / 名称：按已应用条件模糊匹配（示意）。
  • 产品组 / 业务类型：下拉取值，「全部」不参与限制；对已应用条件为精确匹配。
  • 勾选行即绑定该产品；已选以标签（chips）展示，可单条移除。
  • 「仅显示已选」：在当前筛选条件下仅展示已勾选行。
  • 「勾选当前筛选结果」：将当前列表中可见行批量加入已选。
  • 列表区固定高度内滚动；本页为约 120 条静态数据示意，正式环境可接虚拟滚动、排序等。

6. 与组织策略、权限引擎的关系

弹窗内配置为角色维度的数据与功能边界；与用户组织、岗位、其它数据权限规则并存时，有效权限取企业权限引擎计算结果（交集/并集规则以平台统一策略为准）。本原型不实现引擎，仅表达配置意图。

7. MVP 验收要点（产品侧）

  • 四块权限区域可折叠展开，状态与表头箭头一致。
  • 分公司：选项来源与大区分公司页面一致（本页为静态示意）；触发器文案与勾选状态一致；全选/清空/完成、点击外部关闭可用。
  • 销售产品：列表仅含已启用产品（本页静态数据均视为已启用）；条件需查询后生效；四类条件、表格、已选 chips、批量操作与说明一致。

8. 非目标（本 HTML 不承诺）

真实后端保存、权限冲突校验、审计日志、字段/查询矩阵完整配置 UI、国际化、无障碍全量达标等，由后续迭代与研发拆分。
