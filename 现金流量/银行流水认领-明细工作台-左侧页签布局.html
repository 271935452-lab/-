银行流水认领 · 左侧页签布局

与《现金流量表-MVP》及《现金流量数据-系统需求.xlsx》「现金流量表新」页签口径一致：财务对每一笔流水认领为「收入 / 代理 / 费用 / 往来」四类之一后，该笔从待认领池移除并出现在对应页签矩阵中，与现金流量表勾稽。

页面概览

  • 左侧竖向场景页签：待认领、收入、代理、费用、往来；角标为已认领/待认领笔数示意。
  • 右侧主栏：筛选（含「我方账户 / 对方账户」+ 查询 / 明细 / 重置）→ 各页签标题栏内嵌功能按钮 → 认领明细矩阵。
  • 四类矩阵与《现金流量表新》对应：1·收入（客户收款）、2·代理（服务商成本）、3·费用（日常费用）、4·往来（内部往来）；各表默认当月汇总，可展开每日明细。
  • 对比版说明：原版（顶部横向页签）见 银行流水认领-明细工作台.html。
  • URL 约定：?tab=pending|in|agent|fee|due 与日期、账户 query，便于从总览 KPI 跳转。
  • 分类码与《现金流量表-MVP》中 scenario=income|agent|fee|due 及凭证明细钻取保持一致。

筛选条件

  • 默认仅展示第一行常用条件（含我方账户、对方账户）；点「展开全部」显示其余行（原型仅收集条件，查询仍为示意）。
  • 筛选操作区：查询刷新当前视图；明细按账户条件打开关联银行流水弹窗（已认领页签）；重置筛选清空条件。
  • 下列筛选与财务「银行凭证 · 待认领」查询区字段对齐；正式环境将各控件序列化为查询参数。
  • 待认领池：认领状态 = 未认领；各业务页签：认领状态 = 已认领 AND 分类 = 对应枚举。

功能按钮（各页签标题栏）

布局说明：凭证操作按钮置于当前页签列表标题栏右侧；筛选区保留「查询 / 明细 / 重置筛选」。切换左侧数据视图时，仅展示该页签相关按钮。

各页签可见按钮：

  • 待认领：查询数据、新增/修改、查看详情、凭证认领、导入、导出、修改汇率(批量)、修改备注、修改财务备注、作废、认领规则、删除。
  • 环节拆分 / 费用批量拆解：二期能力，本版界面不展示按钮（规则见 PRD 代理/费用章节）。
  • 收入 / 代理 / 费用 / 往来：查询数据、查看详情、撤销认领、导出、收起日明细、说明。
  • 已认领页签（二期）：修改备注、修改财务备注、查看关联流水 — 本版界面不展示按钮（矩阵行点击仍可打开流水弹窗；顶部筛选「明细」保留）。
  • 收入：标题下标注「默认汇总」；矩阵按部门默认归集。
  • 凭证审核：认领后财务审核节点，本版界面不展示按钮（接审批流，详见交付说明）。

功能分组（逻辑参考）：

  • 查询导出：查询数据、导出（随当前左侧视图导出待认领列表或矩阵）。
  • 凭证维护：新增/修改/查看详情、凭证导入、修改财务备注、修改汇率(批量)、删除数据（标红）。
  • 认领审核：凭证认领、撤销认领、系统认领规则；凭证审核接审批流（界面不展示按钮）。
  • 拆解归集（二期）：环节拆分、费用批量拆解在待认领页签执行（认领前预处理）；本版界面不展示按钮，拆分结果参与代理/费用矩阵汇总。
  • 作废与对冲：凭证作废在待认领页签；凭证对冲/撤销对冲为二期能力，界面不展示。

功能取舍（原型）：

  • 必备：查询数据、查看详情、凭证认领、撤销认领、凭证导入、修改备注、修改财务备注、系统认领规则（凭证审核见 PRD，界面不展示）。
  • 凭证详情页：银行流水凭证详情-MVP.html — 摘要三栏（凭证 / 我方账户 / 对方账户）+ 核销明细 / 附件 / 操作记录 / 对冲页签；从「查看详情」穿透打开。
  • 建议有：新增/修改数据（补录纠错）、修改汇率(批量)、凭证作废。
  • 强风险单独标红：删除数据（置于「凭证维护」页签）。
  • 二期/高级：环节拆分、费用批量拆解、凭证对冲、撤销对冲（界面不展示，见 PRD 占位说明）。
  • 正式环境：与财务系统凭证操作按钮集对齐，可置于顶部工具栏或右键菜单，不必占用列表上方固定区域。

认领明细与多维聚合（界面已精简，见 PRD）

  • 为节省纵向空间，「认领明细与多维聚合」标题栏与「收起明细」折叠控件已从界面移除；筛选下方直接展示当前场景矩阵/列表。
  • 已认领页签内点击矩阵数据行打开「关联银行流水」弹窗，字段与待认领列表一致（42 列，不含认领操作列）。
  • 矩阵内日汇总行（▾ 汇总）支持点击或键盘展开/收起当日明细；月合计行同样可点击收起/展开当月全部明细（含日汇总）；页签工具栏提供「收起日明细 / 展开日明细」批量操作。
  • 各矩阵底部为{月份}月合计 / {年份}年合计示意行；筛选跨年时按自然年分别展示多行年合计（如 2025年合计、2026年合计）；下方合计条联动。

待认领

财务核对路径：先按日期、金额、对方户名与网银对账单比对；确认业务实质后选择认领类型并确认认领。列表区不重复展示「待认领银行流水」标题（左侧页签已标识场景）。

  • 认领成功后流水归入对应页签；总览 KPI「未认领笔数 / 金额」在正式系统中与《现金流量表》总览联动。
  • 列表字段已与财务系统「银行凭证 · 待认领」对齐（凭证 + 金额流水 + 双方账户 + 客户名称 / 服务商名称 + 费用/审核 + 系统字段）；底部有月合计 / 年合计行。
  • 列表支持复选框批量勾选；演示：勾选 → 选择现金流量类型 → 点「确认认领」。
  • 外币流水展示水单汇率与汇损；认领汇率在确认认领弹窗中录入（外币建议必填，可与水单汇率不同）。
  • 外币服务商付汇若需「代理 + 费用」分账（如 USD 1 万付汇、汇损进费用），见「外币付汇 · 代理 + 费用拆分」。
  • 列表含水单汇率、汇损列；付汇/收汇汇损规则见下文「汇率与汇损」。

1 · 现金流入 · 收入

归集客户收款 / 退款。横向：部门；纵向第 1 列：日期，第 2 列：客户（含客户代码、客户简称）。

矩阵列（示意）：日期 → 客户代码 → 客户简称 → 未核销 → 营销一部、营销二部、营销三部、营销四部、营销五部、义乌同行、宁波、广州、泉州、厦门、青岛、苏州、台州、杭州、坂田一部、深圳坂田、深圳、深圳福永、潍坊、中山、产品部。

数据规则（《现金流量表新》）

  1. 系统中的「财务」→「银行凭证」，认领类型 = 客户；根据认领的账户编号及账户名称匹配对应业务员所在部门，金额落入对应部门列。
  2. 未核销列数据来源：「财务」→「银行凭证」中凭证状态 = 待认领的全部流水（待匹配金额）。
  3. 报表默认展示当月汇总（如 2026 年 1 月汇总），支持展开查看每日明细；2 月、3 月等后续月份以此类推。

原型补充

  • 页签角标统计已认领流水笔数；矩阵数据行点击可打开关联银行流水弹窗（字段同待认领）。
  • 账户筛选在顶部「筛选条件」（我方账户 / 对方账户）；「明细」按钮打开流水弹窗。
  • 每日首行日汇总、每月月汇总可收起/展开明细；部门归属以认领时业务员所在部门为准，后续调岗不改历史行。
  • 外币收款汇损：核销实时汇率 − 月初汇率（× 外币金额）；客户侧允许手工调整，见「汇率与汇损」。

2 · 现金流出 · 代理

归集支付代理成本款。横向：产品；纵向第 1 列：日期，第 2 列：代理（服务商）。

矩阵列（示意）：日期 → 代理 → 美海汇总、美海-清关、美海-海外仓、美海-FEDEX、美海-UPS、美海-内陆费、美海-头程 → 渠道汇总、渠道-包干 → 美空汇总、美空-头程、美空-清关、美空-内陆费 → 制单汇总、制单-UPS、制单-FEDEX。

数据规则（《现金流量表新》）

  1. 「财务」→「银行凭证」筛选：认领类型 = 服务商；数据来源为系统维护的服务商明细；匹配逻辑：提取明细中的费用部门及费用明细，自动映射至报表对应字段。
  2. 报表按「部门-费用明细」归集，并自动汇总至对应部门的汇总栏。例如：「美海-清关」至「美海-头程」汇总至「美海汇总」；「渠道-包干」汇总至「渠道汇总」。
  3. 动态扩展：后续新增费用类型（如制单部门新增「头程」），系统自动匹配并生成「制单-头程」明细列，数据同步汇总至「制单汇总」栏。
  4. 报表默认展示当月汇总，支持展开查看每日明细；后续月份以此类推。

原型补充

  • 服务商多环节（二期）：待认领页签「环节拆分」手工拆至报关、订舱等（本版界面不展示按钮），汇总按环节 + 服务商聚合。
  • 服务商汇损：付款侧汇损 = 月初汇率 − 实时汇率（× 外币金额）；外币付汇汇损拆分到「费用」见「外币付汇 · 代理 + 费用拆分」。
  • 每日日汇总行可收起/展开；示例数据见 AGENT_MOCK_ROWS。

数据规则（《现金流量表新》）

  1. 报表「类型」栏 = 费用明细：在「财务」→「银行凭证」中以费用明细为匹配依据，归类至报表「类型」栏。
  2. 自动抓取并匹配该费用明细所归属的费用部门及费用员工姓名，金额落入对应部门列。
  3. 动态扩展：新增费用明细或部门时，系统自动匹配并生成明细行，数据同步至对应部门及类型。
  4. 报表默认展示当月汇总，支持展开查看每日明细；后续月份以此类推。

原型补充

  • 费用批量拆解（二期）：待认领页签对工资类凭证拆 600+ 子行，支持导入工资 / 社保 / 医保模板（本版界面不展示按钮）。示例：2026-01 工资 ¥1,280,000 → 628 行。
  • 汇损归集：服务商外币付汇产生的汇损差额，一部分须在「费用」页签以「汇兑损益」等类型呈现，见「外币付汇 · 代理 + 费用拆分」。
  • 按日期自动生成日汇总行；示例数据见 FEE_MOCK_ROWS。

4 · 现金流出 · 往来

归集内部往来及特殊款项。纵向：日期 → 部门；横向科目列如下。

矩阵列（示意）：内部转账、MEEKOO-代收客户款、老板往来、员工借款、保证金、理财、社保（刘海云）、手工备注栏。

数据规则（《现金流量表新》）

  1. 数据来源：「财务」→「银行凭证」认领流水，按下列规则匹配至报表科目列。
  2. 内部转账：费用类型 = 银行存款，费用明细 = 转账 或 内部转账；另增加「提现 T+1 到账」规则认领（见系统认领规则）。
  3. MEEKOO-代收客户款：费用部门 = MEEKOO。
  4. 老板往来：费用部门 = 总经办，费用类型 = 其他应收款，费用明细 = 转账。
  5. 员工借款：费用员工姓名 = 闫雪，费用类型 = 其他应收款，费用明细 = 借款。
  6. 保证金：费用类型 = 其他应收款，费用明细 = 保证金。
  7. 理财：费用类型 = 理财，费用明细 = 招商-理财 / 泰隆-理财 / 美国账户-理财。
  8. 社保（刘海云）：费用员工姓名 = 刘海云，费用类型 = 其他应收款，费用明细 = 社保。
  9. 以上往来类流水匹配时，将对应流水的财务备注自动带入报表「手工备注栏」。
  10. 动态扩展：新增部门或往来类型时，系统自动匹配并生成明细，数据同步至对应部门及科目。
  11. 报表默认展示当月汇总，支持展开查看每日明细；后续月份以此类推。

部门行（示意）：财务部、总经办、MEEKOO、操作中心、操作中心-同行组、操作中心-直客组、公司、广州、海外仓、杭州、客服中心、联东 U 谷、美海、宁波、泉州、人力行政中心、深圳、深圳操作、深圳福永、苏州、腾信运通供应链、销售四部等。

原型补充：「内部转账」可为正/负；按日期自动生成日汇总行；示例见 DUE_MOCK_ROWS。

交互与逻辑

  1. 账户筛选：「我方账户 / 对方账户」置于顶部筛选区第一行；「查询 / 明细」与「重置筛选」同在筛选操作区，便于按收付款账户核对矩阵与流水。
  2. 已认领页签查看银行流水：矩阵中点击数据行打开弹窗；明细字段与待认领列表完全一致（含客户名称 / 服务商名称，不含认领操作列）。
  3. 数据导出：按当前筛选条件导出待认领列表或当前页签矩阵（示意；正式环境置于工具栏或右键菜单）。
  4. 业务员换部门：归属部门以认领时所在部门为准；后续调岗不追溯改写历史行。
  5. 列表底部展示{月份}月合计（可点击收起/展开当月明细）及{年份}年合计行；筛选跨年时每个自然年一行；矩阵下方合计条联动。

汇率与汇损

  • 流水汇损：水单带水单汇率；付汇/收汇与记账本位币差额记汇损（列表「汇损」列展示）。
  • 汇率口径：月初汇率 = 当月财务基准汇率（月初基准）；实时汇率 = 水单/网银实际成交汇率；核销实时汇率 = 认领核销时确认的汇率（默认可带水单汇率，弹窗可改「认领汇率」）。
  • 汇损计算公式（汇率差 × 外币金额 = 汇损本位币，方向如下）：
    • 收款：汇损 = 核销实时汇率 − 月初汇率
    • 付款：汇损 = 月初汇率 − 实时汇率
  • 汇损规则：收款（客户付款）侧按上式计算，允许手工调整汇损；付款（服务商付汇）侧按上式自动计算（可配置是否允许改）。
  • 认领时汇率：点「确认认领」在弹窗内录入认领汇率（外币建议必填，默认带水单汇率）；已认领流水明细仍展示认领汇率。

外币付汇 · 代理 + 费用拆分（业务说明）

以下场景来自财务对外币服务商付款的认领口径说明，用于解释「同一笔待认领流水为何拆成两笔、分别进入代理与费用」。

  • 待认领示例：网银有一笔 USD 10,000（一万美金） 的外币付汇流水处于「待认领」。
  • 汇损差额：付款侧按 月初汇率 − 实时汇率 计算（× USD 10,000 等外币本金），示意约 人民币 1 万元 量级（以财务确认为准）。
  • 汇损呈现：汇损的一部分须在「现金流出 · 费用」页签呈现，作为汇兑损益类支出归集，不与代理成本混在同一服务商产品列。
  • 拆分原则：认领时拆成两笔（一行到代理、一行到费用）：
    • 一笔 → 代理：外币本金按认领汇率折算后的代理成本（如海运费、清关费等），归入「现金流出 · 代理」对应产品/渠道列。
    • 一笔 → 费用：汇损差额（月初汇率 − 实时汇率 × 外币金额）归入「现金流出 · 费用」，费用类型建议为「汇兑损益」或财务配置科目。
  • 操作路径（原型）：在待认领页签完成核对后，通过「确认认领」选择分类，或结合「环节拆分 / 认领弹窗内分录」将同一凭证拆为代理 + 费用两条明细；拆分后待认领池移除，分别在「代理」「费用」矩阵汇总。
  • 校验：代理金额 + 费用（汇损）金额 = 流水本位币合计（或凭证金额）；汇损金额与待认领列表「汇损」列、水单汇率一致，可追溯至原流水号。
  • 与《现金流量表》勾稽：代理部分计入流出·代理汇总；汇损部分计入流出·费用汇总；总流出不变，避免汇损重复计入代理列。

交付说明（给开发）

  1. 矩阵结构、列定义及匹配规则以《现金流量数据-系统需求.xlsx》「现金流量表新」页签为准；四类矩阵分别见 #prd-in / #prd-agent / #prd-fee / #prd-due。

  3. 待认领列表列已与财务系统银行凭证待认领界面字段对齐；接口可按列名一一映射。
