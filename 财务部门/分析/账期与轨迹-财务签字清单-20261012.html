〇、背景 · 目标 · 验收 · 变更

需求背景 账期锁账口径不统一（含开船结如何取时间、截止日怎么算）、轨迹报表缺卸船/交货地/还柜等列，财务对账与锁账口径需统一确认。
目标 本期把下方功能点与截止日对照表一次确认清楚，开发/验收按本清单执行，范围不重不漏。
验收标准 ① 本清单勾选项全部实现；② 账期按对照表算出截止日，锁账=截止日当天 0 点；③ 开船结只认 A00106 第一次时间；④ 轨迹三列与筛选按 TRK 条验收；⑤ 口头补充不对抗本清单。
变更规则 签字后新增/修改范围须另开变更说明并重新确认；未勾选条目本期不做；本清单外需求不纳入本期验收。

A. 账期锁账

确认 编号 功能点
LOCK-01 客户账期 / 账期申请：确认签入、到港、签收可选，按对应签入 / 到港 / 签收时间起算（原有节点本期确认，不能停用）
LOCK-02 客户账期 / 账期申请：新增开船结；开船时间只认轨迹 A00106 第一次时间
LOCK-03 结算周期应结截止日：按下表默认值执行（勾选本条 = 同意下表口径）；表中「号数 / +N 天数」支持后续配置调整（见 LOCK-06）
LOCK-04 锁账时刻：截止日当天 0 点锁账；时区中国
LOCK-05 改账期：整客户回刷；未核销 / 部分核销 / 已锁未完全核销按新账期重算；已完全核销 / 已结算不回刷；新单直接用新账期
LOCK-06 截止日「后面的时间」可配置调整：半月结上半月各节点号（默认 20/21/22/23）、下半月次月号（默认 5）、月结 +5/+10/+15/+25 的次月固定号、+45 在月末后再加的天数（默认 +15）均可改；改后对新单生效，历史按改账期回刷规则
