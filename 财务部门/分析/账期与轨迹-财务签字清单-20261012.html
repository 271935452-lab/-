A. 账期锁账

确认 编号 功能点
LOCK-01 客户账期 / 账期申请：确认签入、到港、签收可选，按对应签入 / 到港 / 签收时间起算（原有节点本期确认，不能停用）
LOCK-02 客户账期 / 账期申请：新增开船结；开船时间只认轨迹 A00106 第一次时间；无开船轨迹时标「异常待补」、先不算账期；按柜时取该柜开船时间
LOCK-03 结算周期：新增现结；当节点为签入 / 开船 / 到港 / 签收时，发生当天应结 / 锁账，无宽限天数
LOCK-04 结算周期：周结一律下周五 0 点（当天周五仍取下周五）；半月结 1–15 为当月 20/21/22/23 日 0 点（签入/开船/到港/签收），16–月末统一次月 5 日 0 点；月结 +30 取次月最后一天 0 点，+60 取隔月最后一天 0 点
LOCK-05 锁账时刻：截止日当天 0 点锁账；统一写「×日 0 点」，不写「×前」；时区中国
LOCK-06 改账期：整客户回刷；未核销 / 部分核销 / 已锁未完全核销按新账期重算；已完全核销 / 已结算不回刷；新单直接用新账期

B. 轨迹报表

确认 编号 功能点
TRK-01 列表：新增卸船、到达交货地、还柜；取值分别为轨迹 A00193 / A00161 / A00197 第一次时间；无轨迹时为空，不强制报异常
TRK-02 列表：已签收必须有到港；已签收 / 全部签收 / 个别签收且到港为空时，标「缺到港」、进异常、行标红
TRK-03 列表 / 筛选：新增运单号多值搜索（换行 / 逗号 / 空格拆分）；新增开船时间、到港时间区间筛选；支持按货型、轨迹完整性筛选
