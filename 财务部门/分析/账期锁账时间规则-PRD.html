二、本期增量 · 开船结 本次新增

  2. 客户管理、账期申请、锁账任务需能选「开船」维度（与现有到港 / 签收 / 到货等并列）。

三、改账期后 · 未核销账单回刷 本次新增

现网痛点：下单时即锁定账期；客户/单据改账期后，历史未结账单仍按旧账期，导致锁账日、应结口径不一致。

  1. 触发：客户主数据「结算周期 / 账期节点」变更并保存成功（范围 = 整客户，已确认）。
  2. 回刷范围：该客户下未核销、部分核销的账单 / 应收费用行，全部按新账期重算应结截止日 D 与锁账时间 L（含已锁账但未完全核销的，一并回刷并重调度 L）。
  3. 不做回刷：已完全核销 / 已结算单据保持原账期快照。
  4. 落库：回写账期类型、节点、D、L；保留变更前账期与操作人、时间，便于追溯。
  5. 锁账任务：按新 L 重新调度；旧 L 上未执行的锁账任务取消或作废。
对象改账期后处理结论
未核销按新账期回刷，重算 D、L已确认
部分核销同样回刷已确认
已锁账但未完全核销同样回刷并重算 L已确认
已完全核销 / 已结算不回刷已确认
回刷范围改整客户（非按批次勾选）已确认
新下订单直接取当前新账期已确认

测：客户改「开船结」→ 未核销 2 笔、部分核销 1 笔、已锁未核销 1 笔均回刷；已完全核销 1 笔不变。

与开船结关系：若新账期为开船结，回刷时节点时间取各单开船时间；无开船时间的未核销/部分核销单标异常待补，不静默用错节点。

四、锁账总则 本次明确

  1. 先按「结算周期 + 账期节点」得到应结截止日 D（表中「×号前 / 下周五前」均指 D）。现网已有周期的 D 值须核实后再用；开船结启用同一换算。
  2. 锁账时间 L = D 的前一天 24:00。等价：L = D 日 00:00:00（进入 D 日 0 点即已锁）。
  3. 业务含义：截止日当天起不可再改归属本账期的应收/计费（以实现为准）；锁账任务在 L 触发。
  4. 若表述为「次月 5 号前」，则 D = 次月 5 日，L = 次月 4 日 24:00。

统一换算：凡表中出现「N 号前」，锁账时刻一律取 (N 号 − 1 日) 24:00，不得理解为 N 号当天 24:00。

七、系统计算步骤

  1. 读取客户/单据：结算周期、账期节点类型。
  2. 取节点发生时间 T（签入 / 开船 / 到港 / 签收时间）。
  3. 由 T 的年月 + 结算周期 + 节点类型，查矩阵得截止日 D。
    • 周结：D = T 之后的下一个周五（「下周五前」）。T 当天已是周五时，仍取下周五，不取本周五。
    • 半月结：按第六节窗口选行（已确认）。
    • 月结 +N：D = 次月（或隔月）对应号；凡含 +30 的，D = 该目标月最后一天。
  4. 锁账时间 L = D 前一天 24:00。
  5. 到点执行锁账；解锁走现网/申请流（不在本规则改）。

特殊日历

  • 月结 +30：D = 次月最后一天（不固定 30 号；2 月等小月自然取月末）。
  • 月结 +60：D = 隔月最后一天（同 +30 口径）。

十、验收要点

  1. 可选开船结；锁账时刻 = 截止日前一天 24:00。
  2. 改账期：整客户；未核销、部分核销、已锁未完全核销均回刷；已完全核销不回刷；有留痕。
  3. 半月结：1–15 / 16–月末分流；上半月 D=20/21/22/23；下半月 D=次月 5 日。
  4. 月结 +30 / +60：D 取次月 / 隔月最后一天。
  5. 周结：D = 下周五；T 当天是周五仍取下周五。
  6. 月结+5～+25/+45、签入/到港/签收与现网一致性：核实完成后再验收覆盖。
