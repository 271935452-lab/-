三、改账期后 · 未核销账单回刷 本次新增

现网痛点：下单时即锁定账期；客户/单据改账期后，历史未结账单仍按旧账期，导致锁账日、应结口径不一致。

  1. 触发：客户主数据「结算周期 / 账期节点」变更并保存成功（范围 = 整客户，已确认）。
  2. 回刷范围：该客户下未核销、部分核销的账单 / 应收费用行，全部按新账期重算应结截止日 D 与锁账时间 L（含已锁账但未完全核销的，一并回刷并重调度 L）。
  3. 不做回刷：已完全核销 / 已结算单据保持原账期快照。
  4. 落库：回写账期类型、节点、D、L；保留变更前账期与操作人、时间，便于追溯。
  5. 锁账任务：按新 L 重新调度；旧 L 上未执行的锁账任务取消或作废。

四、锁账总则 本次明确

  1. 先按「结算周期 + 账期节点」得到应结截止日 D（表中一律写「×号 0点 / 下周五 0点」，不再用「×前」）。现网已有周期的 D 值须核实后再用；开船结、现结启用同一换算口径。
  2. 锁账时间 L = D 日 0点。即 L = D 日 00:00:00（进入 D 日 0 点即已锁）。等价旧述「D 的前一天 24:00」。
  3. 业务含义：进入 D 日 0 点起不可再改归属本账期的应收/计费（以实现为准）；锁账任务在 L 触发。
  4. 若表述为「次月 5 号 0点」，则 D = 次月 5 日，L = 次月 5 日 00:00:00。

统一换算：凡表中出现「N 号 0点 / 周五 0点」，锁账时刻一律取该日 00:00:00，不得理解为该日 24:00。

八、系统计算步骤

  1. 读取客户/单据：结算周期、账期节点类型；读取截止日配置（号数 / +45 追加天数，缺省用矩阵默认）。
  2. 取节点发生时间 T（签入 / 开船 / 到港 / 签收时间）。开船结：T = 轨迹 A00106 第一次发生时间；无该轨迹则本单跳过起算并标异常。
  3. 由 T 的年月 + 结算周期 + 节点类型，查矩阵得截止日 D。
    • 现结（仅签入）：账期节点必须为签入；D = 签入发生日（T 的日历日）；无 +N 宽限。若 T 已落入该日，则签入后立即应结/锁账；矩阵写「签入发生日 0点」。开船/到港/签收不适用现结。
    • 周结：D = T 之后的下一个周五（矩阵写「下周五 0点」）。T 当天已是周五时，仍取下周五，不取本周五。
    • 半月结：按第七节窗口选行；号数取配置（默认 20/21/22/23 与次月 5）。
    • 月结 / 月结 +30：D = 次月最后一天。
    • 月结 +60：D = 隔月最后一天。
    • 月结 +45：先取次月最后一天，再加配置天数（默认 +15）得 D。
    • 月结 +5/+10/+15/+25：D = 次月配置号（默认即 +N 号）。
  4. 锁账时间 L = D 日 0点（00:00:00）。
  5. 到点执行锁账；解锁走现网/申请流（不在本规则改）。

特殊日历

  • 月结 / +30：D = 次月最后一天 0点（不固定 30 号；2 月等小月自然取月末）。
  • 月结 +60：D = 隔月最后一天 0点（同月末口径）。
  • 月结 +45：D = 次月最后一天 + 15 天（+15 可配置）；例 1/20 → 2/28 → 3/15。
  • 号数可调：半月结、+5～+25、+45 追加天数均可配置；改配置后新单按新值，历史按改账期回刷。

十一、验收要点

  1. 可选开船结；开船时间 T = 轨迹 A00106 第一次发生时间；无该轨迹标异常、不顶替；锁账时刻 = 截止日 D 日 0点。
  2. 可选现结：仅签入现结；D = 签入发生日；无 +N 宽限；矩阵「签入发生日 0点」；不可配开船/到港/签收现结。
  3. 改账期：整客户；未核销、部分核销、已锁未完全核销均回刷；已完全核销不回刷；有留痕。
  4. 半月结：1–15 / 16–月末分流；上半月默认 D=20/21/22/23 日 0点；下半月默认 D=次月 5 日 0点；号数可配置。
  5. 月结 / +30 / +60：D 取次月 / 次月 / 隔月最后一天。
  6. 月结 +45：D = 次月最后一天 + 15 天（追加天数可配置）。
  7. 周结：D = 下周五 0点；T 当天是周五仍取下周五。
  8. 截止日「后面的时间」可配置；改配置后新单用新值，历史按改账期回刷。
