〇、背景与边界

项说明
业务痛点整柜应付导入后业务员成本重复录入；账期锁客户无法按费用类型开关。
为啥两个字段同步成本管「写不写成本」；锁客户管「到账期算不算进锁」——场景不同，禁止绑死同一开关。
与账期 PRDD / L 换算、改账期回刷等仍以《账期锁账时间规则》为准；本需求只加费用类型过滤条件。

一、BDS-1022-A · 应付同步业务员成本

1.1 触发与命中

项规则
入口①财务 → 成本管理 → 外部成本管理(实际) → 导入对账单
入口②财务 → 业务数据统计相关导入（与应付落账同源批次）
入口③主单实际费用 → 按主单添加
写入时机应付导入确认后再写；写前弹窗提示财务（确认写入 / 取消）
命中运单类型=整柜 且 网点 ∈ 网点启用表（种子：苏州、青岛）
界面财务确认弹窗展示预计同步/跳过条数；结果页：成功 / 跳过 / 失败条数

1.2 过滤与写入

步骤规则
① 读标记应付行费用类型「是否同步业务员成本」
② 否跳过该行，不写成本、不计入通知触发行
③ 是等额写入业务员成本；币别/汇率跟应付行
④ 种子默认是；D01 海运费、Q01 关税 = 否
⑤ 冲突同运单同费用类型已有业务员成本 → 财务弹窗以列表展示运单号/费用类型/金额/汇率，必选追加或覆盖后再写入

1.3 失败与重跑

情况处理
成本同步失败不回滚已成功应付；记失败清单
重跑按批次重跑同步；成功行补通知

1.4 业务员通知（对齐扣件放行）

类型规则
触发·同步导入/按主单添加：应付同步至少 1 行业务员成本写入成功
触发·客服直录业务客服在业务数据统计直接添加业务员成本（不是应付，不走同步写成本）保存成功
接收人运单业务员；同批次同人合并一条
通道我的通知 + 右下角 toast≈3s；不以弹窗为唯一入口
正文·导入同步运单{运单号}因整柜应付导入同步，已将费用写入业务员成本（费用类型未勾选同步的已跳过），请知悉。
正文·客服直录运单{运单号}因业务客服在业务数据统计添加了业务员成本，请知悉。
不通知同步未写入；客服直录未保存成功

企微/钉钉本期不做 → R-5。多票运单号拼接 → R-6。同步时机已定：导入确认后再写 + 财务确认弹窗（见交互稿）。

二、BDS-1022-B · 到账期是否锁客户

核心：标记是 → 账期内未结算参与锁；标记否 → 不因该费锁客户。

2.1 配置

项规则
位置费用类型表字段「到账期是否锁客户」（是/否）
维护与费用类型同权；改动写操作日志
与同步字段独立；可「同步=是、锁=否」或相反
种子各类型默认值由财务签字（R-10 / 签字清单 A）

2.2 判定

步骤规则
① 时机账期锁账任务到达 L（= D 日 0 点）
② 计入标记=是 且 落在当前账期 且 未结算（含未核销/部分核销）且仅应收
③ 锁计入集合非空 → 锁客户
④ 不锁集合为空 → 不因费用账期锁客户
⑤ 标记=否该类型永不进集合

未结算=含未核销与部分核销；费用侧=仅应收（签字清单 C-04 / C-05 已定）。
