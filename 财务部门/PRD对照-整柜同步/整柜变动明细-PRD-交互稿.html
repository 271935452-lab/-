序号功能点一句话

逐点清单

与原型页橙色序号 1～6 一一对应。

1数据来源 / 进表范围

取费用变动明细；仅整柜运单进入。散货运单一律不进。

项口径
费用变动对齐现网《费用变动表》费用行（应收 + 成本）
进表运单类型 = 整柜 → 其费用变动全部进入
排除散货运单（含销售产品名含「整柜」的散货）→ 不进本页

2解锁次数

业务数据统计 · 财务（锁账/解锁）操作中的「解锁」次数，按运单累计。

项口径
操作来源业务数据统计 · 财务菜单下的锁账 / 解锁操作
计数仅计「解锁」成功次数（不含锁账）；按运单累计
列表展示费用行带出所属运单的解锁次数；同运单多行同值
汇总有解锁运单数 = 解锁次数>0 的运单数；解锁次数合计 = 各运单解锁次数之和（运单去重后加总）

3筛选（默认含所属公司 · 更多展开）

默认：到货时间、客户简称、运单号、所属公司、业务员、费用项。更多：加收时间、加收人、费用侧。

条件位置说明
到货时间默认区间；空则不限
客户简称 / 运单号默认模糊
所属公司默认 · 新增精确；全部 / 指定公司
业务员 / 费用项默认精确
加收时间 / 加收人 / 费用侧更多区间 / 精确；费用侧：全部 / 应收 / 成本

4明细列

对齐《费用变动表》+ 销售产品、所属公司、装柜时间、解锁次数等；一条费用变动一行。不做运单类型列。

补充列说明
费用侧应收 / 成本
销售产品展示销售产品名称
所属公司运单所属公司
装柜时间新增列；展示装柜时间
解锁次数见橙圈 2；正数=加收、负数=冲减

5列下合计

不做顶部汇总卡片；合计落在表底对应列下。

列合计内容
序号匹配行数
原币金额加收行 / 冲减行
结算金额应收结算变动合计、成本结算变动合计
解锁次数有解锁运单数 / 解锁次数合计（按运单去重累计）

6导出

导出当前筛选结果（列与列表一致，含解锁次数、销售产品）。

导出范围 = 当前筛选命中行，不另扩范围。
