入口 · 签字清单 · 版式对齐 扣件放行交互稿

背景

苏青整柜导入应付后，业务员成本常需手工再录一遍；账期到点锁客户时，又缺「哪些费用类型该计入」的配置。 本期在费用类型主数据上挂两个开关：①「是否同步业务员成本」管导入写成本；②「到账期是否锁客户」管账期到点是否因该费未结算而锁客户。 网点启用另表（苏/青）；成本非导入即写。其中外部成本管理、主单实际费用在分摊时弹出对应财务确认弹窗再写；若业务员成本已有相同费用，弹窗须选追加或覆盖。

§1 应付同步业务员成本 · 核心口径（开发必看）

  1. 入口：① 外部成本管理 → 导入对账单；② 业务数据统计相关导入；③ 主单实际费用 → 按主单添加。三入口共用同步服务。
  2. 时机：非导入即写。外部成本管理、主单实际费用：在分摊时弹出对应财务确认弹窗，确认后再写业务员成本；业务数据统计相关导入：应付确认后写（同弹窗口径）。
  3. 财务弹窗：写前弹窗提示财务（①③在分摊动作触发）；取消 → 只保留应付、不写成本。若检出业务员成本已有相同费用（同运单同费用类型），须以列表展示已存在行（运单号、费用类型、金额、汇率），并让财务选追加或覆盖后再确认写入。
  4. 命中：运单类型=整柜且网点 ∈ 网点启用表（种子：苏州、青岛主数据 ID）。
  5. 过滤：费用类型「是否同步业务员成本」——是 → 等额写；否 → 跳过。种子：默认是；D01 海运费、Q01 关税 = 否。
  6. 失败：成本同步失败不回滚已成功应付；可按批次重跑。
  7. 通知业务员：① 应付同步写业务员成本成功 → 通知；② 业务客服在业务数据统计直接添加业务员成本（不是应付，无需再写/同步成本）保存成功 → 同样通知。「我的通知」+ 右下角 toast≈3s。

§2（到账期锁客户）：费用类型「到账期是否锁客户」=是 → 落在账期内且未结算（含未核销/部分核销）的应收费用参与锁客户；=否 → 不参与。锁账时刻 L 仍按《账期锁账时间规则》（D 日 0 点）。与同步成本字段独立。

§1 · 写入时机与财务确认弹窗

项口径
写入时机 · 总则非导入即写；写前须财务确认弹窗
弹窗触发 · 外部成本管理在分摊时弹出对应确认同步弹窗
弹窗触发 · 主单实际费用在分摊时弹出对应确认同步弹窗

弹窗对象当前操作的财务
相同费用检测按同运单 + 同费用类型比对当前业务员成本是否已有记录
存在相同费用弹窗以列表展示已存在行：运单号、费用类型、金额、汇率；并让财务二选一：追加 / 覆盖；未选不可确认写入
无相同费用不展示冲突列表与追加/覆盖选项，直接确认即可写入
取消只保留已确认应付，不写业务员成本

§2 · 到账期是否锁客户

项口径
配置费用类型字段「到账期是否锁客户」是/否；与「是否同步业务员成本」独立
时机账期锁账时刻 L（截止日 D 日 0 点）
计入标记=是 + 落在当前账期 + 未结算 + 仅应收
未结算含未核销与部分核销（已定）
费用侧仅应收（已定；不含成本）
锁客户计入集合非空 → 锁；为空 → 不因费用锁客户
标记=否该类型不进集合，不因该费锁客户

字段谁读是否
