## 一、会议结论摘要

1. **分析组（唐斌）**问题面最广：业务数据统计计费/成本联动、轨迹与资金占用口径、提成与离职报表性能。
2. **应收 / 资金 / 风控（徐珍霞、小双）**集中在：锁账时间口径、现金认领体验、滞纳金月度核算、风控弹窗与流水对接。
3. **税务（田苗）**明确个税测算按公司/身份证累计口径，提成表需补身份证。
4. 大量事项属**规则口径未闭合**或**性能瓶颈**，需先定公式与验收样例，再排期开发；下列「方案」仅为流程骨架，不替代评审定稿。

## 二、分模块问题清单

### 2.1 业务数据统计（唐斌）

| # | 问题 | 现状/诉求 |
| --- | --- | --- |
| 1 | 运费优惠和折扣只能添加一次 | 系统限制不合理或过严；需确认是否允许多次、是否互斥 |

## 四、流程性事项 · 大致方案

### 4.1 业务数据统计 · 计费与成本解耦

```
触发源                    重算范围（建议）
─────────────────────    ──────────────────────────
改收货计费重              → 运费/优惠/折扣（应收侧）
                          → 默认不重算业务员成本（除非勾选「同步成本」或走审批）
改销售产品 / 比重         → 自动比重优惠必须重算
改出货重（单票）          → 走审批流；通过后按审批结论刷计费；成本是否刷单独勾选
合并计费                  → 按合并后重量落入重量段；取消合并仅允许：未核销且无「处理成本」锁定
核销完成 / 已处理成本     → 禁止取消合并
无成本票                  → 报表空值兜底（显示「无成本」），禁止全表扫描卡死
```

**优惠/折扣**：产品确认后改为「按规则可多次但类型互斥」或「同类型覆盖」；落库唯一约束与提示文案同步改。

**退件退款对冲（草案，待 D-01）**：

| 费用项 | 系统自动算费 | 建议对冲 |
| --- | --- | --- |
| 运费 | 是 | 是 |
| 运费优惠 | 是 | 是（与运费成对） |
| 折扣 | 视是否系统项 | 与优惠同策略 |
| 人工加余额 | 否 | 默认**不对冲**或单独「余额冲减」动作（需拍板） |

### 4.2 单个出货重调整 · 审批流（草案）

```
业务发起改重
  → 校验：原重 / 新重 / 原因 / 是否影响大货价
  → 审批（建议：业务主管 → 财务分析岗）
  → 通过：写入计费重 + 记操作日志
  → 分支：
        A. 仅调应收计费
        B. 同步重算业务员成本（需权限）
  → 驳回：保持原重，通知发起人
```

「重量不变走大货价」：独立申请类型「计价档位例外」，不改重量字段，只改价档标记。

### 4.3 轨迹报表补齐

1. **数据源**：整柜轨迹单独接入（开船、到港、卸船、到达交货地、签收）。
2. **完整性规则**：状态=已签收 ⇒ 校验必须存在到港（或等价节点）；缺失进「异常轨迹」队列。
3. **查询**：多运单号（换行 / 逗号 / 空格）；筛选：开船时间、到港时间。
4. **时效**：每个轨迹节点输出「节点时间 + 相对上一节点时长」；统计维度表由唐斌提供后挂配置。

### 4.4 资金占用 · 时间口径

| 费用类型 | 应结款时间起点（草案） |
| --- | --- |
| 运费、海运费 | 到货时间 |
| 整柜（除关税） | 开船时间 |
| 整柜 · 关税 | 沿用原规则（待唐斌书面确认） |
| 其他 | 现有「其他规则」文档化进配置表 |

- 新增字段：**实际账期**、**资金占用时长费用**。  
- 入表过滤：算完 = 0 的费用行丢弃。

### 4.5 提货分摊（草案）

```
地址主数据沉淀（省市区+详细）
  → 区域映射表（东阳等纠偏）
  → 派车：多地址可勾「同车」
  → 计费：同车合并后按规则分摊到部门 / 业务员成本
  → 特殊：合并、减半（D-03 确认后配置化）
```

### 4.6 离职交接 & 提成

```
离职申请
  → 上级确认
  → 指定承接人（客户/在途单/提成归属）
  → 生效：历史业绩按规则切分；提成扣千分之二（若适用）
  → 报表：支持离职人员检索（修 2.11#14）
```

导出性能：分页游标 / 异步导出；目标验收：应收明细 ≥3000 行、营业额月报 ≥1 万行可完成（对照田苗案例）。

### 4.7 月度滞纳金（草案）

```
配置：结算账期、销售产品规则（含整柜清关到港日月结）、免收名单（客户/单号）
定时：
  - 每月 10 日 10:00：核算「上上月及以前」应收回未收妥（近 2 年）
  - 每月最后一天：月结类补算（与上项关系见 D-05）
计算：逾期金额 × 2‰；先扣减余额；排除多收与负数
输出：明细 → 特殊事项扣款 → 当月应发提成扣减
例外：新杂费可免；理赔走「按单号导入」；后期运费补录规则单独配置
```

### 4.8 收款锁账 & 现金认领体验

- **锁账时间**与**账期**统一锚定**到货时间**（徐珍霞）。  
- 现金流程：全局搜索条 + 认领纠错「改认领」不强制跳页签；错误认领一键重选客户/费用。

### 4.9 风控弹窗策略（草案）

| 场景 | 行为 |
| --- | --- |
| 同账号回款多客户且命中关联规则 | 弹窗锁定，可走解除流程 |
| 风险已解除 | 本笔/本规则不再弹 |
| 业务员垫付 | 白名单，不弹 |
| 现金流量 | 高风险行着色 |
| 退款未自动认领 | 排查原账户 vs 换账号；原路退回优先自动认领 |

### 4.10 报关抵扣（草案）

```
场景：客户直付报关行 → 我司应付登记负抵扣 → 应收侧给客户加余额
导入：
  - 同日 + 同一代理 → 汇总一条
  - 多客户混在一起 → 拦截，提示先拆分
  - 报关行名称与系统主数据 100% 匹配
改数：评估是否级联改已核销收款；不能改则走线下沟通单
```

### 4.11 个税测算（田苗）

```
按公司拉取个税申报表 + 专项附加扣除
主键：身份证号
累计：年初至今应纳税所得
公式：年度应缴（含 5000 及速算扣除）− 累计已缴 = 本月应缴
提成表：强制身份证字段，与个税表关联校验
```

### 4.12 损益流水补录

- 提供「流水手工录入 / 导入」权限页；标记来源=人工；进损益汇总（部门 × 产品组月导）时与系统流水并列，需审计字段。

### 4.13 提成试算与规则包（骨架）

1. **映射表**：人 ↔ 规则名预匹配；试算字段扩充分公司/部门/小组/昵称。  
2. **展示**：试算默认对业务员隐藏；财务/规则管理员可见。  
3. **扣减**：表外成本、特殊扣款仅挂**客户单号**；一人多票防重复扣。  
4. **组织**：换部门按日期切段；主管看小组汇总（含回款率、同行总方数）。  
5. **角色**：直客出退件提成，同行不出；大客户净利润 = 大客户规则结果 + 普通客户结果。  
6. **类型**：列表/详情/筛选项增加提成类型；私卡多选。
