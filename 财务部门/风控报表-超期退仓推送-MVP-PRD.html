二、跑批规则 KEY

每日跑批；命中进财务全量。分流：已签出只给财务看；未签出才推黄少飞退仓。

规则适用销售产品时间差公式阈值财务黄少飞 / 退仓
① 指定销售产品 美森 / EXX / T16 / 以星快船
  1. 已签出：签出 − 签入
  2. 未签出：当前 − 签入
 > 8 天 进清单 仅未签出可推；已签出不推、不退仓
② 其余销售产品 非上述指定销售产品 同左 > 16 天 进清单 仅未签出可推；已签出不推、不退仓

硬约束（10/12）：① 财务必须同时展示已签出与未签出；② 已签出不得推送黄少飞、不办理退仓；③ 只有未签出命中票进入退仓待办。

字段来源类型来源说明空值

签出时间业务回写仓库签出时间；未签出为空展示「—」；走未签出公式
销售产品主数据 / 运单命中美森/EXX/T16/以星快船用规则①，否则规则②按其余销售产品

五、推送链 · 业务员缓冲 · 自动退件退款 KEY · 10/13

主路径：推送少飞 → 少飞一键推业务员 → 缓冲至次日 08:30 → 未操作自动退件退款。

功能点说明原型
① 推送少飞
  1. 财务对未签出命中票推送少飞（单行 / 一键）
  2. 少飞待办列表可见预配舱号、扣件状态
 财务推送
② 少飞 → 业务员
  1. 少飞点击待办后，可一键推送给业务员
  2. 推送成功后记录推送时间，并计算缓冲截止时间
 少飞待办
③ 缓冲截止
  1. 业务员缓冲约一天；截止时刻固定为次日 08:30（中国时区）
  2. 例：少飞 10/13 15:20 推业务员 → 截止 10/14 08:30
 截止展示
④ 自动退件退款
  1. 截止前业务员有操作 → 走人工结果，不自动退
  2. 截止时仍无操作 → 系统自动退件退款；财务清单保留并标「自动退件退款」
 规则验收（日志）

六、验收测点（Given / When / Then）

#测点
P1Given 美森已签出超 8 天；When 跑批；Then 进财务清单，状态「仅财务看 · 不退仓」，无推送按钮；列表有预配舱号、扣件状态
P2Given EXX 未签出超 8 天；When 跑批；Then 进财务清单且可「推送少飞」
P3Given 财务点一键推送；When 成功；Then 只推未签出进少飞待办
P4Given 少飞点「一键推送给业务员」；When 成功；Then 业务员待办生成，截止=次日 08:30
P5Given 已推业务员且截止前无操作；When 到次日 08:30；Then 系统自动退件退款，清单标自动退
P6Given 业务员在截止前已处理；When 到次日 08:30；Then 不自动退件退款

过会口令：推送少飞→少飞推业务员；次日 08:30 自动退件退款；列表预配舱号/扣件状态；财务看全量；退仓只对未签出。
