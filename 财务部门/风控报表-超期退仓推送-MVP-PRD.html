二、跑批规则 KEY

每日跑批；命中进财务全量。分流：已签出只给财务看；未签出才推黄少飞退仓。

规则适用销售产品时间差公式阈值财务黄少飞 / 退仓
① 指定销售产品 美森 / EXX / T16 / 以星快船
  1. 已签出：签出 − 签入
  2. 未签出：当前 − 签入
 > 8 天 进清单 仅未签出可推；已签出不推、不退仓
② 其余销售产品 非上述指定销售产品 同左 > 16 天 进清单 仅未签出可推；已签出不推、不退仓

硬约束（10/12）：① 财务必须同时展示已签出与未签出；② 已签出不得推送黄少飞、不办理退仓；③ 只有未签出命中票进入退仓待办。

字段来源类型来源说明空值
签入时间业务回写仓库签入轨迹/节点首次发生时间（与现网签入一致）无签入不进跑批
签出时间业务回写仓库签出时间；未签出为空展示「—」；走未签出公式
销售产品主数据 / 运单命中美森/EXX/T16/以星快船用规则①，否则规则②按其余销售产品
超期天数计算按上表公式；命中才进清单—

五、终配提醒 / 待办交互 KEY

主路径 = 终配时弹出（黄少飞 10/12）。文案对齐询价代办；不另发明一套提醒。已配完舱一般不追代办。

功能点说明原型
终配舱登记提醒（主）
  1. 触发：终配舱录入数据（登记）或配舱完成，勾选舱内有「未签出 ∩ 签入超阈值」
  2. 文案固定（每票一行）：运单：{运单号} · 销售产品：{销售产品} · 签入时间大于{N}天，请及时办理退仓
  3. N：美森/EXX/T16/以星 = 8；其余销售产品 = 16
  4. 按钮：稍后处理 / 已知晓，继续登记
  5. 测：勾选「261012-美森EXX-1」点录入 → 弹出 EXX-771203 大于8天文案
 终配舱 · 录入
已配完舱
  1. 不另推代办（黄少飞：应该不会）
  2. 财务全量清单仍可保留该票作风控记录
 背景
去处理 / 办理退仓
  1. 去处理：定位到对应运单/行并高亮
  2. 办理退仓 → 提醒关闭；财务全量行保留、标已办；不从财务清单删除

六、验收测点（Given / When / Then）

#测点
P1Given 美森已签出超 8 天；When 跑批；Then 进财务清单，状态「仅财务看 · 不退仓」，无推送按钮
P2Given EXX 未签出超 8 天；When 跑批；Then 进财务清单且可「推送退仓」
P3Given 财务点一键推送；When 成功；Then 只推未签出；已签出不进黄少飞待办
P4Given 财务对已签出行点推送；When 操作；Then 拦截，不创建待办
P5Given 美森EXX 未签出且签入＞8天；When 终配舱登记（录入）；Then 提示「运单：… · 销售产品：… · 签入时间大于8天，请及时办理退仓」
P6Given 该票已终配完成；When 系统评估是否塞代办；Then 不另推代办
P7Given 黄少飞办理退仓；When 成功；Then 提醒关闭；财务清单该未签出行仍在且为已办

过会口令：扣件/运费涨价背景；终配时提醒；已配完舱不追代办；财务看全量；退仓只对未签出。
