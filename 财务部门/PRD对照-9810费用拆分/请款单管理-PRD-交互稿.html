功能说明

9810 默认规则 开发必看

打开「导出 9810 账单」弹窗时：客户无沉淀 → 按下表默认规则（种子）；有沉淀 → 带该客户最新一版沉淀（不用默认种子）。与原型 pin 9～12、§9810 默认规则 一致。

类别默认口径
弹窗项模版固定 9810；计费方式按方数；账单运费=勾选请款待收合计；「保存规则」默认勾选
只读收货方数、计费重；抬头数按勾选自动识别
默认三行（不可删）类型+税率默认：道路 9%、港杂 6%、报关 6%；不需要则基数改 0
手工追加默认税率代理服务费 6%；其他费用 6%
按方数种子国内道路货物运输费：中美&T25 20元/方、其他 100元/方；港杂 40元/方；代理报关费取本票运单实际报关费基数汇总（无固定种子）
算例 V=2方内陆 43.60；港杂 84.80；若实际报关基数 188 → 188×1.06=199.28
按计费重种子T25：内陆 0.215、港杂 0.43；其他：内陆 0.54、港杂 0.43（元/KG）；报关仍定额
含税公式数量×单价基数×(1+税率)；报关=基数×(1+税率)
页签默认「中美&T25」；「其他产品」各一套默认三行
带出优先级无沉淀→默认种子；有沉淀→该客户最新保存版（覆盖写，不保留历史多版）
手工追加代理服务费 6% / 其他费用类型（无自动单价；调拨仅代理 6%）
