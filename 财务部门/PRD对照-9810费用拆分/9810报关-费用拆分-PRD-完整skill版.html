一·附、按账期请款 · 圈票场景 NEW

请款单管理原型用小号序号 1～4 引用本节（与 9810 / 指定票件同包）。规则：每一次请款只圈「一个账期窗口」内、节点时间落入该窗且未请款的票件；圈票节点 = 客户账期节点（不另设请款模式）。锁账截止日公式见分析组《账期锁账时间规则》，本节只定圈票窗口。

序号节点 · 结算周期圈票口径示例窗口
1 到货 · 月结+15 节点时间 = 到货时间；只圈本窗内到货票 09-21 ~ 10-20
2 开船 · 月结 节点时间 = 轨迹 A00106 首次；无轨迹不静默圈入 09-01 ~ 09-30
3 签收 · 签收结+5 节点时间 = 签收时间；只圈本窗内签收票 09-26 ~ 10-10
4 签入 · 现结 节点时间 = 签入日；窗口 = 当日；签入当天一笔一圈 当日

原型：请款单管理 · 指定票件整合 MVP。已出请款单写入账期快照，改账期不回溯；未请款票按新账期再圈。

二、功能怎么走

环节大白话
1. 选模版
  1. 清关管理勾票 → 导出请款单（本期新增按钮）
  2. 账单模版选「9810」；非 9810 票不可用本模版（或导出时过滤/提示）
2. 带出配置
  1. 读配置表 + 运单销售产品（列表已展示）、收货方数、报关费基数
  2. 费用类型自动带出：国内道路货物运输费、港杂费、代理报关费（名称/税率按对照表），并带建议金额
  3. 财务可增删内陆第二行「国内货物运输代理服务费」；两行金额人工定；有调拨则该段只能用 6% 代理服务费
  4. 写入请款明细行，金额/计费重可改；费用类型默认不可乱改成对照表外类型（第二行仅允许追加代理服务费）
3. 单抬头 / 多抬头
  1. 仅 1 个抬头 → 请款单界面处理，并拉该客户账单账期
  2. 多个抬头 → 走请款单管理内的指定票件请款
4. 总运费
  1. 按拆分行税费回写/汇总进总运费
  2. 直客、同行均执行
