无沉淀 → 按默认规则（种子）；有沉淀 → 按该客户最新一版沉淀（每次保存覆盖旧版，打开弹窗只读最新，不回落默认种子）。

  2. 有沉淀 → 按客户名称读取最新保存版，带出计费方式、各页签费用行（类型/基数/税率/含税）等；不再套默认种子。
  3. 确认导出且勾选「保存为本客户默认拆分规则」→ 将本次确认结果覆盖写为最新版沉淀；未勾选则本次不写库。本期无独立规则管理页。

导出账单 · 开票税费 C01 开发必看

确认导出 9810（及按同一拆分口径出账）时执行。直客与同行完全同一套，不做客户类型分支。

1. 计算公式

对账单内每一项拆分费用行（含默认三行、代理 6%、其他费用等；国际段免税行税费=0）：

单行税费i = 含税总价i − 运费基数i
（等价：运费基数i × 税率i，以界面最终含税与基数为准）

C01 开票税费金额 = Σ 单行税费i

2. 写入哪里（按运单）

写入对象挂载粒度费用类型金额条数
运单 · 业务员成本每运单C01 开票税费该运单 Σ 拆分税费每运单 1 条
运单 · 应收 / 账单每运单C01 开票税费同上每运单 1 条
运单 · 总运费每运单—按已确认口径加计拆分税费部分与现网总运费字段回写一致
  • 一条请款含多运单时：每运单独立拆分、独立 C01、独立黄列行（导出文件按运单/明细行展开）。
  • 客户类型：直客 = 同行，均执行，无豁免。
  • 客户账单黄列仍按「金额=运费+税费」展示；C01 是成本/应收侧的汇总税费费用项，不替代黄列拆分。
  • 若某运单 Σ 税费 = 0，该运单可不写 C01（建议不写 0 元空记录）。
  • 第二次及以后导出（同一运单）：弹窗二次确认后覆盖该运单上次 9810 导出产生的 C01 与账单拆分回写（更新为本次金额，不追加第二条 C01）。导出日志保留最近一次成功记录。

入口 方案 A：「导出 9810 账单」。方案 B：「导出账单」→ 选形态=9810 的模版（见 §导出入口方案对比）。普通导出不写 C01。
运单维度 弹窗顶部或左侧展示本次勾选下的运单清单；拆分行、方数/计费重、C01 预览、回写均按运单计算（多产品按运单销售产品走对应配置/页签）。
确认前校验 各行 含税总价 与基数×税率一致性；国际段残差 ≥ 0；回写预览可读。
确认导出 事务顺序建议：① 写运单账单拆分结果与总运费 ② 写成本/应收 C01 ③ 生成客户账单文件 ④ 记导出日志。任一步失败则整单失败并提示，不产生半套回写。
覆盖回写 若运单存在「9810 已导出」标记：确认前展示将覆盖上次回写；用户确认后删除/更新原 C01 与账单侧拆分数据，写入本次结果。
客户规则 可选勾选保存客户沉淀；不改变「按运单回写」粒度。

二、功能怎么走

环节大白话
1. 选模版
  1. 清关管理勾票 → 导出请款单（本期新增按钮）
  2. 账单模版选「9810」；非 9810 票不可用本模版（或导出时过滤/提示）
2. 带出配置
  1. 按 §9810 默认规则 带出：计费方式、默认三行、单价种子或客户沉淀；读运单销售产品、收货方数、报关费基数
  2. 默认三行不可删：国内道路货物运输费、港杂费、代理报关费（税率 9%/6%/6%），建议含税金额=数量×基数×(1+税率)
  3. 财务可追加「国内货物运输代理服务费」6% 或「其他费用类型」；有调拨则内陆段只能用 6% 代理服务费
  4. 单价基数/含税总价可改、可置 0；切换按方数/按计费重时重算默认三行
3. 单抬头 / 多抬头
  1. 按勾选请款单/票件自动识别抬头数（9810 拆分弹窗不再提供「发票抬头」下拉）
  2. 仅 1 个抬头 → 请款单界面处理，并拉该客户账单账期
  3. 多个抬头 → 按现网分单请款（指定票件等）；本期交互原型仅演示欠费明细弹窗示意
4. 导出确认
  1. 展示按运单的回写预览（C01、总运费）；用户确认导出
  2. 每运单：C01 = Σ 该运单拆分行（含税 − 基数）；成本 + 应收各 1 条
  3. 同一运单再次 9810 导出 → 二次确认后覆盖上次回写
  4. 详见 §导出 9810 交互、§开票税费 C01

候选口径 · R-H 普通/9810 请款互斥 待确认 · 不得开发

背景：现网同一运单可出现在多张请款单。若一张为普通请款、另一张为9810 请款，则客户账单形态、C01 回写、重复收款风险冲突。下列为产品候选方案，须姚总/收款组确认后升版为已确认口径。

环节候选规则
原则运单对外账单拆分 + C01以运单为唯一真相（9810 导出按运单回写、可覆盖，见 #23）；请款单可多张，但同一运单在有效期内只能绑定一种请款模式（普通 或 9810）。
圈票 / 生成请款运单已在未作废请款单 A 中：若 A 为普通，禁止（或强提示后禁止）加入 9810 请款 B；若 A 为 9810，禁止加入普通请款 B。提示含原请款单号。
导出普通账单仅处理请款模式=普通的请款单。运单已有 9810 回写标记时：拦截对客户出普通账单，或仅允许内部附件（待选一项）。
导出 9810运单须来自 9810 请款（或请款单标记 9810）。仅挂在普通请款中的运单不允许 9810 导出。
历史双挂已同时关联普通+9810 请款：9810 导出前二次确认「将按 9810 覆盖运单回写」，并提示处理普通请款避免重复收款。
部分请款若业务需同一运单多请款单仅拆请款金额：9810 客户账单/C01 仍建议每运单只导出一次（账单运费=运单级）；是否本期支持「部分请款+9810」单列例外（默认不支持）。

需求清单：INV-1021-002。确认后写入已确认口径并开放圈票/导出校验开发。
