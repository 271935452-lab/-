超期退仓 · 精简说明（大白话）

对照用 · 详细版见 完整大白话 PRD · 推送原型 · 配置原型

本期做 / 不做

要做每天算超期、财务看全部单、没签出的自动通知接收人 → 接收人推业务员 → 推送后 2h 未点「去处理」自动退；能配规则；列表看预配舱、扣件、退仓进度
不做财务手工推接收人；已签出办退仓；改运单签入签出；业务员完整页面（靠日志验）

几条硬规矩

  • 定时任务每天 1 次（默认早上 6 点，配置页可改）。
  • 进列表要同时满足：超期天数 > 0；运单非已退件（不看扣件类型）。
  • 财务看已签出 + 未签出；只有没签出的系统自动通知接收人；已签出标「仅财务看·不退仓」。
  • 流程：算超期 → 自动通知接收人 → 接收人推业务员 → 2h 内点「去处理」并选处理方式，否则自动退。
  • 到点前业务员没处理 → 自动退件退款；处理了就不自动退。到点前已放行或已退款 → 也不自动退。
  • 配置改完保存，一般从第二天任务开始用新规则，老单子不倒算。
  • 财务没有「推接收人」按钮；接收人看不到已签出的待办。

怎么查

条件说明
运单、预配舱、产品、签入时间、提醒已读查询 / 重置
全部 / 未签出 / 已签出芯片上数字跟着查询结果变

列表多出来的列

列说明
预配舱没有就「—」
扣件状态正常件 / 普通扣件 / 特殊扣件（仅展示，不进池）
超期天数、命中规则系统按配置算；超期才进列表
提醒已读推接收人后：未读 / 已读 / —
退仓标记、操作待推送 → 业务员跟进中 → 业务已处理 或 系统自动退件退款（2h 未点「去处理」，问题件退件·退件退款）

功能要点

环节说明
配置 + 定时任务
  1. 配置页改超几天、几点跑、谁收待办。
  2. 保存后去推送列表点「刷新」验证命中规则。
财务列表
  1. 「刷新」按最新配置重算；新来的超期未签出会自动通知接收人。
  2. 侧栏演示可以模拟「又过了一天」。
业务员「去处理」
  1. 代办点「去处理」→ 运单页带运单号查询 → 弹窗必选：退件退款 或 刷新到货时间为今天。
  2. 退件退款 → 问题件跟踪·退件（处理方式=退件退款）；刷新到货 → 存原到货时间、到货时间=确认时刻 + 重新计费 + 运单日志（由…更新为…）。
接收人 + 自动退
  1. 推业务员 → 记推送时刻；展示自动退截止 = 推送 +2h。
  2. 2h 内未点「去处理」→ 自动退（问题件退件·退件退款）。
