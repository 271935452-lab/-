本期做啥 / 本期不做啥

本期要做本期不做
  1. 配置页：不同产品超几天算超期、每天几点自动算
  2. 财务列表看全部单（已签出 + 未签出）；只有没签出的系统自动通知接收人
  3. 接收人推业务员 → 第二天早上 8:30 前没人处理就自动退件退款
  4. 配置保存后，下一次定时任务用新规则
  5. 列表有预配舱、扣件状态、退仓标记、点「日志」；自动退只在运单上留 1 条记录；演示按钮在侧栏「原型演示」里
  1. 财务不能手工帮接收人推
  2. 已签出的不能办退仓、不能推接收人
  3. 不能在本需求里改运单签入、签出原始数据
  4. 接收人终配舱弹窗（辅助功能，另说）

为啥要做

项大白话
业务痛点扣件在仓放太久，海运费还涨；没签出的超期要能催到业务员、到点能自动退
公司要啥财务能盯全部风险单；没签出的能自动走完退件退款
怎么走每天算出超期 → 系统自动找接收人 → 接收人推业务员 → 财务看列表 → 第二天早上 8:30 没人管就自动退

谁干什么

谁能看啥能干啥不能干啥
财务所有进列表的单（含已签出）查询、看退仓标记、点日志不能手工推接收人；不能给已签出办退仓
接收人（如黄少飞）系统推来的、还没签出的待办一键推业务员、标已读已签出的不会推过来
业务员接收人转过来的（本期主要看日志验收）缓冲期内自己处理—
配规则的人配置页改阈值、时间、接收人并保存保存前别乱改已生效口径

名词（口语版）

词意思
签入时间货第一次进仓的时间；没有就不算超期
签出状态已经签出 / 还没签出；没签出就没有签出时间
超期天数比配置多放了几天；已签出用签出减签入，没签出用今天减签入，再减配置天数；必须大于 0
能进列表超期了 +（普通扣件或特殊扣件）+ 还没办过退件
扣件状态和运单列表一样：正常件 / 普通扣件 / 特殊扣件（正常件不进列表）
缓冲到几点推了业务员以后，固定到第二天早上 8:30（国内时间）

一、怎么查

条件在哪说明原型
新页面—没有老页面筛选项，全是新建的—
运单、预配舱、产品、签入时间、提醒已读上面查询区预配舱可模糊；查完可重置搜索
全部 / 未签出 / 已签出列表上方芯片只在已经进列表的单里再筛；括号条数跟着当前查询变，不会从别处拉新数据芯片
已签出 / 未签出数据哪来的进池规则定时任务或「刷新」按配置重算超期；已签出、未签出用同一套条件进列表（超期 + 普通扣件或特殊扣件 + 非已退件）。签出状态来自仓库轨迹。进池后：未签出自动通知接收人、可推业务员；已签出仅财务盯盘，不推、不自动退（退仓标记口径见第 9 点）

二、列表上每一列是啥

只有「超期了 + 普通扣件或特殊扣件 + 还没退件」的单才会出现在列表；签入签出时间跟运单一致。

列从哪来说明原型
勾选框—全选当前页；上面显示选了几条列表
运单运单只显示运单号，不显示柜号列表
销售产品主数据用来匹配配置里超几天列表
运单状态运单已签入、海外出库等；自动退完会变已退件列表
签出状态仓库已签出 / 未签出列表
预配舱业务数据没有就显示「—」列表
扣件状态运单列表正常件 / 普通扣件 / 特殊扣件（正常件不进列表）列表
签入、签出时间运单没签出则签出时间为「—」列表
超期天数系统算比配置多几天；不大于 0 不进列表列表
命中规则系统算显示匹配的配置名和天数；不能用来筛，只能看列列表
提醒已读系统推接收人后：未读 / 已读 / —列表
退仓标记系统未签出：待推送业务 → 业务员跟进中 → 次日早上 8:30 自动退（调问题件跟踪-退件-退件退款接口）或业务已处理；已签出：仅财务看·不退仓列表
操作按钮推业务员、标已读、业务已处理、看日志；自动退在运单上只留 1 条日志列表

三、功能怎么走

环节大白话原型
每天自动算 关键
  1. 每天跑一次（几点在配置页设），用已保存的配置
  2. 不同产品可以设不同超期天数；没配到的产品不算
  3. 要超期 + 普通扣件或特殊扣件 + 没退件才进列表
  4. 系统自带的 8 天、16 天只是示例，运营可以改
 配置
改配置
  1. 保存后一般从第二天那次任务开始用新规则，老列表不倒算
  2. 能改：超几天、几点跑、谁收待办
  3. 验证规则是否生效：去推送列表点「刷新」看命中规则列
 规则配置
自动通知接收人
  1. 算完后：进列表、还没签出、还没办完的单，系统自动通知配置的接收人；已签出的不通知
  2. 弹窗大意：签入太久超了，请关注并告诉业务员；财务这边没有「推接收人」按钮
  3. 已签出的在列表上标「仅财务看·不退仓」
 列表
点「刷新」
  1. 用最新配置重新算谁超期、规则列显示啥
  2. 不该在列表的会去掉；新超期且没签出的会自动通知接收人
 刷新
接收人推业务员
  1. 列表里「一键推业务员」
  2. 记下推送时间，截止第二天早上 8:30（演示里会弹窗给业务员看）
 列表
次日 8:30 自动退 关键
  1. 截止前业务员已经处理了 → 不自动退
  2. 到 8:30 前单子已经放行或已经退款了 → 也不自动退、不写那条自动退日志
  3. 否则：到次日早上 8:30还没人管 → 调用问题件跟踪-退件-退件退款接口退件退款，改退仓标记，运单上留 1 条自动退记录
 日志

#测什么
