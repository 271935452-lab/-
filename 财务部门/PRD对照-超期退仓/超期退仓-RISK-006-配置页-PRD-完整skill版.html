一、页面上分几块

配置页没有「查询区」，按面板从上到下三块；橙色编号见第三节。

区块位置干什么原型
标题栏 页顶 页面名；右侧 保存、逐点/功能说明（评审用） 保存
定时任务 第一块面板 启用开关；执行时间（每天 1 次） 定时任务
阈值规则 第二块面板 表格多行规则（含序号列）；可展开「列说明」；底部「+ 新增一行」 规则表
推送 第三块面板 推送范围固定文案；接收人下拉 推送
选择产品 弹窗 从主数据选销售产品，回写到当前规则行 规则行「选择产品」

二、阈值规则表 · 列说明

与原型「阈值规则」面板内绿色列说明区块、表头「序号 ?」一致。

列必填口径原型
序号—只读；自上而下 1、2、3… 表示匹配顺序；增删行后重排，不单独落库规则表
名称否可空；保存自动补「阈值规则 N」；推送列表「命中规则」展示用规则表
适用销售产品否可不选；各行产品互斥；未进任何行的产品不参与超期计算选择产品
阈值（天）否正整数；空或非法保存时回落默认正数（初装 8 / 16 仅为示例）规则表
操作—删行；至少保留一行规则表

三、每个配置项是啥

项来源口径读写原型
启用录入关则定时任务不跑（或按现网停用策略）可改定时任务
定时任务时间录入24 小时制；每天 1 次；国内时间可改定时任务
序号计算见上表「列说明」只读规则表
规则名称录入非必填；空保存时自动补「阈值规则 N」；列表「命中规则」列展示用可改规则表
适用销售产品主数据非必填；各行互斥；未进任何行的产品不参与超期计算可改选择产品弹窗
阈值（天）录入非必填；正整数；非法回落默认可改规则表
推送范围固定文案仅未签出（办理退仓）；已签出不走接收人待办只读推送面板
接收人录入/字典未签出且新进待办时，系统自动通知此人（弹窗 + 未读角标）可改推送面板

超期怎么算、怎么进列表：与推送 PRD 一致——超期天数 > 0 +（普通扣件或特殊扣件）+ 非已退件；已签出/未签出用同一套阈值匹配，进池后行为不同（已签出仅财务看）。

四、功能怎么走

功能大白话原型
保存配置 ①
  1. 点右上角保存
  2. 名称/产品/天数均不拦空；规则名空则自动起名；天数非法则回落默认正数
  3. 同一产品出现在多行时，保存时去重（以最后一次整理结果为准）
  4. 成功提示；配置带版本/生效时间，下一次定时任务起用新规则
  5. 已在推送列表里的历史行不按新规则倒算；要更新展示去列表点「刷新」
 保存
维护规则行 ②
  1. 每行：序号 + 名称 + 选产品 + 天数；序号即匹配顺序，至少保留一行
  2. 匹配顺序：自上而下，运单销售产品命中第一行即用该行阈值
  3. 命中后推送列表「命中规则」列显示类似「规则名·阈值 N 天」
  4. 可删行（保留最少一行策略以实现为准）
 阈值规则表
新增一行 ③
  1. 点「+ 新增一行」增加一档产品组合
  2. 新行默认名称与示例天数；产品可不选
  3. 与保存一起落库
 新增一行
选择产品弹窗
  1. 按名称/产品组/派送方式查询左侧候选（三项均非必填，空则查全部候选）
  2. 勾选或双击加入右侧已选；可批量删已选
  3. 确定回写当前规则行；取消不改
  4. 已被其他行占用的产品不可再选（互斥）
 弹窗
定时任务消费配置
  1. 到点读已保存配置，按规则算各运单是否超期
  2. 满足进池条件的写入/更新推送列表
  3. 未签出且需办退仓的，按接收人配置发待办（非财务手工推）

验收怎么测（配置页）

#测什么
C1改定时时间为 07:00 并保存 → 次日任务按 07:00 调度（或验收环境可手动触发验证读到的 time）
C2两行规则产品互斥 → 保存成功；同一产品不能出现在两行
C3某产品不在任何规则行 → 对应运单不因本需求进超期列表
C4改阈值保存后 → 推送列表点「刷新」，命中规则列与超期天数按新阈值重算
C5改接收人保存 → 新进未签出待办发给新接收人（已签出不发）
C6关闭启用并保存 → 定时任务不再产生新进池（口径与现网停用一致）
