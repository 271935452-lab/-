二、销售产品 · 邮编规则

字段说明原型
销售产品
  1. 默认七条（简称）：萨凡纳 / 休斯顿 / 芝加哥 / 奥克兰 / 西雅图 / 洛杉矶 / 纽约，对应「××私人卡派」销售产品
  2. 可新增、改名、禁用、删除；名称不可重复
① 产品表
判定模式
  1. 三种写死：邮编前缀 / 全部本地 / 全部外州
  2. 前缀：目的邮编命中任一本地前缀→本地，否则外州
  3. 测：萨凡纳 31408→本地、30301→外州；奥克兰任意→本地；西雅图任意→外州
判定模式
本地邮编前缀
  1. 仅前缀模式必填；多值用 / 或空格（默认：31、77、60、90/91/92、07/08）
  2. 全本地/全外州时前缀置灰不填
前缀列
SLA 口径组
  1. 挂在销售产品上：洛杉矶 / 外港。默认仅「洛杉矶」挂洛杉矶组，其余外港
SLA 口径组

三、SLA 要求

口径组本地 / 外州默认原型
洛杉矶
  1. 本地：提柜→签收 ≤ 3
  2. 外州：提柜→出库 ≤ 3 且 出库→签收 ≤ 7
② SLA
外港
  1. 本地：拆柜+1→出库 ≤ 3 且 拆柜+1→签收 ≤ 3
  2. 外州：拆柜+1→出库 ≤ 3 且 拆柜+1→签收 ≤ 7
  3. 拆柜+1 = 节点 − 拆柜 + 1
② SLA
可改项
  1. 每段：指标（下拉写死五种节点）+ 天数（整数 ≥0）
  2. 可增删段；每区至少 1 段。任一段超限 → 时效表超时
② SLA

四、功能逻辑

功能点说明原型
草稿 / 发布
  1. 改表即脏草稿；保存草稿不切换已发布副本
  2. 发布后 ver+1，时效表读已发布版
  3. 恢复默认 = 填回七产品 + 默认天数，仍须再发布
  4. 测：改萨凡纳前缀为 32 后试算 31408→外州；未发布前时效表仍按旧（示意）

  3. 测：样例「洛杉矶 · 94501」→ 外州 · 提柜→出库 ≤3 · 出库→签收 ≤7
