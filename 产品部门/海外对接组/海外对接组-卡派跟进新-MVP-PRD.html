四、出库登记 · PRO / 17TRACK（私卡·袁华君 2026-09-02）

← 挂旁支计划二 #8 17TRACK 卡车轨迹 · 验收分册 #s-f8

PRO 是卡车公司给的出库单追踪号（可在 17TRACK 等网站查询），不是卡派 POD。港后在出库时登记，便于后续自动追轨迹。

功能点说明原型
登记入口
  1. 卡派跟进工具栏出库登记（出发登记）
  2. PRO：手输 或 上传出库单附件识别（OCR/版面识别，识别结果可改）
  3. 二选一须有值；无 PRO 不可确认出库（拼车例外见 §四-B）
出库登记
机器人抓取
  1. PRO 落库后，机器人（或定时任务）到 17TRACK（17track.com）按该号查询
  2. 查得节点写入本票轨迹维护，并刷新列表「最新轨迹」
  3. 抓取失败：保留 PRO，轨迹保持「待 17TRACK 抓取」类摘要，支持人工重试 / 轨迹维护补录
轨迹维护
与 POD 区分
  1. POD = 签收回传文件 / POD 轨迹（TC00105 / TC00102）
  2. PRO = 出库单卡车追踪号 → 17TRACK
  3. 两套字段、两套入口，勿混
PRO追踪号

四-A、出库通知（全类型通用）

FBA / 私卡 / 快递派等，出库登记弹窗在 PRO 下方固定展示「出库通知」区。确认出库后按勾选向业务员、客服推送站内消息。

功能点说明原型
上传附件
  1. 可选上传出库相关附件（出库单照片等）；上传后生成链接写入通知正文
  2. 私卡场景：本附件视为出库单，必传
  3. 与「上传识别」互补：识别区可只为 PRO OCR；通知区附件用于推送留痕
 出库通知 · 附件
通知内容
  1. 打开弹窗时按票信息 / PRO / 附件自动生成正文，可手动编辑
  2. 「按附件重生成」可覆盖回模板
  3. 确认出库时正文不可为空
 通知内容
通知人
  1. 默认勾选：业务员 + 客服
  2. 可取消其一，但至少保留一方；全不勾则拦住确认
  3. 确认出库成功后推送站内消息（演示弹摘要）
 通知人

四-B、私卡出库 · 装车凭证（仅私卡派）

勾选运单均为私卡派时，在通用「出库通知」之外，额外要求装车前/完毕照；拼车可免 PRO 但须填预计送达。出库附件与通知正文/通知人仍走 §四-A。

功能点说明原型
触发条件
  1. 已选票全部为「私卡派」→ 展开「私卡 · 装车凭证」区
  2. 私卡与非私卡混选 → 拦住，提示分开勾选
  3. 非私卡 → 仅通用通知区 + PRO/17TRACK，无装车照区
 出库登记
必传附件
  1. 通用区出库单照片/附件 1 份（必传）
  2. 出库货物图片 2 张：装车前整体 1 张、装车完毕 1 张
  3. 上传后系统生成可点击链接，写入通知正文
 装车凭证
PRO / 追踪网址 / 拼车
  1. 默认：PRO 必填（沿用上方录入）；追踪网址默认按 PRO 拼 17TRACK，可手改
  2. 勾选「拼车」：可免 PRO，但预计送达时间必填
 出库登记
推送
  1. 通知内容默认带私卡服务标准文案 + 装车照链接
  2. 通知人仍用通用区「业务员 / 客服」勾选
  3. 测：私卡缺出库附件或装车照不可确认；确认后提示已推送

五、预警桶 · 轨迹编码（一字不差）

预警桶进入条件离开条件
未约仓预警
  1. 已有提柜轨迹 A00195
  2. 自该提柜起满 15 天仍没有约仓闭环轨迹：TC001011、TC00101（二者皆无）
  3. 进入对应「未约仓」预警桶
 出现 TC001011 或 TC00101 后立即出桶消失
未传 POD 预警
  1. 已有签收轨迹：TC0010301（FBA 签收）或 TC0010401（私卡签收）
  2. 自该签收起满 2 天仍没有 POD 闭环：
    • 私卡缺 TC00105
    • FBA 缺 TC00102
  3. 进入对应「未传 POD」预警桶
 出现对应 POD 轨迹（私卡 TC00105 / FBA TC00102）后立即出桶消失

编码清单（开发对照，勿改字）： A00195、TC001011、TC00101、 TC0010301、TC0010401、TC00105、TC00102。
