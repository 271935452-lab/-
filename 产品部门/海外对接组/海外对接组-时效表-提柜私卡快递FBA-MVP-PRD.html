二、列表字段

按销售产品 · 派送方式页签切换列组：FBA派入仓 / 卡派 / 快递派 / 提柜（跨派送）/ 周汇总。

维度核心列 / 口径原型
卡派
  1. 分流：派送方式 = 卡派（私卡）
  2. 列含：私卡渠道、邮编、本地/外州、提柜→出库、拆柜+1→出库、出库→签收、提柜→签收、拆柜+1→签收、SLA 要求
  3. NEW 本地/外州按渠道邮编规则；超时按洛杉矶 / 外港分口径（见功能逻辑）
  4. 测：切卡派时效，有本地/外州列；PK-20260722-019（洛杉矶外州）SLA 文案含「提柜→出库 ≤3」
卡派时效
快递派
  1. 分流：派送方式 = 快递派
  2. 快递时效 = 最早扫描时间 −（开船日 + 1）；实际签收时效 = 最早扫描时间 − 拆柜时间
  3. 最早扫描时间（产品确认）：取轨迹编码 TB00114、TB00110 中第一次维护时间的较早者（两码有一即可；都有取更早；都无则空、不算时效）
快递派时效
FBA派 / 入仓
  1. 分流：派送方式 = FBA派
  2. 提柜→签收；对照「亚马逊入仓时效要求」表（默认 7 天）标超时
FBA派入仓
提柜（付雪）
  1. 跨派送方式；提柜时效 = 实际提柜 − 开船 + 1，按周看出柜快慢
  2. 柜下列展示该柜下票的派送方式标签
  3. 到仓 / 等拆 / 拆柜耗时不在本页 → 提柜拆柜时效
提柜时效

三、功能逻辑说明

功能点说明原型
私卡本地/外州判定
  1. NEW。按私卡渠道 + 目的邮编前缀：萨凡纳本地=31；休斯顿=77；芝加哥=60；洛杉矶=90/91/92；纽约=07/08；奥克兰=全部本地；西雅图=全部外州
  2. 同渠道非本地前缀即外州
  3. 测：萨凡纳 31408→本地、30301→外州；奥克兰任意邮编→本地；西雅图任意→外州
卡派时效
私卡 SLA（洛杉矶 vs 外港）
  1. NEW。洛杉矶本地：提柜→签收 ≤3；外州：提柜→出库 ≤3 且 出库→签收 ≤7
  2. 外港（非洛杉矶）本地：拆柜第二天→出库 ≤3 且 拆柜第二天→签收 ≤3；外州：拆柜第二天→出库 ≤3 且 拆柜第二天→签收 ≤7
  3. 拆柜第二天口径 = 节点时间 − 拆柜 + 1。任一段超限即超时黄底
  4. 测：洛杉矶本地票提柜→签收=3 不超时；外港外州拆柜+1→签收=8 超时
卡派时效
最早扫描时间
  1. 产品确认（2026-09-01）：快递派时效终点节点
  2. 口径 = 轨迹 TB00114、TB00110 第一次维护时间中的较早者（编码一字不差，与尾程快递件同源）
  3. 仅有其一则用该时间；两者皆无则最早扫描为空，快递时效 / 实际签收时效不出数
  4. 用于：快递时效 = 最早扫描 −（开船日+1）；实际签收时效 = 最早扫描 − 拆柜
快递派时效
分流字段

  2. 与部门进仓数据派送方式枚举对齐：卡派 / 快递派 / FBA派 / 自提（本页主统计前三者）
