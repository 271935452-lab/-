五、通用拆柜模板 · 私卡备注（港后导出给海外仓）

业务诉求（私卡·袁华君 2026-09-02）：报价员确认尾端价格时可写备注（带不带尾板、服务标准等）；港后客服做柜子资料导出时，海外仓也要能看到价格口径与服务标准。现网备注已有，但未在海外侧 / 导出资料中展示——本期在主单跟进「通用拆柜模板」补字段打通。

功能点说明原型
字段：私卡备注
  1. NEW。通用拆柜模板新增列/字段「私卡备注」
  2. 取值：报价员确认尾端价格时填写的核对备注 / 报价备注（如需尾板、不带尾板、住宅/商业、预约要求、服务标准等）
  3. 只读：港后 / 海外仓侧不改写；与港后「修改备注」分字段、不互写
  4. 无私卡派票的柜：列显示「—」；有私卡派但无备注：显示「无报价备注」
  5. 测：含私卡派柜导出通用拆柜模板，预览列有备注文案；非私卡柜为「—」
导出资料 · 通用拆柜模板
数据来源与同步
  1. 同源：报价组核对确认时渠道备注（与尾程预估「报价备注」同源字段）
  2. 私卡绑运单 / 尾端派送费挂运单后，备注随柜汇总到主单跟进导出可用
  3. 对照：散货 AI 询价报价 PRD 核对备注；尾程预估运单维 报价备注
尾程预估
导出给海外仓
  1. 港后客服在主单跟进勾柜 → 导出资料 → 选通用拆柜模板 → 文件含私卡备注列
  2. 目的：海外仓做柜子资料时能看到尾端服务要求（尾板等），避免只见价不见标准
  3. 测：导出 toast / 文件预览含私卡备注；切回仓预报模板可不带该列
