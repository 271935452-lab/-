并行带说明

P1 下单并行带（T2）

订舱配舱 ∥ 推送资料（报关行）

有资料即可推，不必等排柜。两轨无汇合硬门；都服务后续出单/舱单，但不互相阻塞启动。

P2 到仓并行带（T3）

风控查货 ∥ 推送资料给报关行

到仓后两轨同时开。旁路是推送资料给报关行（不是出单核准）；有问题可拦截给报关行的资料。侵权后即扣件，授权一致或罚款后放行才终配舱；交到关务即为可执行。

P3 核准后并行（舱单&报关）

发舱单 AMS/ISF ∥ 报关申报

纠正参考图「发舱单→报关」串行误读：两轨同一门槛（资料核准），无先后。砍「核准后再甩船务发舱单」一周等待。

回退 / 支线（挂在节点上，不破坏并行）

R1 报价过期 / 驳回

②绑价 ──▸ ①询价

串行段内回退；与并行带无关。

R2 查货拦控

P2·查货 ──▸ ②/业务（H2）

只打查货轨；出单轨可继续，除非业务决策停单。

R3 核准退回

P2·核准 ⟲ 出单重做

退回改资料/预录；未通过则不能进 P3。

R4 改配：船务发起并安排

船务发起 ──▸ 船务安排配舱/船期 ∥ 关务配合更新资料

三类：甩柜换船 / 查验换船 / 查验换柜。改配由船务发起并安排；关务配合更新资料（舱单/AMS/ISF）。场景③可能重建核准。

R5 查验 → 改配切片

⑥查验 ──▸ 交船务发起 → 船务安排 · 关务配合更新资料

与改配三类联动；分工同上。

R6 未放行盯控

⑥ ⟲ 自环（不进⑦）

未放行：通知船务盯控，并须通知客户。进港：先判飞驼能否抓；未进港预警。

B1 取消 IT → 关务清关（仅火车）

火车提单 · 取消IT ──▸ 关务目的港清关（H3）

旁路支线；仅火车，非火车无此交接。清关是关务分支，不是海外。

B2 尾单 → 工单

海外尾程 ──▸ 工单（H6）→ 回写

不重走头程主链。

画并行的口诀：能同时开工的放进同一列双轨，列头写时间窗（T2/T3）而不是假序号； 只有「下一节点必须等某轨完成」才画汇合条（P2→P3）。P1/P3 不画硬汇合。 主干不画回退线——R1–R6 / B1–B2 只挂卡片；细图（各组痛点）才画红虚线回退。
