一、范围

入口：财务结算 → 费用管理 → 主单实际费用。编辑对象是费用行上的修改后金额（海外口径）；归集到运单后与尾程预估对照。

点说明原型
修改实际费用
  1. 行内「修改」或勾选后「修改实际费用」开抽屉
  2. 编辑修改后金额；默认可带出预估；须填修改原因
  3. 未确认实际金额只读展示，修改保存时不改
 修改抽屉

二、列表字段（本期）

字段说明原型
未确认实际金额
  1. 账单 / 导入落库的原始实际金额，待财务确认
  2. 新建或首次导入时，与修改后金额默认相同
  3. 用户修改修改后金额后，本列不变
 列表
修改后金额
  1. 原列表「金额」列；经人工修改后的实际金额口径
  2. 默认 = 未确认实际金额；修改后与未确认列可不一致
  3. 折合 RMB、分摊、对冲均按本列计算
 列表

三、修改逻辑

按费用行是否已分摊分流，不得混用。

状态说明原型
未分摊
  1. 含：待确认、待分摊、待重新分摊等尚未完成分摊的费用行
  2. 直接修改修改后金额 / 币别 / 汇率，写修改原因与备注；未确认实际金额不变
  3. 不生成对冲分录；保存后仍可点「分摊」按修改后金额分摊到运单/票
  4. 测：待分摊行改金额保存后，修改后金额更新、未确认列不变，无对冲痕迹
 未分摊行 · 修改
已分摊
  1. 分摊状态 = 已分摊（已分摊到运单/票）
  2. 修改不直接覆盖已落库的分摊结果，走现网对冲逻辑（按现网财务对冲规则记差额 / 对冲分录，轧平后再落到新修改后金额口径）
  3. 对冲完成后：本费用行进入待重新分摊或等价状态；再次「分摊」只重摊本费用项修改后金额，不整柜重摊其它费用项
  4. 测：已分摊行点修改保存后，走对冲而非静默改数；列表可见待重摊或对冲留痕（以实现为准）
 已分摊行 · 修改

对冲细则（科目、凭证形态、可否部分对冲）对齐现网财务实现，本 PRD 只定分流：未分摊=直接改修改后金额，已分摊=对冲。

四、分摊（沿用）

点说明原型
按费用项分摊
  1. 只对勾选费用行，用修改后金额（含已调整）分摊到运单/票
  2. 同柜未勾选费用项保持原分摊，不整柜重算
