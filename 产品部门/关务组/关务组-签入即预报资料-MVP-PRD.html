背景与痛点 · 我们解决什么问题

业务背景

关务在运单签入后立刻做资料（推送报关行、跟预录、确认、改单撤销重发）。这是运单维作业，不并进报关执行列表先做三套功能；先把资料发出去，预录进度在本页跟。本页报关状态页签/列名与报关执行一致。

核心痛点

  • 报关件混进买单：专门的预录页必须只看报关件，非报关件不应出现、也不该生成催促代办。
  • 着急看的三件事散落：是否已出预录、哪家报关行、预录是否已确认，必须在列表上一眼看到。
  • 确认口径不清：确认是关务手动勾选，允许改回；上传放行单后必须锁定。
  • 改单路径断：件毛体/品名变更后要先撤当前预录，再重发，新预录回来再确认。
  • 合并报关漏改：多运单共用一份报关时，推送/确认/改单/放行必须同组一起改。

本期要解决什么

  • 独立作业台：签入成功 → 仅报关件进本页。
  • 列表三件套 + 报关标记（报关 / 合并报关 / 拆分报关）+ 客户委托标记 + 报关编号 运单号-序号(件数)。
  • 合并组同改状态；拆分一票多编号。
  • 与运单管理（待配舱/终配舱）、报关执行列表同源展示报关行、预录确认、已放行；状态名与报关执行对齐。

一、规则口径（8/15–8/20 沟通）

1. 只看报关件 张珊珊 8/15

专门的预录单页面不进买单/非报关件。签入后若非报关件，跳过本页，不生成预报/预录待办。后续改成报关件再重新判定。

是否报关件报关资料系统动作本页
是已上传进入「待推送」；推送后跟预录/确认显示
是未上传拦截推送；催促代办显示（待上传资料）
否—跳过预报/预录路径不进本页

2. 列表三件套

每票必须能直接看到：是否已出预录单、哪家报关行、预录是否已确认。运单管理同步展示标识。

3. 确认 = 手动勾选

关务核对后勾选「预录已确认」；允许取消/改回。客户改口或核对有误时可反复改，直到放行单上传。留操作人、时间。

4. 放行后锁定

上传放行单后不可再取消/修改确认。改单撤销、重发同样不可用，走线下异常单。

5. 改单 → 撤销 → 重发 卢慧恒 8/20

  1. 改单：件毛体、品名/HS、收发通、抬头等变更（含退税改买单）。
  2. 撤销单：撤销当前有效预录；同时取消「预录已确认」；记原因。
  3. 重发：按最新资料再推报关行，状态回到「报关行处理中」。
  4. 新预录回传后，关务重新核对并勾选确认。
  5. 已上传放行单：本路径关闭，走线下异常 / 改配，不在本页硬撤。

6. 待配舱 ≠ 终配舱

运单管理原「待终配舱」拆成两个状态。本页同步展示配舱阶段：待配舱也可提前推送；终配舱后继续跟预录/放行。本页配舱阶段只读，主数据在运单管理。

7. 签入后推送

报关件 + 资料已上传 → 待推送；报关件缺资料 → 拦截并催促（业务/客服代办）。资料齐后自动转待推送。推送与放行后抓取主键为报关编号（合并报关多运单共用一个编号，工作可在分单号未出前置）。客户单号可随附件带出作辅键。分单号在绑定提单之后按规则生成，只给舱单；调整后重算，不因此重推报关行。无客户委托不可推送报关行（须委托标记=已委托）。

8. 与报关执行列表

本页是关务「做资料/预录」作业台（运单维、只报关件，未排柜可用）。报关执行列表不再展示预录阶段页签，也不再挂本页入口。排柜后正式件/放行在报关管理列表，预录单状态与预录已确认打在运单明细。两边报关状态说法一致：待推送 / 报关行处理中 / 预录待复审 / 待放行 / 已放行。

9. 报关标记 NEW

三档：报关（单票）· 合并报关（多运单一组、同一报关编号）· 拆分报关（一票拆成多份报关编号）。勾选后可改标记。已放行的运单不可改标记。

10. 合并报关 · 同改状态 NEW

同组合并报关的运单，推送 / 出预录 / 确认 / 改单撤销 / 重发 / 放行一起改，避免漏改导致漏报、重复报。

11. 报关编号 NEW

格式 运单号-序号(件数)，例 WY260820001-1(8)。合并组用主运单号 + 组内件数合计；拆分同一运单出 -1(3) -2(2)。

12. 客户委托标记 NEW

对接报关行：不按分票号查询委托。报关行自行匹配电子委托书，与报关单、放行单打包回传。未对接报关行时本页人工「委托标记」：无标记 / 未委托 / 已委托（无「催办」「已标记·催客户」）。列表「委托标记」列始终展示状态标。合并组同步。仅已委托可推送/重发报关行。

13. 报关行默认分配 NEW

报关件签入进入本页时，按《报关件预录单-销售产品与报关行规则》的收货仓 → 报关行自动指定报关行。规则表「整柜」组已填写映射；散货各组单元格为空，本期凡进本页的报关件一律按收货仓套用同一映射（产品组差异待业务补全后再覆盖）。收货仓无法匹配时报关行为空，须「修改报关行」手工指定后才能推送。可手工改；已推送后改行则退回待推送再推。合并组同步。待放行及之后不可改（含已放行）。改单已撤销仍可改，再重发。

规则表产品清单（T16/T20/T25、美森、纽约、整柜、中美等）= 可进本页的销售产品范围。推送前仍须委托标记=已委托。

14. 报关客服按报关编号随机分配 NEW

本票报关客服（关务侧作业人）按报关编号在客服池中随机均分（同一编号永远分给同一人，刷新不重抽）。合并报关共用一个报关编号 → 组内同一报关客服。拆分报关同一运单多段编号时，按第一段编号分配（一行一个报关客服）。客服列仍是运单客服，不参与本分配。

改标记

  • 标记合并报关：勾选 ≥2 票；指定合并组号、主运单（编号前缀）。组内共用一个报关编号。

五、边界与联动

  • 本页：签入后做资料、推送报关行、预录进度、确认、改单撤销重发（运单维 · 仅报关件）。含报关标记与报关编号。
  • 运单管理：待配舱/终配舱拆分；展示报关行、预录已确认标识（放行后锁定）。
  • 报关管理列表：排柜后正式件、放行抓取、查验；不再展示预录阶段页签。不替代本页预录确认勾选。状态名与本页对齐。
  • 预录单审核详情：本页操作列/工具栏「预录审核」进入同一页（字段对比 + 沟通侧栏）。推送后即可进；已出预录默认落字段对比，处理中/改单已撤销默认落沟通侧栏。
  • 签入代办：仅报关件且资料未传时，给业务/客服催促上传。资料齐后转本页待推送。「待上传资料」页签支持一键催促。
  • 供应商上传 / 协作链接：未对接报关行可走链接协作上传报关资料（#04 资料通道）；预录单回传若仍无 API，在本页上传预录单补录。
  • 报关行、预录确认、已放行与运单管理列表、报关执行列表同源展示。

六、开发要点

  1. 本页查询默认 是否报关件=是，买单不入库。
  2. 预录确认是运单上手动布尔字段，可反复改；放行单已上传 后字段只读。
  3. 改单事件：撤销当前预录（清确认、记撤销原因）→ 重发报关行 → 等新预录回传后再确认。
  4. 配舱阶段取运单管理：待配舱 / 终配舱，禁止再写「待终配舱」。
  5. 本页提供修改报关行（勾选/行内）与推送报关行（须已指定报关行、资料已齐、委托标记=已委托、状态=待推送）。进入本页时按收货仓默认报关行（青岛→鸿程捷运、厦门→通航顺、天津→聚航、宁波/上海/义乌→欣扬、盐田/深圳→盛世通）；未匹配须手工指定。已推送后改报关行则退回待推送再推。待放行及之后不可改报关行。改单已撤销仍可改再重发。合并组同步。
  6. 报关行、预录确认、放行锁定与运单管理列表、报关执行列表同源展示。
  7. 报关标记 = 报关 / 合并报关 / 拆分报关；合并组共用报关编号，状态动作按组写入。
  8. 推送 / 回调 / 放行抓取主键 = 报关编号；合并组一次推送。客户单号为辅键。
  9. 委托标记 = 无标记 / 未委托 / 已委托；列表列始终显示。合并组同步。无委托（含无标记、未委托）不可推送/重发。对接行不按分票号查委托，由报关行匹配后随报关单/放行单回传。
  10. 报关客服按报关编号在客服池哈希均分（同一编号同一人）；合并组共用编号故同一报关客服。列表另展示所属业务员、运单客服、客户单号。
  11. 操作列「结构化」「沟通」合并为单一按钮预录审核，进预录单审核详情。
  12. 报关编号 运单号-序号(件数)；列表默认按报关编号排序。
  13. 「待上传资料」工具栏一键催促：勾选则催所选，未勾选则催当前筛选结果中缺资料票。
  14. 上传预录单（NEW）：报关行在API 配置中未启用 / 未对接 #04时，推送进入「报关行处理中」后，关务收到报关行线下回传的预录 PDF/Excel，在本页工具栏或操作列上传。写入预录附件，preIssued=true，进入「预录待复审」，后续确认/改单/放行与 API 回传一致。已对接行禁止手工上传（拦截并提示等系统回传）。合并组同步。支持批量勾选上传（同一附件写组内全部运单）。
