背景与痛点 · 我们解决什么问题

业务背景

关务在运单签入后立刻做资料（推送报关行、跟预录、确认、改单撤销重发）。这是运单维作业，不并进报关执行列表先做三套功能；先把资料发出去，预录进度在本页跟。本页报关状态页签/列名与报关执行一致。

核心痛点

  • 报关件混进买单：专门的预录页必须只看报关件，非报关件不应出现、也不该生成催传代办。
  • 着急看的三件事散落：是否已出预录、哪家报关行、预录是否已确认，必须在列表上一眼看到。
  • 确认口径不清：确认是关务手动勾选，允许改回；上传放行单后必须锁定。
  • 改单路径断：件毛体/品名变更后要先撤当前预录，再重发，新预录回来再确认。
  • 合并报关漏改：多运单共用一份报关时，推送/确认/改单/放行必须同组一起改。

本期要解决什么

  • 独立作业台：签入成功 → 仅报关件进本页。
  • 列表三件套 + 报关标记（报关 / 合并报关 / 拆分报关）+ 报关编号 运单号-序号(件数)。
  • 合并组同改状态；拆分一票多编号。
  • 与运单管理（待配舱/终配舱）、报关执行列表同源展示报关行、预录确认、已放行；状态名与报关执行对齐。

一、规则口径（8/15–8/20 沟通）

1. 只看报关件 张珊珊 8/15

专门的预录单页面不进买单/非报关件。签入后若非报关件，跳过本页，不生成预报/预录待办。后续改成报关件再重新判定。

是否报关件报关资料系统动作本页
是已上传进入「待推送」；推送后跟预录/确认显示
是未上传拦截推送；催传代办显示（待做资料）
否—跳过预报/预录路径不进本页

2. 列表三件套

每票必须能直接看到：是否已出预录单、哪家报关行、预录是否已确认。运单管理同步展示标识。

3. 确认 = 手动勾选

关务核对后勾选「预录已确认」；允许取消/改回。客户改口或核对有误时可反复改，直到放行单上传。留操作人、时间。

4. 放行后锁定

上传放行单后不可再取消/修改确认。改单撤销、重发同样不可用，走线下异常单。

5. 改单 → 撤销 → 重发 卢慧恒 8/20

  1. 改单：件毛体、品名/HS、收发通、抬头等变更（含退税改买单）。
  2. 撤销单：撤销当前有效预录；同时取消「预录已确认」；记原因。
  3. 重发：按最新资料再推报关行，状态回到「报关行处理中」。
  4. 新预录回传后，关务重新核对并勾选确认。
  5. 已上传放行单：本路径关闭，走线下异常 / 改配，不在本页硬撤。

6. 待配舱 ≠ 终配舱

运单管理原「待终配舱」拆成两个状态。本页同步展示配舱阶段：待配舱也可提前推送；终配舱后继续跟预录/放行。本页配舱阶段只读，主数据在运单管理。

7. 签入后推送

报关件 + 资料已上传 → 待推送；报关件缺资料 → 拦截并催传（业务/客服代办）。资料齐后自动转待推送。

8. 与报关执行列表

本页是关务「做资料/预录」作业台（运单维、只报关件）。排柜后正式件/放行仍在报关管理列表。两边报关状态说法一致：待推送 / 报关行处理中 / 预录待复审 / 待放行 / 已放行；共用报关行、预录确认、放行标识。

9. 报关标记 NEW

三档：报关（单票）· 合并报关（多运单一组、同一报关编号）· 拆分报关（一票拆成多份报关编号）。勾选后可改标记。已放行的运单不可改标记。

10. 合并报关 · 同改状态 NEW

同组合并报关的运单，推送 / 出预录 / 确认 / 改单撤销 / 重发 / 放行一起改，避免漏改导致漏报、重复报。

11. 报关编号 NEW

格式 运单号-序号(件数)，例 WY260820001-1(8)。合并组用主运单号 + 组内件数合计；拆分同一运单出 -1(3) -2(2)。

筛选与页签

  • 默认查询 是否报关件=是，买单不入库。
  • 页签：全部报关单 / 待做资料 / 待推送 / 报关行处理中 / 预录待复审 / 待放行 / 改单已撤销 / 已放行（与报关执行对齐；待做资料、改单已撤销为本页作业态）。
  • 筛选：运单号、客户、报关客服、报关行、配舱阶段、报关标记、报关编号、是否已出预录、预录已确认。

三、报关标记 / 编号

改标记

  • 标记合并报关：勾选 ≥2 票；指定合并组号、主运单（编号前缀）。组内共用一个报关编号。
  • 标记拆分报关：一票拆成 运单号-1(件数)、运单号-2(件数)。第 2 票件数填 0 则只出 -1。
  • 已放行不可改标记。原型工具栏不放「改为报关」。

编号规则

标记编号示例
报关本运单号-1(本票件数)WY260820001-1(8)
合并报关主运单号-1(组内件数合计)，组内各行相同WY260820006/010/011 → WY260820006-1(12)
拆分报关同一运单多段WY260820009-1(3) WY260820009-2(2)

同组合并报关：推送、出预录、预录确认/取消、改单撤销、重发、上传放行单一并写入组内全部运单。

五、边界与联动

  • 本页：签入后做资料、推送报关行、预录进度、确认、改单撤销重发（运单维 · 仅报关件）。含报关标记与报关编号。
  • 运单管理：待配舱/终配舱拆分；展示报关行、预录已确认标识（放行后锁定）。
  • 报关管理列表：排柜后正式件、放行抓取、查验；不替代本页预录确认勾选。状态名与本页对齐。
  • 预录单审核详情：本页「结构化」进字段对比（通道②预录结构化）；「沟通」进同一页右侧沟通侧栏。推送后可沟通；须已出预录才看结构化。
  • 签入代办：仅报关件且资料未传时，给业务/客服催传。资料齐后转本页待推送。
  • 报关行、预录确认、已放行与运单管理列表、报关执行列表同源展示。

六、开发要点

  1. 本页查询默认 是否报关件=是，买单不入库。
  2. 预录确认是运单上手动布尔字段，可反复改；放行单已上传 后字段只读。
  3. 改单事件：撤销当前预录（清确认、记撤销原因）→ 重发报关行 → 等新预录回传后再确认。
  4. 配舱阶段取运单管理：待配舱 / 终配舱，禁止再写「待终配舱」。
  5. 本页提供修改报关行（勾选/行内）与推送报关行（须已指定报关行、资料已齐、状态=待推送）。已推送后改报关行则退回待推送再推。已放行不可改。合并组同步。
  6. 报关行、预录确认、放行锁定与运单管理列表、报关执行列表同源展示。
  7. 报关标记 = 报关 / 合并报关 / 拆分报关；合并组共用报关编号，状态动作按组写入。
  8. 报关编号 运单号-序号(件数)。
  9. 列表单元格单行：额外说明用 title，禁止第二行副标题、同组票数换行。

七、怎么测

  1. 非报关件签入：本页无此票、无催传代办。
  2. 报关件缺资料：待做资料；资料齐后转待推送。
  3. 未指定报关行时点推送会拦截；先「修改报关行」再「推送报关行」进入报关行处理中。
  4. 已推送票改报关行：状态回到待推送，再推一次。
  5. 模拟预录回传后进入预录待复审，可勾选确认进入待放行，允许取消再勾。
  6. 上传放行单：进入已放行，改单撤销/重发禁用。
  7. 预录待复审后改单撤销 → 确认取消 → 重发 → 报关行处理中。
  8. 勾选 WY260820006 / 010 / 011（或任意 ≥2 票）标记合并：编号变为主运单-1(件数合计)；对其中一票推送/确认/放行，组内同步。
  9. 拆分一票：列表单行展示 -1(n) -2(m)，不折成两行。
  10. 按报关客服「王敏」查询：只出王敏名下票（含合并组 WY260820006/010/011）。
  11. 表格任意状态下列高约一行，横向滚动不换行。
