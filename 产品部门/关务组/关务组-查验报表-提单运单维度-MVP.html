国内周分析

  • 口径：总计 / 正常 / 查验 / 查验甩柜 / 船公司甩柜 / 查验未放行 + 占比饼图
  • 按报关行：数量、查验数、查验率
  • 未放行盯控：本周装柜 vs 历史遗留（装柜日 / 查验日 / 卡点说明）

国外周分析

  • 口径：总计 / 正常 / 查验 / 查验率 / 查验未放行
  • 按进口商占比；明细：到港、船名航次、起运目的、查验方、送检、开查、放行、海外仓、清关行、系统轨迹
  • 未放行：本周到港 vs 历史遗留

统一进度

  • 每个柜子：查验通知/送检 → 开查 → 放行；段耗时可统计
  • 去掉进度时间轴与日期列重复：只保留通知/送检、开查、放行三列 + 段耗时
  • 查验进度「全部」时：国内 / 国外分开展示（不混排）
  • 增列：查验备注、情况说明；「谁做」责任人 待业务确认
  • 可下钻提单/运单维度；导出国内模版 + 国外模版
