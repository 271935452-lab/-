## 一、背景（给产品）

### 现状

| 能力 | 现状 |
|------|------|
| 分单号规则配置页 | 已有（船司×港口→模板，含试算） |
| 终配舱绑定主单 `bindPickNo` | **只绑提单**，不生成分单号 |
| 手工绑分单号 `bindCustomsSplitBillNo` | 前端传入分单号列表后落库 |

### 本期诉求（开发理解）

在 **`bindPickNo` 绑定/换绑主单成功后**，按分单号规则自动生成分单号。

### ✅ 已确认：分单号按「关务报关编号」维度

> **产品口径（2026-09-05）：分单号规则基于关务报关编号维度绑定；报关编号相同 → 分单号相同。**

| 规则 | 说明 |
|------|------|
| 分组键 | `S_CUSTOMS_DECLARATION.DECLARATION_NO`（关务报关编号，不含括号） |
| 总票数 N | 本终配舱下**有效报关编号去重个数**（不是运单数） |
| 合并报关 | 1 个报关编号下挂多运单 → **仍只算 1 票、只分配 1 个分单号**；组内运单共用该分单号 |
| 单独报关 | 1 报关编号 = 1 分单号 |
| 展开落库 | 按报关编号下挂运单写入时，**同编号运单写同一个分单号** |
