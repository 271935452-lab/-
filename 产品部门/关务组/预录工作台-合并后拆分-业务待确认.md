# 预录工作台 · 标记合并 / 拆分报关 · 业务待确认

> 模块：预录工作台（关务组）  
> 关联接口：`/customsDeclaration/markMerge/preview`、`/customsDeclaration/markMerge`、`/customsDeclaration/markSplit`  
> 对照接口（运单管理侧）：`/customs/mergeCustomsDeclare`、`/customs/splitCustomsDeclare`  
> 日期：2026-08-31  
> 状态：**产品已确认（2026-09-01）**  
> 原型已对齐：`关务组-签入即预报资料-MVP.html` + 待配舱「报关编号 / 关务报关标记」

### 产品回复（可转发开发）

1. **回写运单（§2.5）**：关务合并 / 拆分 / 再分票 / 撤销合并后，**要回写**运单执行字段（报关编号 `DECLARATION_NO` 存库不含括号、关务报关标记）。待配舱列表展示「报关编号」+ 新增「关务报关标记」。**不改**运单报关编号、客户/业务员原合并拆分标记、附加服务原记录。  
2. **调整窗口（§3.3）**：报关状态**不是「待放行」**均可撤销合并后再重新合并，也可直接走「合并后再分票」。**待放行及之后**锁死（不可撤销 / 再合 / 再分票）。  
3. **方案 D**：新按钮「合并后再分票」（例 10→3）；「标记拆分报关」仍只做单票按件数 / 整柜按票。

### 2.1 合并范围：只合勾选运单（非整张报关单）

| 项 | 当前实现 |
|----|----------|
| 勾选 | 列表勾选 **运单行** ≥2 票 |
| 合并对象 | **仅勾选运单**进入新报关编号 |

**示例**

| 对象 | 结果 |

## 三、待确认② · 标记拆分报关 & 合并后能否再拆

### 3.1 当前拆分实现（单票）

| 项 | 当前实现 |
|----|----------|
| 勾选 | 只勾 **1** 票运单 |
| 卡控 | 该报关编号下必须只有 1 票；合并组（≥2 票）直接拒绝 |
| 散货 | 填拆分件数；固定拆成 2 段（件数 + 余数）；件数落 `SEGMENT_PIECE` |
| 整柜 | 不填件数；按海关表票数一票一段 |
| 编号 | `运单号-序号`（不含括号） |
| 原单 | 作废 |

### 3.2 与运单管理侧「拆分报关」差异

| 维度 | 运单管理 `/customs/splitCustomsDeclare` | 预录 `/customsDeclaration/markSplit` |
|------|------------------------------------------|--------------------------------------|
| 业务含义 | 标记「这票要报成 N 份」 | 关务实际拆成多段报关编号 |
| 入参 | `customsSplitPiece` = **拆成几票** | 散货 = **第一段件数**；整柜按海关表 |
| 落库 | `CUSTOMS_BATCH=billNo-1;…`；加 CFBG | 作废旧单；续编多个 `DECLARATION_NO` |
| 合并组 | 不看预录合并关系 | **合并组不可拆** |

### 3.3 因此产生的问题

运单一旦进入多票合并单，再点「标记拆分报关」会被拦截：

> `拆分报关仅支持单票运单（当前关联N票）`

**合并后的运单，关务还要不要在预录工作台再拆？** 请选方案：

#### 方案 A · 合并后不允许再拆（维持现状）

- 多票合并单只能整组作业；要按件数拆须在合并前做，或走运单管理侧  
- 建议文案：「合并报关单不可拆分」

#### 方案 B · 允许「拆出勾选运单」（从组合并）

- 勾选部分运单 → 新报关编号；剩余留原单（非按件数拆）

#### 方案 C · 允许「单票按件数拆」

- 合并组内勾 1 票 → 按现拆分弹窗拆段；其他运单留原合并单

#### 方案 D · 支持 PRD「合并组再分票」（如 10 票拆成 3 份）← **产品已选**

- 按运单列表拆成多个报关编号；**新增独立功能**（不是改现有「标记拆分报关」）
- 用途：客户已合并后，关务再调整实际报几票（例 10→3）；收费按关务调整后的报关编号票数
- 入口：**新按钮**「合并后再分票」（勿塞进「标记拆分报关」）
- 「标记拆分报关」继续只做：单票按件数拆两段 / 整柜按票拆；合并组仍不走件数拆
- 编号续编：与现合并/拆分一致（指定票件前缀 + maxSeq+1；存库无括号；展示 `(运单数)`）
- 再分票成功后同样**回写运单执行字段**；待配舱新字段同步更新

### 3.3 合并后调整窗口 · 产品定稿（2026-09-01）

| 项 | 口径 |
|----|------|
| 原则 | 合并后只要报关状态**还不是「待放行」**，均可**撤销**后再**重新合并**（也可再走「合并后再分票」） |
| 可操作状态 | 待上传资料 / 待推送 / 报关行处理中 / 预录待复审（及本页其它未到待放行的作业态，含改单已撤销） |
| 不可操作 | **待放行及之后**（含已放行）：不可撤销合并、不可再合并 / 再分票 |
| 撤销含义 | 撤销关务侧本次合并（预录报关单恢复/作废按实现）；运单执行字段回写同步清空或回退；**客户原标记 / 运单报关编号仍不改** |
| 与方案 D | D = 在合并不撤销的前提下直接再分票；本条 = 允许先撤销再重新合。两条都要支持，窗口均为「非待放行」 |
