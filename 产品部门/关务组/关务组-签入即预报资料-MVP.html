改单后撤销预录单

撤销后：预录确认取消，状态变为「改单已撤销」，可重发报关行出新预录。

标记合并报关

将勾选运单标为同一合并报关组。推送、预录确认、改单、放行将同步到组内全部运单。

报关编号 = 主运单号-1(组内件数合计)

标记拆分报关

一票运单拆成多份报关编号：运单号-1(件数) 、运单号-2(件数)。

第 2 票填 0 则只出 -1(件数)。多选时按各票自己的件数拆。

修改报关行

勾选运单后指定报关行。合并组同步；待放行及之后不可改。已推送的票改报关行后回到「待推送」，需再推一次。

默认（收货仓→报关行）：青岛港→鸿程捷运；厦门港→通航顺；天津港→聚航；宁波/上海港→欣扬；盐田港→盛世通。可手工改。

客户委托标记

未对接报关行时人工登记客户委托。合并组同步。仅已委托可推送报关行。

上传预录单 NEW

勾选运单处于「报关行处理中」，且报关行未对接 API。

支持 PDF / Excel / 压缩包 / 图片

上传后写入预录附件，状态进入「预录待复审」，等同 API #04 回传。已对接报关行由系统自动回传，无需手工上传。
