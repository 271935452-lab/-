步骤 ↔ 页面 / 功能对照表

流程节点 对应页面 功能点
1签入 · 进预录池 预录工作台 散货报关件签入 / 整柜勾选「我司代理报关」→ 进池；主键报关编号；筛选含业务类型散货/整柜；整柜运单号 TXZG…，编号 -1/-2不带件数
2报关行配置 报关行配置 散货：已启用销售产品多关键词搜索多选 → 分公司 → 报关行；整柜：配送方式×港口多选 → 报关行；推送 #01 时自动命中 / 手改
3待上传 → 待推送 预录工作台 · 页签 资料齐 → 待推送；缺资料 → 待上传资料；工具栏按 §四六态显隐；委托标记、操作日志任意态可用
4推送报关行 · 预录回传 预录工作台 · 推送 #01 推送后 → 报关行处理中；报关行回传预录 / 上传资料 → 预录待复审；H7 预录回传接入
5预录待复审 · 确认 预录工作台 · 手勾确认 勾选预录已确认；合并组同步；改单撤销 → 改单已撤销页签 + 原单回退待推送
6散货 · 终配舱卡控 ① 预录工作台 · 配舱只读 终配舱落位：不重推报关行；件毛体以终配舱为准；分单号重算只写号；仍留本页跟预录；整柜无此卡控
7待放行 · 出池 ② 预录工作台 · 待放行 → 报关执行 预录确认后状态待放行；本页停止作业（待放行无工具栏）；主战场转至报关执行列表；已放行后本页只读
8报关执行 · 申报/放行 报关管理列表 页签仅待放行 / 查验 / 放行；无预录阶段页签；工具栏：分单号自动生成（待放行）、发舱单、下载舱单 #08/#10；已去掉改单/改配入口
9绑定提单后 · 分单号 分单号规则配置 绑主单成功后按船司×港口规则整组生成；配舱调整已绑提单 → 重算；只给舱单，不进 #01
10终配舱后 · 双通道核准 做资料分票核准 有资料即按报关编号推；散货必分票、整柜看情况；双通道比对 H7 预录；P2 汇合后进 P3
11P3 发舱单 ∥ 报关 报关管理 · 发舱单/下载舱单 发舱单推海管家；下载舱单推代理；H5 船务只读订阅舱单/放行
12改单（截单/运抵/舱单） ⑤改单方案 截单资料·保函 / 改运抵 / 改舱单：先通知报关行勿报关
13查验 · 改配三类 改配三类 查验登记通知客户；改配由船务发起 R4；业务标记 ①甩柜 ②换单 ③换柜
14目的港清关 清关管理 清关待办 / 查验通知；H3 取消 IT（仅火车）；清关放行 → H4 海外
