————————————————
一、结论摘要
————————————————

1. 查验通知：报关行通知我司 → 开船前一天通知客户；系统侧希望「查验通知一键发给客户」。
2. 查验后处置看海关指示：有问题可移交科室、删预配、删报关单；严重时可全部落货。
3. 合并报关：尽量装同一柜子；分柜装则我司承担风险。
4. 可「一票部分报关」——只申报其中一部分。
5. 查验需标识「查验多少天」。
6. 品牌侵权场景：客户上传授权附件；授权须与报关抬头一致。
7. 海外清关关注品名（海外清关品名）。
8. 改港费：清关时间过长时，需增加改港费。


————————————————
二、国内外查验
————————————————

【通知链路】
报关行通知查验 → 我司侧处理 → 开船前一天通知客户。
需求点：查验通知支持一键发送给客户（减少人工转发遗漏）。

【查验过程中】
按海关指示走，可能结果包括：
· 移交科室
· 删预配
· 删报关单
· 全部落货（整票/整柜落货）

【状态与标识】
需要「查验多少天」的标识（便于催办、对客说明、统计延误）。

【海外清关】
单独关注「海外清关品名」（与出口报关品名可能不一致，需口径对齐）。


————————————————
三、报关件 / 合并报关 · 分柜装
————————————————

【原则】
合并报关的货，尽量装在同一个柜子。
若拆开分柜装 → 风险由我司承担（关务口径）。

【部分报关】
支持「一票部分报关」：同一票里可以只报一部分（报部分）。

【品牌 / 授权 / 抬头】
涉及品牌侵权风险时：
· 客户须提供授权文件（系统里为上传附件）
· 授权主体必须与报关抬头一致
· 抬头不一致不可硬过，需先对齐再报


————————————————
四、改港费
————————————————

清关时间过长时，需要增加「改港费」（费用项可落系统，触发条件与金额口径待与船务/海外对齐后固化）。


————————————————
五、系统落点（建议）
————————————————

| 能力 | 说明 | 优先级建议 |
|------|------|------------|
| 查验通知一键发客户 | 报关行通知入库后，一键触达客户；默认节点含「开船前一天」提醒 | P0 |
| 合并报关同柜校验 | 合并报关若分柜装 → 强提示「我司承担风险」；可要求确认后才能继续 | P0 |
| 授权附件 + 抬头校验 | 上传授权文件；校验授权抬头 = 报关抬头 | P0 |
| 查验天数标识 | 列表/详情展示已查验天数，可预警 | P1 |
| 查验异常处置状态 | 移交科室 / 删预配 / 删报关单 / 全部落货 可登记、可追溯 | P1 |
| 一票部分报关 | 支持同票勾选部分报关件申报 | P1 |
| 海外清关品名 | 字段独立维护/展示，与出口报关品名区分 | P1 |
| 改港费 | 清关超时可加收改港费；费用项与触发规则待固化 | P1 |


————————————————
六、与既有口径的衔接
————————————————

· 改配三类（甩柜/查验换船/换柜）：查验导致换船/换柜时，走既定轨迹延续或覆盖规则，并通知客服/海外/仓库。
· 资料核准：品牌授权、抬头一致性可作为核准必比项。
· 装柜表：合并报关同柜校验宜挂在排柜/装柜确认节点。
· 改港费：与海外清关时效、改港作业衔接，跨组确认计费触发点。
