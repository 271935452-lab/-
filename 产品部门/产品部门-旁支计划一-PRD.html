五、待确认 / 边界

事项说明
舱位 · 已放舱退运 待确认未放舱已定（已退仓 + 运单待订舱）。已放舱确认后状态、是否回退运单、与提单「已作废」如何对齐，拍板后再改分册。
提单退运 vs 仓位退运 入口不同：船务按柜作废提单；仓位按 SO 退仓。勿混成同一按钮。
查货率报表 清单二，状态完成；进本期计划一验收。
计划二不在本文 海外仓对接 / 信号旗·飞驼 / 工单 / 供应商上传等 → 旁支计划二。主单基础费用批量维护已在计划一 #12，不在计划二。

已放舱退运未拍死前，开发不得按「与未放舱完全相同」自行验收。
