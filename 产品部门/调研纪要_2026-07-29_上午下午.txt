一、上午 · 关务组
════════════════════════════════

【结论】
1. 查验：报关行通知 → 开船前一天通知客户；要「查验通知一键发给客户」。
2. 处置看海关指示：移交科室 / 删预配 / 删报关单 / 全部落货。
3. 合并报关尽量同柜；分柜装 → 风险由我司承担。
4. 支持一票「报部分」。
5. 要标识「查验多少天」。
6. 品牌授权须与报关抬头一致（授权为上传附件）。
7. 海外清关关注「海外清关品名」。
8. 清关过久需加「改港费」。

【查验】
· 通知链路：报关行通知 → 我司处理 → 开船前一天告客户。
· 处置：移交科室、删预配、删报关单、全部落货。
· 标识：查验天数；海外清关品名独立维护。

【合并报关 / 分柜装】
· 原则：合并报关尽量装同一柜子。
· 分柜装：我司承担风险（需系统强提示确认）。
· 一票可只报一部分。

【授权 / 抬头】
· 客户上传授权附件。
· 授权主体 = 报关抬头，不一致不可硬过。

【改港费】
· 清关时间过长时增加改港费（触发与金额待与船务/海外固化）。

【系统落点 · 建议】
P0  查验一键发客户（含开船前一天提醒）
P0  合并报关同柜强提示（分柜装确认）
P0  授权附件 + 抬头校验
P1  查验天数 / 处置状态 / 部分报关 / 海外清关品名 / 改港费

二、下午 · 风控组（查货）
════════════════════════════════

【结论】
1. 查货：先看图，有疑问再问；系统有标识，但仓库查货不规范，要补卡点。
2. 附加服务可勾选；要多收费的须进业务数据统计。
3. 多品名：超 5 个，每个加收 30。
4. 品牌侵权：看图 → 豆包 → 确认品牌 → 网站查 → 要授权；留记录并提醒。

【查货操作】
· 标准：先看查货照片/标识 → 有疑问再问客户/业务。
· 现状：有标识，仓库执行不规范。
· 建议：照片必看/已看标记；疑问留痕；完结前强制步骤。

【附加服务与计费】
· 可勾选；多收费项必须写入业务数据统计（勾选 ≠ 完成计费）。
· 同行：费用加客户。
· 直客：费用加业务员；查货费加应收；业务数据统计加「附加服务业务成本」。

【多品名】
· 品名数 > 5 → 多品名；每个 +30（按超出部分理解，待最终确认）。
· 需区分：包装 / 分开包装。

【品牌侵权查询】
① 看图
② 问豆包（图片识别辅助）
③ 确认品牌
④ 去网站查是否侵权
⑤ 必要时要授权书（抬头与报关抬头一致，衔接收关上午口径）
⑥ 侵权留记录 + 提醒
· 豆包仅辅助，不作唯一卡控依据（待评估）。

【其他】
· 查货管理新增「客户备注」。
· 违禁品表格给客户看。
· 客户下单附件是否带到查货（链路待确认）。

【系统落点 · 建议】
P0  查货先看图（已看 + 疑问留痕）
P0  附加服务多收费 → 业务数据统计
P0  多品名自动识别与计费
P0  品牌侵权查询链路（豆包辅助）
P1  客户备注 / 违禁品对客 / 下单附件带入
