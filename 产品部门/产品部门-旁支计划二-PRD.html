#5 整柜权限 · 岗位 × 页面矩阵

权威口径挂旁支计划二 #5。运单/舱位/提单待办路由读客户最终配置（客服/订舱员/报关员/海外对接），不直接读业务员团队。 分册：客户权限 PRD · 岗位绑定 · 员工岗位团队。

岗位 应处理的整柜页面 数据范围 主要操作权限
业务员 客户管理、传统订单管理、整柜下单、询价报价 自己名下客户 维护客户绑定业务员；查看客户运单；发起下单、报价相关操作
客服 传统订单管理、订单详情、客户服务相关节点 客户最终配置中「客服」字段对应客户 查看并处理该客户运单；维护客服负责的资料、跟进和待办
订舱员 仓位管理、订舱登记、放舱确认、提单完善 客户最终配置中「订舱员」字段对应客户 订舱、放舱、导出订舱资料、维护提单相关资料
报关员 清关节点、报关资料页 客户最终配置中「报关员」字段对应客户 查看/维护报关资料、处理清关节点
海外对接 整柜尾端派送、卡派跟进、POD、海外仓工单 客户最终配置中「海外对接」字段对应客户 约仓、提柜、派送、POD、海外仓指令与处理结果回写
报价员 我的询价、询价报价列表、报价员配置 不按客户岗位表过滤，沿用独立报价员路由 报价、维护报价；不自动获得该客户运单权限
产品 / 订舱主管 / Admin 整柜客户岗位绑定 全部客户 新增、编辑、删除、导入导出客户四岗绑定；恢复业务员默认团队
销售 / 财务 / Admin 客户管理 现有原型仅明确菜单可见 客户主档维护；财务、联系方式等敏感字段还需另拆字段权限
员工管理维护人 员工管理 全部员工 仅业务员可维护自己的整柜默认岗位团队；非业务员不展示该区块

测：① 客服登录仅见其绑定客户运单；② 订舱员仅能操作其绑定客户舱位/提单；③ 报价员能报价但不能进该客户运单待办；④ 非业务员员工编辑页无「整柜岗位团队」区块；⑤ 客户改四岗后运单权限即时跟最终配置。
