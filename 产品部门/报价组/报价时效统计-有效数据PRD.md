## 1. 什么是「有效」

**有效询价** = 纳入报价时效看板统计（计入票数、平均时长、超时占比）的询价单。

**不是**系统里所有询价单都会统计。看板上的「有效询价票数」是分母，只包含满足下文全部条件的单据。

**有效时长** = 在有效询价上，按规则计算出的报价耗时（分钟），用于判断是否超时及求平均。

---

## 2. 「有效」与「无效」判定总表

| 判定 | 条件 | 是否计入看板 | 说明 |
|------|------|-------------|------|
| **有效** | 当日 **09:00–18:00** 重提 | ✓ | 从重提时刻起算 |
| **有效** | 该轮次**全部报价方案**已提交完成 | ✓ | 有全部方案提交完成时间 |
| **有效** | 重提时刻不在 **11:30–13:00** | ✓ | 午休时段重提整单剔除 |
| **无效** | 未重提（含仅草稿、打回/撤回后尚未重提） | ✗ | 不算一次有效询价 |
| **无效** | **09:00 前** 或 **18:00 后** 重提 | ✗ | 非工作统计时段 |
| **无效** | **11:30–13:00** 重提 | ✗ | 午休剔除 |
| **无效** | 打回/撤回后**尚未重提**的轮次 | ✗ | 作废轮次，等重提 |
| **无效** | 尚未完成**全部方案**报价 | ✗ | 无完整结束时间，不参与统计 |

---

## 3. 询价计时起点（已确认）

**不单独区分「草稿 / 打回重提 / 撤回重提」，统一以重提时间为准。**

- **重提时间** = 有效轮次业务员**最后一次正式提交**时刻（首次正式提交即该轮重提时间）。
- 草稿保存、打回前提交、撤回前提交等**作废轮次**不参与计时。
- 打回前的等待时间**不算**在报价员考核里。

**示例**

```
09:00 提交 → 打回 → 09:40 重提 → 全部方案 09:55 提交完成
→ 有效轮次起点 = 09:40（重提时间）
→ 终点 = 09:55（全部方案提交完成）
→ 有效时长 = 15 min
```

---

## 4. 有效时长计算（在「有效询价」上）

| 步骤 | 规则 |
|------|------|
| 起点 | 有效轮次 **重提时间**（见 §3） |
| 终点 | **所有报价方案均已提交**的时间（非首个方案） |
| 午休扣除 | 若过程跨越 11:30–13:00，**减去 90 分钟** |
| 公式 | `有效时长 = (终点 − 起点) − 午休重叠分钟` |
| 超时 | 有效时长 **> 20 分钟** |

---

## 5. 看板指标与「有效」的关系

| 指标 | 计算 |
|------|------|
| 有效询价票数 | 当日满足「有效」条件的询价单数（散货/整柜分别统计） |
| 平均报价时长 | `SUM(有效时长) / 有效询价票数` |
| 超时票数 | 有效时长 > 20 min 的单数 |
| 超时占比 | `超时票数 / 有效询价票数 × 100%` |
| **达成率** | `(有效询价票数 − 超时票数) / 有效询价票数 × 100%`（= 20min 内占比） |

---

## 5.1 月度考核（7/24 袁华君补充）

| 指标 | 说明 |
|------|------|
| 统计周期 | **自然月**（按有效轮次**重提时间**归属月份） |
| 月度有效票数 | 当月全部有效询价合计（散货/整柜分别统计） |
| 月度超时票数 | 当月有效时长 > 20 min 的单数 |
| **月度达成率** | `(月度有效 − 月度超时) / 月度有效 × 100%` |
| **考核达标** | 月度整体达成率 **≥ 90%** 即达标（不要求平均时长单独达标） |
| 按人考核 | 每人当月达成率 ≥ 90% 为个人达标；看板需展示个人 + 整体合计行 |

**示例：** 散货 7 月有效 532 单，超时 45 单 → 达成率 91.5% → **达标**。

**备注文案（看板展示建议）：**

> 有效询价：09:00–18:00 重提且全部方案已报价完成，剔除午休重提、作废轮次；计时起点统一为重提时间，终点为全部方案提交完成时间。

## 6. 系统实现要点

### 6.1 需落库字段

| 字段 | 用途 |
|------|------|
| `inquiry_no` | 询价单号 |
| `submit_seq` | 提交轮次（1, 2, 3…） |
| `resubmit_time` | 重提时间（有效轮次最后一次正式提交） |
| `all_plans_quote_time` | 全部报价方案提交完成时间 |
| `plan_count` | 报价方案数 |
| `is_valid_for_sla` | 是否纳入 SLA 统计 |
| `invalid_reason` | 无效原因：未重提/时段外/午休/未完成全部方案/已作废轮次 |

### 6.2 计算逻辑（伪代码）

```text
FOR each inquiry ON stat_date:
  IF 无有效重提 OR 仅草稿/作废轮次 → invalid
  IF 最新有效轮次 resubmit_time NOT IN [09:00, 18:00] → invalid
  IF 最新有效轮次 resubmit_time IN [11:30, 13:00) → invalid
  IF 最新有效轮次 未全部方案报价完成 → invalid

  start = 最新有效轮次.resubmit_time
  end   = 最新有效轮次.all_plans_quote_time
  duration = end - start - lunch_overlap(start, end)

  IF duration > 20 → timeout
  ELSE → normal

  纳入看板汇总（按报价员 × 散货/整柜）
```

### 6.3 明细页建议展示

- 询价单号、业务类型、报价员
- **当前统计轮次**（第几次提交）
- **重提时间**、全部方案提交完成时间
- 是否有效、无效原因（无效单可单独 Tab 查看，不进 KPI）
- 有效时长、是否超时、报价方案数

## 8. 权限（按组织结构）

数据可见范围与系统**组织架构 / 汇报关系**挂钩，接口层强制过滤。

| 角色 | 可见范围 |
|------|----------|
| **报价员** | 仅**本人**（统计、KPI、汇总、超时明细） |
| **上级**（主管 / 组长等） | **本人 + 组织下级**（直接/间接下属，以组织树为准） |
| **其他管理角色**（报价主管、部门负责人、管理员等） | **全部**报价员 |

**补充规则**

- 「上级看下级」：按**当前生效的组织汇报关系**解析；人员调动以组织主数据为准。
- 汇总「合计 / 整体」行：在**当前用户可见范围**内重算（管理员看全部时为全量）。
- **导出 Excel**：与当前可见范围一致。
- 报价员登录时「报价员」筛选默认锁定本人（或隐藏该筛选项）。
