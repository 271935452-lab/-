背景与痛点 · 我们解决什么问题

业务背景

散货私卡尾程报价链路长：业务员发起询价 → 系统按销售产品、海外仓、内外州与万物智联等规则试算 → 报价员核对后回写各渠道单价 → 业务员确认 → 报价员绑定运单挂尾程费。现网以人工报价为主，AI 能力尚未形成「可管、可控、可绑」的闭环。

核心痛点

  • 算价复杂、口径分散：内州 713 价表、外州万物智联、仓绑定、头程运价合并等规则分散，改价无统一配置与版本，报价员难以追溯「价从哪来」。
  • AI 与业务员边界不清：AI 试算结果若直接暴露给业务员，未核价即可见，易引发误解与纠纷；报价员也缺少结构化复核入口。
  • 多渠道回写混乱：一单多销售产品时，单价、有效期、尾程、备注等应按各产品各一条回写，现网口径不统一。
  • 过期价仍被使用：动态调价后旧有效期报价仍可能被绑单、采用，缺少强制卡控。
  • 绑单与询价不匹配：运单计费重、入仓时间与询价计费重 / 报价有效期不一致时仍可绑定，产生后续成本与对账风险。

本期要解决什么

  • 建立AI 试算 + 报价员核对门控：AI待确认不回业务员；核对确认后按渠道回写；支持打回、撤回核对后再编辑（已核对不可 AI 重算）。
  • 上线AI 报价规则配置（内州 / 外州 / 仓绑定 / 有效期 / 版本发布）与试算结果日志，报价员可核对每轮试算明细。
  • 落实有效期规则（默认 7 天 + 15/30 截断）与绑单 A/B 校验（运单计费重 = 询价计费重、入仓时间在有效期内）。
  • 打通绑运单 / 改绑 / 解绑全流程；绑单后报价与运单不回写联动；财务已锁账 / 成本已审核后禁止改绑与撤回。
  • 业务员侧无感知 AI 过程，仅在看板收到已核对的多渠道报价并单选确认；整柜不在本期 AI 算价范围。

二B、询价（业务员）

2.1 发起询价字段调整

  • 销售产品下拉多选（PC 下拉 / APP 底部弹层）。一产品挂多仓地址时拆成多条选项（选时带地址）；回显为产品 · 仓名不带门牌。询价页不另开海外仓表单；询价员不填托数。

2.2 收货邮编 / 城市 / 州

  • 新增收货邮编、收货城市、收货州，均可根据详细地址（询价详情）AI 识别回填。
  • 收货州 vs 收货邮编：收货州必须等于收货邮编所在州。若误填成海外仓所在州（例：洛杉矶仓 CA，货发丹佛 80202 却填 CA），保存拦截并标红。
  • 海外仓州 vs 收货州：二者不一致时不拦截，弹窗提示：「海外仓州和目的州不一致，请确认」。用户确认后允许保存 / 提交测算；报价按收货州匹配价格段（见下条）。典型为纽约海外仓 NY / NJ 跨州收货（例：仓址在 NJ、货发 NY），不是内外州 / 外州迈数（>150 迈）判定场景，不算填错。
  • 按收货州匹配价格段（纽约仓）：仅纽约海外仓绑定的产品适用——收货 NY → 一口价（26：230+80×续托；53：1400）；收货 NJ → NJ 距离档（最后一档默认 101–150 迈）。其他仓仍按距离档判定内外州（默认 ≤150 / >150 迈，规则页可改），不按州名。规则页内州价表「州 / 适用地址」选项口径见 §5.6。

2.3 距离 · 后台测算

  • 询价页不展示距离字段，业务员不可手填或手改。保存 / 提交后由后台用海外仓邮编 + 收货邮编调用测距（AI / 地图工具）。
  • 测距结果、海外仓地址、匹配规则与算价明细写入报价员端「试算结果日志」（见 6.2.1），仅报价员可见。
  • 默认 ≤150 迈内州（含上限）；超过走外州。同州超上限也走外州。迈数与拆车上限在「AI报价规则」可改。询价不可手切内外州。

2.6 散货单价怎么算

  • 船务运价管理下发头程运价（H1），报价前就绪。
  • 算价时：总价 = AI 规则配置（内州 713 / 外州万物智联等）+ 头程运价；单价 = 总价 ÷ 计费重，给业务员取个位 USD/KG。外州万物智联渠道价取对接含附加费返回总价。
  • 业务员只看确认后的各渠道单价（多渠道多条），不展示头程、计费重、万物智联品牌表。

4.4 报价区按钮（打回 / 核对 / 编辑 / 绑单）

  • 待报价：详情大字状态 = 待报价（AI 尚未出账）。顶部展示 打回；不展示核对确认、编辑报价、试算日志（无 AI 价可核）。列表仍可点「报价」人工报价。
  • AI待确认：详情大字状态 = AI待确认；顶部同排 打回 + 试算日志 + 编辑报价 + 核对确认。进入详情默认只读展示 AI 已带出的单价、尾程派送费、有效期，可直接核对或先编辑。

5.11 算价引擎逻辑（询价 / 试算共用）

业务员询价与规则页试算坞走同一套引擎；差异仅为：询价用真实测距 + 已发布版（或预约前生效版），试算坞可用草稿 + 手填距离。

判定顺序

  1. 绑仓：销售产品 → 海外仓邮编。
  2. 测距：仓邮编 + 收货邮编 → 配送距离（迈）。询价页不展示距离，结果进试算日志。
  3. 内外州切轨：距离 ≤ 内州上限迈 → 内州 713；> 上限 → 外州。同州超上限仍走外州。不可手切。
  4. 纽约仓例外：仍 ≤150 迈内州范围内，按收货州选 NY 一口价或 NJ 距离档（非按距离代替州）。

四步算价

步骤内容
① 地址锁车型住宅或商业无卸货台 → 仅 26 尺；商业有卸货台 → 26 / 53
② 车型适配按方 / 重 / 板数与大小车上限拆车；有卸货台时任一项大于小车上限才上大车
③ 锁价内州：距离档 → 起步 + 续托 / 53 整车。外州小车：万物智联多品牌取最优。外州大车：距离 × 档位的 $/mile（取整）
④ 核算多车费用累加 = AI 规则总价。给业务员：（AI 规则总价 + 头程运价）÷ 计费重 → 个位 USD/KG。尾程派送费不参与上式

内州计费要点

  • 小车：起步价（含 N 托）+ 续托单价 × 超出托数。
  • 多车：按小车上限拆分，体积 / 重量各自扣上限；第 1 辆按实载，后续独立套公式。
  • 大车：未超 68 方且 18 吨 → 整车价；超出则循环扣减 + 追加大车 / 改小车。

外州计费要点

  • 小车：万物智联 8 品牌各 1 条最低价；对接价含附加费。
  • 大车：≤32 板且不能改小车 → 整车价 × 板数 ÷ 32 × 1.2；>32 板按 32 板整车循环 + 尾量处理。
  • 目的州仅用于合规（如 CA 平台费率 / TX 6.25%）与展示，不参与单迈价档选取。
