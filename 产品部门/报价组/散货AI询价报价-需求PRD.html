一、其他关联模块

1. 销售产品新增海外仓字段

  • 销售产品主数据「新增/编辑」弹窗 · 基本信息区增加 海外仓 下拉（必填，六仓）。位置：「提货类型」同行第三列。选仓后预览只读带出仓地址、邮编。原型：销售产品-新增数据-MVP.html。
  • 销售产品主数据增加「海外仓」关联（六仓：洛杉矶 / 纽约 / 萨凡纳 / 芝加哥 / 休斯顿 / 奥克兰）。
  • 一仓可绑多个销售产品；一个产品只能绑一个仓。询价勾选任一产品即带出该仓。
  • 发起仓地址 = 该海外仓下维护的海外仓地址里的邮编，不是国内交货仓。
  • 询价勾选销售产品后，不在询价页展示海外仓、仓邮编、仓地址与距离；后台按产品绑定仓做测距与算价。完整仓址与试算明细见报价员「试算结果日志」（见 6.2.1）。

2. 海外仓地址新增海外仓字段

  • 海外仓地址主数据必须挂在某个海外仓下（仓 1 : N 地址，本期按一仓一址使用）。
  • 地址含门牌、城市、州、邮编；邮编即发起仓邮编。

询价页：销售产品下拉多选，不展示海外仓 / 距离 / 仓地址；保存后后台按各产品绑定仓测距并试算。主数据维护见 销售产品 · 新增数据（海外仓字段）；与 AI 规则页「销售产品↔海外仓」表口径一致。测距与算价明细见报价员端 试算结果日志。

二、询价（业务员）

2.1 发起询价字段调整

  • 销售产品下拉多选（PC 下拉 / APP 底部弹层）。询价页不展示海外仓、仓邮编、仓地址、距离；询价员不填托数。

2.2 收货邮编 / 城市 / 州

  • 新增收货邮编、收货城市、收货州，均可根据详细地址（询价详情）AI 识别回填。
  • 收货州 vs 收货邮编：收货州必须等于收货邮编所在州。若误填成海外仓所在州（例：洛杉矶仓 CA，货发丹佛 80202 却填 CA），保存拦截并标红。
  • 海外仓州 vs 目的州：二者不一致时不拦截，弹窗提示：「海外仓州和目的州不一致，请确认」。用户确认不一致后，允许保存 / 提交测算；报价须按收货州匹配价格段取价（见下条）。仓州 ≠ 目的州为常见外州场景，不算填错。
  • 按收货州匹配价格段：纽约仓收货 NY → 一口价（26：230+80×续托；53：1400）；收货 NJ → NJ 距离档（最后一档默认 101–150 迈）。其他仓价格段仍按距离档，内外州默认按 ≤150 / >150 迈（规则页可改），不按州名。

2.3 距离 · 后台测算

  • 询价页不展示距离字段，业务员不可手填或手改。保存 / 提交后由后台用海外仓邮编 + 收货邮编调用测距（AI / 地图工具）。
  • 测距结果、海外仓地址、匹配规则与算价明细写入报价员端「试算结果日志」（见 6.2.1），仅报价员可见。
  • 默认 ≤150 迈内州（含上限）；超过走外州。同州超上限也走外州。迈数与拆车上限在「AI报价规则」可改。询价不可手切内外州。

2.4 收货地址参数（原「地址类型」· 万物智联拆参）

询价编辑必填。MVP 原型仍为三选一单选（住宅 / 商业无卸货台 / 商业有卸货台），便于业务员理解；上线系统须拆为多个独立字段落库，并按下列规则组装万物智联 destinationInfo（及必要时的 originInfo）。

2.5 外州小车 · 万物智联 8 品牌

  • 优先 8 品牌（XPO / Estes / ABF / FedEx Priority / FedEx Economy / TFORCE / Saia / ROADRUNNER），每个有报价的品牌取最便宜 1 条，仅报价员核对。
  • 8 个品牌如果没有报价（全部没有，或部分没有）：再从其他承运商里按总价从低到高补，返回给报价员。全部没有时至少返回名单外最便宜的 1 条（平台有返回的前提下）。
  • 业务员仍然只收确认后最优 1 条单价，不看品牌表。

2.5.1 万物智联附加费（业务确认）

2026-08-18 业务评审结论：外州小车走万物智联对接时，平台返回的报价已含对应附加费（如尾板 Lift Gate、预约 Appoint、住宅 Residential、州合规附加等）。ESS 侧不再维护独立附加费金额表，也不在 API 返回价之上本地叠加一套附加费。

  • 取价口径：外州 26 尺万物智联测价，以对接接口返回的含附加费总价（如 totalCharge / totalFreightCharge 或产品约定字段）参与 AI 算价与渠道比价。若 rate 明细中已含 Lift Gate 等项，禁止 ESS 再本地加一次，避免重复计费。
  • 传参：外州 26 尺测价须传 2.4 拆分字段（isResidential、hasLoadingDock、needLiftGate、needAppointment、locationType）；平台据此返回含附加费总价。ESS 只传参、不维护附加费单价。
  • 不适用：内州 713 价表、外州 53 尺单迈价不走万物智联，不适用本条。
  • 尾端派送费：仍为报价员确认台按票取整登记，不做自动计算；与万物智联附加费不是同一笔。
  • 规则维护台：不维护附加费模块；仅维护内州价表、外州单迈价、拆车、品牌启用、产品↔仓等（见第五章）。
  • 原型说明：外州测算页 carrierAccessorial 本地查表叠加逻辑为 MVP 演示参考，非上线口径；开发 / 测试以本 PRD 与万物智联对接返回为准。

2.6 散货单价怎么算

  • 船务运价管理下发头程运价（H1），报价前就绪。
  • 算价时：总价 = AI 规则配置（内州 713 / 外州万物智联等）+ 头程运价；单价 = 总价 ÷ 计费重，给业务员取个位 USD/KG。外州万物智联渠道价取对接含附加费返回总价（见 2.5.1）。
  • 业务员只看确认后的 1 条单价，不展示头程、计费重、万物智联品牌表。

二B、我的询价（业务员列表）

对应原型：ESS我的报价-列表-MVP.html

  • 维度 Tab：散货 / 整柜；角标 = 该维度草稿 + 报价中合计。
  • 支持新建询价、查看详情、复制报价。
  • 工具栏「+ 新增询价」标记 改：跳转新版询价编辑（6.1）；相对原流程增加销售产品多选、海外仓只读带出、测距、地址类型等。提交后业务员侧仍为「报价中」，看不到 AI 过程。
  • 关联运单：仅散货工具栏展示；整柜 Tab 隐藏。
  • 报价耗时列展示工作时长分钟数；统计不含 12:00–13:00、18:00–次日 09:00。
  • 收到报价 / 打回：角标 +1 + 右下角代办弹窗（服务端推送）。
  • 业务员看不到 AI 测算与其余产品销售产品比价；仅展示核对确认后的 1 条单价。确认并绑运单后报价锁定。
  • 报价状态列：报价员核对确认后展示 人工已报价；不出现「未确认」「已确认·单价」等报价员侧状态。
  • 人工已报价页签：已收确认单价、有效期内、尚未关联运单；报价状态列同步展示「人工已报价」。

列表顶栏不放业务说明长文案；以本 PRD 为准。

三、报价员列表

3.1 报价 + 核对确认

  • 保留人工「报价」。
  • 列表增加 更新时间 列（散货 / 整柜均有），位于「创建时间」之后；格式 YYYY-MM-DD HH:mm，取本票询价/报价最后一次变更时间（含 AI 出账、核对确认、绑单、改绑、打回等）。无后续变更时与创建时间相同。
  • 「核对确认」进入报价员详情完成。详情默认带出 AI 单价、尾程派送费、有效期；点「编辑报价」进入可改状态，点「核对确认」保存。列表不再另做核对弹窗。字段级新增/改动见第六章。
  • 有效期默认按 7 天含当日、遇 15/30 截断带出，详情页可改。过期须重算。

3.2 绑定运单 · 匹配

  • 定时任务每小时刷一次，带出符合条件的运单。
  • 绑定运单按钮文案仅「绑定运单 / 改绑运单」；符合票数在弹窗内展示，不挂在行操作链接上。
  • 散货：目的国 + 邮编 + 交货仓；整柜：起运港 + 目的港 + 柜型。散货整票仅绑 1 张运单。散货运单号前缀 ICBU。
  • 散货多渠道：绑单弹窗左侧只读展示本票询价各渠道单价；右侧列出全部符合条件运单，整票选 1 张绑定并挂接尾程费。弹窗字段见6.3。

3.3 列表状态 · 已报价 vs 已完结

  • 取消报价员侧「AI已报价」。AI 出账后列表状态为 AI待确认：价格不返回业务员。
  • 核对确认后：列表状态改为 已报价（蓝色标签），单价返回业务员，但尚未绑定运单。
  • 绑定运单成功后：列表状态改为 已完结（绿色标签）。改运单不回写已确认价。
  • 待绑运单页签：已报价 + 有效期内 + 已登记尾程派送费 + 尚未绑定。
  • 业务员无感知：业务员列表 / APP 不改。AI待确认期间仍为报价中、无单价；确认后才见 1 条单价。

3.4 行上操作按钮（按状态）

散货 / 整柜列表「操作」列按报价状态动态渲染，规则如下：

列表状态行上按钮说明
待报价报价、打回不展示绑定运单

  • 整柜「报价」跳转整柜报价编辑；散货「报价」跳转报价员详情。
  • 工具栏「核对确认」：勾选 AI待确认 或 已报价 散货单可用。「绑定运单 / 改绑运单」：勾选 已报价 / 已完结 且未过有效期可用；已锁账 / 成本已审核不可改绑时置灰，点击即 toast 拦截。

四、报价员详情交互优化

对应原型：ESS散货询价方案详情-MVP.html。角色仅报价员。

4.1 左侧列表

  • 页签：待核对 / 待绑运单（标注 改）；Tab 上展示动态数量 (N)。
  • 待核对：报价员状态非「已完结」（含 AI待确认、待报价、报价中等）。
  • 待绑运单：已报价 + 有效期内 + 已登记尾程派送费 + 尚未绑定运单。
  • 切换 Tab 过滤左侧询价单号列表；点击单号带 ?xj= 进入对应详情。待绑运单入口可带 #bind 直接打开绑单。
  • 列表项副标题：待核对显示「AI待确认」；待绑运单显示「已报价 · 未绑运单」；已绑定显示「已完结」。

4.2 中间报价卡片

  • 每个销售产品一张卡：单价、尾程派送费、有效期从/至可改（默认仍按 7 天含当日、遇 15/30 截断带出）、备注。不展示头程、计费重、万物智联 8 品牌。
  • 万物智联多价时，测算阶段取最优给报价员。AI待确认不返回业务员；本页核对确认后改为已完结，价格才返回业务员。本页不比品牌、不选手动「报给业务员」。
