背景与目标

项内容
用户价值业务投诉报价慢。看板让报价员和上级看到：从业务员重提，到报价员把价回给业务员，有没有落在 20 分钟内。
公司价值报价时效进月度考核。当前查询范围内，有效询价的 20 分钟内占比 ≥90% 即达标。
主用户报价员（看自己）、报价主管 / 组长（看下级）、报价部门负责人与管理员（看全部）。
场景散货：业务员提交 → AI 试算 → 报价员核对确认 → 业务员见到「人工已报价」。整柜：报价员把全部手报方案提交完。考核只量这一段。
可量化目标单票有效时长 ≤20 分钟为未超时；月度整体达成率 ≥90% 达标。平均时长只作参考，不单独作为达标条件。

角色与权限

可见范围在接口层按当前生效的组织汇报关系过滤。兼岗、调动以组织主数据为准。前端「报价员」下拉只列出当前用户能看的人。

角色可看可操作不可
报价员本人 KPI、汇总行、本人超时明细查自己的月份 / 日期 / 单号 / 业务员；导出本人看其他报价员；改「报价员」筛选（锁定本人或隐藏该项）
上级（主管 / 组长）本人 + 组织树上下级（直接和间接下属）在可见人员里筛选、下钻、导出看平级或其他分支
报价主管 / 部门负责人 / 管理员全部报价员筛选、下钻、导出全量—

合计 / 整体行只在当前用户可见范围内重算。管理员看全部时，合计才是全员口径。导出 Excel 与屏幕可见范围相同，不得带出无权限行。

名词解释

词口径
重提时间本轮业务员最后一次正式提交的时刻。首次正式提交也算这轮的重提时间。草稿、打回前、撤回前的提交作废，不参与计时。
报价完成时间散货：报价员「核对确认」保存成功的时刻；AI 失败改走人工「报价」时，取该次提交时刻。整柜：全部手报方案提交完成的时刻。
有效询价进 KPI 分母的单。不是系统里全部询价。条件见下文「什么算有效」。
有效时长（报价完成时间 − 重提时间）− 与午休 11:30–13:00 重叠的分钟。结果小于 0 时按 0。
超时有效时长 > 20 分钟。
达成率（有效票数 − 超时票数）/ 有效票数 × 100%。即 20 分钟内占比。
完成路径散货：AI核对 / 人工兜底。整柜：手报价。散货不用报价方案个数判断是否完成。
统计归属月按有效轮次的重提时间落在哪个自然月。

三、功能逻辑

功能点说明原型
什么算有效
  1. 散货同时满足：重提时刻在 09:00–18:00；重提时刻不在 11:30–13:00；报价员已核对确认，或 AI 失败后的人工报价已提交。
  2. 整柜同时满足：重提时刻在 09:00–18:00；不在午休；全部手报方案已提交。
  3. 以下不算有效，不进分母：未重提（草稿、打回后未重提）、时段外或午休重提、仍停在待报价 / AI待确认、全渠道价未齐还不能核对、只试算未核对、已打回且本轮未重提。
  4. 已完结（已绑运单）仍算有效，时长沿用首次核对确认，绑单不延长、不重算。
  5. 测：Given 询价停在 AI待确认 When 打开当月看板 Then 该单不进有效票数。
 KPI
计时 改
  1. 起点一律是重提时间。打回前的等待不算进报价员考核。
  2. 终点散货 = 核对确认保存成功（列表变为已报价，业务员见到人工已报价）。AI 失败走人工报价时，终点 = 该次报价提交。
  3. 终点整柜 = 全部手报方案提交完成。
  4. 午休：过程与 11:30–13:00 有重叠就扣掉重叠分钟。整段跨过午休扣 90 分钟。
  5. 有效时长 = (终点 − 起点) − 午休重叠分钟，小于 0 记 0。大于 20 为超时。
  6. 不改终点：业务员「确认报价」；绑运单 / 改绑 / 解绑；核对之后再撤回再核对（仍以首次核对关账）。
  7. 示例：09:00 提交 → 打回 → 09:40 重提 → 09:55 核对确认。时长从 09:40 起算，15 分钟，未超时。
  8. 测：Given 11:00 重提、13:25 核对确认 When 计算 Then 扣除午休 90 分钟，有效时长 55 分钟，记超时。
 散货核对确认
查询与 Tab
  1. 入口：报价时效统计看板。默认散货、默认统计月份。
  2. 点「查询」：按月份（及可选日期）、报价员、是否超时、单号、业务员重算 KPI 和汇总。标题带上当前范围，例如「2026年7月 · 散货 · 全部报价员」。
  3. 统计日期不在所选月份内：不刷新数据，提示「统计日期须在统计月份内」。
  4. 重置：月份回到默认月，其余筛选项清空，收起明细，再查一次。
  5. 切换散货 / 整柜：沿用当前筛选项重算，收起明细。
  6. 测：Given 统计月份 2026-07、统计日期 2026-08-01 When 点查询 Then 出现上述提示，数字不变。
 查询
下钻超时明细
  1. 仅超时票数 > 0 的报价员行可点。票数为 0 的行不可点，姓名为普通文字。
  2. 点开后，明细插在该行正下方，只列有效时长 >20 的单。20 分钟及以内的单不下钻、不出现在这张表。
  3. 再点同一行或点「收起」则收起。同时只展开一行。
  4. 无匹配超时单时，展开区文案：「暂无超时明细」。
  5. 测：Given 某报价员超时票数为 0 When 点该行 Then 不出现明细。
 汇总行
月度考核
  1. 不选统计日期时，KPI 与合计行就是该月、当前 Tab、当前可见范围的整体结果。
  2. 个人达标：该报价员行达成率 ≥90%。整体达标：合计行达成率 ≥90%。
  3. 平均时长不单独决定达标。85% 到 90% 之间标「接近」，考核结论仍是未达 90%。
  4. 有效票数为 0：达成率「—」，考核结果「无有效票」，不显示「未达标」。原型演示数据分母都不为 0；分母为 0 时原型目前会显示 0% 和「未达标」，开发以本条为准。
  5. 示例：散货 7 月有效 532、超时 45 → 达成率 91.5% → 达标。
  6. 测：Given 可见范围内有效 10、超时 0 When 看合计 Then 达成率 100.0%，考核结果达标。
 考核结果
导出
  1. 入口：筛选区「导出 Excel」。
  2. 导出当前查询下、当前用户可见的汇总；若某行已展开，一并带出该行超时明细。未展开的人不带明细。
  3. 文件只含有权数据。无权时按钮不可用，不给空文件。
  4. 原型此按钮为占位，不生成真实文件。
  5. 测：Given 报价员登录 When 导出 Then 文件只有本人一行。
