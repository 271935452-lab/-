地址库沉淀 V2 · 验收用例

需求口径对应 报价 V2 · PRD 交互稿；Given / When / Then 与勾选验收在本页维护。

一、业务员询价

通过编号Given / When / Then
TC-XJ-01Given 业务员未填详细地址 When 保存 Then 提示「请填写详细地址」并标红。
TC-XJ-02Given 库中已有同邮编+门牌主档 When 打开询价编辑 Then 地址类型默认带出库中一级场景（可改）。
TC-XJ-03Given 邮编门牌未命中 When 提交询价 Then 新增 ADDR 主档且状态为待报价核实。
TC-XJ-04Given 询价单已业务员确认报价 When 点一键下单（PC） Then 下单页重量/客户/产品/地址/备注/附件已回填且可改。
TC-XJ-05Given 提交时命中地址库已有主档且报价员已核对确认 When 打开询价详情 Then 展示渠道单价与「地址提示」整块。
TC-XJ-06Given 提交时未命中、新建 ADDR 主档且报价员已核对确认 When 打开询价详情 Then 仅展示渠道单价，无「地址提示」区域。

二、报价员核实

通过编号Given / When / Then
TC-QT-01Given 新地址且无库中核实迈数 When 未点「确认核实」点核对确认 Then 拦截并提示须先完成地址核实。
TC-QT-02Given 海外已核准一级场景 When 打开报价员详情 Then 类型只读、不需再核实。
TC-QT-03Given 确认核实完成 When 核对确认 Then 状态→待海外核准；各行核实迈数写入地址库。

三、港后沉淀

通过编号Given / When / Then
TC-OS-01Given 私卡派 When 出库登记未填一级场景 Then 不可确认出库。
TC-OS-02Given 非私卡派 When 出库登记 Then 地址补录区灰显、不写库。
TC-OS-03Given 私卡 POD When 缺客户特征或外景必传 Then 不可确认上传。

四、地址库与预设

通过编号Given / When / Then
TC-ADDR-01Given 管理员修改二级场景用途 When 保存类型预设 Then 卡派出库二级下拉即时生效。
TC-ADDR-02Given 仅轨迹更新无字段完善 When 查看主档 Then 「最近核准」时间不变化。
