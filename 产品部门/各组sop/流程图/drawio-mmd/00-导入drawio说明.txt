产品部门 · 全流程大图包小图 · 导入 draw.io
==========================================

目录：产品部门/各组sop/流程图/drawio-mmd/
配套页：产品部门/各组sop/产品部门-全流程-drawio代码包.html（一键复制）

【推荐】draw.io 插入 Mermaid
1. 打开 https://app.diagrams.net 或桌面版 draw.io
2. 菜单：排列 → 插入 → 高级 → Mermaid…
   （英文：Arrange → Insert → Advanced → Mermaid…）
3. 打开对应 .mmd → 全选复制 → 粘贴 → 插入
4. 建议：每个 .mmd 单独一页（File → Page）或单独文件，不要塞进同一张画布

【文件清单】
00-L0加L1-HTML对齐.mmd       … ★ 推荐：L0阶段条 + L1泳道矩阵（对齐评审 HTML）
00-L0-主链路阶段.mmd          … 仅 L0
01-L1-部门泳道矩阵.mmd        … 仅 L1
02-H-跨组交接.mmd             … H1～H8
10～17-L2-S*.mmd              … 各阶段小图
G1～G5-*-组流程.mmd           … ★ 按责任组拆分的全组流程图（HTML 见 流程图/G0～G5）

【嵌套关系】
L0 → L1（矩阵格 = 小图名）→ 各 L2 .mmd
或：L0 → 按组 G1～G5（组内串起该组相关 S）→ 细节仍可回 L2
跨组只用 H 交接图，勿在 L1 上拉斜线

【泳道色（插入后可手调）】
报价橙 #FFF3E0 / 风控紫 #F3E5F5 / 船务蓝 #E3F2FD / 关务青 #E0F7FA / 海外红 #FFEBEE

【备选】mermaid.live 粘贴 → 导出 SVG → 拖入 draw.io
