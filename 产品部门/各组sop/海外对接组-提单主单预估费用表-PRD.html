提单主单预估费用

口径来源：卢慧恒 2026-08-07 上午沟通 · 「以上是提单的预估」

打开原型 产品导航

1. 背景与目标

  • 仓位表人员预估不了：头程金额不由仓位手工填写，系统按价表自动带出。
  • 范围仅覆盖提单/主单侧预估（头程、拖车、装卸、报关、查验、税金/关税）。
  • 海外仓费用、海外实际费用按运单维见「尾程预估费用表」（卢慧恒 8/7 10:20）。
  • 取消 IT 操作费，不再进入标准固定费与预估合计。

2. 头程价表（四维）

唯一匹配键：代理 × 船司 × 始发港 × 柜型。维护有效期与金额；匹配失败主单标「缺规则」。

3. 固定费

  • 维护一套标准固定费。
  • 与标准不一致的按代理/船司/航线等维护差异覆盖项。
  • 交互：标准与差异分栏，避免混在一张大表里难改。

4. 拖车

  • 按拖车堆场分类维护价格；并支持省 / 市 / 区维度预估。
  • 有工厂地址即有预计拖车费；无地址则无法出拖车预估并告警。
  • 可按船司 + 港口提前分配拖车行；船司拖车可按代理 + 船司固定。
  • 改拖车行 → 预估同步重算（确认后刷新拖车及关联装/卸柜口径）。

5. 装柜 / 卸柜

装柜费、卸柜费进入预估合计（与拖车/工厂环节关联）。

6. 报关 / EDI / 买单件

  • 报关：标准票按标准价；改合票允许数据略有差额。
  • EDI：按舱单份数计费，约 ¥10 / 份。
  • 买单件：易漏登，缺件标红提醒。

7. 查验 / 税金 / 关税

  • 支持查验费用登记；是否进预估用开关，待业务最终确认。
  • 清关：维护税金单与查验费；关税进入提单预估。

8. 实际差额

主单实际费用与预估有差异、账单有差额时，默认排查实际代理出错；登记原因并可催代理核对或调整预估口径。

9. 原型信息架构

  1. 主单预估清单（自动汇总 + 明细抽屉）
  2. 头程价表维护
  3. 固定费标准 / 差异
  4. 拖车价表（堆场 · 省市区 · 船司分配试算）
  5. 报关 · 查验 · 关税
  6. 实际差额
