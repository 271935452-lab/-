产品部门 · 复杂泳道导入 draw.io 说明
================================

文件：产品部门-复杂泳道全图-drawio.mmd
（与评审版「① 复杂泳道全图」一致；资料员+舱单/AMS/ISF 在关务）

触发已拆分（非同时）：
  T1 询价 → 私卡
  运价上系统 → 价目维护（不定期，下单流程外）──引用──┐
  T1 询价 → T2 客户下单 → T3 到仓（到仓在下单之后）
  T2 后并行 → 船务引用运价·播报/订舱 ∥ 推送资料→报关行对接
  T3 后并行 → 仓库拍照→风控查货 ∥ 资料员出单（出单依赖到仓）
  船务主链 → 引用运价订舱 → 配舱…；取消IT标记 → 提醒关务清关
  船务区内（紫虚框）→ 运价上系统 · 出货要求沉淀 · 进口商管理 · 仓位表/装柜计划表上系统（虚线引用，不串主链）
  关务出口后 → 目的港清关（资料/税金→清关行→放行）→ 海外派送

【推荐】draw.io 直接插入 Mermaid
1. 打开 https://app.diagrams.net 或桌面版 draw.io
2. 菜单：排列 → 插入 → 高级 → Mermaid…
   （英文：Arrange → Insert → Advanced → Mermaid…）
3. 用记事本打开 .mmd，全选复制，粘贴到对话框
4. 点「插入」
5. 插入后可按泳道改颜色、拉间距

【备选】mermaid.live 中转
1. 打开 https://mermaid.live
2. 粘贴 .mmd 内容
3. Actions → SVG / PNG 导出
4. draw.io：文件 → 从设备导入 / 拖入文件

【读图】
- 实线：组内主流程
- 虚线：跨组交接（报价挂运单、舱单状态只读等）
- H1 授权 → 订舱信息可供出单引用 → H3 同柜 → H5 放行 → H6 改配 → H7 通知
- 出单触发 = T3 到仓（非 T2 下单）
- 泳道底色：报价橙 / 风控紫 / 船务蓝 / 关务青
- 黄底文本框（📌）= 各组重点系统介入
- 红框 = 物理堵点；紫虚框 = 流程外主数据；⏱ = 平均耗时（估算）
