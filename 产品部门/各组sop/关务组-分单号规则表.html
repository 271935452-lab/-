关务组 · 分单号规则表（船司 × 港口）

来源：部门问题汇总表 · 关务问题「分单号数字多录少录」。 目标：系统按船司+港口自动生成分单号 → 再据系统分单号做资料 → 省去逐票手工绑定。

硬约束：分票顺序写错可接受，但分单号必须与舱单数据一致，否则会改运抵。 华南不做资料，报关资料打包给报关行，系统分单号直接以单号为准。
可自动生成 规则明确，系统可配置 需人工申请/手填 规则例外，保留手动 特殊策略 华南等非标准做资料路径

一、分单号生成规则主表

「主单」= 提单号（MBL/提单号本体）；「第 N 票」按同柜/同合并报关组内报关件序号。

例：提单 …9 → …0 / …1 / …2		 配置：删末位 + 数字序号（从 0）

二、规则类型抽象（便于系统配置）

建议做成「船司 + 港口 → 规则模板」配置表，模板参数化，避免写死代码。

模板编号 模板名称 逻辑 适用（本表）
T1 删末位 + 数字序号 base = BL[:-1] → base + start, start+1… 美森·上海（start=0）；COSCO/OOCL·青岛（删末位0，start=1）
T2 整单后缀字母 BL + A/B/C/D…（每票都加） 美森·宁波；以星·宁波；COSCO/OOCL·宁波/厦门；WHL·宁波/厦门；EMC·宁波
T3 第1票=主单，其后加字母 票1=BL；票N=BL+字母 合德
T4 第1票=主单，其后加两位数字 票1=BL；票N=BL+01/02/03… COSCO/OOCL·上海
T5 去片段 + 特殊后缀 去 GLV 后加 A01/A02…（第1票保留主单） EMC·上海
T6 去前缀 + 后缀字母 去 EGLV 后加 A/B/C… EMC·青岛
T7 人工申请 / 手填 无公式；可从申请池选用或借用他票 以星·上海；WHL·上海
T8 等于系统单号 不做资料路径；分单号=单号 华南

三、现状 vs 目标操作

现状
自己先填分单号
→ 做资料
→ 再系统逐票绑定
→
目标
系统按船司×港口自动生成
→ 按系统分单号做资料
→ 去掉逐票绑定

四、落地两个难点（须产品确认）

  • 难点1 · 格式多变 / 准确率：可自动规则走配置表；以星上海、WHL上海等保留手动填写；申请类在放舱节点提醒。
  • 难点2 · 合并报关分柜装：自动生成前/绑定时，若识别为分柜装，须提示避免重复报关（此为分单号自动生成的附带校验；与报关管理「按合并报关列表聚排」是不同需求）。

五、生成与校验清单（建议写入系统）

# 检查项 说明
1 船司 + 起运港命中规则 未配置港口时：阻断自动生成，强制手填并告警
2 模板 T7 不自动生成 以星上海 / WHL上海 → 手填或从申请池选择
3 分单号 ↔ 舱单一致 硬校验 不一致则提示将导致改运抵，禁止静默提交
4 合并报关分柜装提示 生成/推送前展示同组柜号与报关责任人；未指派不可推送
5 允许手动覆盖 自动结果可改；改后标记「人工覆盖」并留痕
6 华南走 T8 不做资料；分单号=单号；跳过 Excel 做资料路径
