0729 大致方案 · 查验通知 / 合并报关同柜 / 授权抬头

调研日：2026-07-29 上午 · 大致方案（可评审、未定稿）。 口径：报关行通知 → 开船前一天告客户；合并报关尽量同柜，分柜装我司担风险；授权须与报关抬头一致；清关过久可加改港费。 关联： 0729 上午摘录 · 关务组总结 · 改配三类 · 资料核准 · 线下三表

① 范围与 P0 ② 查验 ③ 同柜 / 分柜装 ④ 授权抬头 ⑤ P1 附项 ⑥ 衔接与待确认

① 方案范围 · 三件套优先

先做能立刻降漏通知 / 降分柜风险 / 降侵权硬过的三件事；其余挂 P1。

P0 查验一键发客户

  • 报关行通知入库
  • 关务一键触达客户
  • 开船前一天自动提醒
  • 查验天数可见

P0 合并报关同柜强提示

  • 排柜/装柜确认卡控
  • 分柜装 → 强提示我司风险
  • 需勾选确认才可继续

P0 授权 + 抬头校验

  • 客户上传授权附件
  • 授权主体 = 报关抬头
  • 不一致不可硬过
  • 挂资料核准必比项
落点建议：查验挂「报关管理 / 柜子详情」；同柜校验挂「装柜表 / 排柜确认」；授权挂「资料核准工作台 + 客户上传」。

② 查验通知与处置 P0

核心链路：报关行通知 → 我司登记处理 → 开船前一天通知客户；系统补「一键发客户 + 查验天数」。

④ 品牌授权 · 抬头校验 P0
