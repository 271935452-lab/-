查货操作 · 产品确认 / AI识图（合并）

仓库拍图后默认自动 AI 识图并回传风控；产品确认与识图合并为逐条确认工作台。

NEW改

改 · 拍图自动识图 + 产品确认合并

  • 仓库完成查货拍图上传后，系统默认自动调用 AI 识图，结果直接回写列表（识图状态 / 建议品名 / 匹配度 / 品牌 / 是否侵权 / 是否带电），风控同事无需再点「触发识图」。
  • 喂给 AI 的输入：查货图片、下单/申报品名、品牌名、是否侵权（申报/历史标签）、是否带电等上下文；AI 结合图片与文本交叉校验后回传。
  • 主入口「产品确认（逐条）」= 识图确认 + 产品确认：打开侧栏逐票看图 → 核 AI 结果 → 改/采纳品名 →「确认并下一条」；同屏可勾选查货标记并「扣件确定」（看图即判场景整合）。
  • 扣件整合口径：日常「边确认边扣件」整合进确认侧栏；「+ 查货扣件」仍保留给批量/只扣不确认场景。子单级精细标识（行内「标识」）复杂批处理可继续用独立扣件弹窗（现网）。
  • 确认后回写：主品名、产品已确认、核对人/时间/备注；队列自动进下一条，直到本批结束。
  • 页签「待确认」= 有图且待核票；「多品名」= 单独页签，汇集实核品名>5 / 已打多品名标记 / 已加超品名费的票。
  • 「子单批量确认」保留现网子单表批量能力（可选）；日常以逐条为主。

现网能力

  • 筛选：到货时间、产品组、运单号、销售产品、客户、到货网点、终配舱单号、扣件状态、记录状态、查货员、业务员、客户类型等。
  • 按钮：查询、查货扣件、查验扣件放行、产品确认、批量修改附加服务（改：回显已有、可勾选可勾除，对齐运单管理）、多品名加费确认、添加成本费用等。
  • 状态页签：全部 / 查货中 / 查货扣件中 / 产品已确认 / 已退件。
  • 列表列：状态、收货时间、客户单号、运单状态、查货率、计费重、件数、扣件状态、客户简称、主品名、查货标记/备注/员/时间、核对人/时间/备注、附加服务、各类备注、收货仓、销售产品、业务员/客服、客户类型、业务类型、报关编号、终配舱单号、财务、所在仓、创建人/时间。

NEW · AI识图 / 品名识别（自动回传）

  • 触发：仓库拍图上传成功 → 自动识图（非人工批量按钮）。
  • AI 输入（喂给模型）：① 查货图片；② 品名（下单/申报）；③ 品牌名；④ 是否侵权（申报侧/历史）；⑤ 是否带电；及其他必要上下文（客户类型、销售产品等可扩展）。
  • AI 输出（回传风控）：识图状态、建议品名、匹配度、识别品牌、侵权风险结论、带电判断、品名识别状态。
  • 列表列：AI识图状态、查货图、AI建议品名、匹配度、品名识别状态、AI识别品牌、侵权/带电结论。
  • 人工确认入口合并进「产品确认（逐条）」侧栏。

改 · 批量修改附加服务（勾选 / 勾除）

  • 问题：现网「批量添加」每次打开空白刷新，不展示已有服务 → 无法取消，且可能重复加收；取消只能去运单管理 / 业务数据统计。
  • To-Be：与运单管理附加服务同理——打开回显已有；勾选=增加，取消勾选=移除。
  • 多票：全有勾选、全无空选、部分有半选；半选未改动则该服务对各票保持原样。
  • 确定时按「新增 / 移除」差分写入，列表「附加服务」列即时更新；多收费项仍建议配合「添加成本费用」落业务数据统计（勾选 ≠ 自动计费完毕）。

NEW · 多品名加费确认（确认后自动加费）

  • 入口：工具栏「多品名加费确认」；列表页签「多品名」单独汇集；产品确认侧栏亦可进入。
  • 规则：实核品名数 > 5 → 多品名；超出个数 × 30 CNY = 超品名费；包装类型必选（包装 / 分开包装）。
  • 品名清单：AI 建议可一键填充，支持增删；改数后重算费用预览。
  • 确认后自动：打「多品名」标记、勾选附加服务示意、写入超品名费到业务数据统计（直客→业务成本；同行→应收+成本），无需再手工加费。
  • 若未超限（≤5）：确认只落标记/包装类型，不加费。

NEW · 添加成本费用

  • 工具栏入口「+ 添加成本费用」；对勾选运单批量添加（产品确认时可直接备注，免找客服/业务）。
  • 筛选 / 列：成本费用状态与摘要。
  • 同行：写入对客应收 + 成本；直客：写入附加服务业务成本（查货费可加应收）。
  • 支持超品名费：默认单价 30，按超出个数加收。
  • 与「批量修改附加服务」区分：本入口强调计费落账进业务数据统计。

改 · 产品确认（逐条为主 · 子单批量为辅）

  • 主入口：「产品确认（逐条）」→ 侧栏队列，确认并下一条。
  • 可选：「子单批量确认」仍用现网子单表弹窗。

改

  • 识图改为仓库拍图后自动触发；人工侧重点从「触发识图」变为「核图确认」。
  • 主品名：采纳 AI 建议后回写（需人工确认，AI 不作唯一卡控）。

NEW · 侵权查询 / 罚款 / 告知

  • 侵权查询链路：AI识别品牌 →「品牌侵权查询」→ 看图结论 → 外链查询（可放行/需授权/确认侵权）→ 授权比对或扣件处置。
  • 罚款500：确认侵权 → 扣件并加收「侵权罚款」500 CNY/票（成本费用列标红），状态改查货扣件/退回。
  • 扣货风险告知：涉证场景「扣货风险告知」→ 固定文案「涉证/扣货风险已告知客户与业务员；扣货不赔」→ 发送预览 → 行标记「已告知」。
  • 授权衔接收关：需授权时上传「品牌授权书」+ 授权主体 vs 报关抬头比对；附件类型同步至做资料分票核准「品牌授权比对」硬卡。

业务规则

  • 匹配度 ≥90%：可批量确认；70～89% 待人工；<70% 标红建议重拍/手填。
  • 疑似品牌 → 走侵权查询链路（见上方 NEW 节）。
  • 识别结果沉淀品牌/品名库，供后续智能体与历史对照。
