1. 页面目标

替代手工筛表：在已签入运单范围内，按仓库 / 查货员 / 日期汇总查货情况，核对查验空白与保函附件，统计漏查与查货率；支持下钻明细、导出与趋势图。目标查货率 100%（应查尽查）。

本 PRD 只描述报表本身；查货操作如何录入、品名库如何沉淀不在本文范围。

2. 查询条件（每个字段说明）

筛选区确定统计范围；点「查询」刷新 KPI、汇总表或趋势图；「重置」恢复默认。

字段控件说明默认 / 备注
收货仓 下拉 按运单收货仓过滤。选具体仓时：仓库维只显示该仓；查货员维只显示该仓下查货员；趋势图按该仓汇总。 全部仓库

3. 统计维度 Tab（每个维度说明）

维度用途汇总逻辑可下钻
查货率趋势（默认首页签） 柱状图看趋势 隐藏汇总表，展示趋势图；维度见 §7（总票数 / 漏查票数 / 查货率）。时间由「统计粒度 + 月份/周次」选定，无起止日期筛选 无表下钻
按仓库 看各收货仓查货率是否达标 一行一个仓；完整查货率口径（总票/实查/空白/保函/漏查/应查/率） 有空白的行 → 空白票清单
按查货员 看各查货员实查量与不规范标记 一行一个查货员 + 所属仓库；因查完才挂查货员，不算该员总票/空白/率；展示实查票数、不规范票数。顶部 KPI 中仓级指标仍走「仓维口径」 不下钻（仅汇总展示）
按日期 看每日查货率（表） 一行一个自然日；口径同按仓库 同按仓库，下钻空白票

4. 指标口径（公共定义）

适用于 KPI、按仓库/按日期汇总表、趋势图中同名指标。保函以是否已上传保函附件为准，不在报表上手动「标记有保函」。

指标定义 / 公式说明
总票数 统计范围内已签入的运单票数 仅已签入计入；其中查验次数为空的票需结合保函附件判断豁免或漏查
实查票数 查验次数非空的票数 按查货员维：挂到该查货员的实查合计
查验空白 查验次数为空的票数 已上传保函附件 → 计入保函豁免；未上传且待确认 → 可点「确认漏查」；已标无保函 → 已计漏查，无确认按钮
保函豁免 已上传保函附件的票数 计为豁免（正常），不计入漏查，从应查中扣除
漏查票数 查验空白 − 保函豁免 空白且未上传保函附件
应查票数 总票数（已签入） − 保函豁免 分母口径
查货率 实查票数 / 应查票数 × 100% 目标 100%；应查为 0 时按 100% 展示
达标 查货率 ≥ 100% → 已达标；否则 未达标 仅两态，无「接近」
不规范票数 该查货员标记为「不规范」的运单数 仅按查货员维；数据来源：查货操作中的查货员标记，按标记人汇总

10. 验收要点

  • 总票数口径为已签入；保函豁免口径为已上传保函附件。
  • 漏查 = 空白 − 保函豁免；查货率 = 实查 / 应查；达标仅「已达标 / 未达标」。
  • 空白票清单无「有保函」操作；无保函行无「确认漏查」；待确认行确认漏查后漏查增、率下降。
  • 空白票清单附件列：有保函附件时可预览、下载；无附件显示「—」。
  • 仅看未达标仓能筛出率 < 100% 的仓/日期行。
  • 按查货员表含仓库列，且受收货仓筛选；含不规范票数，不下钻。
  • 趋势页签为默认首页签：顶部可选按月度/按周及月份/周次（无起止日期筛选）；图含总票数、漏查票数、查货率三组柱。
  • 工具栏有「导出本周」「导出当前列表全部 sheet」；无「导出漏查明细」、无单独「仓库查货率模板」。
  • 切换维度后 KPI 与表体一致；查询 / 重置行为符合 §2、§9。
