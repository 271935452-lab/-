添加成本费用 · PRD

2026-08-20 · 弹窗原型： 查货操作原型 · 主 PRD： 7.2 节

一、页面职责

本弹窗用于查货操作中对一批或单票运单写入业务数据统计层面的成本/应收费用。 与「批量添加 / 修改附加服务」不同：本入口直接落账，不写入列表「附加服务」勾选项。

核心区分：附加服务弹窗 = 改列表附加服务列；添加成本费用 = 改成本费用列 + feeItems[] 明细。

1.1 入口

入口前置条件带入数据
工具栏「+ 添加费用」 批量模式 ≥1 票勾选；单票模式恰好 1 票勾选 勾选运单进入「适用运单」表格，默认全选
产品确认侧栏底部「添加费用」 操作台已打开 本批队列全部票，默认全选
列表行操作「加费用」 无模式限制 仅当前行 1 票

1.2 弹窗通用规则

  • 标题：添加成本费用 NEW
  • 点击遮罩不关闭；仅「关闭 / 取消」可退出（与查货模块其他弹窗一致）。
  • 顶部黄条「写入规则」只读说明，不参与提交。
  • 底部绿色「预览写入」随表单实时刷新，确认前可核对摘要。

二、字段与交互（逐项说明）

下表与原型弹窗自上而下顺序一致；开发按表实现，测试按「验收要点」逐条过。

2.1 写入规则（黄条 · 只读）

说明项规则
直客只加业务成本（列表 已加业务成本）
同行加成本 + 应收（列表 已加应收+成本）
费用录入每行下拉选费用类型 + 填金额；「+ 添加费用类型」可增行；不写入附加服务列
主品名数 >5列表标红提示；可选「多品名费30/个」并手动填金额；暂不支持「超出个数」自动计算
附加费备注与侧栏「风险告知」分离；21 条 QUICK_FEE 快捷语；勾选后双通道通知

2.2 适用运单 改

项交互验收要点
表格列勾选、客户单号、客户、主品名、客户类型、计费重与带入运单一致；可滚动
默认勾选打开弹窗时全部勾选计数「本批 N 票 · 已选 N」
勾除可取消部分运单，仅对仍勾选票写入预览区「共 M 票」随勾选变化
全选 / 全不选表格上方快捷按钮即时刷新计数与预览
校验确认写入时至少保留 1 票勾选0 票 → toast「请至少勾选 1 票后再写入费用」

2.3 客户类型

项交互验收要点
控件下拉：直客 / 同行可改
默认值取「适用运单」第一票的客户类型打开弹窗即展示
联动切换后刷新「写入去向」与预览见 2.4
写入确认时对勾选票回写 custType（若与现值不同）—

2.4 写入去向（只读 · 自动）

客户类型展示文案列表 costFee
直客直客 → 仅业务成本已加业务成本
同行同行 → 成本 + 应收已加应收+成本

不可手选去向；仅随「客户类型」自动计算。

2.5 费用类型 + 金额 改

项交互验收要点
布局表头：费用类型 | 金额 | 删除至少保留 1 行
费用类型下拉，14 项正式清单（见 主 PRD 8.1）未选类型时金额 disabled
金额数字输入，>0选手输；多品名费不自动按个数×30
增行「+ 添加费用类型」可多行；每行独立类型+金额
删行行末「−」仅 1 行时删除按钮 disabled
去重同一费用类型不可选两次已选类型在其他行下拉中 disabled；重复提交 toast 拦截
已选摘要绿条「费用类型 已选：…」实时展示各类型 + 金额 + 币种
不写入—不勾选/更新列表「附加服务」列

2.6 附加费备注 NEW

项交互验收要点
区块标题附加费备注 · 附加费 · 下拉多选与侧栏「风险告知」词表分离
词表QUICK_FEE 21 条（主 PRD 8.3）下拉多选；交互同风险告知；无手输备注框
可选可不选任何快捷语，仅写费用预览不展示「附加费备注 N 条」
勾选后确认写入时双通道通知（企微 + 系统消息）不回写列表「风险告知」；写入 feeRemarkPhrases / 费用记录

2.7 币种

项规则
选项CNY / USD
默认CNY
作用范围同一次确认写入的所有费用行共用同一币种

2.8 预览写入（绿条 · 只读）

实时拼接：各费用行「类型 + 金额 + 币种」→ 写入去向 → 勾选票数 →（可选）附加费备注条数 →（可选）本批勾除提示。

示例：多品名费30/个 120 CNY → 直客 → 仅业务成本 · 共 3 票 · 附加费备注 2 条

三、按钮与校验

按钮行为校验 / 结果
关闭 / 取消 关闭弹窗，不写入 已填内容丢弃（原型无草稿）
确认写入业务数据统计 对勾选运单追加 feeItems[]；刷新列表成本费用列；双通道通知 ① ≥1 票勾选
② ≥1 项费用类型且金额 >0
③ 费用类型不重复
④ 附加费备注可选

四、写入后联动

对象变化
列表 · 成本费用costFee / costLabel 更新摘要
feeItems[]每费用行追加一条：{ 类型, 金额, 币种, 去向, 来源=添加费用, 时间, phrases? }
侧栏 · 已添加费用若从操作台打开，④ 下方块即时刷新
风险告知列附加费备注勾选不回写「风险告知」
通知写入通知列表 + 企微私聊；企微收件人取员工管理 · 企微名称（见 主 PRD 7.5.2）
附加服务列不变
