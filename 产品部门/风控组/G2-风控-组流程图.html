步骤 ↔ 页面 / 功能对照表

流程节点 对应页面 功能点
1仓库拍图 · 自动 AI 识图 查货操作 · AI 回传列 仓库完成查货拍图上传后，系统自动调用 AI 识图，识图状态 / 建议品名 / 品牌 / 侵权·带电等结果回传列表（无需人工「触发识图」）
2产品确认 · 看图卡点 查货操作 · 产品确认侧栏 风控核图确认：须点图逐票点开 ≥1 张查货图；确认时中英文品名置灰只读；风险告知快捷语
3品名库查询 → 自动 / 手标沉淀 品名库 · 七类合规标记 命中：自动带出合规标记到确认侧栏；未命中：人工勾选标记后沉淀回品名库，形成闭环
4额外服务和扣件标记 确认侧栏 · 额外服务和扣件标记 附加服务：14项正式清单全部平铺；附加费通知口径在「添加费用」下拉；资质快捷语在确认侧栏；扣件标记：违禁/瞒报/授权等
5附加费 / 扣件判断 查货操作 · 工具栏批量/单票 批量添加附加服务（≥2 票）/ 修改附加服务（1 票）；弹窗回显已有，勾选↔费用，多品名费除外
6添加费用 · 入账 查货操作 · 添加费用 批量默认全选可勾除；主品名数>5 仅列表标红，超品名费在此手动加；双通道通知
7扣件 查货操作 · 扣件确定 查货标记勾选 + 扣货快捷语；状态→查货扣件中；企微+系统消息
8侵权 · 授权/罚款 待定 查货操作 · 品牌侵权/授权查询 原型逻辑待定：外链查询 / 授权比对 / 罚款500 等流程尚未定稿，评审勿当作已确认方案
9其他扣件处置 查货操作 · 查货标记 违禁品 / 瞒报 / 授权类等标记处置
10查货扣件中 列表页签「查货扣件中」 扣件未放行状态跟踪
11查货扣件放行 工具栏 · 查货扣件放行 仅查货相关放行；完成后企微私聊 + 系统消息
12产品已确认 确认并下一条 确认队列逐条处理；页签「产品已确认」
终配舱 船务 / 关务 · 终配舱单 查货完结后进入终配舱；旁路仅推未扣件资料给报关行
旁路 · 终配舱推送 关务 / 报关侧（跨组） 仅推未扣件资料；再次扣件时旁路拦截 → H2 交关务
配套报表 操作查货率报表 总票 / 保函 / 漏查等统计（不在主干节点上，配套查看）
