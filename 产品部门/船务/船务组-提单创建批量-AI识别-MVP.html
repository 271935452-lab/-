字段映射说明
  • B/L No / Booking No → 提单号
  • Container / Seal → 柜号（多柜拆多行，同提单号）
  • Size/Type → 柜型（20GP/40HQ…）
  • POL / POD → 国内出发港口 / 国外到达港口（码表匹配）
  • Carrier / Vessel / Voyage → 船公司、船名航次
  • ETD / Sailing → 开船时间（只保留月-日，如 08-12）
  • Cut-off / 截单 → 截单时间（月-日 + 时:分，可空）
  • Loading / 装柜 → 装柜时间（月-日 + 时:分，可空）
  • Ocean Freight → 海运费；Free time → 国内/国外免用箱天数（分两格），缺省须手补
  • Transhipment / Via → 中转港（非必填）；Remark → 备注（非必填）
