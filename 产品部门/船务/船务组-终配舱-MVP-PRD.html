3.2 自动配舱（后台规则，无配置页）

终配保存时系统自动跑。待配仓只负责勾选、改预配舱号；规则说明弹窗在本页。

功能点说明原型
渠道
  1. 先按渠道/仓口切开。不同渠道不混一柜，混了不让保存
  2. 测：不同渠道各有合并报关 → 不混柜
规则说明
定档
  1. 每票只进一档，自上而下先匹配：① 合并报关 → ② 服装 → ③ 托盘 → ④ 报关件 → ⑤ 买单
  2. 多标签取最高档（服装且合并报关 → 合并报关）
  3. 托盘/合并报关/报关件/买单走业务标签，不按品名猜
  4. 测：一票服装+合并报关 → 按合并报关装
规则说明
同渠道装填
  1. 先装 1～4 档。当前柜还有空、且前四档都装完了，才用买单补空
  2. 买单不抢前序柜位。一柜须同时满足方数 < 68、重量 < 20 吨；未满才进下一档，顶到上限开新柜
  3. 测：五类货一柜装不满前四档：合并→服装→托盘→报关件→买单补
  4. 测：前四档已满另有买单 → 买单不进该柜
规则说明
配仓上限
  1. 自动装填一柜：方数合计 < 68，重量合计 < 20 吨（< 20000 kg）
  2. 方数取各票未出货方数（落成后看实收方数）；重量取各票未出货实重
  3. 再装一票会达到或超过任一条 → 不进本柜，开新柜
  4. 单票自身已 ≥68 方或 ≥20 吨 → 不自动进柜，手配
  5. 保存时柜内合计 ≥68 方或 ≥20 吨 → 硬拦
  6. 测：柜内已 60 方，再装 8 方（合计 68）→ 不开进本柜
  7. 测：柜内已 19.5 吨，再装 0.6 吨 → 不开进本柜
  8. 测：合计 67.9 方可保存；合计 68 方存不了
规则说明
服装判定
  1. 不用人勾。主品名+各明细品名，任一命中整票算服装
  2. 规范化：去首尾空、去中间空、英文小写、全角转半角
  3. 匹配=包含子串，不做全等、不做拼音/错字
  4. 排除词同时出现则不算（衣架、人台、展示架、模具、缝纫机）。鞋靴、箱包、面料默认不进
  5. 测：男士休闲服装 / 服装 / CLOTHING → 入服装档
  6. 测：电子产品/鞋靴/箱包不入。服装衣架因排除词不入
规则说明
服装词表
  1. 配置表+种子，不要写死代码。通称：服装衣服成衣服饰衣物
  2. 大类：男装女装童装校服制服工作服运动服针织/梭织/休闲服装
  3. 衣裤：上衣裤子裙子连衣裙衬衫T恤卫衣外套夹克大衣羽绒服棉服
  4. 内衣家居：内衣内裤文胸袜子泳装泳衣睡衣家居服
  5. 英文：clothing clothes garment(s) apparel sportswear knitwear
  6. 测：词表可后台增删（本期不做页面）
规则说明
反倾销
  1. 属性标记，不占装填档（仍按合并报关→服装→托盘→报关件→买单定档，反倾销另加同柜约束）
  2. 命中来源：申报/品名带出 或 附加服务手标 或 查货扣件标记，任一命中。本期不做源表维护页
  3. 关务不能改船务打的附加服务 / 扣件标
  4. 同渠道必须同一柜；装不下再开一柜专装，不得掺进已排好的非反倾销柜
  5. 柜内空位默认可按装填顺序补其他货；现场要求专柜则人工确认锁柜
  6. 测：同渠道反倾销两票推荐同柜；拆到多柜保存须强提示
规则说明
保存检查
  1. 跨渠道混柜 → 硬拦。一柜方数 ≥68 或重量 ≥20 吨 → 硬拦
  2. 反倾销被乱拆 → 强提示，确认可保存并记日志
  3. 合并报关拆组 → 待配仓改号时强提醒
  4. 测：混柜存不了
  5. 测：柜内 68 方或 20 吨 → 存不了
规则说明
自动配舱标
  1. 系统按本规则自动装柜并终配落成才打
  2. 纯手配、或自动后又手改再终配 → 不打
  3. 标只展示、不手打。本页单号旁、待配仓配舱状态旁、运单配舱阶段旁能看见
  4. 测：自动落成的青岛T25 有标；手改拆柜后再终配没有

3.3 终配舱号

功能点说明原型
格式
  1. {YYMMDD}-{销售产品名称原文}-{序号}，半角 -、中间无空格
  2. 例 260820-青岛T25-1
  3. 日期=终配落成日（仓库当地），不用 YYYYMMDD
  4. 名称保留空格，不用交货仓名/仓库代码
  5. 一柜只能一个销售产品且不能为空，否则不出号硬拦
  6. 新规则只对新单。存量舱号不动，新旧格式共存，不批量重算
  7. 测：销售产品为空点终配 → 不出号
  8. 测：同日另一产品 T16卡派15 序号从 1 起、与青岛T25 互不影响
终配舱
序号
  1. 同一天+同一销售产品按生成先后 1、2、3… 不补零
  2. 隔天从 1 再起。号一经生成不因改品名改货而改号
  3. 整柜作废后该号不复用，当天后续柜继续往下编
  4. 手改舱号须留痕，不得与已占用号重复
  5. 测：2026-08-20 青岛T25 两柜 → -1、-2
