销售产品 · 报价管理 · 批量调价 NEW

船务侧维护销售产品报价时，支持列表勾选后批量加减价。 对齐现网「批量修改报价」：多选后弹窗内销售产品、所属分公司置灰只读，只改有效期与加减金额。 　原型 　导航 　协议价 PRD

一、筛选 / 列表

功能点说明原型
列表勾选
  1. 报价管理列表支持多选。未勾选时「批量修改报价」灰显不可点
  2. 测：勾 0 条按钮灰；勾 ≥1 可点
 批量修改报价
筛选
  1. 报价编号 / 销售产品 / 所属分公司 / 状态 / 关联客户
  2. 测：按分公司筛后勾选再批量
 查询

二、批量修改报价弹窗

功能点说明原型
销售产品 · 只读
  1. 由列表勾选行去重带出，弹窗内置灰不可改选。要换产品须关闭后重勾
  2. 测：勾两条不同产品 → 芯片展示两个产品名，无下拉
 弹窗
所属分公司 · 只读
  1. 由勾选行带出，置灰不可编辑。同一分公司回显名称；多个分公司只读汇总「多分公司：A、B…」
  2. 测：勾深圳+宁波 → 分公司栏只读汇总，无下拉
 所属分公司
可改字段
  1. 报价开始/结束时间、调整类型（加/减）、调整金额*、关联客户（通用 / 指定客户保持各行）
  2. 测：金额空保存拦住
 调整金额
保存
  1. 仅作用于勾选行：写回有效期、按加/减改单价（示意写入备注）、产品与分公司不变。草稿可升正式
  2. 测：保存后列表备注见 ±金额，产品列未变
 保存

三、边界

  • 不做：在弹窗内重选销售产品 / 分公司；按比重分档；指定格覆盖。
  • 与客户协议价分离：本页改的是销售产品报价底价；协议价折扣/减额见协议价 PRD。
