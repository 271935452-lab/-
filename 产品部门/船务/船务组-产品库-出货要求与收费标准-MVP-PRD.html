口径来源：产品部门/船务/产品库.xlsx（cpsc产品及出货要求 / 附加费清单 / 出货要求及附加表）· 2026-08-20

打开原型 船务导航

1. 背景与目标

  • 现网以 Excel 维护 CPSC 相关品名的仓口出货要求与附加费，文案不统一（「正常出 / 海运鉴定报告msds / 不接 / +2」混写）。
  • 目标：建设标准产品库页面，沉淀「出货要求 + 收费标准」，收费关联附加服务（与风控查货附加服务↔费用同口径），供下单/查货/报关引用。
  • 前置：所有品名规则建立在不能侵权基础上（源表页眉说明）。

2. 信息架构

  1. 产品出货库：品名主数据 + 报关/清关 HS + 清关要求 + 五仓口规则 + 证件 + 收费关联 + 合规策略
  2. 收费标准 · 附加服务：服务码价目（金额/币种/单位/条件/同步费用项）
  3. 字段标准说明：枚举与映射规则（给运营/开发）
  4. 预留：反倾销列表（源表页为空，仅留入口）

2.1 报关 HS · 清关 HS · 清关要求 NEW

字段说明引用方
报关 HS国内出口报关税号；可与清关 HS 不同报关 / 做资料
清关 HS目的国进口清关税号清关行 / 海外 / 进口商
清关要求目的国清关注意点（FDA/EPA/DOT、反倾销、商检、授权信、木质包装等）清关协同 / 下单提示

下单选品名后自动带出；报关用报关 HS，清关用清关 HS + 清关要求。二者均可空，空则人工补录。

3. 出货要求标准

3.1 仓口维度

宁波 · 上海 · 盐田 · 南沙 · 青岛（与 Excel 列一致；可配置扩展）。

3.2 出货结果枚举

枚举Excel 原文映射系统行为
正常出正常出可出，无强制资料
需资料出海运鉴定报告 msds 等须备齐对应证件/报告；资料说明字段存原文要点
有条件出图案不侵权正常出 / 军绿迷彩不接 / 玩具可杀伤力强不行…可出但展示条件；条件不满足则按不接或人工审核
不接不接 / 带气的不接 / 不能出该仓（或全仓）拦截下单

3.3 进口证件标签（多选）

CPSC · UN38.3 · MSDS/海运鉴定 · UL 授权 · ETL · 蓝牙授权 · 商检 · 其他。

3.4 合规策略（源表「要求」列）

  • 可以走，无资质扣货不赔
  • 带电资质不齐全不接；无 CPSC 扣货不赔
  • UL 无授权不接；无 CPSC 扣货不赔
  • 不接

4. 收费标准 · 关联附加服务

4.1 原则

  • 产品行不存散落价文案（禁止长期保留「液体+2」纯文本作为唯一价源）。
  • 产品只选择收费模式 + 附加服务码；金额在附加服务价目统一维护。
  • 命中规则时：自动勾选附加服务 → 同步生成费用项（对齐 8/16 风控「附加服务↔费用」）。

4.2 收费模式

模式Excel 映射关联方式
无附加0 / 未写明不关联服务
固定附加0.5（带电）、3（液体类）关联 1 个服务码，如 AS-BATTERY-05 / AS-LIQUID-3
按属性分段液体+2 膏体+2 固体无附加；液体+4 固体膏体+2按形态属性分别关联服务码

4.3 附加服务价目字段

服务码 · 名称 · 计费方式 · 标准金额 · 币种 · 单位（建议 kg，可配）· 适用条件 · 同步费用项名称 · 状态。

4.4 建议预置服务（来自表内高频）

  • AS-BATTERY-05：带电/电池附加 0.5
  • AS-LIQUID-3：液体类固定附加 3
  • AS-FORM-LIQ-2 / PASTE-2 / LIQ-4 / SOLID-2：形态分段

5. 页面与交互

  • 列表筛选：品名、仓口、出货结果、收费模式、证件、清关 HS。
  • 新增/编辑抽屉：基本信息（含报关 HS / 清关 HS / 清关要求）、五仓口、证件多选、收费模式与服务关联。
  • 导入：支持从 产品库.xlsx 批量导入；导入时做枚举映射与附加服务匹配（匹配失败进待确认）；HS/清关要求列可扩展映射。

6. 与周边模块

  • 风控品名库：合规七类标记可下期；出货/收费/HS 以本产品库为准，查货页引用附加服务。
  • 下单：选品名+仓口 → 展示出货结果 + 报关/清关 HS + 清关要求；不接拦截；需资料出须校验资料。
  • 报关：引用报关 HS、证件与出货结果。
  • 清关：引用清关 HS + 清关要求。

7. 验收要点

  1. 泡泡水：五仓需资料出 + CPSC + 固定附加 AS-LIQUID-3 + 报关/清关 HS 有值
  2. 玩具车（带电）：需资料 + UN38.3/CPSC + AS-BATTERY-05 + 清关要求含电池申报
  3. 数字油画颜料：按属性分段液/膏 +2、固无附加
  4. 弹弓（带钢珠）/ 卡丁车（用油）：不接
  5. 改附加服务价目金额后，所有关联产品下单带出费用用新价
  6. 编辑保存报关 HS / 清关 HS / 清关要求后列表立即展示
