查验标记 NEW

口径（0730）：查验默认挂柜（本提单/柜可见）；若因某票货物导致查验 → 选「查验挂票」，运单侧同步打标，柜上仍可见汇总。

改单标记 NEW

改单＝改截单资料（件毛体、收发通、HS/品名、铅封、VGM、提单号等）。 与改运抵（港区运抵数据）不同。船开前完成；可生成改单/改 VGM 保函。

绑定进口商 · 一水绑柜校验 NEW

散货规则：同一进口商在同一水船（同船名航次）已绑柜数须 ≤ 5。 绑定时按勾选提单所属航次累计校验；超过则强提示。

提单分配 · 发拖车代理群 NEW

像发微信群消息一样：核对信息 → 一键复制 → 粘贴到拖车代理群。分配结果同步写回系统（拖车代理 / 装柜时间 / 地址）。
● 宁波拖车代理群 预览 · 可编辑后复制
复制后可直接粘贴微信/企微拖车代理群；点「确认分配」将代理与装柜信息写回勾选提单。

一键复制仓位播报 NEW

0730：播报现状手动拼 → 系统按勾选/当前筛选提单同船聚合生成文案 （待配仓货量 · 航线截单 · 可选运价摘要）→ 一键复制 → 粘贴集团营销中心群。挤满柜子再排。
● 集团营销中心群 预览 · 可编辑后复制
复制后粘贴企微/微信营销群；文案可改。运价来自运价管理示意价，正式版联动「我司订舱价」。
