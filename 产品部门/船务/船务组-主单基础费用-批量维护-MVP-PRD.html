条件位置说明原型
勾选行 列表
  1. 批量维护前须勾选 ≥1 条；可跨不同服务商勾选
  2. 测：勾青岛港信 + 宁波通航两条点批量维护 → 弹窗正常打开

二、列表字段

现网列（状态 / 生效起止 / 服务商 / 运输方式 / 港向 / 柜型 / 船司 / 费用项等）本期不改。批量不新增列表列。

三、功能逻辑说明

功能点说明原型
批量维护按钮
  1. NEW。工具栏放在「禁用」右侧（查询 / 新增 / 复制 / 修改 / 启用 / 禁用 之后）
  2. 文案「批量维护」，标 NEW
  3. 测：工具栏可见「批量维护」
 批量维护
打开条件
  1. 未勾选 → toast「请先勾选…」，不弹窗
  2. 勾选 ≥1 条（含多个服务商）→ 打开批量维护弹窗
  3. 测：勾青岛港信两条能开；再勾宁波通航一条仍能开（不 toast 拦住）
 批量维护
弹窗 · 服务商置灰
  1. NEW。弹窗结构同「新增 / 修改」（基本费用 + 预付费用项各环节页签）
  2. 单服务商勾选：服务商带出该值，置灰 disabled
  3. 多服务商勾选：服务商显示「多个服务商（各行保持原值）」，置灰 disabled
  4. 运输方式、匹配时间类型、开始时间、各环节费用项等仍可改
  5. 测：批量弹窗服务商无法点开下拉；新增弹窗服务商可选
 弹窗
保存回写
  1. 确定后：勾选行的可编辑字段按弹窗内容回写；各行服务商字段保持原值不变
  2. 必填仍校验（匹配时间类型、开始时间等）；服务商因置灰不参与「请选择」校验
  3. 测：跨服务商批量改开始时间后，勾选行开始时间均更新、各服务商列不变
 确定
与新增 / 修改差异
  1. 新增 / 修改：服务商可选可改
  2. 批量维护：服务商只读置灰；一次更新多条；不要求同一服务商
  3. 复制仍走新增带出，服务商可改
 打开
