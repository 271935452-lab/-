业务要求（评审新增 · 已写入原型）

菜单拆分 提单创建、提单汇总在导航/菜单上单独列出，不与提单管理混为一页；提单管理页不提供「提单创建」主按钮（汇总页只读查询/导出）。
线下表对齐 提单管理、提单汇总列表的列顺序与字段命名对齐当前线下装柜计划表（资料员 → … → 实际离场；含「代理+报关+拖车」合并列名）。
色标一致 提单管理/汇总/创建相关页：行底绿=已装完、行底橙=未装完（仓库可识读）；预配蓝 / 待配橙 / 终配绿 与船务待配仓、终配舱口径一致，不另搞一套色。
组合/终配入口 「需组合配舱号」链待配仓；「最终配舱号」链终配舱记录；工具栏显式入口，避免字段名与配仓模块打架。
仓库也用装柜计划表 As-Is：线下华南/华东装柜计划表船务排柜、仓库同样要看/要改（顺序、地址、到柜/离场、贴单监装打单等）。To-Be：线上同一套装柜计划数据，不单建第二套 Excel；仓库侧用「装柜计划 / 仓库视图」（独立菜单或提单管理的仓库角色视图），列与线下表一致、可编辑字段按角色限制；PDA 装柜扫描回写同一行。

待业务确认（评审清单）

  1. 「同步提单」触发点 已确认：放舱出号即自动建提单。 仍待 IT：重复号/接口失败是否仅「同步失败·重推」、是否阻断出号？
  2. 预配 → 待配 → 终配：谁有权改状态？是否必须终配才能点「分配」/导出装柜计划？待配能否下载内部排班表？
  3. 需组合配舱号：长文本预配明细是否还要维护，还是终配后只保留「最终配舱号」？与现网「配舱单号」是否合并为一字段展示？
  4. 渠道：装柜表「渠道」与运单/产品渠道是否同一字段？若不同，以哪个为准做统计？
  5. 清关行分配：与「绑定进口商」里的清关行不一致时，以哪个驱动报关？列表是否两列都展示？
  6. 代理+报关+拖车：是否必须拆三字段且与费用/供应商台账关联？还是保持一段文本+可选结构化？
  7. 装柜日「顺序」：是否按自然日 0 点切块（对齐 xls 每日表头）？跨日改装柜时间顺序是否重算？
  8. 资料员：是否等于关务资料员账号？变更是否通知？能否一单多人？
  9. 仓库装柜计划视图：原型已独立菜单 装柜计划 · 仓库视图。待确认：权限是否仅本仓、船务字段只读范围是否足够？
  10. 现场字段（装柜费/团队/贴单/监装/到离柜）：仓库可改哪些、船务可改哪些？与 PDA「装柜完成」、行色绿/橙谁为准？
  11. 进港代码：需求清单写「排装柜计划时登记、可导出」——导出模板是否沿用现 xls？必填还是可选？
  12. 华南 / 华东：线下两表结构相同；系统是否仅「预配/终配」分工 + 权限，不再做双 Sheet？
  13. 待配仓 / 终配舱：原型已并存（链式跳转 + 侧栏入口）。待确认：终配落成后是否强制回写「最终配舱号」到提单管理？自动配舱标是否只在终配舱页展示？
  14. 提单汇总：汇总粒度（按装柜日 / 按周 / 按船）？是否与导出 xls 模板一一对应？
  15. 海派仓位 ↔ 舱位播报：播报是否只读引用仓位池货量，还是仍在提单管理打开（现 PRD）？
  16. 已放舱未生成提单（异常态）：允许在仓位侧重推几次？是否允许删仓位（整柜仓位已取消退运按钮）？
  17. 整柜与海派：同一客户既有 FCL 又有海派时，进口商/配舱号是否跨模块可见？

建议评审输出：每题负责角色（船务/关务/仓库/IT）+ P0 必答 / P1 可后补标记。
