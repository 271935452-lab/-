大客户协议价 · 交互说明

2026-08-22 · 船务组 · 原型：船务组-客户协议价格维护-原型.html　← 船务导航

场景：在现有销售报价基础上，给大客户维护优惠或其他价格；分区/重量段继承基准报价，避免整表重录。

1. 与销售报价关系

  • 销售报价：维护通用价矩阵（分区 × 重量段），可含关联客户 / 排除客户 / 客户等级。
  • 大客户协议价：选择 1 条或多条基准销售报价，只维护该客户的优惠。第①步「分公司」可多选（义乌总部 / 北苑 / 青岛 / 深圳 / 苏州），不是特价仓。
  • 多条报价的分区 / 重量段可以不一样：禁止拼成一张总表（避免串格、漏段）。统一折扣 / 减额一次套到全部，各报价用自己的结构出生效价。
  • 取价：运单命中协议客户 + 产品时，落到对应那条销售报价的矩阵。

2. 计价方式

  • 统一折扣：生效价 = 基准价 × 折扣 ÷ 10（如 9.5 折）。
  • 统一减额：生效价 = 基准价 + 减额（如 −0.7 元/kg）。
  • 全量重填价格：结构一致时按该协议分区 × 重量段整表重填单价。列表勾选 ≥1 条，或第①步选此方式。勾选多条、或重量段/分区不一致时：只改价格和生效时间，不展示各报价不同维度的矩阵。折扣 / 减额不是批量。
  • 重量段可调（第②步，按报价页签）：默认同基准销售报价，可增删改区间。基准价按新段的「到」去原报价上就近取格。
  • 快递派可协议内同步（8/22 秋玉）：不是客户下全部产品，也不是个别一两个。大约 5–6 个快递派销售产品。第②步「同步到本协议其它快递派」把当前页签重量段套到本协议已挂的其它快递派；分区 / 单价仍各跟各的报价。
  • 其他的就要用批量：批量交互只有全量重填价格。重量段/分区不一致时弹窗只留统一价格 + 生效时间。改失效日期走「修改失效日期」。不做指定格覆盖、不按比重分档，也不批量改折扣/减额。

3. 向导步骤

  • ① 选 1 条或多条基准销售报价 + 协议客户 + 所属分公司（可多选） + 有效期 + 计价方式（统一折扣 / 统一减额 / 全量重填价格）
  • ② 可调本报价重量段；快递派可同步到本协议其它快递派 → 预览折扣/减额生效价。多报价时出现报价页签
  • ③ 确认提交为草稿，列表启用后生效

4. 基准改价联动

  • 统一折扣 / 减额：基准销售报价改价后，协议价自动按规则重算。

5. 大客户调成本（保留）

  • 申请价 vs 协议生效价（或系统价）差额 → 一键落业务员成本。
  • 对照本协议第②步矩阵逐格计算：计费重段 × 分区。
  • 与「协议价维护」分离：协议价管对客价，调成本管对内成本，不在调成本里维护第二张价表。

6. 运单对照 · 下单后看原价差额

  • 做在哪里：客户协议价格维护列表，勾选 1 条 → 工具栏「运单对照」。不在运单管理做主入口（运单页仍只记成交价）；也不并进「大客户调成本」。
  • 看什么：该协议客户在有效期内实际下单的运单。原价 = 基准销售报价对应分区×重量段；运单价 = 下单命中的协议生效价。
  • 差额：原价金额 − 运单金额（让利）。汇总票数 / 计费重 / 原价合计 / 让利合计，可导出。
  • 到货时间范围：弹窗内按到货日起止筛选，汇总与列表同步；不填则看全部。列表带出到货日。起日晚于止日拦截。
  • 草稿、未发生下单 → 空表。历史过期协议仍可对照当时运单。

7. 销售报价 · 批量调价（0820 · 对齐现网「批量修改报价」）

  • 入口：报价管理列表勾选 ≥1 条 →「批量修改报价」（未勾选按钮灰显）。
  • 只读：销售产品、所属分公司由勾选行带出，弹窗内不可编辑；多分公司时只读汇总。
  • 可改：报价起止时间、调整类型（加/减）、调整金额、关联客户。不可改重量段（结构不同不能一批改）。
