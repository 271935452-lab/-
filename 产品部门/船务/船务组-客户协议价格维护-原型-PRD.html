三、功能逻辑说明

3.1 向导

功能点说明原型
向导三步
  1. ① 报价+客户+分公司+有效期+计价（仅折扣/减额）+同步对象（业务员成本 / 应收 / 两者，默认业务员成本）→ ② 返回结构 / 不返回结构 → ③ 确认
  2. 提交=草稿。点遮罩关不掉。旧「整表统一价 + 生效时间」那种全量重填模式本期不做
  3. 测：新增默认勾「业务员成本」；提交后确认页能看到同步对象
  4. 测：没有整表统一价 / 大客户调成本入口
新增
同步对象
  1. 第 1 步必选。业务员成本（默认）/ 应收 / 业务员成本+应收
  2. 下单取价时按选项回写对应维度；对照表两边金额都展示
  3. 测：新增默认=业务员成本。改应收后确认页显示「应收」
同步对象
多条报价
  1. 分区、重量段可以不一样。禁止拼成一张总表，返回结构时各报价自己一页签
  2. 测：两条报价分区不一样也不拼总表
向导
本期不做
  1. 不做特价仓。协议价不推报价组。不按比重分档。旧全量重填模式（整表统一价）不做
  2. 改重量段后按 Excel 交互在格子里填价（见下「格子 Excel 粘贴」），这个要做
  3. 测：向导计价没有整表统一价入口；改段后格子可 Excel 粘贴
列表

3.2 结构 / 计价

功能点说明原型
统一折扣
  1. 生效价 = 底价 × 折扣 ÷ 10
  2. 例 9.5 折。只能在向导改。底价改了协议价跟着变（含不返回结构）
  3. 测：改底价，折扣协议生效价变
第 2 步
统一减额
  1. 生效价 = 底价 + 减额。例 −0.7 元/kg
  2. 可负数。只能在向导改。底价改了跟着变
  3. 测：切减额，预览按基准+减额
优惠减额
返回结构
  1. 第 2 步默认。展开分区 × 重量段，可改段、预览格子
  2. 改了段 → 这张报价统一折扣/减额停用，只能改格子价（按 Excel 交互填，即改重量段时的全量重填）
  3. 恢复基准段后折扣/减额重新可用。新段按「到」就近取底价格
  4. 测：某段「到」40 改 45 → 折扣灰掉、格子可输入
  5. 测：点恢复基准后折扣重新可用
结构开关
格子 Excel 粘贴
  1. 改段后（或整表可编）格子按 Excel 用：从当前格向右向下粘贴 Tab 分隔的块；框选多格可复制出价（不含「基准」）
  2. 带表头/段名的块会自动丢掉非数字列/行
  3. 方向键 / Tab 移格；Ctrl+A 选全部格子
  4. 测：Excel 复制 4×3 数字贴进矩阵对上；复制含「美西」表头也能贴
矩阵
不返回结构
  1. 不展开分区/重量段，也不能改格子
  2. 只在第 2 步上面填折扣比例或优惠（减额），挂上的报价全部按这条算
  3. 底价改了跟着变。从返回结构切过来：本页已改的重量段和格子价会丢掉（先确认）。列表打「不返回结构」标
  4. 测：点不返回结构：重量段栏和矩阵消失
  5. 测：切优惠（减额）预览变。再切回返回结构矩阵回来
  6. 测：样例 AP202608012 第 2 步默认无矩阵
结构开关
同步其它快递派
  1. 只套本协议已挂的其它快递派重量段，不套分区和单价，不是客户名下所有产品。空派不同步
  2. 测：只改本协议其它快递派的段；非快递派不动
同步

3.3 发布 / 取价 / 对照

功能点说明原型
何时真取价
  1. 启用 / 改失效 / 已启用改期保存 → 先出发布表，点确定才算数
  2. 取消还是原样。只有已启用且在期内才取价。过失效日=已过期
  3. 测：点启用再取消，仍是草稿
启用
发布表 · 本条
  1. 草稿第一次启用=「新增并发布」（旧空/新=当前期）→ 已启用
  2. 作废后再启用或只改期=「发布」（旧=改前/新=改后）
  3. 测：改失效、已启用改期：修改方式=发布，表上有旧期新期
启用
发布表 · 删除
  1. 撞车的已启用协议：同一客户+同一产品+分公司有交集+日期重叠（含头含尾）→ 那条「删除」→ 作废，不再取价
  2. 端点相接不算重叠：前一条止日 = 后一条起日时，该日归后一条
  3. 不进删除行：已过期、不同客户、不同产品、分公司没交集、草稿
  4. 测：启用一条会撞车的草稿：本条新增并发布、对方删除
  5. 测：8/1–8/15 与 8/15–8/31 可同时启用。不同客户/产品/分公司没交集/已过期 → 无删除行
启用
下单取价
  1. 运单客户、产品、分公司对上，且到货日在有效期内 → 用协议生效价（落到对应销售报价矩阵）
  2. 对不上 / 过期 / 作废 / 草稿 → 销售报价原价
  3. 测：草稿运单仍原价；作废条不再命中
列表
运单对照
  1. 列表勾 1 条。只看不改。列：原单价、协议价、原应收、协议应收、应收差额；新增原业务员成本、协议业务员成本、业务员成本差额
  2. 汇总含应收差额与业务员成本差额。有数据时表底加合计行（计费重、原/协议应收、应收差额、原/协议业务员成本、业务员成本差额；单价与分区等不合计）
  3. 到货日起晚于止拦住。草稿/没单=空表，无合计行
  4. 测：勾 AP202608001：列名已改，有业务员成本三列，表底有合计
  5. 测：到货日起晚于止 → 拦住
运单对照
导出对照
  1. 导当前对照表：列、筛选后的行与页面一致，不另组表、不加未展示列
  2. 有数据时导出带表底合计行，与页面合计同一套数
  3. 空表只导出当前空态，不编造行
  4. 测：筛到货日后导出，文件行=当前表行+合计行。空表导出无合计行
导出对照
