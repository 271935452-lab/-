二、列表字段

本页为新能力，下列均为本期新增。无现网列可归。

2.1 清关行页

字段说明原型
清关行
  1. 只有 6 家：精准 / 02B / 赛因 / 关关通 / 人人数智 / 帝成。不能手加第 7 家
  2. 测：想加第 7 家加不了
打开
不接港口
  1. 按清关行维护。目的港在名单里不能派这行（关关通中转落到这港也不行）。进口商弹窗只读
  2. 测：该港派该行被拦或下拉没有
打开
对接邮箱
  1. 邮箱能看，密码打码，页面不显示明文
  2. 测：看不到明文密码
打开

2.2 进口商授权页

字段说明原型
进口商
  1. 主数据名称。停用 / 停用待观察行底黄
  2. 测：停用行变黄；绑柜仍按状态拦
打开
Bond
  1. 只读带出 Bond 分配
  2. 测：跟进口商页一致
打开
精准 / 02B / 赛因 / 关关通 / 人人数智 / 帝成
  1. 六列格子。点一下转一档：未分配 → 授权 → 禁接 → 未分配
  2. 点完马上存。进口商弹窗不能改格子
  3. 测：点三下回到未分配；进口商弹窗只有只读「已授权」
打开

三、功能逻辑说明

功能点说明原型
绑定时下拉
  1. 只出「授权」。禁接、未分配都不出
  2. 改禁接/未分配后新绑选不到；旧柜仍显示旧行
  3. 测：授权后再去绑柜下拉有；改禁接下拉没了
绑柜
保存
  1. 授权页点格子即存；工具栏保存为确认
  2. 测：改格子后去绑柜立刻生效
保存
