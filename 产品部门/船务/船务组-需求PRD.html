〇、约定

点规则
谁说了算规则以分册 PRD为准（验收）。开发/测试入口是产品部全文。本文只做跨页索引+配置数+二期。冲突时以分册为准。原型演示数据不是接口真值。
分册骨架一页三段：筛选条件（条件 / 位置 / 说明 / 原型）→ 列表字段（字段 / 说明 / 原型）→ 功能逻辑说明（功能点 / 说明 / 原型）。筛再多、列再多也不另开骨架。每条说明带可点的原型链接，测法写在说明末句「测：…」。
原型只展示怎么点。不放长说明。点遮罩不关。结果 toast。危险确认框。侧栏 PRD 芯片可嵌分册。
标记NEW=新；改=相对现网；待定/二期=不得开发验收。
勾选分配/取消IT/绑定/换柜换船/费用 ≥1；日志、发 AMS / 发 ISF 只能 1；播报/查询/创建不用勾。弹窗按现网新增AMS/新增ISF，不另加字段。查验挂票/改单手打/进港代码按钮本工具栏没有。
