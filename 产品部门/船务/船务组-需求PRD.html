一、关联模块与组间交接

  • 上游 H1：运价列表展示合约价 → 合约价确认开关（可配置）→ 下发私卡报价；私卡报完价、绑运单完成后回接船务安排订舱/配舱。
  • 并行：无需报价分支（改配、其他价格表出价渠道，不含私卡）→ 系统按价格表自动出价 → 同样直接船务安排。
  • 本组：运价维护 / 点价订舱 → 提单创建（AI）→ 提单管理（分配、播报、标记、费用、进口商）→ 放行盯控 → 进港 → 离港。
  • 下游 H3：取消 IT（仅火车）→ 关务清关待办提醒。
  • 下游 H4：进港时间落库、离港后交海外港前。
  • H5：关务舱单/放行只读订阅 → 船务拉数比对放行状态（海放 / 码放）。

4.7 自动配舱规则 NEW（同渠道）

口径：仓库配舱按渠道分组，不同渠道不混柜。同一渠道内系统按下列优先级往柜子里装；未满再补下一档。反倾销是硬约束，与货类优先级并行。

4.7.1 分柜前提

  • 先按渠道切开待配货（仓口 / 航线渠道以业务配置为准）。本规则只在「同一个渠道」内执行。
  • 每票货归入且只归入一个装填档（自上而下先匹配先入档）：① 合并报关 → ② 服装货 → ③ 托盘货 → ④ 报关件 → ⑤ 买单。一票同时带多个标签时，取最高档（例如服装且合并报关 → 按合并报关装）。
  • 反倾销为属性标记，可与上列货类并存，不占单独装填档。
  • 柜容积 / 限重按柜型配置；未达满柜才进入下一档。

4.7.2 同渠道装填顺序

顺序货类规则
1合并报关同渠道内先配，尽量同柜；合并报关件不得无故拆到多柜（关务漏报/重复报风险）
2服装货合并报关装完（或本柜已满另开柜）后再装服装
3托盘货服装之后装托盘
4报关件托盘之后装其余报关件
5买单仅补位：以上四档装完后柜子仍未满，再用买单货填满。买单不抢前序货的柜位

买单是「不够再补」，不是优先货。禁止先装满买单再把合并报关/服装/托盘/报关件拆到别的柜。

4.7.3 反倾销硬约束

  • 同一渠道下，反倾销货必须集中装在同一个柜子，禁止拆散到多个柜子。
  • 一柜装不下时：先装满第一柜反倾销，溢出部分开下一柜继续只收反倾销，不得把剩余反倾销掺进已排好的非反倾销柜。
  • 反倾销柜若仍有空位：默认可按 4.7.2 用同渠道其他货填满该柜。若现场要求反倾销专柜、不得混装 → 人工确认后锁柜，空位不补。

4.7.4 系统行为

项规则验收
建议配柜按 4.7.2 + 4.7.3 出推荐方案，船务可手改推荐结果可看出货类顺序；手改留痕
拦截保存时若同渠道反倾销被拆到 ≥2 个非连续专柜，或合并报关被无故分柜强提示，可强制保存留痕
作业台独立配舱作业台 / 终配性能优化见 第九章，本迭代以规则入库为准

8.5 预警阈值（可配置）

临近截单：提前 24 小时。临近未海放/未码放：ETD ≤ 3 天。价目即将过期：≤ 7 天。

8.6 船公司提单号规则（数据字典） NEW

维护在「船公司(航运)」字典，字段名建议 bl_prefix。示意（以现网代码为准，业务可改）：

OOCL→OOLU · EMC→EGLV · CMA→CMAU · KMTC→KMTU · HPL→HLCU · YML→YMLU · MSK→MAEU · ONE→ONEY · WHL→WHLU · ZIM→ZIMU · COSCO→COSU · MSC→MEDU · HMM→HDMU · MATS→MATS · HEDE/CUL/SLS 可空

以上以业务确认后的配置为准；原型常量为示意，交互不变。

8.7 配舱货类档（可配置） NEW

装填顺序：合并报关 → 服装货 → 托盘货 → 报关件 → 买单（补位）。属性标记：反倾销（同渠道必须同柜）。渠道维度以仓口/航线渠道配置为准。
