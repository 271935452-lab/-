背景与痛点 · 我们解决什么问题

业务背景

船务组承接头程全链路：维护运价 → 创建提单 → 分配配舱 → 盯进港 / 离港 → 与报价组、关务、海外港前后衔接。现网各模块能力分散，运价下发、提单录入、配舱作业依赖大量人工协同与线下表格。

核心痛点

  • 运价维护与报价脱节：我司合约价、代理订舱价、价差对比分散维护，同步报价组口径不统一，点价订舱效率低。
  • 提单创建录入重：批量提单信息靠人工录入 / 粘贴，字段多、易错，缺少 AI 辅助识别。
  • 配舱分配靠经验：同渠道自动配舱规则不透明，按周分配、舱位播报、标记口径各说各话。
  • 进港 / 滞箱信息滞后：飞驼、落箱、滞港 / 滞箱等节点分散查询，放行盯控与 H5 关务回写比对不便。
  • 组间 handoff 断点：H1 运价 → 私卡报价 → 回接订舱配舱、H3/H4/H5 与关务 / 海外港的节点缺少系统串联。

本期要解决什么

  • 统一运价管理（我司 / 代理 / 价差三 Tab、合约价确认开关、同步报价组、点价订舱）。
  • 上线提单创建 AI 识别，降低批量录入成本；配套船公司 / 提单号规则数据字典。
  • 完善提单管理：按周分组与分配、舱位播报、操作日志、费用 / 进口商绑定、同渠道自动配舱规则。
  • 打通进港 · 飞驼 · 落箱及滞箱 / 滞港展示，支撑放行盯控与组间交接。
  • 弹窗交互、标记口径、换柜换船 / 查验换船等边界在本 PRD 与原型中可开发、可验收。

2.5 点价订舱

  • 入口：点击蓝色价格，或行「点价订舱」。

  • 带入：船司、港口、柜型、海运费（代理带订舱口）、合约号、ETD、柜量。

4.7 自动配舱规则 NEW（同渠道）

口径：仓库配舱按渠道分组，不同渠道不混柜。同一渠道内系统按下列优先级往柜子里装；未满再补下一档。反倾销是硬约束，与货类优先级并行。

4.7.1 分柜前提

  • 先按渠道切开待配货（仓口 / 航线渠道以业务配置为准）。本规则只在「同一个渠道」内执行。
  • 每票货归入且只归入一个装填档（自上而下先匹配先入档）：① 合并报关 → ② 服装货 → ③ 托盘货 → ④ 报关件 → ⑤ 买单。一票同时带多个标签时，取最高档（例如服装且合并报关 → 按合并报关装）。
  • 服装货不靠人工勾选：按票上品名做包含匹配判定，词表与规则见 4.7.4。托盘货 / 合并报关 / 报关件 / 买单仍走各自业务标签，不按品名猜。
  • 反倾销为属性标记，可与上列货类并存，不占单独装填档。来源两者都有：① 申报/品名带出；② 船务手标。任一命中即按反倾销约束配舱。
  • 柜容积 / 限重按柜型配置；未达满柜才进入下一档。

4.7.2 同渠道装填顺序

顺序货类规则
1合并报关同渠道内先配，尽量同柜；合并报关件不得无故拆到多柜（关务漏报/重复报风险）
2服装货品名命中 4.7.4 词表。合并报关装完（或本柜已满另开柜）后再装服装
3托盘货服装之后装托盘
4报关件托盘之后装其余报关件
5买单仅补位：以上四档装完后柜子仍未满，再用买单货填满。买单不抢前序货的柜位

买单是「不够再补」，不是优先货。禁止先装满买单再把合并报关/服装/托盘/报关件拆到别的柜。

4.7.3 反倾销硬约束

  • 来源两者都有：申报/品名带出，或船务手标。命中任一即本约束。
  • 同一渠道下，反倾销货必须集中装在同一个柜子，禁止拆散到多个柜子。
  • 一柜装不下时：先装满第一柜反倾销，溢出部分开下一柜继续只收反倾销，不得把剩余反倾销掺进已排好的非反倾销柜。
  • 反倾销柜若仍有空位：默认可按 4.7.2 用同渠道其他货填满该柜。若现场要求反倾销专柜、不得混装 → 人工确认后锁柜，空位不补。
