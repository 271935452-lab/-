配舱规则说明
终配舱 / 自动配舱与智能仓共用同一套配舱规则；维护入口在侧栏「配舱规则配置」。列表列对齐现网（配舱清单号 / 车架号 / 票数 / 出货方数 / 预估重 / 预估毛重 / 预计装柜时间 / 服务渠道 / 所属关系 / 创建人 / 报关行等），另加「业务标记」。运输页签：全部 / 待出仓 / 已分配 / 可出仓 / 已出仓；配舱状态：待配 / 配中 / 终配。自动配舱进配中 → 运输改已分配。「业务标记」：多家报关行、合并单多舱、配舱超限 / 未满 / SKU未达标 / SKU超杂柜 / 超重 / 超超重等。终配舱不叠截单色标；截单预警在提单管理——绑了提单才预警，没绑不预警。

系统执行步骤

  1. 待配运单按渠道分开，不同渠道不进同一柜
  2. 每票定档位：合并报关 → 服装 → 托盘 → 报关件 → 买单（多标签取最高档）
  3. 服装看品名包不包含词表，不用人勾
  4. 同渠道按上面顺序往柜里装；一柜方数 < 68、重量 < 20 吨，顶到上限开新柜；买单只补空位
  5. 反倾销同渠道必须同柜，装不下再开反倾销专柜
  6. 保存前检查混渠道、超方/超重、拆反倾销、拆合并报关、买单抢位
  7. 通过则终配落成，自动生成舱号如 260820-青岛T25-1，写回列表
  8. 落成后关务按船司×港口规则生成分单号（给舱单）；配舱或货物再调整则整组重算
  9. 这一步是系统按规则装的，本页终配舱单号旁打「自动配舱」；只要最初是自动配，后续人工补货/改舱再终配仍保留标

自动配舱标记

  • 系统按规则自动装柜，硬约束通过进入配中 → 运输状态改为已分配，单号旁打「自动配舱」
  • 继续终配落成 → 保留「自动配舱」标；运输状态再按出仓改为可出仓 / 已出仓
  • 只要最初是自动配 → 后续人工补货/改舱/再终配仍保留「自动配舱」标；仅纯手配不打标。手配进配中不自动改「已分配」
  • 标只展示、不手打。运单配舱阶段、待配仓配舱状态旁也能看见
配仓上限：一柜方数合计 < 68、重量合计 < 20 吨（< 20000 kg）。再装一票会达到或超过任一条 → 不进本柜、开新柜。单票自身已超 → 不自动进柜、手配。保存时 ≥68 方或 ≥20 吨硬拦。
合并报关：尽量进同一个终配舱。被拆到 ≥2 舱时，在「标记」列打红底「合并单多舱 · N舱」，下面列出另舱单号。同一舱有多家报关行才展示报关行；只有一家不展示。点标或另舱号看同组分布。同舱不打分舱胶囊。配仓时（待配仓改预配舱号）若会拆组，先弹谁报+风险确认。分舱风险由我司承担。

会拦住的情况

  • 不同渠道混一柜 → 不让保存
  • 一柜方数 ≥68 或重量 ≥20 吨 → 不让保存
  • 销售产品空或一柜混多个 → 不出号
  • 反倾销被乱拆 → 强提示，确认后可保存
  • 合并报关被拆组 → 待配仓改号时强提醒；本页配舱调整再确认一次
