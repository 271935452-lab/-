终配舱 · 规则说明
终配保存时系统自动跑规则，不用配配置页。推荐画面二期再做，本期先把装柜顺序、校验和出号跑通。

系统执行步骤

  1. 待配运单按渠道分开，不同渠道不进同一柜
  2. 每票定档位：合并报关 → 服装 → 托盘 → 报关件 → 买单（多标签取最高档）
  3. 服装看品名包不包含词表，不用人勾
  4. 同渠道按上面顺序往柜里装；一柜方数 < 68、重量 < 20 吨，顶到上限开新柜；买单只补空位
  5. 反倾销同渠道必须同柜，装不下再开反倾销专柜
  6. 保存前检查混渠道、超方/超重、拆反倾销、拆合并报关、买单抢位
  7. 通过则终配落成，自动生成舱号如 260820-青岛T25-1，写回列表
  8. 落成后按船司×港口规则生成分单号（舱单用）；再调整则整组重算
  9. 这一步是系统按规则装的，终配舱页打「自动配舱」标；手改过装柜结果再终配则不打
配仓上限：一柜方数合计 < 68、重量合计 < 20 吨（< 20000 kg）。再装一票会达到或超过任一条 → 不进本柜、开新柜。保存时 ≥68 方或 ≥20 吨硬拦。

会拦住的情况

  • 不同渠道混一柜 → 不让保存
  • 一柜方数 ≥68 或重量 ≥20 吨 → 不让保存
  • 销售产品空或一柜混多个 → 不出号
  • 反倾销被乱拆 → 强提示，确认后可保存
  • 合并报关被拆到不同预配舱 → 配仓时强提醒（谁报 + 分柜风险由我司承担），确认后才改号
