只写本期新增或改口径的列/格。

2.1 信息管理

字段说明原型
Bond 额度预警
  1. 面额+已用/上限+剩余+颜色。默认上限 250 次
  2. 已用 ≥200 黄、≥240 红、≥250 用尽要提额。保存前算预警档
  3. 测：已用 200 / 240 / 250 → 黄 / 红 / 用尽
打开

  1. 有/无。绑定页只读带出
  2. 测：绑柜只读区跟主数据一致

  1. 列表只写已维护/未维护，不明文。密码跟邮箱配对。别的模块不存明文
  2. 测：填密码后列表只有已维护
打开
清关行
  1. 列表只读看出配置页谁已授权。本弹窗不分配
  2. 测：弹窗没有清关行格子

  3. 测：绑定页打开看到新值且不能改
编辑
Bond 保险代码
  1. 只有 054 / 846 / 856 / 036。绑定页只读带出
  2. 测：绑柜只读区跟主数据一致

  1. 临期=失效 30 天内
  2. 测：点临期卡能筛出

  1. 中国及其他只能护照。美国：护照 / 驾照 / 身份卡。改国籍时不合法类型清掉
  2. 测：美国再改中国，类型只剩护照

发货人

  2. 改成已停用后绑柜/绑提单下拉没了

  2. 测：打开页这些列/格还在

2.2 使用管理

字段说明原型
在途未清关（柜）
  1. 已绑且清关没完的柜数。在途>5 标一下。没绑的柜不进
  2. 测：绑一柜在途+1
使用管理
最近一周 / 本月 / 累计查验率
  1. 查验柜 ÷（清关完成 + 清关查验）
  2. 柜上「是否查验=是」算查验；=否且已清关算完成。在途不算分母。≥10% 标异常
  3. 测：10 柜清关完 9、查验 1，另有在途 → 10%
打开
查验备注
  1. 按进口商多条、新的在上，不写进收货人备注
  2. 测：写查验备注，收货人备注不动
打开
现网字段
  1. 进口商编码/名称、状态/使用渠道/Bond 分配、操作：与信息管理同一套只读带出
  2. 测：切页签对得上；能导出
使用管理

  2. 测：点导出 toast 现网能力
