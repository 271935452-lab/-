A. 页面拆分 · 总体

不新开作业页骨架：沿用海派仓位 / 提单管理 / 待配仓 / 终配舱 / 仓库视图 / 配舱规则配置；本期加字段与入口。

确认编号说明
PAGE-01 无号仓位只在海派仓位表维护；放舱出号后进提单管理。不在提单管理维护无号仓位。
PAGE-02 装柜计划：船务在提单管理橙底跟看；仓库在装柜计划·仓库视图维护现场字段（同一套计划数据）。
PAGE-03 PDA 装柜扫描回写同一计划行；配舱规则独立配置页，不嵌作业页。

B. 海派仓位表

确认编号说明
PAGE-04 创建仓位：渠道与销售产品同源必填（销售产品主数据）；截单时间必填。
PAGE-05 批量创建提单：跳转提单创建页；不在本页内嵌创建表单。
PAGE-06 放舱出号：补录提单号 → 进提单「待分配」；不自动跳转提单管理。
PAGE-07 已出正式提单号后，仓位侧关键字段编辑锁定（与现网一致）。
PAGE-08 分配预计装柜时间 + 要求到柜时间（日期时间）写入仓位，供提单/仓库跟看。
PAGE-09 退运：仅待分配可退；作废提单；退运费/亏舱费有则写入提单预估（对齐现网）。
PAGE-10 导出按当前筛选条件导出（非仅勾选行，除非另有勾选导出入口）。

C. 提单管理 · 列表规则与橙列

确认编号说明
PAGE-11 状态=待分配且无正式提单号 → 不进列表、不计入待分配数量。
PAGE-12 预计装柜时间← 海派仓位表；本页橙底只读；周页签按此切换。
PAGE-13 组合配舱：列表单元格内多行展示「号 + 方数」（对齐线下需组合配舱号）；不弹明细窗。配中可与终配舱号同屏。
PAGE-14 终配舱号：配中有则显；终配后必有。与组合配舱并列，不互斥隐藏。
PAGE-15 配舱状态：待配 / 配中 / 终配（不用「已分配」）。
PAGE-16 预录资料员← 预录工作台；截单资料员← 报关管理；两列分列，本页只读。
PAGE-17 顺序：列表顺序标记字段；单元格可改数字；点表头对当前筛选结果升序→降序→回默认周/船名序。
PAGE-18 渠道展示；清关行← 进口商绑定分配；要求到柜时间← 仓位表只读。
PAGE-19 装柜团队 / 贴单核对 / 监装 / 打单← 仓库视图维护结果只读展示；有则显、无则空；本页不代填。

D. 仓库视图 · 现场字段取值（已确认）

橙列仓库可改；保存回写计划主数据。装柜费/卸柜费有改须选「追加」或「覆盖」同步提单预估。

确认编号说明
PAGE-20 装柜团队：服务商列表，类型∈卸车服务商、装卸服务商、装柜服务商、拖车服务商；仅启用；落库服务商ID，展示名称；回写提单「装柜团队」。
PAGE-21 卸柜团队：与装柜团队同池同过滤；仅本页维护，提单管理无此列；可与装柜团队选同一服务商。
PAGE-22 贴单核对 / 监装 / 打单：三列同池。人事在职同事，部门名称精确匹配：台州仓、北苑仓、宁波仓、义乌操作中心、潍坊仓、中山仓、厦门仓、坂田仓、泉州仓、广州仓、福永仓、操作部。不按当前本仓过滤；落库员工ID，展示姓名；回写提单对应橙列。
PAGE-23 上述字段空值允许；同池允许同选（装柜=卸柜同一服务商、贴单=监装同一人均可）。
PAGE-24 两柜对调入口仅本页（义乌仓）；同渠道同柜型、到场未开装；终配舱不做。
