配套页面：海派仓位表 · 提单管理 · 装柜计划·仓库视图

A. 谁管什么

确认编号口径
PAGE-01 不新开页面。还没出提单号的仓位，只在海派仓位表维护；放舱出号后进提单管理。提单管理里不维护无号仓位。
PAGE-02 装柜计划：船务在提单管理看着；仓库在装柜计划·仓库视图改现场信息。两边看的是同一套计划。
PAGE-03 仓库用手持机扫码装柜后，计划和提单这边能看到同一条结果。

B. 海派仓位表

确认编号口径
PAGE-04 本页沿用之前的批量登记仓位。改未出号仓位时，渠道、销售产品、截单时间都要填。放舱出号 / 批量创建提单时也要填。
PAGE-05 批量创建提单：跳到提单创建页去填，不在本页里填。
PAGE-06 放舱出号：补上提单号后进提单「待分配」；不自动跳到提单管理。
PAGE-07 已经出了正式提单号，仓位这边关键项就不能再改（和现在线上一样）。
PAGE-08 预计装柜时间、要求到柜时间以海派仓位为主数据，与提单同源。仓位空时可在仓位表改，也可在提单分配改并带出；以最后一次保存为准。终配舱绑定、换柜换船不写这两项（新建为空）。
PAGE-09 退运：装柜前用退运（未装完可退）；装柜完成后改走换柜换船。退后仓位/提单作废；退运费 / 亏舱费有则写进提单预估。
PAGE-10 导出按勾选的行导出。

C. 提单管理

确认编号口径
PAGE-11 状态是待分配、但还没有正式提单号 → 不出现在列表里，也不计入待分配数量。
PAGE-12 预计装柜时间与仓位同源回显；提单分配可带出、可改（改完回写仓位，最后一次为准）。周页签按仓位预计装柜时间切。
PAGE-13 组合配舱（按提单）：工具栏或列表点「组合配舱」打开弹窗，可按仓库、预配舱单号、运单号筛。可勾整舱或单票；确认后列表一行行显示「号 + 方数」，并同时生成终配舱（状态变成配中、写出终配舱号，终配舱页「配中」能看到）。已经终配的不退回配中。组合号和终配舱号同一行都能看见。仓库视图等后面有组合信息时，按本页同样口径带入。
PAGE-14 终配舱号：组合配舱确认后就有（配中必有）；终配之后也一直有。和组合配舱两列一起显示，不互相藏。
PAGE-15 配舱状态：待配 / 配中 / 终配。组合配舱确认后：待配 → 配中。
PAGE-16 预录资料员＝预录工作台的报关客服；截单资料员＝报关管理的资料员。两列分开，本页只能看。
PAGE-17 顺序：格子里可改数字；点表头可对当前筛出的结果升序 / 降序，再点回到默认的周、船名顺序。
PAGE-18 展示渠道；清关行来自进口商绑定；要求到柜时间来自仓位表，本页只能看。
PAGE-19 装柜团队 / 贴单核对 / 监装 / 打单：仓库在仓库视图填好后，本页只展示；有就显示、没有就空着。本页不代填。

D. 装柜计划 · 仓库视图

确认编号口径
PAGE-20 列表按柜号一行；有预计装柜时间才进本列表。装柜团队＝现网装车服务商（同源字段）。从已启用服务商选（卸车 / 装卸 / 装柜 / 拖车）；提单跟着更新。与调拨无关。
PAGE-21 卸柜团队：和装柜团队同一批服务商可选；只在本页维护，提单管理无此列；可与装柜团队选同一个。与调拨无关。
PAGE-22 贴单核对 / 监装 / 打单：三列同一批人可选。取人事在职同事，部门名要对上：台州仓、北苑仓、宁波仓、义乌操作中心、潍坊仓、中山仓、厦门仓、坂田仓、泉州仓、广州仓、福永仓、操作部。不按「当前本仓」再缩一圈；页面显示姓名；提单对应列跟着更新。
PAGE-23 以上字段都可以空着；同一批选项允许选成一样（装柜=卸柜同一服务商、贴单=监装同一人都可以）。
PAGE-24 两柜对调只在本页做：同渠道、同柜型、两柜都到现场且还没开装。对调结果写进终配舱操作日志。终配舱页不做对调按钮。
PAGE-24b 终配舱操作日志记三类：待办确认、调整终配、柜子对调；可按类型、终配舱号筛。自动配舱任务日志里要带生成的终配舱号。
PAGE-24a 每行有保存（只存这一行）；顶部「保存现场字段」按勾选批量存。装柜费/卸柜费＝操作装车费/操作卸车费；有变 → 选追加或覆盖 → 写入提单预估（币种 CNY；金额 2 位小数）。预估已转应付 → 不可操作，提示联系财务。无多提单分摊场景。

确认编号口径
PAGE-25 渠道、销售产品跟自动配舱用同一套；仓位填好后，后面各页列表跟着看。
PAGE-26 销售产品新增 / 维护时，渠道为必填项。
