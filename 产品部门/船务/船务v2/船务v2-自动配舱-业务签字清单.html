海外仓关注 ＝海外拆柜/接柜重点看的口径（地址种类、重量、合并多舱、业务标记等）。方数/箱数/重量档、服装上限、SKU 两档等一律以规则配置页为准；清单里的数字仅示意。

配套页面：待配仓 · 终配舱 · 配舱规则 · 仓库装柜计划 · 自动配舱日志

A. 谁用、从哪点、记什么

确认编号口径
STOW-01 按「货现在在哪个仓」各开一套；仓与仓不串规矩。货池「所在仓」＝运单管理所在仓（含调拨转入）。不按签入自动跑；人点一次，出一套方案。
STOW-02 候选定版：非扣件＝运单扣件状态「正常件」；已放舱＝已进提单管理且有提单号；未装柜＝提单状态为「待分配」或「待装柜」（终配舱侧对应未出仓且非终配）。不同销售渠道不能同柜。柜型已定。
STOW-03 在待配仓点「自动配舱」执行。改规矩去侧栏「配舱规则」。跑完有任务日志（含生成的最终配舱号）。

B. 点开以后怎么选

确认编号口径
STOW-04 弹窗里：渠道可以多选；每种柜型填要配几只（大于 0 才算，比如 40HQ 填 2）。不用再一条条勾柜子。
STOW-05 按你填的柜型数量，从上述候选柜里取；不够就有多少配多少，并提示「计划几只 / 实际几只」。
STOW-06 没选渠道，或柜型数量全是 0 → 不能执行，只能先看预览。

C. 装进柜子的硬规矩

确认编号口径
STOW-07 海外仓关注 每柜方数、箱数上限看已发布规则（示意：40HQ 约 70 方、40GP 约 60、45HQ 约 80；箱数约 ≤1100）。数字以配置为准。超限：自动侧按「超限怎么处理」；人工审核后仍可占用该柜并保存，再按实际打标。
STOW-08 海外仓关注 重量只看整柜合计（档位以配置为准；示意：≤19.5 通过；19.5～25.9 出方案+待办黄少飞，打「超重」；>25.9 自动不落成，打「超超重」）。人工仍可调整后按实际打标。
STOW-09 海外仓关注 所有规则都不拦人工调整。自动配舱：不同渠道不进同一柜（最高目标）；其余目标顺序、是否「必须做到」、超限处理均按规则配置。人工改舱开放手动调整（含跨渠道等），保存后按实际打标，不因规矩挡住保存。

D. 谁先谁后 · 合并报关 · 调拨

确认编号口径
STOW-10 海外仓关注 合并报关＝同一渠道尽量同柜；调拨跟合并报关同序（先合并再塞同渠道调拨，目标同一提单同一柜）。渠道之下默认顺序（可配）：①合并报关同柜 · 调拨跟合并报关同柜 → ②反倾销尽量集中 → ③服装货合计 < 40 方（上限以配置为准）→ ④地址种类少一点装满 → ⑤限时达尽量集中 → ⑥同一来源仓尽量整柜。
STOW-11 同一合并报关组尽量进同一柜；组里有扣件 → 等放行后再整组配，不拆着配。
STOW-12 海外仓关注 同渠道有多组：尽量都装进同一柜；实在装不下 → 再整组拆到不同柜，并标「合并单多舱」；不能为了装满把某一组拆散。
STOW-13 合并报关组若跨了不同渠道 → 自动不出方案，待办给配舱同事（渠道高于合并）。系统侧限制不同渠道做合并报关；人工仍可调整，保存后按实际打标。

E. 地址种类怎么数、怎么标 海外仓关注

确认编号口径
STOW-14 海外仓关注 地址种类怎么数：快递派选了尾端服务商时按服务商计（如 UPS、FedEx 各算 1 种）；未选服务商时按大类算 1；海外仓自提默认大类 1；FBA 按仓代码、私卡按地址。两档阈值可配（示意 15 / 20）：小于达标线 → 达标（不打标）；达标～超杂柜线 → 未达标；大于超杂柜线 → 超杂柜。后两档仍出方案并打标。
STOW-15 海外仓关注 列表标记含：地址未达标、超杂柜、未满、超方/超箱、超重（审核区间）、超超重（超过禁止上限）、合并单多舱、反倾销分柜、调拨柜等。达标不打标。人工调整后按实际重算打标。
STOW-16 海外仓关注 地址种类偏多、未满、超方超箱：先打标、停在待配，可不推待办。待办只在待配推一次，改成配中后关掉；同一柜同一原因不重复推。待办内支持点击查看货物（交互对齐提单「组合配舱」：舱行可展开看运单号 / 件数 / 重量 / 方数等，只读）。
STOW-25 海外仓关注 终配落成后的柜子业务标签（如超杂柜、合并单多舱、超重/超超重、调拨柜等）写入拆柜计划模板；模板上按柜展示，并打上每个柜子的排柜顺序，供海外拆柜按序作业。

F. 配完以后什么状态、谁改、记什么

确认编号口径
STOW-17 自动配通过规矩进入配中时：打「自动配舱」标记，运输状态改为已分配。只要一开始是自动配出来的，后面人工补货、改舱、再终配，标都保留。只有全程人手配的才不打这个标。
STOW-18 配舱进度只用：待配 / 配中 / 终配。运输侧可看：全部 / 待出仓 / 已分配 / 可出仓 / 已出仓。截单预警：绑了提单才预警；没绑不预警（只在提单管理；终配舱不叠截单色标）。
STOW-19 自动侧规矩都满足时可直接终配。人工随时可改，保存时再按规则验一遍并按实际打标；规则不拦人工保存。
STOW-20 每个渠道大约留 10 票偏小方数货 + 10 票单票单件（可改），专门给人补柜用。自动配舱不会动这些留货。柜没装满时，在终配舱用「人工补货」：同渠道从留货里勾运单 → 补进勾选舱 → 确认保存；优先运单号少的。
STOW-21 两柜对调：同一渠道、同一柜型；两柜都到现场且还没开装；只对调柜号/提单，配舱号里的货不动。只在仓库装柜计划做；对调结果写入终配舱操作日志。
STOW-22 终配舱有操作日志：待办确认、改配/补货保存/配舱完成、柜子对调（仓库写入后这里能查）。可按类型、最终配舱号筛选。

G. 规矩怎么配、怎么发、改完怎么算

确认编号口径
STOW-23 按「货现在在哪个仓」各配一套：本仓开不开自动配、草稿和已发版本互不串。可把别的仓规矩复制过来改，还要再保存/发布。自动配只拿本仓现在的货（含调拨进来的）。
STOW-24 规则页能配：柜型方数/重量、地址种类与两档门槛、服装词表与上限、谁先谁后（含①合并+调拨 → ②反倾销 → ③服装<上限 → …）、限时达词、超限处理、留货、生效时间。数值以配置为准。发版后已终配绑当时版本。草稿不影响在跑任务。终配/补货保存再验：规则不拦人工保存，按实际打标。装完/离港前给海外看的重货、多地址、超限、合并多舱提示只展示不拦流程 海外仓关注。
