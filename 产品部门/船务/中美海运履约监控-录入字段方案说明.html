一、已定口径（5 条）

  • ③ 等装与 ④ 装柜时长是两套考核，字段分开，不合并。
  • 仓库保留 实际离场（车/柜离仓）；另增装柜完成专门给④，二者不等同。
  • 要求到柜：装柜日前改为必填。
  • 整体时效：POD 回传 − ATD（实际开船） ≤ 承诺客户时效(天)。
  • 海外各「最迟××」：系统按规则自动算，页面默认可看；特例才允许覆盖，覆盖非必填。

三、按页面改什么（只列增量）

1. 海派仓位表 / 提单管理 · 船务

字段动作必填关联
要求到柜时间 改规则 装柜日前 ✓ ②应；仓库/提单只读带出
最迟还重柜时间 新增 放舱后～开装前 ✓ ⑤应；实=飞驼
报关最迟放行时间 新增 绑提单后 ✓ ⑥应；关务只读；实=海放/飞驼

截单、ETD、ETA、起运港/目的港、柜号、提单号 —— 已有，不重复加。

2. 装柜计划 · 仓库视图 · 出库组

字段动作必填关联
具体到柜时间 已有 到场 ✓ ②实 → 回写提单
实际开始装柜 新增 开装 ✓ ③实（等装）
装柜开始时间 新增 ✓ ④起点
装柜完成时间 新增 装完 ✓ ④实；点「装完」可带出可改
实际离场时间 保留 离场时填 车/柜离仓；不参与④判定

3. 报关管理 · 关务

字段动作必填关联
实际截单时间 新增 截单办结 ✓ ①实；对船务「截单时间」；≠ 海放时间

4. 主单跟进 · 海外（柜级）

字段动作必填关联
最迟卸船 / 提柜 / 拆柜 自动 + 覆盖 覆盖非必填 ⑨⑪⑫应
实际卸船 / 提柜 飞驼优先；无轨迹补录 无轨迹时 ✓ 柜级主数据；与卡派提柜对齐
实际拆柜 美库优先；外港补录 外港 ✓ ⑫实

5. 卡派跟进 · 海外（票级）

字段动作必填关联
实际出发（出库） 已有 出库登记 ✓ ⑬实
签收 / POD 上传时间 已有 按现网 ⑭实
最迟出库 / 派送 / POD 自动 + 覆盖 覆盖非必填 渠道·区域规则见台账第 7 行
外港无美库时的实际时刻 人工兜底 无抓取时 ✓ 票写票、柜汇总；不双录主数据

6. 报价 / 销售产品

字段动作必填关联
承诺 / 参考时效(天) 打通只读引用 出运前有值 整体时效分母；船务/履约看板不改

四、判定公式（定稿）

节点达标条件
③ 等装实际开始装柜 ≤ 具体到柜 + 1 小时
④ 装柜时长装柜完成 ≤ 装柜开始 + 3 小时
整体时效(POD 回传 − ATD) 折合天数 ≤ 承诺客户时效(天)
其余节点实 ≤ 应（最迟）；缺一边不判定

五、明确不做

  • 判定列、责任组列 —— 系统计算，无录入。
  • 飞驼 / 美库已抓到的实际时间 —— 不要求再手填。
  • 海外「最迟××」—— 不默认手填；只保留覆盖入口。
  • 用「实际离场」顶替「装柜完成」—— 不做。
  • 在运单上重复维护柜级节点主数据 —— 不做（运单只读挂载）。
