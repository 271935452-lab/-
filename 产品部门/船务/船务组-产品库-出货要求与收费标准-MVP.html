产品库 · 出货要求与收费标准 NEW

将 Excel「cpsc产品及出货要求 / 附加费清单」标准化为： 品名主数据 + 仓口出货规则 + 报关/清关 HS + 清关要求 + 进口证件 + 收费标准（可关联附加服务）。 下单/查货勾选品名后，自动带出货要求、HS 与清关要求，并挂对应附加服务与费用。

标准模型： ① 出货结果枚举（正常出 / 需资料出 / 有条件出 / 不接）按仓口维护； ② 报关 HS · 清关 HS · 清关要求（新增）； ③ 证件标签（CPSC、UN38.3、MSDS、UL、蓝牙授权、商检…）； ④ 收费：无附加 / 固定附加 / 按属性分段；金额写入附加服务价目，产品只关联服务码，不散写文案价。
前置条件：均在不能侵权基础上；无资质策略见「合规策略」列

命中产品规则时：自动勾选附加服务 → 生成费用（与风控查货「附加服务↔费用」同口径）

1. 仓口出货结果（标准化枚举）

正常出 可直接出，无额外资料。
需资料出 须备齐证件/鉴定报告后方可出（如海运鉴定报告 MSDS）。
有条件出 可出但有限制文案（杀伤力弱可/图案不侵权/军绿不接等）——条件写入「条件说明」。
不接 全仓或该仓拒收。

2. 报关 / 清关 HS · 清关要求 NEW

报关 HS：国内出口报关用税号（可与清关不同）。
清关 HS：目的国进口清关用税号。
清关要求：目的国清关注意点（FDA/EPA/DOT、反倾销、需商检、授权信等），供关务/清关行引用。下单选品名后带出。

3. 进口证件要求（可多选标签）

CPSC · UN38.3 · MSDS/海运鉴定 · UL 授权 · ETL · 蓝牙授权 · 商检 · 其他。缺件策略与「合规策略」联动（不接 / 扣货不赔 / 可走）。

4. 收费标准 → 附加服务

Excel 原文「0 / 0.5 / 3 / 液体+2」标准化为：
· 无附加：不关联服务
· 固定附加：关联 1 个服务码（如 AS-LIQUID-3、AS-BATTERY-05）
· 按属性分段：按形态（液体/膏体/固体）关联不同服务码
金额、币种、单位在「收费标准·附加服务」统一维护；产品行只存关联，不存散落数字文案。

5. 与周边模块

风控查货：勾选品名 → 带出附加服务清单并联动费用。
下单/报关：展示仓口出货结果、报关 HS、证件要求；「不接」拦截下单。
清关：带出清关 HS + 清关要求给清关行/海外。
反倾销：独立清单（表内「反倾销列表」页暂空，预留入口）。
