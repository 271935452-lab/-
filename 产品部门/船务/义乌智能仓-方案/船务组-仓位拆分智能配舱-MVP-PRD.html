  1. 打：SKU未达标、SKU超杂柜、未满、配舱超限、超重（审核区间）、超超重（超过禁止上限）、合并单多舱、反倾销分柜、调拨柜等；SKU达标不打标（默认 <15 达标、15～20 未达标、>20 超杂柜，阈值可配）

  4. 分册交互稿：仓位拆分-提单管理-PRD-交互稿

  1. 装完 / 离港前由终配标记映射：重货 / 多SKU / 超限 / 合并多舱
  2. 只展示、不拦流程；入仓仍按实收核对

三、功能逻辑说明

3.1 海派仓位

分册交互稿（橙圈 1–7）为开发主口径：仓位拆分-海派仓位表-PRD-交互稿。

功能点说明原型
批量创建提单
  1. 跳转现有批量创建提单页；勾选可带入船期/港口/渠道等，未勾选空白录入
 批量创建
渠道 · 销售产品
  1. 均取销售产品主数据（同源）；编辑仓位两者都必填（本页沿用之前的批量登记仓位）
  2. 创建提单（放舱带出 / 批量创建）两者都必填
 渠道/销售产品
放舱出号
  1. 补录正式提单号 → 生成「待分配」提单；本页不跳转，去提单管理待分配页签查看
  2. 无号只在海派仓位维护；已出号后本页不可再编辑仓位
 放舱出号
编辑仓位
  1. 本页沿用之前的批量登记仓位；可编辑未出号行
  2. 已生成提单不可编辑；提示：已生成提单，请在提单管理页面编辑
 编辑仓位
分配预计装柜时间
  1. 按预计装柜日期落入对应周；无预计装柜时间只在「全部周」
  2. 可同时维护要求到柜时间（日期+时间）
 分配预计装柜
退运
  1. 装柜前用退运（未装完可退）；装柜完成后走换柜换船
  2. 退后仓位已作废；已出号同步提单作废；退运费选填挂提单预估
 退运
导出
  1. 按勾选行导出
 导出
方案绑舱位
  1. 自动配舱方案对到哪个未过期仓位，由人来选；同渠道多仓位时系统不自动绑死
 海派仓位

3.3 待配仓 · 自动配舱

功能点说明原型
适用范围
  1. 按所在仓启用（规则配置开关）；按销售产品渠道切开
  2. 候选定版：所在仓＝运单「所在仓」（含调拨转入）；非扣件＝扣件状态「正常件」；已放舱＝有提单号；未装柜＝提单「待分配」或「待装柜」（终配舱：未出仓且非终配）
  3. 人选渠道+柜型数量点「自动配舱」；不按签入自动跑；一次一套方案
 待配仓
柜型上限
  1. 按已有柜型：40HQ 70 方 / 40GP 60 / 45HQ 80；箱数 ≤1100
  2. 重量只看整柜：≤19.5 通过；19.5～25.9 出方案+待办黄少飞，打「超重」；>25.9 不落成，打「超超重」
 规则配置
优先级
  1. 渠道硬隔离最高且不可关
  2. 其下可上移/下移调序，每条可开「强制」：①合并报关同柜·调拨同序、②反倾销集中、③服装货合计<上限（默认40方）、④少地址 SKU 装满、⑤限时达集中、⑥单仓整柜。人工调整不拦，保存按实际打标
  3. 强制开启：不满足走「超限怎么处理」；未开强制仅为软排序
 方案 · 优先级
地址 SKU
  1. 快递派 / 海外仓自提：默认一级整类计 1；选了服务商简称则 1+2 算整类
  2. FBA 按仓代码；私卡按地址。三档可配（默认 15 / 20）：小于达标 → SKU达标不打标；达标～超杂柜阈值 → SKU未达标；大于超杂柜阈值 → SKU超杂柜；后两档仍出方案并打标
 规则配置
任务日志
  1. 执行自动配舱留任务日志（含生成的终配舱号）；规则快照看已发布版本列表
 任务日志
规则入口
  1. 待配仓不设规则说明入口；改规则进侧栏「配舱规则配置」
  2. 既有待配仓字段 / 出号细则仍以 V1 PRD · 待配仓 为准
 待配仓

3.4 终配舱 · 补货 / 标记 / 待办

功能点说明原型
直接终配
  1. 硬条件与优先级都满足可直接终配；仍允许人工改，保存再校验
 终配舱
转人工
  1. SKU 超限 / 未满 / 方数箱数超限：打标停待配，可不推待办
  2. 重量中档：待办黄少飞；超重或服装超 40 方：待办配舱同事
  3. 合并报关跨渠道：不出方案，待办配舱同事
  4. 合并单多舱 / 反倾销分柜 / 调拨柜：进「超限怎么处理」可配只打标或转人工（默认只打标）
  5. 待办在待配推一次，改配中后关掉；同舱同原因不重复推
 方案 · 转人工
人工补货入口
  1. 未满舱从「人工补货」封门；弹窗勾选运单后「补进勾选舱」；留货队列不进自动配舱
  2. 既有终配舱作业细则见 V1 PRD · 终配舱
 终配舱
操作日志
  1. 工具栏「操作日志」：待办确认、调整终配（补货保存 / 配舱完成）、柜子对调（仓库视图写入可回看）
  2. 可按类型 / 终配舱号筛选
 终配舱 · 操作日志

3.5 配舱规则配置

功能点说明原型
按所在仓独立
  1. 顶部选货物所在仓（含调拨转入；≠收货仓）；本仓启用开关；草稿 / 版本按所在仓存
  2. 自动配舱候选货=该所在仓库存货（含调拨过来的），不按收货仓筛
  3. 可从其他仓复制到当前仓（覆盖表单，需再保存）
 规则配置
配置项
  1. 柜型方数 / 重量、地址 SKU·尾端（含达标/超杂柜阈值）、服装词表、优先级（①合并报关同柜·调拨同序+强制）/ 限时达词、超限处理（含SKU未达标/超杂柜、合并单多舱/反倾销分柜/调拨柜）、封门留货、生效时间、版本摘要
  2. 左侧配置导航 + 右侧编辑（对齐现网配置页交互习惯）
 规则配置
发布
  1. 填生效时间后发版；已终配柜子绑当时版本，不随新发布重算
 规则配置

3.6 封门货 / 留货

功能点说明原型
怎么留
  1. 每渠道约 10 票 2.5～3.5 方 + 10 票单票单件（可配置）
  2. 自动不封门；未满由终配人工同渠道从队列补；优先少运单号
 规则 · 封门货
关务衔接
  1. 签入预报与普通货同一套；制单 / 核准 / 舱单以含封门后的终配合计为准
  2. 封门改已开工柜 → 配舱变更通知资料员。详见对接确认页
 关务对接

3.7 装前换柜

功能点说明原型
两柜对调
  1. 勾选两条，对调「配舱号 ↔ 柜 / 提单」；配舱号内货不动
  2. 必须同渠道、同柜型；两柜都已到现场且未开装
  3. 只在装柜计划·仓库视图做；终配舱不做入口；写入终配舱「操作日志」（柜子对调）
 仓库视图

3.8 海外接柜预判

功能点说明原型
标记映射
  1. 超重/超超重 → 重货；地址SKU超限 → 多SKU；方数/箱数超限 → 超限；合并单多舱 → 合并多舱
  2. 装完 / 离港前推主单跟进；到港前海外可见
 泳道图
