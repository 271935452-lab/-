A. 入池与排除

编号场景实际配舱情况谁动手
A1 货在义乌智能仓、非扣件、有渠道 进入自动配舱候选池，按渠道切开后跑规则 自动
A2 货在分公司 / 非智能仓 不走本套自动逻辑；仍手配或现网终配规则 不进本方案 → 手配
A3 运单为扣件状态 不能配舱，剔出候选池 不配
A4 尾端「一件代发」 自动配舱按海外仓自提计地址 SKU / 归类；洛杉矶柜常态进美库；海外仓后续一件代发人工衔接 归类自动 + 海外仓衔接
A5 全部硬条件 + 软优先级均正常满足 直接落自动配舱方案，打自动配舱标，无需人工确认 自动落成

B. 渠道 / 柜型 / 容量

编号场景实际配舱情况谁动手
B1 同渠道货源充足，方数/箱数/重量均在第一轮上限内 默认按 40HQ、70 方打一舱（或开多舱），自动落成 自动落成
B2 美森 CLX 与 T16（或中美）货都在池里 自动绝不混柜；各开各的舱 分渠道配
B3 某渠道缺货，想跨渠道升舱补货 自动不做；必须人工确认后手配/改舱 人工确认
B4 终配时仍不知真实柜型 第一轮一律按 40HQ · 70 方生成 按默认柜型
B5 实际用到 40GP 人工改按 60 方上限调方案 / 踢货或减载 人工调柜型
B6 实际用到 45HQ 人工可按 80 方放宽或补货 人工调柜型
B7 同渠道货量 > 一柜上限（方 / 箱 / 重任一顶满） 当前舱打住，开下一舱继续装同渠道剩余货 多舱
B8 箱数将超过 1100 不再往本舱塞；超额票进下一舱或不进本方案 开新舱 / 跳过
B9 第一轮配到接近上限但柜未满（如 65/70 方） 自动先落方案；剩余空位不自动硬塞（不封门），留给现场用封门货队列补 留余量 → 人工封门
B10 同渠道内同时有 FBA 卡派、快递、自提、私卡 允许同柜（非强制分柜）；仅作很弱排序参考，以地址 SKU 为主 可同柜

C. 地址 SKU

编号场景实际配舱情况谁动手
C1 舱内地址 SKU ≤ 15（默认阈值） 不打超限标；满足其他硬条件则自动落成 自动落成
C2 舱内地址 SKU > 15 仍生成方案，页面打标提示配舱同事；用不用人工决定（不禁配、不强制审批流） 出方案+打标 → 选用
C3 运营把阈值改成例如 12 或 18 按新阈值判断是否打标；逻辑同 C1/C2 改配置 + 系统按新阈值
C4 舱内仅快递派 + 海外仓自提（无 FBA/私卡散地址） 地址 SKU = 2。配舱时快递派整类算 1，不按 FedEx、UPS 拆开 易落成
C5 FBA 卡派含 16 个不同亚马逊仓代码 SKU=16 → 超默认 15 → C2 打标；系统仍可出方案 打标
C6 FBA 按仓代码货量排序后，「少 SKU 装满」与「单仓能整柜」冲突 按优先级：少 SKU 装满（③）优先于单仓整柜（⑤） 按优先级

D. 优先级与标记货（合并报关 / 反倾销 / 限时达 / 服装）

编号场景实际配舱情况谁动手
D1 同渠道有合并报关组 + 其他散货 合并报关优先同柜（优先级①）；同柜后该舱地址 SKU 往往偏多（预期行为） 合并优先同柜
D2 同渠道两组合并报关合计超过一柜上限 自动拆开配到不同舱，业务标记打「合并单多舱」 自动拆 + 合并单多舱
D3 查货备注或额外服务 / 附加服务命中反倾销多票 任一命中即认。同渠道集中同柜（优先级②） 反倾销集中
D4 合并报关 vs 反倾销不能两全（容量不够） 先保合并报关同柜（① > ②）；反倾销剩余票开专舱或进下一舱 按优先级
D5 销售产品名含「限时达」的 FBA + 快递派 优先同柜（④）；且允许快递限时达与 FBA 限时达同柜 限时达同柜
D6 限时达货与「少 SKU 装满」冲突 少 SKU（③）优先于限时达（④） 按优先级
D7 单个 FBA 仓代码货量本身可装整柜 在更高优先级都满足后，优先做单仓整柜（⑤，最弱） 单仓整柜
D8 品名命中服装，舱内服装合计 ≤ 40 方 可进自动方案 可配
D9 服装合计将 > 40 方 转人工判断（不自动硬踢末票）；方案不自动落成该组合 转人工
D10 风控在备注打了服装 / 反倾销，与品名不一致 反倾销：查货备注或额外服务/附加服务任一命中即认；服装以品名或风控备注为准 按标记命中
D11 美西一件代发 + 普通海外仓自提同渠道 一件代发按海外仓自提归类，可与自提同「地址 SKU=1」口径；进美库后续人工衔接 归类 + 海外仓
D12 新增销售产品未单独通知规则 按现有渠道↔尾端映射默认一致参与自动配舱 默认规则

E. 重量审核

编号场景实际配舱情况谁动手
E1 舱内实重合计 ≤ 19.5 吨 重量关自动通过；再叠其他条件决定是否落成 重量通过
E2 整柜实重在 19.5～25.9 吨 先出方案，推黄少飞看整柜。不看单票重，也不因没有大单票退回重配 黄少飞确认
E3 整柜实重 > 25.9 吨 不落成。方案留下，转配舱同事拆舱或踢票 禁落成 → 人工
E4 单票十几吨，整柜仍在某一档 单票不单独确认。整柜 ≤19.5 走 E1；19.5～25.9 走 E2；大于 25.9 走 E3 只看整柜

F. 截单与舱位

编号场景实际配舱情况谁动手
F1 仓位已录入，且未过「最迟配舱终止时间」 自动配舱可针对该渠道/仓位窗口出方案；对舱位由人工完成 出方案 + 对舱位
F2 已过该仓位最迟配舱终止时间 该仓位不再作为自动配舱匹配窗口（避免截单后才配完） 跳过该仓位窗口
F3 仓位与渠道尚未人工绑定 系统不强行精算唯一舱位；配舱方案可先出，对舱位等人绑好再做 先绑仓位↔渠道
F4 配舱完成但订舱舱位不足 / 加班船装不下 配舱与订舱平行；舱位不够由人工改配、拆舱或换船（一期不自动补哪票） 人工调
F5 同渠道、同柜型；两柜都已到现场；都未开装；B 货急、A 柜先到 仓库视图勾选两条做换柜对调（终配舱不做）。配舱号里的货不动，只对调柜/提单绑定。之后用到场的 A 柜装 B 配舱号的货 换柜
F6 不同渠道的两条要换柜 不允许。同渠道才会换 硬拦
F7 柜型不同（如 40HQ ↔ 45HQ）要换柜 不允许。只换同柜型 硬拦
F8 柜未到现场，或任一柜已开始装柜 不允许换。必须两柜都到现场，且装柜开始之前 硬拦
F9 立库已按配舱号下发，但还没开始往物理柜里装 仍允许换柜。换的是配舱号↔柜绑定，跟货在立库或已下发到哪无关 可换

G. 落成后 · 现场与推送

编号场景实际配舱情况谁动手
G1 自动方案已落成，柜未满（封门货） 终配舱「人工补货」从本渠道封门货留货队列取普货补满；自动不消费该队列。兼降查验掏柜风险 人工封门
G1a 剩余约 2～3 方要封门 优先取队列里 2.5～3.5 方一票封住（单号越少越好）；不够再搭 1～2 件「单票单件」。同渠道；可同渠道升级，默认不告知客户 人工封门
G1b 本渠道封门货不够，想跨渠道封门 不自动跨渠道；须人工确认后再补。渠道硬隔离高于封门便利 人工确认
G2 纯立库出货，方案方数 ≤ 第一轮上限 按配舱号推送；主线不因「差一点满」暂停；因上限留了余量，一般装得下 推送
G3 立库 + 地堆混合装同一配舱号 一期不标地堆/立库、不拆两套方数。仍按柜型上限（如 40HQ=70）留余量 统一上限
G4 人工改完方案保存 / 补货保存 再按规则校验；不在规则内打业务标记，最终由人确认。原有业务标记不取消 校验+打标
G5 美森加班等舱位方数不够吃下已配方案 不自动决定「哪种货补上/卸哪票」；人工改方案（调研池相关） 人工改配

H. 组合冲突示例（一眼看懂怎么配）

编号同时出现实际怎么配
H1 同渠道 · 合并报关 + 反倾销 + 限时达，容量只够一舱的 2/3 先装合并报关同柜 → 再塞能进的反倾销 → 限时达能进则进；剩票开下一舱。地址 SKU 若超 15 → 打标仍出方案。
H2 跨渠道货 + 本渠道货都急着截单 绝不自动混柜；各渠道各自出舱；对到各自未过期的仓位窗口。
H3 地址 SKU=18 + 实重 18 吨 + 服装 30 方 重量过、服装过；SKU 超限 → 出方案+打标，配舱同事决定用不用。
H4 地址 SKU=10 + 整柜实重 22 吨，无论有没有一票 12 吨 进重量审核，黄少飞只看整柜。不看单票重，不退回重配。
H5 服装已 38 方，再进 5 方服装会超 40 该 5 方不自动塞进本舱；整组若只能这样装 → 转人工判断是否超 40 或拆舱。

I. 补充组合（规则叠在一起时）

H 只覆盖了「优先级打架」和几组典型叠标。下面是同一票货 / 同一舱同时踩中两条以上规则时，按已确认口径推出的配法。 标 推论 的是规则能推出来、但群里没单独点名的；标 待确认 的进调研池前先按此草案给业务看。

编号组合实际配舱情况依据
I1 合并报关组里有一票扣件 该组先不配。等扣件放行后，再整组自动配。 已确认 等放行再配
I2 同一合并报关组跨了两个渠道（数据异常） 渠道硬隔离高于合并优先级：不能为了合并报关自动混渠道。整组转人工。 推论 跨渠道绝对不混柜
I3 反倾销货分布在两个渠道 各渠道内分别集中；不跨渠道并成一柜。 推论
I4 同渠道两组合并报关，A=50方、B=30方（合计>70） 两组各自完整进不同舱（自动拆开），打「合并单多舱」。不能为了装满把某一组拆散。 已确认 自动拆 + 打标
I5 同渠道两组合并报关，各 20 方，都能整组装进 70 方 允许两组都完整地进同一舱，再用散货补到上限内。 推论
I6 反倾销合计 90 方 > 70（合并报关说「不会超一柜」，反倾销没这么说） 尽量集中：第一舱装满反倾销，剩余反倾销再开一舱，不把剩余反倾销拆进已装好的普通柜。 推论 集中 + 方数上限
I7 单个 FBA 仓能「整柜」，但这一个仓就有 75 方 一舱最多 70。超出的尾数进下一舱（下一舱因此 +1 个地址 SKU）。单仓整柜让位给方数上限。 推论 ⑤最弱
I8 合并报关同柜后地址 SKU=18，同时实重 18 吨、服装 30 方 重量、服装都过；只因 SKU 超阈值 → 出方案 + 打标，不拦。这是「合并报关自然变成 SKU 多的柜」的正常结果。 已确认方向
I9 SKU≤15，但实重 22 吨且服装将超过 40 方 两条都要人工：先按服装转人工判断；若人确认可超 40，再看是否进重量审核。不自动落成。 推论
I10 边界：SKU=15 / 服装=40 方 / 实重=19.5 吨 / 实重=25.9 吨 15 个不打标；服装 ≤40 可自动；≤19.5 自动过；≤25.9 仍在审核档（含 25.9），大于 25.9 才禁。 按原文 ≤
I11 整柜刚好 19.5 吨，里面有一票 18 吨 整柜未进审核档 → 重量关通过。单票再重也不另审。 已确认 只看整柜
I12 整柜落在 19.5～25.9，人改方案后拆开了合并报关，或地址 SKU 更高 重量待审只看整柜，不因单票退回重配。人改过的方案以人工结果为准。 已确认 不自动重配
I13 方案已落成，现场补的「普货」会让重量进审核档 / 箱数>1100 / 服装>40 / SKU 从 15 变成 16 补货前先算一遍。会踩新红线的票不建议补；补了则该舱改为手配（取消自动标），整柜进 19.5～25.9 的再走 E2。 推论
I14 截单前该渠道货只有 40 方（装不满 70） 仍要在最迟配舱终止时间前出方案（未满舱），打未满提示更好；剩下空位现场补普货。不能为了等满柜错过截单。 推论 截单前必须配完
I15 同一渠道两个仓位都没过截止时间 自动配舱按渠道出方案；对到哪一个仓位由人工选。系统不自动绑死唯一舱位。 已确认 对舱位人工
I16 立库已按配舱号开始下货，此时才发现装不下或想抽货改配 主线不停、该配舱号会出完。抽货/改配要在下发立库之前做完；下发后只允许现场在余量内补普货，不回滚。 推论 张富强：暂停会卡主线
I17 尾端不是快递派、海外仓自提、FBA 卡派、私人卡派 目前不存在。配舱按销售产品上的派送方式名称选。 已确认 不存在
I18 整柜直送产品 不在本自动配舱规则内，不与散货走这套拼柜逻辑。 已确认 整柜另册
统计：硬条件都满足且未超标未超重 → 自动落成； 仅超地址 SKU → 出方案+打标； 重量中档 / 服装超 40 / 未满封门货 / 跨渠道补货 / 改柜型 / 补货踩线 / 对舱位 / 装前换柜 → 人工； 扣件、非智能仓、>25.9 吨、过期仓位窗口、尾端无法归类、跨渠道或不同柜型换柜、未到场或已开装换柜 → 不配或硬拦。 渠道硬隔离始终高于合并报关 / 反倾销 / 限时达。封门货不进自动：同渠道留货队列、优先少单号。
