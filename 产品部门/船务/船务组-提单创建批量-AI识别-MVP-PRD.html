3.2 批量 Excel

功能点说明原型
界面
  1. 现网路径 Excel 表，不是单票表单
  2. 浅色分组表头（基本蓝 / 费用绿 / 船期橙 / 柜子紫 / 港口青 / 航运粉）
  3. 列字母徽章。必填列名带 *。页顶只留操作提示，不写路径、不写回写预估长文
  4. 测：点 A1 编辑栏为 A1；无 /Scan/BillAddBatch 长文案
批量
换格 / 填
  1. Tab 右、Shift+Tab 左、Enter 下
  2. Shift 选多行后 Ctrl+D 或「向下填充」= 用第一行盖下面
  3. 没选多行 toast 先选。默认预留空行，清空后仍是空表不是 0 行
  4. 测：没选多行 Ctrl+D 提示先选
向下填充
粘贴
  1. 格内 Ctrl+V。第一行含「提单号/柜号」等表头 → 按列名对位并跳过表头；无表头从当前格按列序写
  2. 行不够自动增行。不另设「从 Excel 粘贴」按钮
  3. 测：粘贴带表头的表，表头行不入库

  1. 同单票：三项回写预估。中转港、备注、装柜不参与保存拦截
  2. 港口/船司低置信度须手核。未放舱、提单号空着也能存，落入提单管理待分配，列表提单号为空
  3. 测：不填中转港/备注其它必填齐能存；空提单号保存后进待分配

3.3 AI 识别

功能点说明原型
三步
  1. ① 上传 PDF/PNG/JPG/Excel 或粘贴邮件
  2. 批量一次最多 30 份、单文件 ≤20MB，清单表不是 chip
  3. 写入：追加 / 覆盖空表。② 按文件排队识别，进度 x/n 完成 · 成功 · 失败 · 进行中
  4. 先完成的先校对、先写入，不必等全部结束
  5. ③ 左文件列表 + 右该文件 Excel 格（分组表头、列字母、点格编辑），红格先核
  6. 筛全部/需校对/失败，默认需校对
  7. 只写入勾上的行，格子橙色。点遮罩关不掉
  8. 取消整表不变。单票只走 ①②：识别完成直接填入本页编辑，不走第 3 步列表。
  9. 测：8 份演示：未等全部结束就能勾成功行写入；失败份不进表
  10. 测：单票：开始识别后不出现左列表/Excel 格，关弹窗后停在编辑页
批量 AI · 单票
收起
  1. 顶栏「收起」变右下角悬浮条，识别不停、不挡本页表格/顶栏
  2. 切到提单管理 / 待配仓 / 运价等页，条仍在右下角；点「展开」回到原创建页并打开弹窗。取消或关弹窗后条消失
  3. 测：收起后点提单管理，右下角仍有「AI 识别已收起」；点展开回到本页校对步
收起

  2. 测：切「失败」点重试本份；同时已勾成功行能写入

字段映射
