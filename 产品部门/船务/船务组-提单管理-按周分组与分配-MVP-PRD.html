  2. 测：待分配未装完即使 ETD 已过也不进；装完 08-06 无进港也进未进港
未进港

周页签
现网条件首行

三、功能逻辑说明

3.1 工具栏 / 勾选

功能点说明原型
留哪些
  1. 查询、提单创建、批量创建提单、修改、删除、导出、复制提单、换柜换船、分配、绑定进口商、费用登记 ·水单、舱位播报、取消 IT、发 AMS、发 ISF、操作日志
  2. 创建/批量标「改」，紧挨查询右侧。删除为红按钮
  3. 测：有「发 AMS」「发 ISF」。查询右侧是创建、批量，均标改。有删除、导出、复制提单
查询
拿掉
  1. 提单公告、查验标记/挂票、改单、查验换船、换单撤销、进港代码、修改装车/作废/船单/截单
  2. 舱单仍在报关管理发；AMS/ISF 改回本页装柜前发送
  3. 测：工具栏有发 AMS / 发 ISF，没有查验挂票/改单手打
打开
勾几条
  1. 分配、取消 IT、绑定、换柜换船、费用登记、删除、导出、复制 ≥1
  2. 修改、日志只能 1 条。播报、查询、创建不用勾
  3. 未勾选打开动作 → toast，不弹窗（播报除外）
  4. 点遮罩关不掉。勾选里任一提单号为空 → 点分配拦住（见分配抽屉）
  5. 测：不勾点费用/分配拦住；无号行点分配拦住；绑 2 条开日志拦住；不勾开播报能开
打开
提单修改
  1. 勾 1 条，打开与创建同一张表（含两免用箱、装柜时间、进港时间补录、进港代码）
  2. 删除、导出、复制提单跟修改同一排，规则按线上
  3. 测：免用箱有值；清空国内免用箱确定拦住
  4. 测：修改页有进港代码格，能空着也能手填 SHA
修改
分页 / 排序
  1. 流转看时分页作用在当前周内；单独筛按该类全量分页
  2. 切周/切状态/点预警/查询/改每页条数 → 回第 1 页
  3. 同船名航次聚在一起，船内未装完优先
  4. 测：切周后再翻页只翻当前周内；同船未装完在前
打开
进待分配
  1. 未放舱、尚无提单号的柜，创建或订舱落入后直接进待分配，不等放舱出号
  2. 待分配页签提单号列为空（—）。放舱补号后列里才有号，状态仍待分配直到点分配
  3. 无号行不能分配，点分配 toast「请先补充提单号等信息」，抽屉不开；补号走提单修改
  4. 测：切待分配，提单号是 — 不是假号
  5. 测：无号行勾选点分配拦住、抽屉不开
待分配
装完色标
  1. 仓库「装柜完成」回写：绿底已装完、橙底未装完
  2. 预警行不打装完绿底。仓库撤销则退回未装完。船务列表无打标按钮
  3. 测：本页没有装完按钮。预警行无绿底
打开
IT / 查验 / 改单口径
  1. 取消IT 只存 无 / 已取消IT。本期不对接有IT接口，人工判断要不要取消，不按接口有无拦按钮
  2. 已取消IT 不能改回无。没有「取消中」。关务展示已取消IT
  3. 国内查验标根据查验轨迹编号才打；本页无手打、查验挂票不在本页做
  4. 改单标由换柜换船②查验换船 / ③查验换柜换船写下；本页无改单按钮。改运抵走港区运抵通道
  5. 海放/码放：TR00803 报关放行已登记才算海放，A00178 码头放行已登记才算码放；无编号=未放
  6. 测：工具栏无查验挂票/改单手打；轨迹无编号不打查验标；查验换船确定后出现改单标
取消IT

3.2 分配 / 播报 / 取消IT / 绑定 / 换柜换船

功能点说明原型
分配抽屉
  1. 勾选 → 点分配。勾选里任一提单号为空（或 —）→ toast「请先补充提单号等信息」，抽屉不开，整批拦住
  2. 补号走提单修改。有号才开抽屉
  3. 顶栏：提单号、柜号、始发港、柜型。页签仓库装柜 / 工厂装柜
  4. 仓库必填：所属客户、第一装柜地点、装柜地址1、预计装柜时间1
  5. 工厂必填：所属客户、第一装柜地点、工厂地址1、预计装柜时间
  6. 填预计装柜时间1（工厂页签则该格）即时带出周（只读，人不能改周本身）；周按时间1所在自然周（周一～周日），时间2不参与
  7. 车辆：提箱地点、还港/还箱地点必填。拖车默认「数据为空」，查询价格后点选
  8. 本期不对接到企微群：抽屉无群文案、无一键复制到企微
  9. 确定（校验）：先再核提单号，空号同样 toast、抽屉不关；必填通过后写回拖车/地址/时间/客户/车辆，装柜时间写回列表，按该日落入对应周页签（从原周挪走），待分配→待装柜，写日志（含周旧→新）
  10. 空提交该项红字「此项为必填项」
  11. 测：待分配无号行勾选点分配，toast「请先补充提单号等信息」，抽屉不开
  12. 测：混勾空号+有号整批拦住。有号待分配行能开、确定写回
  13. 测：必填留空点确定不关闭
  14. 测：把装柜时间改成 08-12，格下带出「落入 2026 第33周（08-10～08-16）」；确定后切第33周能看到该行
分配
舱位播报
  1. 不用勾提单。仓→起运港→目的港→勾飞驼船期
  2. 仓：青岛/宁波/厦门/义乌。范围（周）1～8，默认 1 周，按 ETD 窗口筛船期
  3. 起运港/目的港单选下拉，不选=该层全部
  4. 无渠道/播报群/发出方式。飞驼可刷新
  5. 默认勾：窗口内或截单已过须更新。飞驼开航/截单/到达/下一水只读
  6. 勾选后带出下方 Excel 表。表格可手改（含标题/备注/格子）。船期列表不打「仓位充足」
  7. 底栏「一键复制」复制手改后的表格。本期做一键复制播报，不做推群、不另生成播报文件
  8. 不写拖车、不写日志。表格列：序号｜航线｜{仓}截单｜起航｜到达｜始发港｜舱位情况｜船名航次｜下一水
  9. 测：不勾能开。范围改成 8 周列表变长
  10. 测：改表格一格后再一键复制，粘贴含改后值。无推群按钮
播报
取消 IT
  1. 状态为「无」可点；已是「已取消IT」拦住，不能改回。本期不对接有IT接口，不按接口有无控制按钮，人工判断
