提单管理增量

与报关管理相同：右侧「PRD」按钮展开/收起；页顶增量说明收入 PRD，不占主列表。

页顶说明（已收入 PRD，不占主列表）

  • ① 列表平铺：去掉按周分组表头；周改底部 Excel 式页签悬浮切换；表内船名航次（含船司·港·柜型）汇集；排序仍为同船→未装完优先
  • ② 装完色标：未装完（橙）/ 装完（绿）行底色（列表不展示色标列；已去掉「美装完」）
  • ③ 取消IT标记→通知关务清关待办
  • ④ 提单分配改为「发群消息」交互，一键复制到拖车代理群
  • ⑤ 查验标记（默认挂柜；单票责任标「查验挂票」）
  • ⑥ 改单标记（截单资料：件毛体/收发通/HS品名/铅封/VGM 等，可挂改单保函）
  • ⑦ 一键复制仓位播报（按同船聚合生成播报文案 → 营销中心群）
  • ⑧ 临近截单 / 临近未海放 / 临近未码放自动预警标记（海放≠码放）
  • ⑨ 一水绑柜：散货超过 5 柜在绑定进口商时强提示（不设独立超限页签）
  • ⑩ 费用登记（含水单）：费用与水单合并同一入口；可对接邮件回邮
  • ⑪ 发送标记 = AMS / ISF（卢慧恒截图批注）：筛选项「发送标记」与工具栏 AMS、ISF 打通
  • ⑫ 业务标记合并列：原「IT / 发送 / 查验 / 改单」四列合并为列表「业务标记」一列（筛选项与工具栏动作仍分项，不合并）

背景（0730 船务）

  • 同船数据分散不好用 → 列表不再按周分组折叠；周用底部页签切换；船名航次进列汇集；排序：同船名航次 → 船内未装完优先。
  • 装完色标：未装完（橙底）/ 装完（绿底）用行底色区分；已去掉「美装完」色标与工具栏；列表不展示色标列 / 费用列 / 水单列。
  • 分配提单依赖个人经验、先群里安排再录系统 → 改为发群消息式交互，一键复制到拖车代理群并写回。
  • 取消 IT：牵动提单 / 清关 / 报关 / 标记 / 加费；确认后提醒关务清关；截单可补中转港。
  • 查验标记：默认挂柜；单票责任标查验挂票并回写运单；可与关务查验处置联动。
  • 改单标记：改截单资料（件毛体 / 收发通 / HS品名 / 铅封 / VGM / 提单号）；与「改运抵」区分；可挂改单/改 VGM 保函并通知关务+代理。
  • 仓位播报：现状手拼 → 按勾选/筛选提单同船聚合生成播报文案，一键复制到营销中心群（可带截单、待配仓货量、运价摘要）。
  • 放行预警：临近截单（截单前 提前 24 小时）；开船窗口内按海放 / 码放分别盯控——临近未海放 / 临近未码放（ETD ≤3 天且对应侧未放）；已过 ETD →「开船未海放 / 开船未码放」（衔接触发智能甩柜）。
  • 一水绑柜：同进口商 + 同船名航次统计已绑柜数；散货超过 5 柜 → 列表红标 + 顶部横幅 + 绑定进口商弹窗强提示（不设独立「超限」页签）。
  • 费用登记（含水单）：同一工具栏入口；可「仅费用 / 费用+水单 / 仅水单」；归属改为挂柜/挂票双列表多选；邮件带入费用 + 水单回邮；已付可进业务员成本。
  • 发送标记：筛选项对应 AMS/ISF 发送状态；工具栏「AMS」「ISF」对勾选提单打「已发」并回写列表（与筛选联动）。

业务标记（合并列）

  • 列表仅一列「业务标记」，内嵌展示：IT、AMS/ISF、查验（有则显）、改单（有则显）；标签自动换行。
  • 筛选项仍分「IT 状态 / 发送标记 / 查验标记 / 改单标记」；工具栏动作不变（取消IT、AMS、ISF、查验标记、改单标记）。

发送标记（AMS / ISF）

  • 筛选项「发送标记」：AMS 未发/已发、ISF 未发/已发、均已发、缺 AMS 或 ISF。
  • 勾选提单 → 工具栏「AMS」或「ISF」→ 写入对应已发状态；展示在「业务标记」列内。

取消IT标记

  • 业务标记内：有IT（红）/ 已取消IT（紫，含原因·中转港·时间）/ 无IT。
  • 勾选「有IT」提单 → 工具栏「取消IT标记」；或行内点「取消IT →」→ 填原因 / 中转港 / 是否通知关务 → 写回「已取消IT」并通知关务清关待办。
  • IT / 改单筛选用顶部筛选项（已去掉「有IT / 已取消IT / 改单中」页签）；已取消IT 行紫色底高亮。

查验标记

  • 勾选提单 →「查验标记」→ 选状态（查验中 / 查验挂票 / 查验放行 / 清除）。
  • 挂票须填关联运单号；无查验时合并列不展示占位「—」；列表可按查验状态筛选。

改单标记

  • 勾选提单 →「改单标记」或「提单修改」→ 选状态（改单中 / 已改单 / 清除）+ 类型 + 是否保函 + 说明。
  • 有改单时在业务标记列展示类型/保函/时间；筛选用顶部「改单标记」；改单中行蓝色底高亮。
  • 船开前完成；改运抵走港区运抵通道，不走本标记。

列表 · 周页签 / 船名航次

  • 批注：周不要占表内显眼列 → 改为底部 Excel 式工作表页签悬浮切换（全部周 + 各 ETD 周）。
  • 表内只保留船名航次汇集列（船名航次 + 船司 + 港向 + 柜型）；顶部「预计出发周」筛选项已去掉，与底栏页签统一。
  • 排序：同船名航次 → 船内未装完优先；装完绿 / 未装完橙行底色保留。

装完色标

  • 未装完=橙、装完=绿（行底色）；已去掉「美装完」「装柜完成 / 标为未装完」按钮、「未装完 / 已装完」页签及列表色标列。
  • 装完色标仍可在筛选区过滤（未装完 / 装完）。

分配交互

  • 勾选提单 →「提单分配」→ 选择拖车代理群 / 模板 → 绿色气泡预览消息 → 一键复制 →「确认分配并写回」。
  • 消息含：提单号、柜号、柜型、船名航次、装柜地址、预计装柜时间、提箱/还箱点、注意事项（勿选 EPS 等）。

一键复制仓位播报

  • 勾选提单（或选「当前筛选 / 同周」）→「一键复制仓位播报」→ 按船名航次聚合生成文案 → 预览可改 → 复制到营销中心群。
  • 文案含：日期、船司/船名航次、POL→POD、ETD、截单、柜数（待分配/待装柜）、可选运价摘要；挤满提示。
  • 与「提单分配」区分：播报面向营销/客服业务；分配面向拖车代理装柜。

进港 / 飞驼

  • 开船后确认飞驼能否抓进港时间：能 → 飞驼拉数；不能/未覆盖 → 人工确认 · 码头补录。
  • 未进港预警：ETD 已过仍无进港时间则标红盯控（与飞驼能否抓无关；不能抓也必须预警并人工补）。
  • 进港时间落库后触发落箱等费用节点，并经 H4 交海外港前。

临近截单 / 海放 · 码放

  • 系统按截单时刻、ETD、海放（海关）与码放（码头）状态分别打标（示意时刻：2026-08-07 10:00）。
  • 临近截单：距截单时间 ≤ 24 小时且尚未到截单（橙标；列表展示剩余小时/分钟）。
  • 临近未海放：ETD 在今日～今日+3 天且海放=未放行；临近未码放：同窗口且码放=未放行。两侧可一过一不过（示意：海放过/码放未、码放过/海放未）。
  • 已过 ETD 仍未对应放行 →「开船未海放 / 开船未码放」；筛选项 + 页签快捷过滤；正式版阈值可配置，并联动关务/码头拉数。

进口商 · 一水绑柜

  • 列展示：进口商名称 +「一水绑柜 n/5」；n>5 红标「超限」并高亮行；顶部可出超限横幅。
  • 统计口径：同一进口商 + 同一船名航次（一水船）下已绑定柜数（每行一柜）。
  • 勾选提单 →「绑定进口商」→ 预检同船已绑数；绑定后若 >5 弹窗强提示（主提示入口），仍可强制绑定（留痕示意）。
  • 不设「一水绑柜超限」状态页签；筛选项可保留「超限」过滤。
  • 整柜可不限本规则；散货默认启用 ≤5。

费用登记（含水单）· 对接邮件

  • 勾选提单 →「费用登记 ·水单」→ 选本次操作：仅费用 / 费用+水单 / 仅水单。
  • 归属：挂柜列表 + 挂票列表多选（批注：改成多个列表）；默认勾选适用提单全部柜；挂票可勾选责任运单或补录运单号；至少勾选一项。
  • 费用：手工或从通知邮箱带入；仅写入已勾选的柜/票；可关联/回复邮件。
  • 水单：同弹窗下方上传；可回邮船司/代理；确认已付进业务员成本。列表不单独展示费用/水单列。
