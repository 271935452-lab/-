本页计算与取值

本页统计整票和维度。单节点达标、超期、加权达标率的定义只在「节点达标率看板」，这里直接沿用，不另写一遍。筛选（统计周期、时间范围、履约阶段、起运港、目的港）先缩小运单，再套下面的公式。原型橙色序号 1 挂在筛选条，说明筛选与七个履约率 / 三维前三 / 明细表的联动。履约阶段与运营中心六段一致，用来收窄运单；选清关/提柜、海外仓作业、尾程派送时供应商明细看尾端环节率，其余（含全部）看起运侧。统计周期可选台账全部，或近一年内任一自然月。时间范围按到货时间过滤；起止都空则不限。时间范围与统计周期同时有值时，以时间范围为准。

1. 一条运单算不算全达标

节点达标 = 见节点达标率看板（实际时间 ≤ 应操作时间） 整票全达标 = 该票全部启用节点都达标（不启用跳过） 供应商全达标 = 该供应商挂到的启用节点都达标（其他部门的节点不算进这一家）

2. 什么票进排名，什么票进待处理

进责任部门排名 = 责任部门有值 进渠道排名 = 渠道有值 进供应商排名 = 供应商有值 且 同一节点只匹配到一家供应商 责任部门缺失 = 启用节点上责任部门为空的运单数（一票只计 1） 供应商缺失 = 启用节点上供应商为空的运单数（一票只计 1） 节点缺失 = 存在启用节点满足任一的运单数（一票只计 1）：①应操作时间为空；②应操作已到且实际仍空；③实际时间晚于当前时间

缺责任部门 / 供应商的票不进对应排名。节点缺失不另算绩效率，进运营中心补应操作、补实际，或核实未来实际。三格数字展示在「节点达标率看板」右侧，不在本页再放一块。渠道空、供应商重复仍不进对应排名，但不在待处理列表单独占格。

3. 顶部七个履约率（全公司）

分子都是「整票全达标」的运单数，分母都是该时间窗里纳入统计的运单数。归属日 = 该票到货时间（日）。

公司履约率 = 当前筛选下全部纳入运单的全达标数 / 纳入运单数 当日履约率 = 归属日 = 今天 当周履约率 = 归属日 ∈ 本周一至今天 当月履约率 = 归属日 ∈ 本月 1 日至今天 累计履约率 = 上线日至今天（不跟统计周期收窄） 累计周履约率 = 只含已经整周结束的自然周（不含本周） 累计月履约率 = 只含已经整月结束的自然月（不含本月）

当日含在当周、当月里，是时间窗嵌套，不是把同一票拆进两个分子。累计周、累计月不含未结束的本周、本月，所以和当周、当月不是同一个数。

4. 责任部门排名、渠道排名、供应商排名

已统计票数（或供应商总票数）= 该名称下进入本维排名的运单数 达标票数 = 责任部门 / 渠道：其中整票全达标的运单数 全达标票 = 供应商：其中供应商全达标的运单数 异常票数 = 已统计票数 − 达标票数（供应商用总票数 − 全达标票） 达标率（供应商称整体达标率）= 达标票数 / 已统计票数 排名 = 达标率从高到低；达标率相同则异常票少的在前

三列卡片按大厂看板 TOP3 样式：金银铜徽标 + 名称 + 进度条 + 达标率/票数；完整名次仍以下方「责任部门与渠道绩效明细」为准。履约阶段选项与运营中心相同。供应商前三与明细的环节率列：清关/提柜、海外仓作业、尾程派送 → 尾端；其余阶段及全部 → 起运侧。不再单独放领奖台式 TOP 3。

5. 部门 / 渠道明细

已统计票数、达标票数、异常票数、达标率 = 第 4 节 范围 = 这一行的责任部门或渠道 时间 = 顶部统计周期或时间范围，不在表里再拆公司 / 当日 / 当周 / 当月 / 累计 / 累计周 / 累计月

七个时间窗只在顶部。明细表跟着上面的筛选走，不再每个时间窗占一列。明细表表头各统计字段旁挂问号，点开见本页公式。

6. 供应商明细里的环节达标率

送柜达标率 = 该供应商「送柜到仓」达标运单数 / 该节点有应操作时间的运单数 装柜达标率 = 该供应商「装柜完成」同上 出库达标率 = 该供应商「尾程出库」同上 派送达标率 = 该供应商「尾端派送」同上 起运港环节只列出送柜、装柜 尾端环节只列出出库、派送

这四列是单节点达标率，判定仍用节点达标率看板的「达标」。整体达标率是第 4 节的供应商全达标，不把这四列再平均进去。

7. 色档

正常 = 达标率 ≥ 80% 关注 = 60% ≤ 达标率 < 80% 异常 = 达标率 < 60%

色档与节点达标率看板相同，本页不另定一档。

8. 导出排名（序号 2）

对应顶栏「导出排名」。页面 TOP3 不够对账时用导出拿全量。

导出范围 = 当前筛选收窄后的运单（统计周期 / 时间范围 / 履约阶段 / 起运港 / 目的港） 导出内容 = 三维全量排名，不只页面前三： ① 供应商：排名、名称、总票数、全达标票、异常票、整体达标率 + 当前环节两列环节达标率 ② 责任部门：排名、名称、已统计票数、达标票数、异常票数、达标率 ③ 渠道：同上 排序 = 第 4 节（达标率高→低；相同则异常票少在前） 格式 = xlsx（可多 sheet 或一张表加「维度」列） 不含 = 顶部七个履约率卡片本身

缺责任部门 / 供应商的票不进对应维。履约阶段决定供应商导出里的环节率列（起运侧或尾端）。
