本页计算与取值

本页只统计单个节点。整票、部门、供应商、渠道的履约率在「履约绩效分析」，这里不重复定义。应操作时间用节点上已经算出的结果，本页不另写小时。

1. 先圈定哪些运单、哪些节点

纳入运单 = 同时满足： 销售产品 = 筛选值（选全部则不限） 起运港 = 筛选值（选全部则不限） 节点.应操作时间 落在统计区间 统计区间 = 时间范围的起止日 当起、止都有值 统计区间 = 台账全部 / 近一年内任一自然月（按月选） 当时间范围为空 不纳入 = 节点为「不启用」 不纳入 = 这条运单这个节点的应操作时间还没算出来

时间范围和统计周期同时有值时，只用时间范围。下面每个数都先过这一道筛选。

2. 一条运单在一个节点上怎么判

达标 = 实际时间 ≤ 应操作时间 超期 = 实际时间为空 且 当前时间 ≥ 应操作时间 或 实际时间 > 应操作时间 暂无样本 = 该节点达标票数 + 超期票数 = 0

即将超时仍算未结案，不记达标，也不记超期，不进本页分子和分母。

3. 顶部四个数（各算各的）

有样本节点 = 已统计 > 0 的节点个数 / 本页启用节点个数 展示为「13 / 15」这种分子 / 分母 节点加权达标率 = 全部节点达标票数之和 / 全部节点已统计之和 不是把 15 个节点达标率再平均 超期次数 = 全部节点超期票数之和 同一运单多个节点超期，按节点次数累加 低于 60% 节点 = 已统计 > 0 且 节点达标率 < 60% 的节点个数

这四个数只加启用节点，不含明细表最后两行「整体时效」「整票履约」。

4. 每个节点共用的三个数

达标票数 = 该节点判为达标的运单数 超期票数 = 该节点判为超期的运单数 已统计 = 达标票数 + 超期票数 节点达标率 = 达标票数 / 已统计 已统计 = 0 时不除，显示「暂无样本」 色档 = 绿 / 正常 达标率 ≥ 80% 色档 = 橙 / 关注 60% ≤ 达标率 < 80% 色档 = 红 / 异常 达标率 < 60% 色档 = 灰 / 暂无样本 已统计 = 0

5. 热力带上的每一格

每一格只显示该节点的达标率，颜色用上一节色档。格子名字和标准节点的对应关系：

截单、送柜到仓、报关放行、卸船完成、清关放行、提柜、拆柜、尾程出库、尾端派送、POD回传 = 同名标准节点 等装时间 = 开始装柜 装柜作业 = 装柜完成 截重还柜 = 还重柜 开船准点 = 实际开船 到港准点 = 实际到港 格子上的百分数 = 该节点达标率

6. 节点达标率条形图

条的长度 = 该节点达标率（暂无样本时长度为 0） 条右侧文字 = 「暂无样本 · 0/0」 当已统计 = 0 条右侧文字 = 「达标率 · 达标票数/已统计」 当已统计 > 0 排序 = 达标率从低到高，暂无样本排在最前

7. 低达标节点（优先改善）

入列 = 已统计 > 0 且 节点达标率 < 60% 排序 = 达标率从低到高 格上的百分数 = 该节点达标率 查看超期票 = 该节点判为超期的运单清单，不另算一个率

这一列的个数等于顶部「低于 60% 节点」。热力带、条形图、这一列、明细表里的达标率是同一个数。

8. 明细表

监控节点 = 热力带上的节点名 时效标准 = 该节点配置里的时长说明，不参与除法 达标票数、超期票数、已统计、达标率 = 第 4 节

9. 明细表最后两行（独立指标）

整体时效天数 = POD回传日 − 实际截单日 整体时效达标 = 整体时效天数 ≤ 该票快照里的承诺时效 整票达标 = 该票全部启用节点都是「达标」（不启用跳过） 这两行的达标票数 / 超期票数 / 已统计 / 达标率 = 按运单套用第 2、4 节，分母是运单数不是节点次数

这两行不进顶部四个数，不进热力带，不进条形图，避免和节点票次加总算重。

10. 数据待处理（放在本页右侧）

四格的算法与「履约绩效分析」进排名条件是同一套，本页只展示，不另算一个率。点「去处理」打开对应清单。

责任部门缺失 = 启用节点上责任部门为空的运单数（一票只计 1） 供应商缺失 = 启用节点上供应商为空的运单数（一票只计 1） 渠道缺失 = 渠道为空的运单数（一票只计 1） 供应商重复 = 同一节点匹配到多家供应商的运单数（一票只计 1）

命中某一类的运单不进履约绩效里该类排名。一票可以同时出现在多类里。
