页头、阶段、工作台计数

下面每一格单独写清算什么。单节点的达标、即将超时、已超时怎么判，用第 2 节，这里不另写。页头三个数按主单计；履约阶段分布按运单计（一票一段）；工作台五个数也按运单计。页头/阶段不受列表筛选；工作台跟当前筛选走。所以页头的即将超时和列表上的即将超时不是同一个数。

整票完成（运单）= 该运单启用节点全部判定为「达标」或「不启用」（没有当前节点） 在途运单 = 尚未整票完成的运单 在途主单 = 其下至少还有 1 条在途运单的主单数（一主单计 1，不按运单加） 节点达标率（页头）= 本月节点达标率（与工作台最右一格同一公式，不另算） 页头即将超时 = 在途主单中，至少 1 条在途运单的当前节点时效状态 = 即将超时 的主单数 （一主单多运单都即将超时，仍计 1；页头不受列表筛选）
节点顺序（标准 15）= 截单 → 送柜到仓 → 开始装柜 → 装柜完成 → 还重柜 → 报关放行 → 实际开船 → 实际到港 → 卸船完成 → 清关放行 → 提柜 → 拆柜 → 尾程出库 → 尾端派送 → POD回传 履约阶段分布 = 在途运单维度（不是主单） 阶段归属 = 该运单当前节点落在哪一段；一运单只进一段 （同一主单下多运单可落在不同段，分别计数） 已整票完成的运单不进任一阶段 六段运单数相加 = 在途运单数（≥ 在途主单；一主单多运单时更大） 国内集货 = 当前节点 ∈ 截单、送柜到仓、开始装柜、装柜完成 的在途运单数 报关 / 还柜 = 还重柜、报关放行 海运在途 = 实际开船、实际到港 到港 / 清关 = 卸船完成、清关放行 海外仓作业 = 提柜、拆柜 尾程派送 = 尾程出库、尾端派送、POD回传

筛选与下方统计（评审序号 1）：筛选项本身不挂问号。顶栏条件怎么收窄列表和工作台计数、哪些块不受筛选，写在序号 1。

筛选条放在页头统计之上；取数对象 = 运单；条件之间 = 且 搜索 = 主单号 / 柜号 / 运单号 / 客户名称 任一包含关键字；空 = 不限 时间范围 = 运单.到货时间（只看日）；起 ≤ 日 ≤ 止；只填一边则单边限制；都空不限 责任部门 / 销售产品 = 精确匹配；全部 = 不限 履约状态.未完成（默认）= 即将超时 ∪ 已超时 履约状态.单档 = 只留该档；全部履约数据 = 三档都留 受筛选 = 工作台五个数 + 底表列表（本月节点达标率区间仍固定本月） 不受筛选 = 页头在途主单 / 页头节点达标率 / 页头即将超时 + 履约阶段分布
今日应处理 = 已过上面筛选后，到货日 = 今天 且 当前节点时效状态 ∈ 即将超时、已超时 的运单数 即将超时（工作台）= 已过上面筛选后，时效状态 = 即将超时 的运单数 已超时（工作台）= 已过上面筛选后，时效状态 = 已超时 的运单数 缺失节点 = 已过上面筛选后，存在启用节点满足任一的运单数（一票计 1；与节点看板「节点缺失」同一口径）： ① 应操作时间为空（起算/时长算不出来） ② 应操作时间已到且实际时间仍为空 ③ 实际时间晚于当前时间（未来实际，需核实回传） 本月节点达标率 = 本月应操作节点的达标票次 / （达标票次 + 超期票次） 达标、超期定义同「节点达标率看板」；统计区间固定本月，不跟时间范围收窄 仍受搜索 / 责任部门 / 履约状态 / 销售产品影响

今日应处理只含到货日是今天的未完成运单，以前留下的已超时不进这一格，只进「已超时」。缺失节点按运单去重；同一票多个节点缺应操作、缺实际或实际晚于现在，仍计 1。节点看板上的超期次数才按节点次数累加。

1. 列表默认范围与底表结构

默认列表（未完成）= 即将超时、已超时 全部履约数据 = 上面两项 + 已完成（含已达标） 时效状态只有三档：即将超时 / 已超时 / 已完成（不再设「待处理」）

底表只显示当前节点一行工作台，字段对齐《全程履约节点配置-横向底表》的当前切片：主单/柜/运单、当前节点、进度（已完成节点数 / 15 + 圆点）、责任部门、供应商、应操作时间、实际操作时间、时效状态、小组是否达标、服务商是否达标。

其他节点怎么看：点「当前节点」打开节点轨迹详情，按横向底表口径展开这一票全部节点（应操作 / 实际 / 判定 / 责任小组 / 小组是否达标 / 供应商 / 服务商是否达标）。全量宽表用「下载底表」。列表不铺整票横表，避免工作台过宽。

已达标明细不默认铺在底表。运营中心先看待办；要核对某一票是否达标，履约状态选「已完成」或「全部履约数据」。报表级已达标明细放在「节点达标率看板」导出。

本期底表不做「操作」列、不开放处置入口；节点轨迹走「当前节点」点击，不是操作列。

2. 三条状态怎么判（只看当前节点）

提前小时在履约规则版本里配。本页用那个小时判断，不在运营中心再配一次。时效状态按当前节点判，不是「任一历史节点超了就整票标已超时」。

节点达标（单节点）= 实际时间有值 且 实际时间 ≤ 应操作时间 节点超期（单节点）= 实际时间有值且实际时间 > 应操作时间 或 当前时间 ≥ 应操作时间 且 实际时间仍为空 不启用 = 本票规则版本未勾选该节点（如自提跳过尾端派送）；不参与超时、不进达标率样本、不进进度分子分母；圆点可虚线占位 预警时刻 = 当前节点.应操作时间 − 履约规则版本里的提前小时 即将超时 = 预警时刻 ≤ 当前时间 < 应操作时间 且 实际时间仍为空（还没达标） 已超时 = 节点超期（见上）且该节点仍是当前节点 已完成（行状态）= 无当前节点（启用节点均已有实际）；整票履约达标见上节（启用节点全达标/不启用） 互斥 = 同一运单同一时刻只落一档；过了应操作时刻后不再算即将超时

即将超时先核实轨迹和实际操作。已超时待办仍推给人；要看全票节点点「当前节点」。同一节点、同一条运单，即将超时只推一次，过点后再推已超时。

3. 当前节点、进度色、是否达标（序号 3）

对应底表「当前节点 / 进度 / 时效状态 / 小组是否达标 / 服务商是否达标」。

当前节点 = 标准顺序上，第一个「启用且实际时间仍空」的节点 （不启用跳过；前面已有实际的不算当前——含晚完成；整票完成后无当前节点，列表进已完成） 不用「尚未达标」推当前（达标是准时性）；也不用「应操作尚未过现在」（已超时仍是当前） 进度分子 = 已有实际时间的启用节点数（未启用不计入） 进度分母 = 本票启用节点数（未启用不进分母；圆点仍可虚线占位展示） 进度展示 = 分子 / 分母 + 按节点顺序的圆点串 时效状态（整行）= 只取当前节点按第 2 节的结果；历史节点超期不抬到整行 轨迹弹窗 = 每个节点各自一套应操作 / 实际 / 判定 / 小组是否达标 / 服务商是否达标；当前行标「当前」
什么情况什么颜色 进度圆点（15 个，按节点顺序）： 绿实心 = 该节点已达标（实际有值且 ≤ 应操作） 橙实心 = 即将超时（预警时刻 ≤ 现在 < 应操作，且实际仍空） 红实心 = 已超期（现在 ≥ 应操作且实际空，或实际 > 应操作） 灰实心 = 未判定（未到预警/应操作，或尚无实际且未超时） 灰虚线 = 本票不启用该节点 蓝圈/蓝点 = 当前节点（可叠在橙 / 红 / 灰上，表示「卡在这里」） 时效状态标签（整行，只看当前节点）： 绿「已完成」 = 无当前节点（启用节点均已有实际） 橙「即将超时」 = 当前节点即将超时 红「已超时」 = 当前节点已超期 灰「—」 = 未判定 小组是否达标 / 服务商是否达标（只看当前节点；轨迹里每节点各自一套）： 绿「达标」 = 该侧按节点达标 红「超期」 = 该侧按节点超期 灰「—」 = 未到判定或尚无应操作；节点未配供应商时服务商列固定「—」

不是：前面某个节点曾经超期、现在已过，仍把整行时效状态打成「已超时」。历史超期只留在节点轨迹该行的判定里。

点「当前节点」：打开节点轨迹，每行各自有应操作 / 实际 / 判定 / 小组是否达标 / 服务商是否达标；当前行标「当前」。

4. 下载底表（序号 4）

对应工具栏「下载底表」。列表不铺整票横表；全量宽表用下载。

导出内容 = 《全程履约节点配置-横向底表》口径 每票展开 = 全部节点行：应操作 / 实际 / 判定 / 责任小组 / 小组是否达标 / 供应商 / 服务商是否达标 导出范围 = 当前筛选结果（搜索、责任部门、履约状态、销售产品） 已完成是否导出 = 履约状态选「已完成」或「全部履约数据」时带上；默认「未完成」则只有即将超时、已超时

点「当前节点」只看一票轨迹弹窗；要批量核对或给报表/对账，用下载底表。
