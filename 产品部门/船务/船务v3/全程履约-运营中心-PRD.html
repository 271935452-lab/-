页头、阶段、工作台计数

下面每一格单独写清算什么。单节点的达标、即将超时、已超时怎么判，用第 2 节，这里不另写。页头和阶段按主单计，不受列表筛选影响；工作台五个数按运单计，跟当前筛选走。所以页头的即将超时和列表上的即将超时不是同一个数。

在途主单 = 其下还有运单未整票完成的主单数（启用节点里还有未达标的） 节点达标率（页头）= 本月节点达标率（同一公式，见下，不另算） 页头即将超时 = 在途主单中，至少一条运单的当前节点为「即将超时」的主单数
阶段 = 该主单下运单里，当前节点最靠前的那一段；一个主单只进一段 国内集货 = 当前节点 ∈ 截单、送柜到仓、开始装柜、装柜完成 报关 / 还柜 = 还重柜、报关放行 海运在途 = 实际开船、实际到港 到港 / 清关 = 卸船完成、清关放行 海外仓作业 = 提柜、拆柜 尾程派送 = 尾程出库、尾端派送、POD回传 六段票数相加 = 在途主单
时间范围 = 按当前节点应操作日过滤列表；起止都空则不限 今日应处理 = 当前节点.应操作日 = 今天 且 时效状态 ∈ 即将超时、已超时 的运单数 即将超时（工作台）= 当前筛选下，时效状态 = 即将超时 的运单数 已超时（工作台）= 当前筛选下，时效状态 = 已超时 的运单数 缺失节点 = 存在启用节点「应操作时间已到且实际时间仍为空」的运单数（一票计 1，不按节点次数累加） 本月节点达标率 = 本月应操作的节点里，达标票次 / （达标票次 + 超期票次） 达标、超期的定义与「节点达标率看板」相同，统计区间固定为本月

今日应处理只含应操作日是今天的未完成运单，以前留下的已超时不进这一格，只进「已超时」。缺失节点按运单去重；同一票多个节点都缺实际时间，仍计 1。节点看板上的超期次数才按节点次数累加。

1. 列表默认范围与底表结构

默认列表（未完成）= 即将超时、已超时 全部履约数据 = 上面两项 + 已完成（含已达标） 时效状态只有三档：即将超时 / 已超时 / 已完成（不再设「待处理」）

底表只显示当前节点一行工作台，字段对齐《全程履约节点配置-横向底表》的当前切片：主单/柜/运单、当前节点、进度（已完成节点数 / 15 + 圆点）、责任部门、供应商、应操作时间、实际操作时间、时效状态、小组是否达标、服务商是否达标。

其他节点怎么看：点「当前节点」打开节点轨迹详情，按横向底表口径展开这一票全部节点（应操作 / 实际 / 判定 / 责任小组 / 小组是否达标 / 供应商 / 服务商是否达标）。全量宽表用「下载底表」。列表不铺整票横表，避免工作台过宽。

已达标明细不默认铺在底表。运营中心先看待办；要核对某一票是否达标，履约状态选「已完成」或「全部履约数据」。报表级已达标明细放在「节点达标率看板」导出。

本期底表不做「操作」列、不开放处置入口；节点轨迹走「当前节点」点击，不是操作列。

2. 三条状态怎么判（只看当前节点）

提前小时在履约规则版本里配。本页用那个小时判断，不在运营中心再配一次。时效状态按当前节点判，不是「任一历史节点超了就整票标已超时」。

预警时刻 = 当前节点.应操作时间 − 提前小时 即将超时 = 预警时刻 ≤ 当前时间 < 当前节点.应操作时间 且 还没有达标的实际时间 已超时 = 当前时间 ≥ 当前节点.应操作时间 且 （实际时间为空 或 实际时间 > 应操作时间） 已完成 = 当前节点.实际时间 ≤ 当前节点.应操作时间

即将超时先核实轨迹和实际操作。已超时待办仍推给人；要看全票节点点「当前节点」。同一节点、同一条运单，即将超时只推一次，过点后再推已超时。

3. 当前节点、进度色、是否达标（序号 3）

对应底表「当前节点 / 进度 / 时效状态 / 小组是否达标 / 服务商是否达标」。

当前节点 = 启用节点链上，按顺序第一个尚未达标的节点（跳过「不启用」） 进度分子 = 判定为「达标」或「不启用」的节点数 进度分母 = 本票节点总数（标准 15；不启用仍占位但圆点虚线） 圆点颜色 = 绿达标｜橙即将超时｜红已超期｜灰未判定｜虚线灰不启用｜当前节点加蓝标 时效状态 = 只取当前节点的判定（见上节） 小组是否达标 = 当前节点责任小组侧：达标 / 超期 / —（未到判定） 服务商是否达标 = 当前节点供应商侧：达标 / 超期 / —；无供应商时为 —

不是：前面某个节点曾经超期、现在已过，仍把整行时效状态打成「已超时」。历史超期只留在节点轨迹该行的判定里。

点「当前节点」：打开节点轨迹，每行各自有应操作 / 实际 / 判定 / 小组是否达标 / 服务商是否达标；当前行标「当前」。

4. 下载底表（序号 4）

对应工具栏「下载底表」。列表不铺整票横表；全量宽表用下载。

导出内容 = 《全程履约节点配置-横向底表》口径 每票展开 = 全部节点行：应操作 / 实际 / 判定 / 责任小组 / 小组是否达标 / 供应商 / 服务商是否达标 导出范围 = 当前筛选结果（搜索、责任部门、履约状态、销售产品） 已完成是否导出 = 履约状态选「已完成」或「全部履约数据」时带上；默认「未完成」则只有即将超时、已超时

点「当前节点」只看一票轨迹弹窗；要批量核对或给报表/对账，用下载底表。
