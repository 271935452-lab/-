本页计算与取值

1. 承诺时效

版本不配天数，也不按销售产品分组。承诺天数用销售产品上已有的字段。列表 / 仓位表 F16 取当前柜子下所挂销售产品承诺时效的最大值，只读。生成运单履约任务时按该柜最大值抄进快照，之后改产品不影响在途票。

承诺时效(柜) = MAX(当前柜子下各销售产品.承诺时效天) 整体时效天数 = POD回传日 − 实际截单日 整体达标 = 整体时效天数 ≤ 承诺时效(柜)

2. 提前小时

每个启用节点填一个提前小时，默认 4。旁边有「推送到人」，直接搜索姓名后点选加入，可以多人。取值来自人员目录（工号 + 姓名）。版本上没有超时动作。到了下面两个时点，给每个已选的人推一条待办。

预警时刻 = 应操作时间 − 提前小时 即将超时 = 预警时刻 ≤ 当前时间 < 应操作时间 且 还没有达标的实际时间 已超时 = 当前时间 ≥ 应操作时间 且 （实际时间为空 或 实际时间 > 应操作时间） 达标 = 实际时间 ≤ 应操作时间 推送对象 = 「推送到人」里搜到并加入的人，可多人 取值方式 = 搜索姓名（或工号），点选加入；点芯片 × 去掉

同一节点、同一条运单，即将超时只推一次。过了应操作时间再推已超时。实际时间补上并且小于等于应操作时间之后，这条待办关掉。应操作时间还没算出来时，不推这两张待办。

3. 发布快照

新建任务固化 = 版本号 + 启用节点 + 每节点提前小时 + 推送到人 + 当时的公式和时长 + 承诺时效 在途任务继续用创建时的快照 生效时间之后新建的运单，才用新版本

4. 配置弹窗（序号 5–12）

点「配置节点」打开弹窗。橙色 5–12 挂在弹窗控件上：规则版本唯一、生效时间切新票、启用唯一、勾选启用、责任/供应商只读、提前小时、推送到人、草稿与发布。

版本唯一 = 规则版本号不与已有版本重复 启用唯一 = 本版本改为启用时，其他启用版本 → 停用 未勾选节点 = 不写入本版本启用清单，不进达标率分母 责任部门 / 供应商 = 只读，取标准节点当时值 草稿 = 不参与新建任务匹配；发布 = 按生效时间固化快照
