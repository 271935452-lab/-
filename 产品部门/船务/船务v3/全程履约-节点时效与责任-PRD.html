本页计算与取值

1. 核算对象三选一（本期全部挂运单）

本期口径：全部节点都挂在运单上。现有 15 个节点的核算对象都是运单。配置里虽可选主单、运单、子单，但当前落地不拆到主单或子单——达标、待办、快照都以运单为唯一落库对象。

因此，每条运单上都要写上目前全部节点字段：每个启用节点对应的「应操作时间」字段和「实际时间」字段，都落在这条运单上。不是只写尾程那几个字段；截单、到仓、装柜、还柜、报关、开船、到港、卸船、清关、提柜、拆柜、出库、派送、POD 等全套，运单上都有一份。

本期：核算对象 = 运单（全部节点） 运单须具备 = 全部启用节点的「应操作时间字段」+「实际时间字段」 柜 / 主单上发生一次的时间 → 抄到该柜下每一条运单的同一字段 节点是否达标 = 这条运单.实际时间 ≤ 这条运单.应操作时间

要抄到运单的柜级时间：柜子实际到仓、实际开始装柜、实际装柜完成、实际还重柜、实际报关放行、实际开船、实际到港、实际卸船。提柜、拆柜、出库若回传在柜上，同样抄到运单后再比。抄完之后，比较只看运单字段，不再回头比柜或主单。

2. 每个节点的应操作时间

节点上的「实际时间来源」「应操作时间」「起算字段」都是下拉，选项就是字段因子里的字段。公式：应操作时间（生成字段）= 起算字段 + 增加时长。不拆分时起算和增加时长写在应操作时间旁边；要拆分时每行各自有「起算字段」和「时效(时)」。已取消单独的分维度时长表。

有公式的节点：应操作时间 = 起算字段 + 增加时长 起算字段 = 命中拆分行.起算字段（有填） 否则 应操作时间旁的起算字段 增加时长 = 命中拆分行.时效 当 有拆分行命中 增加时长 = 应操作时间旁的增加时长 当 不拆分，或没有拆分行命中 节点达标 = 实际字段 ≤ 生成字段

起算字段还是空的，这一条应操作时间先不算出来，停在待处理。上游算出生成字段之后，下游用那个生成字段当起算。清关用的是最迟卸船时间，不是实际卸船时间。

节点应操作时间公式拿哪个实际时间比

3. 增加时长写哪里（取消分维度时长表）

不再维护「分维度：渠道 × 尾程 × FBA 仓」那张单独时长表。时长只在两个地方写：

不拆分起算 → 节点弹窗「应操作时间」旁「起算字段」 不拆分增加时长 → 同旁「增加时长（小时）」 拆分起算 → 「拆分其他维度」每一行的「起算字段」（字段因子；留空回落旁侧起算） 拆分增加时长 → 同一行的「时效(时)」 命中拆分行 → 用该行起算（有填）+ 该行时效；没有命中 → 用旁侧起算 + 旁侧增加时长

装柜两段、清关、拆柜、POD 等不需要按维度拆的，直接在应操作时间旁填小时。卸船、提柜、出库、派送等要按热门仓/渠道/尾程/邮编/快慢船拆的，在拆分行填起算字段和时效。

时效格子填数字表示小时；填「不启用」或不填且无兜底时，这一节点不生成应操作时间，不参与达标，也不推待办。派送若要按美西/美中/美东分区，拆成多行（尾程或邮编区分），每行各自填小时，不再写「美西72 / 美中120 / 美东168」单格。

4. 拆分其他维度怎么命中

这一维命中 = 配置是「不限」或空 或 配置 = 运单该维的值 销售产品命中 = 配置为空 或 运单.销售产品 ∈ 配置拆出的名单 （配置可用逗号或空格分隔多个，如「T16,T25」或「T16 T25」；比较前去空格） 邮编命中 = 起始和结束都空 或 起始邮编 ≤ 运单邮编 ≤ 结束邮编 整行命中 = 热门仓、渠道、销售产品、尾程、邮编、普船或快船 六维全部命中 命中后 = 该行「起算字段」（空则旁侧起算）+ 该行「时效(时)」

普船 / 快船怎么取：取运单所属销售产品上的「干线服务级别」，再映射成拆分行用的两档（不另维护船速字典）：

销售产品.干线服务级别 = 普船 → 履约船速档 = 普船 销售产品.干线服务级别 = 快船 → 履约船速档 = 快船 销售产品.干线服务级别 = 特快船 → 履约船速档 = 快船 拆分行「普船或快船」命中 = 配置是「不限」 或 配置 = 履约船速档

多行都命中时，取得「不限 / 空」更少的那一行。一样多时，用表里更靠前的一行。一行都没命中，用应操作时间旁的起算和增加时长；起算与时长都空，应操作时间算不出来，进数据待处理。

5. 新增节点每个字段怎么取值（弹窗序号 8）

新增和编辑用同一张表。字段取值说明不铺在弹窗里，点橙色序号 8 查看。带 * 的必填。

节点编码 = 系统自增（N+序号），不可改 核算对象 = 仅运单（锁定） 默认责任部门 = 美线海派部下面全部小组 ｜ 或 义乌操作中心「运单所在仓」（挂到每票运单的所在仓） 供应商 = 服务商页面的服务商类型（无则 —） 实际时间来源 / 应操作时间 / 起算字段 = 字段因子里的全部数据 增加时长 = 单位小时；限 3 位数 + 一个小数点（最大 999.9） 是否纳入达标率 = 是 → 计算是否达标；否 → 不计入达标率分母
字段怎么取值
节点编码 *系统自增，格式 N + 两位序号（现有最大号 + 1）。新增自动带出、不可改；编辑也不能改。
节点名称 *手填。字典「标准节点」列展示这个名称。
核算对象 *当前仅支持运单，下拉锁定。落地按运单写全套节点字段，见第 1 节。
默认责任部门 *下拉分两组。美线海派部：下列出其组织树下全部小组。义乌操作中心：选「运单所在仓」= 选择仓库即挂到每个所在仓（运单）的仓库上面；生成待办时按该票运单的所在仓解析到对应仓库。版本上只带出这里配置的值，不能在版本里改。
供应商下拉。取服务商页面的服务商类型。没有对应类型选「—」。
实际时间来源 *下拉，字段因子全部字段。按该字段配置方式取值（库字段 / 轨迹编码 / 自动计算）。
应操作时间 *下拉，字段因子全部字段。作为公式生成字段：应操作时间 = 起算字段 + 增加时长。
起算字段下拉，字段因子全部字段。提单/船期已有的节点可留空。
增加时长（小时）单位小时；限 3 位整数 + 至多 1 位小数（如 12.5，最大 999.9）。不拆分时用这里；拆分行没命中时也用这里兜底。
是否纳入达标率 *是 = 参与达标计算；否 = 不计入达标率分母。新增默认是。
节点说明手填。写适用范围、实际时间口径和例外。不参与计算。
拆分其他维度按钮，原型序号 7。点一次加一行；行上有销售产品（可用逗号或空格填多个）、起算字段、时效(时)。命中规则见第 4 节。
