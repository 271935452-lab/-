本页计算与取值

1. 应操作时间怎么算（不在本页配）

本页已去掉「推算公式」菜单。公式在「节点时效与责任」：应操作时间 = 起算字段 + 增加时长；达标 = 实际字段 ≤ 应操作时间。不拆分写在应操作时间旁；要拆在拆分行填时效。

应操作时间 = 起算字段 + 增加时长 节点达标 = 实际字段 ≤ 应操作时间 时长位置 = 不拆分 → 应操作时间旁；拆分 → 拆分行时效 普船/快船（拆分行）= 取销售产品「干线服务级别」：普船→普船；快船、特快船→快船

2. 热门仓

仓库档 = 热门仓 当 目的仓代码在热门仓名单里 仓库档 = 非热门仓默认 当 是 FBA 仓，且代码不在名单里 仓库档 = 非FBA 当 不是 FBA 仓

名单直接填写，一行一个或用逗号、空格分隔。比较前去空格并转成大写。写上的仓，出库 72 小时、派送 72 小时。没写上的 FBA 仓，出库 168 小时、派送 120 小时。

3. 字段和轨迹怎么取值

来源 = 自动计算：值由节点时长写出（见节点时效与责任） 配置方式 = 字段：本行直接填写数据库字段（如 {bl.siDueTime}），履约字段的值 = 该库字段当前值 配置方式 = 轨迹编码：事件编码命中任一编码（逗号分隔）时 履约字段的值 = 该事件的发生时间

选「字段」不再弹窗选用，行内填写库字段即可。同一字段先到的已对接事件先写入。后面再来的其他平台事件不覆盖。没有可信来源、映射失败，或两个已对接源时间冲突时，才允许人工改，并留下改前值、改后值、操作人和时间。编码还空着的，不能当成已经接通。

4. 轨迹映射

原型没有单独的映射页。一条映射要有：轨迹服务商、映射规则、原始轨迹类型、轨迹编码、发生状态、地点 code、存入字段、采用优先级、是否影响时效。

命中轨迹编码 → 把事件时间写入「存入字段」 → 按第 1 节重算用到这个字段的应操作时间 存入字段只能从字段因子里已有的字段名里选

已对接事件优先：飞驼的开船、到港、还重、卸船、提柜；美库的提柜、拆柜、尾程出库。其他轨迹平台其次。人工确认只在没有可信来源、映射失败或时间冲突时覆盖。

5. 自动带入和人工兜底

订单和已对接轨迹优先自动带入。人工只补没有可信来源的实际时间，以及异常原因。飞驼、美库标成建议自动、编码还空着的，不能当成已经接通。
