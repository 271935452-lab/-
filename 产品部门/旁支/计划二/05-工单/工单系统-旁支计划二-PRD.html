共性 · 唯一在办工单（BR-WO-001）

  1. 同一柜号 / 运单号 / 子单号发起的流程，在同一工单类型且未完结时，只允许存在一张在办工单。
  2. 再次发起同类型：禁止平行新建；进入既有工单继续追加（补充 / 新增后续指令升版本）。
  3. 不同类型可并行；结案后同类型可再开新单。

#9 发起类型 · 非美库

  1. 流程与美库类同（履约工作台 / 统一工单执行），但不对接美库。
  2. 费用、备注、改单须人工标记；不推美库仓工单、不自动贴标附件下发。
  3. 原型：提交入口 / 新建工单（发起类型选非美库场景）。

测：非美库场景提交后工作台可见；无「推美库」自动动作；费用状态可人工改。

权威：工单模块需求 PRD · #9 · 总册 #f9

#10 改快递 · 需重出（美库）

  1. 唯一入口：履约工作台 / 统一工单提交·新建；现网海外跟进、改派 GW 下线。
  2. 流程匹配（BR-WO-017）：自动按名称精确匹配工单流程/场景「重出」；匹配不到则报错阻断。
  3. 按子单重出：发起粒度为快递子单；多子单分别建指令、分别回填新单号，均挂同一母工单；禁止新单号另开平行主单。
  4. 流程：确认费用 → 下重出费用单 → 腾信按子单重出回填 → 打单/地址确认 → 推美库（贴标附件）→ 状态/费用同步。

测：有「重出」流程可建单；无则报匹配不到；未填子单号拦截；两子单可各出指令。演示失败：新建工单-MVP.html?plan2=f10&noReissueFlow=1

#11 快递拦截 · 港前

  1. 入口：港前节点 / 统一工单「快递拦截·港前」/ 履约工作台新建。
  2. 关联：母工单 + 指令版本 + 美库执行单（BR-WO-016），禁止只靠运单号串单。
  3. 流程：V1 拦截 → 仓执行 → 改令升 V2 → 费用/附件挂版本；母工单待货完结再关。

测：详情演示 #WO-202605-INT 可见指令版本链；改令后版本号递增。

权威：工单模块需求 PRD · #11 · 总册 #f11

#12 快递拦截 · 港后

  1. 入口：快递异常件（可选）、尾程快递件、统一工单「快递拦截·港后」、履约工作台；不经海外跟进。
  2. 关联：同 #11 三级关系；港后与港前分流，母工单仍按根货件不断链。
  3. 流程：版本链同 #11；解拦 / 失败 / 已交承运商对齐 Q-WO-004。

测：快递异常件转工单带港后场景；详情版本链与港前同构、入口标签区分港后。

权威：工单模块需求 PRD · #12 · 总册 #f12 · 原型：详情 · 快递异常件

跨页 · 工单异常标记

  1. 统一工单风险标签回写海外对接各派送列表「工单异常标记」列：尾程快递件 / 卡派跟进 / 卡派自提件 / 一件代发。
  2. 与「异常登记」并列、不互相覆盖；提交后按运单派送类型写入；状态/标签变更实时刷新；结案保留最终态、不清空；点击跳转关联工单。

测：提交拦截/重出工单后对应列表出现标签；结案后仍见最终态。
