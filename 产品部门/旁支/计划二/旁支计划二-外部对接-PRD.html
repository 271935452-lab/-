#6 信号旗对接 ISF

  1. 报关管理列表勾选一票，点「发 ISF」，弹窗按现网「新增 ISF」字段布局。
  2. 服务商在弹窗标题栏右上角（不进基本信息网格）：信号旗 / 海管家，默认信号旗；决定报文走哪家通道。
  3. 保存并提交 / 提交均算成功，列表打「ISF」业务标记；操作日志记录所选服务商。
  4. 回执、失败重试、取消与跟单宝轨迹细则见附录；清关 IT / 保税号抓取不混入本条验收。

测：打开发 ISF → 打开新增 ISF，服务商在右上角且默认信号旗；提交后 ISF 标与日志服务商一致。

本期不做：跟单宝全节点回写提单视图、ISF 工单自动建单（见附录范围）。
待确认：信号旗资料归档目录、回调地址与生产凭证交付。
原型：报关管理 · 发 ISF · 报关列表分册
附录：信号旗 ISF 对接 PRD（全文） · 模块导航

#7 DrayEasy · 海外仓柜子预报

  1. 主入口：海外对接 · 主单跟进工具栏「DrayEasy 海外仓预报」；勾选 ≥1 柜后发起。
  2. 按主提单号（MBL）分组：同一 MBL 的柜放入同一 DrayEasy 订单 containers；不同 MBL 分别创建订单。
  3. 成功保存 DrayEasy 订单号与外部原始状态；重复预报返回已有订单号，不重复创建。
  4. 资料不完整柜逐柜标红，不影响其他合格柜；真实发送前须校验费率、目的港/仓库外部 ID、ETA、重量与鉴权。

测：主单跟进勾选多柜 → 点 DrayEasy 预报 → 弹窗按 MBL 分组、逐柜返回成功/失败/已存在；列表同步预报状态。

本期不做：不臆造接口字段验收；费率/映射/更新取消能力待业务拍板（见附录 P0）。
待确认：正式 API 域名、Bearer Token、warehouse_id 映射表维护方。
原型（主链）：主单跟进 · DrayEasy 预报 · 主单跟进分册 §DrayEasy
附录：DrayEasy 预报 PRD（全文） · 0804 价格方案（附录） · 模块导航

#8 17TRACK · 卡车派送轨迹

  1. 卡派跟进（新）出库登记：PRO 必填；落库后按 PRO 向 17TRACK 注册/查询轨迹。
  2. 结果写入轨迹维护 / 最新轨迹；外部节点与本系统提柜、出库、签收节点分栏展示，不直接覆盖业务状态。
  3. 与 POD 区分：PRO = 卡车出库追踪号；POD = 签收回传。
  4. 承运商未支持、注册失败或长期无更新可沉淀工单；轨迹正常更新不自动建单。

测：卡派跟进新开出库登记 → PRO 必填校验 → 保存后轨迹区可见 17TRACK 订阅/最新节点（演示数据）。

本期不做：自建卡车采集、外部轨迹直接推进财务入账。
待确认：美国卡派承运商映射表、Webhook 签名密钥、立即抓取额度预算。
原型：卡派跟进新 · 出库登记 PRO · 卡派分册 · PRO/17TRACK
附录：17TRACK 对接 PRD（全文） · 模块导航
