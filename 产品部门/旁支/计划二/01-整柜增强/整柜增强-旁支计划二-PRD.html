#1 业务数据统计 / 财务 · 整柜配送模式 + 计费重

  1. 业务数据统计、业务数据统计财务列表新增「整柜配送模式」列（取运单配送模式，与整柜下单 7 项枚举一致）。
  2. 收货计费重 = 下单重；出货计费重 = 过磅重；无过磅重时出货计费重取下单重。
  3. 业务 / 财务两入口字段与口径一致。

测：统计/财务列表可见整柜配送模式列；有过磅重时出货计费重=过磅重，无则=下单重；两入口一致。

分册：业务数据统计分册
原型：统计列表 　· 总册 #f1

#2 整柜下单 · 总价* → 申报价值

  1. 下单基本信息新增总价*（金额+币种），口径同发票总价。
  2. 提交预报后回写业务数据统计申报价值；页内提供回显预览。

测：填写总价*提交预报 → 统计列表申报价值与下单一致；页内预览可见。

分册：整柜下单 PRD
原型：订单录入 · 总价 　· 总册 #f2

#3 整柜下单 · 附加服务关联费用 / 整柜杂费包

  1. 整柜附加服务须关联费用并落预估（勾选 ≠ 仅打标）。
  2. 杂费包主数据新增「整柜」杂费包；整柜运单默认关联该包。
  3. 下单额外服务、运单「附加服务 / 批量修改」均从该包解析选项与费用映射。

测：勾选附加服务落预估行；整柜运单默认整柜杂费包；取消勾选移除未确认预估。

分册：下单 · 额外服务 · 传统订单 PRD
原型：额外服务 · 传统订单 · 附加服务 　· 总册 #f3

#4 舱位管理 · 业务分配类型与费用

  1. 完善提单 · 业务分配：类型客户自拖 / 我司拖车 / 我司装柜。
  2. 我司拖车必录拖车费；我司装柜必录装柜费；客户自拖不录费用。

测：选我司拖车/装柜时费用必填；客户自拖无费用字段；保存后挂提单预估。

分册：仓位管理 PRD
原型：完善提单 · 分配 　· 总册 #f4

#5 整柜 · 权限配置

  1. 关系链：业务员团队（员工管理）→ 客户默认继承 → 客户可改 → 运单权限跟客户最终配置。
  2. 按岗位限定可见整柜页、数据范围与操作权限（见下方岗位×页面矩阵）。
  3. 报价员不按客户岗位表过滤；敏感客户字段另拆字段权限。权威口径挂旁支计划二本条。

测：① 客服登录仅见其绑定客户运单；② 订舱员仅能操作其绑定客户舱位/提单；③ 报价员能报价但不能进该客户运单待办；④ 非业务员员工编辑页无「整柜岗位团队」区块；⑤ 客户改四岗后运单权限即时跟最终配置。

分册：客户权限 PRD · 岗位绑定 PRD
原型：客户主档 · 客户岗位绑定 · 员工岗位团队 　· 总册 #f5 · 权限矩阵

岗位 应处理的整柜页面 数据范围 主要操作权限

#13 客户管理 · 响应等级

  1. 客户主档新增「响应等级」字段，枚举：一级、二级。
  2. 用于工单派单 / SLA 等对客户优先响应的区分（一级优先于二级）；未配置时按现有默认口径。
  3. 与整柜岗位绑定独立；不替代客户 SLA 快照（若已有 VIP/承诺 SLA）。

测：客户编辑页可选一级/二级并保存回显；列表或详情可见该字段；工单侧可读取该等级做优先演示（未配置不报错）。

分册：客户主档 PRD · 响应等级
