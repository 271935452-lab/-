发起入口

与列表共用同一套阶段 / 业务场景（装柜完成前 / 港前 / 港后 / 尾端异常）。分类入口按阶段分组出卡，卡片标题=业务场景。运单自动判定仍为 BR-STAGE-001 三段；尾端异常用于异常跟进类场景配置。

附件与其他资料

发起/处理所需资料分两类配置：附件（上传文件，如新标签 PDF/照片）与文字信息（表单填写，如换标要求、操作说明）。均可设是否必填，以及必填时为首次必填或支持补填。已去掉前置单据、费用预览（费用确认走费用配置）。

资料类型 名称 是否必填 首次必填 / 支持补填 填写说明

状态

选择状态流模板（编码 + 名称），不选某一个状态。节点、流转和岗位在 状态流模板 里维护。

费用配置

费用类型下拉取费用类型主数据全部项（不按大类过滤，与基础资料同源）。支持按件 / 票 / 计费重配置单价；可添加多项。多项费用类型相加（预估 = Σ 单价 × 对应计费量）。发起工单提交时按本配置自动弹费用确认，确认后才建单。SLA / 审批流 / 业务联动不在本页维护。

费用类型 计费方式 单价 币种 启用

计费量取数：按件→件数；按票→票数（通常为 1）；按计费重→计费重(kg)。预估仅供下发前展示（应收预估）。海外仓回传实际费用默认追加到关联运单应付（BR-FEE-001），按场景审核通过后再入账；不加应收。业务联动不在本页配置（已去掉）。

海外仓数据同步配置

不是一套「数据回写」。两条链路分开配：头程 → 美库（先改头程，再按最新数据推送）；美库 → 头程（美库做完后，把结果、费用、附件更新回头程）。 粒度是工单类型 + 港前/港后 + 海外仓。例如「港前拦截 + 美库」和「港后换标 + 美库」各自保存修改字段、推送字段、回写字段，不能共用。

当前粒度：—

其他海外仓不走美库推送。本链路关闭：不改完头程再推美库，也不生成美库推送快照。结果由客服人工登记，配在下一页签。

本链路步骤
  1. 工单确认执行
  2. 修改头程柜子 / 运单数据
  3. 保存修改后的头程数据
  4. 按最新数据生成推送快照
  5. 推送美库
  6. 记录美库工单号、推送版本和结果

头程修改对象仅两类：拆柜计划、运单信息。禁止覆盖：—。推送失败时头程修改保留，工单进入「推送失败待重试」，不得回滚为原 Move Type。

本工单类型可回写字段（勾选才写入头程）

实际操作费用写入头程应付，不加应收。其他海外仓没有美库工单号，用人工登记的结果、费用和附件更新头程。

关键状态（美库）

待修改头程数据 → 待推送美库 → 已推送 / 推送失败待重试 → 美库处理中 → 回写头程中 → 已处理并回写 / 回写失败待重试 / 美库无法处理 → 工单完结
