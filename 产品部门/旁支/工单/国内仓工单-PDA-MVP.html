工单待办

本版覆盖范围

业务流转：
统一工单匹配国内仓 → 国内仓 PDA 生成待办 → 上传照片 / 核实材积 / 换标 / 异常处理 → 确认装柜完成 → 国内仓待办关闭，海外对接组生成待办。

页面与交互

  • PDA-WO-01 待办按“待处理 / 处理中 / 已完成”分组；列表只显示当前国内仓和当前岗位可处理的单。
  • PDA-WO-02 工单详情展示业务标识、当前状态、执行要求及所需附件。
  • PDA-WO-03 支持拍照上传、材积核实、换标、异常登记；是否必填由工单场景对应的状态模板定义。
  • PDA-WO-04 必填动作未完成时，“确认装柜完成”不可点；完成后状态进入“待海外对接”。

本期口径

  • [已确认] PDA 是国内仓执行端，不替代原有的签入、上托、装柜扫描等库存操作页面。
  • [已确认] 装柜完成前由国内仓人员处理；装柜完成后转海外对接组。
  • [建议] “确认装柜完成”仅作为工单流转动作；实际装柜扫描/库存出库仍沿用现有仓库作业规则，两个操作结果需联动校验。

待确认（进入开发前）

  • P0 “装柜完成”由 PDA 人工确认、仓库系统回传，还是两者均可触发？这决定最终状态的唯一来源和重复提交控制。
  • P1 材积核实需要录入哪些字段（总件数、长宽高、体积或计费体积）及是否要覆盖业务原数据。
  • P1 换标是否必须上传前后照片、是否要记录新标签号。
