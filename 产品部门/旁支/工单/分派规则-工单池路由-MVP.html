分派规则 · 工单池路由

场景、港前/港后、海外仓等维度路由保留，但最前面增加客户维度（BR-ROUTE-001）。与「编辑角色」配合：规则引用角色/池；角色页维护成员与数据范围。SLA 拆分见场景配置 Tab B（客户承诺优先于场景默认）。

路由优先级（客户优先）

  1. 客户专属客服 / VIP 客户 SLA命中客户主数据上的专属客服、VIP 绑定池或客户专属 SLA 包时，直接路由并套用客户承诺时效。
  2. 客户类型或客户分组直客 / 同行 / 大客户组等分组规则 → 对应客服池或执行池。
  3. 场景 + 港前/港后 + 海外仓/口岸现有场景矩阵（如洛杉矶 + 港后 + 换标 + 美库）。
  4. 默认岗位池场景配置 Tab B「责任池」兜底。
  5. 实际执行人池内认领、转派或海外仓/PDA 接单后落到具体人。

高优先级命中即停。客户 SLA 由客户管理维护；生成工单时读取并固化快照；未配置客户 SLA 时用场景默认。快照不以客户主数据后续变更为准。

客户承诺 SLAVIP/大客户约定的首次响应、完成时限客户管理维护；工单生成时固化快照
