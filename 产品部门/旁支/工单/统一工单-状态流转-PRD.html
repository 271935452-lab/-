1. 一句话结论

已确认 统一工单由“母工单 + 指令版本”组成。每次拦截、换标、重出或仓内操作都是一个指令版本；新要求创建 V2/V3，不能修改已下发或已执行的旧版本。

BR-STS-000 费用确认和后续执行不是两张平级业务工单。它们属于同一母工单的同一指令版本：费用确认是内部子任务/独立确认记录；海外仓执行是该版本的执行阶段，并关联外部美库工单或线下指令。实际加收费用仅新增该版本的第二条费用确认记录。

已确认 每个指令版本必须完成费用确认；“无费用”同样要有确认记录。需要海外仓实际处理、确认可否处理、反馈结果或实际费用时，必须发起统一工单；是否推送美库由海外仓对接能力决定。

2. 生成统一工单的边界

情况是否生成系统处理
海外仓需实际处理、确认能否处理、回传结果或实际费用是API 仓自动下发；无接口仓生成同样的线下操作指令。
港前要求到仓后处理，如留仓、换标、拍照是创建预执行版本，等待海外仓执行。
仅内部沟通、费用预判、客户咨询、系统备注或单纯改内部字段否仅留日志/备注，不创建执行工单。
已有工单后收到新的操作要求是创建关联 V2/V3，不覆盖旧版本。

3. 状态模型：四类状态分开保存

母工单状态草稿、处理中、持续跟进、已完成、已取消
指令版本状态待费用确认、执行中、回写中、版本已完成等
外部执行状态待人工发送、推送中、已受理、已处理、关闭
费用/回写状态预计费用已确认、待实际费用确认、回写失败
BR-STS-001：外部“已处理”仅代表海外仓动作完成，不等于版本完成；仍需实际费用结果、业务/客服确认以及业务数据回写。
BR-STS-002：外部“关闭”不等于处理成功。必须保存关闭原因，进入“海外仓关闭待确认”，再决定新建后续版本或“无法执行”结案。

5. 配置与状态流的关系

已确认 不单独维护全局状态字典。管理员在状态模板内直接新增、编辑和移除状态名称；系统自动生成状态编号。已发布且已被工单使用的模板不可直接改动，需复制出新版本调整；费用快照、外部日志、回写日志、版本关联和“已执行版本不可覆盖”仍是系统固定能力。

配置分类配置项影响状态流
状态节点状态名称、系统自动编号、必经/可选、默认责任岗位/工单池直接在状态模板内维护，不再从状态字典选择。
客户响应等级一级、二级值来源于客户管理的“客户响应等级”字典；状态模板 SLA 的配置级别直接引用此字典，模板内不另建分级；工单创建时固化客户等级快照。
节点 SLA客户响应等级：一级 SLA、客户响应等级：二级 SLA；每组包含处理时限、预警提前量、超时升级岗位同一状态模板内按客户响应等级维护两组 SLA；工单进入节点时按已固化的客户等级读取对应组，不再按等级拆分状态模板。
状态流转当前状态、下一状态模板只配置允许的前置—后置关系；动作和业务校验由系统固定执行。
港前/港后判定轨迹节点、运输状态、优先级、人工覆盖决定走港前/港后分支及是否先做可行性确认。
工单类型流程操作类型、阶段、必填字段/附件、是否需外部执行决定是否进入待执行准备、待外部下发。
费用确认是否必需、免收费条件、确认角色、审批阈值决定待费用确认能否放行；当前每版本都必须确认。
审批状态模板选择审批流程编码｜名称；审批流程维护适用条件、审批人和层级命中审批时进入引用该审批流程的状态。工单详情仅展示审批摘要（审批中/通过/驳回）与放行结果，节点明细以现网审批系统为准。
海外仓能力API/无接口、支持动作、回写方式决定推送中或待人工发送，不改变工单主流程。
外部状态映射/回写外部枚举、回写对象/字段/时机决定外部状态接入和回写中要写入的业务对象。
BR-STS-003：客服不在单票页面选择“是否推送美库”。点击“提交执行/下发”后，系统按“工单类型 + 港前港后 + 海外仓能力”自动决定 API 推送、生成线下指令或无需外部下发。

状态流转当前状态、下一状态从本模板已添加的状态中选择。只维护允许的前置—后置关系；页面不配置触发动作/业务条件。
发布保存、发布、复制管理员操作。发布前校验起始节点、终态和必经节点可达；已发布模板通过复制生成新版本。
BR-STF-002：作业指引随状态模板包保存，但按“状态 + 开发已关联的具体操作”分别配置；工单详情只在用户执行该操作时展示对应指引。
BR-STF-003：资料要求跟随“状态 + 具体操作”保存（附件 / 文字信息）。工单进入状态时固化可用操作及其资料要求快照；用户执行操作时，系统校验必传附件的类型与最少数量，以及必填文字信息。发布且已使用的模板通过复制新版本修改指引和资料要求。

7. 验收标准

  • AC-STS-001：V1 未确认费用时，尝试 API 推送或标记人工发送，系统阻止，状态保持“待费用确认”。
  • AC-STS-002：海外仓已处理但未回传实际费用/无加收结论时，尝试完结，系统阻止，状态保持“待结果与实际费用回传”。
  • AC-STS-003：海外仓配置为无接口时，费用确认后提交执行，系统生成线下操作指令，状态为“待人工发送”，不调用美库接口。
  • AC-STS-004：V1 已下发后产生新换标/拦截要求，系统创建关联 V2；V1 的状态和费用快照不被修改。
  • AC-STS-005：港前拦截留仓回写成功后，Move Type 为“留仓”，且对应柜子备注含指令版本、操作人和时间。
