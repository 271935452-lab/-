履约工作台（BR-WB-002 / BR-WB-003）：七页签同一套数据列，均以子/指令工单为一行。页签只筛状态与权限；「我的发起」可撤回。一期无待转业务记录。
入口收敛：现网海外跟进 / 改派重出(GW) 已下线；跟进与重出一律在本工作台处理。 运单等业务页 → 新建统一工单 / 本台待办。详见 PRD §1.1。

履约工作台（BR-WB-002 / BR-WB-003）：七页签同一套数据列（指令工单号、母工单、海外仓任务号、标题/场景、阶段、状态/当前节点、发起人、当前处理、SLA、更新、操作），只按页签筛状态与权限。同一母工单 M001 下 V1 卡派拦截、V2 快递重出、V3 仓内换标打单各占一行。处理人进子工单可见母单基础信息与关联单号，默认不看其他子工单费用/附件/处理详情。一期无待转业务记录。

发起（BR-ENTRY-001）：提交即创建母工单+指令工单并按状态模板首节点派岗；资料不全只保存发起页草稿，不进工作台。详见 PRD §4.1.0 / 新建工单。

超时标记（C-09 / BR-HAND-001）：SLA 列可叠展示超时标记、已升级层级、最近催办时间；状态列业务态不变。详见 交接·催办·升级。

环节三段（BR-STAGE-001）：装柜完成前→装柜完成前；拆柜前→港前（柜子计划、拦截、换标、共享表、预报）；拆柜后→港后（私卡、FBA、自提、改尾端、未上架索赔等）。费用试算外链示例：工单工作台-MVP.html?fee=1&waybill=运单号&days=30&m3=1.5。
