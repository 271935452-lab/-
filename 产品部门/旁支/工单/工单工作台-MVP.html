履约工作台

履约工作台（BR-WB-002 / BR-WB-003）：六页签同一套数据列（工单号、关联工单、海外仓任务号、标题/场景、阶段、状态/当前节点、发起人、当前处理、SLA、更新、操作），只按页签筛状态与权限。只承接可处理业务队列：待办、发起、交接、超时与异常、审批、历史。不做通知栏目——系统消息 / 催办提醒 / 审批消息 / 预警 / 已读未读 / 消息留存由通知模块统一承接，消息点击跳转工单详情；详情保留操作日志与状态时间线。无母工单；改派三单各为独立行，用关联工单号串链。续办靠关联工单号；「我的发起」可撤回。
入口收敛：现网海外跟进 / 改派重出(GW) 已下线；跟进与重出一律在本工作台处理。 运单等业务页 → 新建统一工单 / 本台待办。详见 PRD §1.1。
发起（BR-ENTRY-001）：提交即创建独立工单并按状态模板首节点派岗；续办/新要求另建工单并填关联工单号；资料不全只保存发起页草稿，不进工作台。详见 PRD §4.1.0 / 新建工单。
超时与异常（业务队列）：保留为本台可直接处理的筛选页签（非通知列表）。SLA 列可叠展示超时标记、已升级层级、最近催办时间；状态列业务态不变（C-09 / BR-HAND-001）。催办消息本身进通知模块。详见 交接·催办·升级。
阶段：运单自动三段（BR-STAGE-001：装柜完成前 / 港前 / 港后）+ 筛选/配置项尾端异常（媒体区断更、预约联系不上等）。

    腾信海外仓 · 费用试算（USD）

    仓储：0–12 天免费；13–60 天 $1.5/立方米/天；61–90 天 $5/立方米/天；超 90 天视为弃货，销毁费另计。其余项按件/票/托等计费；私卡派送失败仓储按车队实报；改地址按 UPS 官网实收；其他特殊操作单独报价实报。

    外链自动打开试算：地址加 fee=1（或 openFee=1）即打开本弹窗；waybill= 回填本字段。可选预填与表单 id 同名短参数：days m3 label unlabel photo destroyBox destroyWood sort op repallet print measPallets weighPallets po truckStorage addrUps other；specialOut=1 urgent=1；intercept=none|ups|amz|free。
