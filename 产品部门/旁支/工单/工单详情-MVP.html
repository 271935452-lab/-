协同结构 UI-WO-016 · 母工单 → 指令工单 → 海外执行子任务

母工单管理同一业务对象的一整段协同周期；其下每张指令工单等同一次「指令版本」。 是否需要海外仓执行，决定是否创建海外执行子任务（纯内部处理可没有）。 关联键为根运单 / 柜号 / 货件 ID；费用、附件、仓结果挂在对应指令工单，不堆在母工单备注。

母工单（协同事项） └─ 指令工单 / 指令版本 V1 └─ 海外执行子任务（可选） └─ 指令工单 / 指令版本 V2 └─ 海外执行子任务（可选） └─ 指令工单 / 指令版本 V3 …
  • 一张母工单可有多张指令工单
  • 指令工单必须隶属母工单，不可独立存在
  • 单张指令完成 ≠ 母工单完成
  • 已下发/执行的指令不可改；新要求建 V2/V3
  • 母工单状态由全部指令工单汇总
  • 无需海外执行时可不建孙级子任务
