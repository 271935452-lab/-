PRD · B21 出库签收预警

出库签收预警 PRD

背景与目标

面向私卡等尾程派送场景，以拆柜时间为时效起点，对未按时出库、签收及 POD 未回传的运单进行监控预警；结合待办角标与消息推送，督促港后客服与业务员及时跟进。

用户与场景

  • 管理员：查看全部预警，批量轨迹维护。
  • 业务员：仅可见本人负责运单的预警。
  • 港后客服：仅可见销售产品配置的港后客服字段与当前登录人一致的运单（配置来源见 销售产品 · 港后客服分配）。

1. 数据范围

  1. 权限：管理员全部；业务员按业务员字段；港后客服按销售产品「港后客服」配置匹配（与客户类型直客/同行及分公司规则一并解析）。
  2. 时间：拆柜开始日期 ≥ 当日 00:00:00，且 < （当前日期 − 1 天）00:00:00。
  3. 行色：超时预警 → 红；即将超时 → 橙；已处理 → 黑。
  4. 排序：预警在前、已处理在后；同组按超时预警天数降序。
  5. 刷新：每小时提取一次；产生新预警时触发待办推送（见 §6）。

2. 基础字段

  • 运单号：点击跳转运单查询详情。
  • 港后客服：取自运单关联销售产品在「港后客服分配」中解析出的客服姓名/标签。
  • 最新轨迹：运单当前最新轨迹节点名称。
  • 列标记：表头 调 = 本期调整（原提柜基准改为拆柜）；新 = 本期新增列。
  • 拆柜时间 / 拆柜天数调：时效基准由提柜改为拆柜，见 §3.4、§3.5。
  • 预计POD回传时间 / 实际POD回传时间新：POD 回传预警专用，见 §3.3、§3.7、§3.8。

3. 动态计算字段

3.1 出库预警

  • 依据：拆柜时间 + 配置出库时效（销售产品 + 邮编）。
  • 超时且未更新出库节点（TC00105 / TC001031）→ 预警分类「出库预警」。
  • 例外：已有签收轨迹（TC0010401）不再发出库预警。

3.2 签收预警

  • 依据：实际出库时间（或预计出库时间）+ 配置签收时效。
  • 超时且未更新签收节点（TC001051 / TC0010401）→「签收预警」。

3.3 POD回传预警新

  • 前置：运单已出库且已签收（或至少已签收，以实现轨迹字典为准）。
  • 依据：实际签收时间 + 配置 POD 回传时效（销售产品 + 邮编，可与签收时效同表扩展字段）。
  • 若超过预计 POD 回传时间，且 POD 附件/轨迹节点（TC0010601 或 POD 上传记录）未回传 → 预警分类「POD回传预警」。
  • 页签档位与出库/签收/POD 预警共用（超时预警 / 即将超时 / 已处理）。

3.4 拆柜时间（时效基准）

  • 来源：轨迹节点「海外拆柜」(TA0001) 的最早发生时间；多记录取最早。
  • 原提柜/提货时间不再作为本页时效基准；原误用 TC00070 / 状态 70 已更正为 TA0001。

3.5 拆柜天数

  • 拆柜天数 = floor((当前时间 − 拆柜时间) / 1天)

3.6 超时预警天数

  • 按当前预警类型取对应配置截止时点 − 当前时间（或 − 实际完成时间）。

3.7 预计出库 / 签收 / POD 回传时间

  • 预计出库 = 拆柜时间 + 出库时效。
  • 预计签收 = 预计出库 + 签收时效。
  • 预计POD回传 = 实际签收时间（无则用预计签收）+ POD回传时效。

3.8 实际出库 / 签收 / POD 时间

  • 出库 TC001031、签收 TC0010401、POD TC0010601 或 POD 上传表最早记录。

3.9 轨迹编码对照（本模块引用）

  • 拆柜：TA0001（海外拆柜，时效基准）
  • 出库：TC00105 / TC001031
  • 签收：TC001051 / TC0010401
  • POD 回传：TC0010601 或 POD 上传记录

4. 规则配置

  • 按销售产品 + 目的邮编配置出库、签收、POD回传时效。
  • 配置页本版暂不处理；参数表维护。

5. 页签口径

  • 全部：符合数据范围的全部记录。
  • 超时预警：已超出配置截止时点且未处理（红色）。
  • 即将超时：临近截止（如剩余 ≤ 1 天）或次级预警档（橙色）；非「已出库超时」语义，表示即将到达出库/签收/POD 截止时点。
  • 已处理：人工标记已处理，或轨迹已补齐至对应节点后自动归档。
  • 出库 / 签收 / POD 回传三类预警均计入上述页签档位。

6. 待办消息推送与角标（新增）

  • 触发：小时任务或实时轨迹变更产生新的未处理预警时，向相关港后客服 / 业务员推送待办。
  • 推送文案：「您有一件待办事项，请及时处理：出库签收预警 · {预警分类} · {运单号}」。
  • 弹窗提醒（新增）：产生新预警时，页面右下角滑入卡片式弹窗（私卡预警 · {分类}），展示运单号与拆柜基准说明；支持「稍后处理」「立即处理」与手动关闭；约 8 秒无操作自动收起；同屏最多堆叠 3 条。顶部同步轻提示（mini toast）。
  • 角标位置：
    • 左侧菜单「B21 出库签收预警」：未处理预警总数；
    • 页面标题旁：同上（当前用户可见范围）；
    • 状态 Tab「超时预警」「即将超时」：各 Tab 下未处理条数；
    • 顶部消息铃铛：待办总数（含本模块及其他待办，本原型仅演示本模块增量）。
  • 消角标：运单标记已处理或轨迹补齐至对应节点后，下次刷新扣减；用户进入页面处理后可同步已读（以实现为准）。
  • 渠道：站内消息 + 铃铛待办（必做）；钉钉/企业微信推送（后续）。

交互说明

  • 筛选含预警分类（含 POD回传预警）、港后客服；查询 / 重置 / 列设置同前。
  • 轨迹维护、修改出库件：勾选后操作。

与其他模块联动

  • 运单管理、轨迹中心、销售产品港后客服配置、消息中心。
  • 港后客服解析规则与「销售产品编辑 · 港后客服分配方式」一致。

非功能性要求

  • 角标与列表计数 eventual consistency，延迟 ≤ 1 小时（与提取频率一致）；实时推送可选。
  • 港后客服数据隔离在接口层强制过滤。

本次范围与后续规划

  • 本次：拆柜基准（轨迹 TA0001）、POD回传预警、港后客服权限、待办角标与消息推送原型。
  • 后续：时效规则配置页、钉钉推送、POD 上传快捷入口。
