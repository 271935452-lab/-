三、功能逻辑说明

3.1 页签 · 与预录工作台衔接

功能点说明原型
预录中
  1. 终配舱后同步进本页，状态预录中；不因终配舱批量改待放行
  2. 作业主战场仍在预录工作台（推送/预录/确认）
预录中
待放行
  1. 预录工作台确认或 #08 收取正式件成功后进入
  2. 线下单亦可直接进入
待放行
报关放行 / 查验放行
  1. 报关放行：未布控查验、海关正常放行；#10 抓到资料自动进入
  2. 查验放行：经海关查验后放行
放行
与预录工作台
  1. 本页不展示待上传/待推送/报关行处理中/预录待复审页签
  2. 推送报关行、预录审核、上传资料、收取正式件、未对接委托催办在预录工作台
  3. 终配舱后不重推报关行
预录工作台

3.2 工具栏 / 勾选

功能点说明原型
分单号自动生成
  1. 勾一票提单 → 按船司×港口规则整组试算 → 写入子表分单号
  2. 货物/配舱变更后可重算；只写舱单用号，不重推报关行 #03
  3. 申请类规则（以星上海、WHL 上海）告警，改走绑定分单号
分单号
发舱单 / 下载舱单
  1. 发舱单：海管家直推，发送成功打「舱单」标
  2. 下载舱单：推代理=下载表格，下载本身不打标
  3. 标记已发代理：线下已发时手工打标
舱单
发 ISF
  1. 旁支计划二 #6 · 验收分册 外部对接 #s-f6
  2. 勾一票，弹窗按现网「新增ISF」
  3. 服务商（NEW）在弹窗标题栏右上角（不进基本信息网格）：信号旗 / 海管家，默认信号旗；决定报文走哪家通道
  4. 保存并提交/提交都算成功，打 ISF 标；日志记所选服务商
  5. AMS 仍在船务，本页不发 AMS
发 ISF
报关放行 / 抓取
  1. 报关放行：登记放行轨迹；弹窗可多选本柜扣货运单
  2. 放行资料抓取：#10 接口/webhook
放行
柜子扣货
  1. 勾提单 → 多选运单打扣货标，不走放行；业务标记「扣货N」
  2. 也可在报关放行弹窗内勾选
扣货
合并报关
  1. 入口在「更多 · 合并报关」下拉；主工作台在预录工作台
  2. 标记须选同柜优先或分柜装（分柜装须风险确认）
  3. 合并后再分票：客户合并 1 票后关务再拆 N 票报关单
合并报关
截单预警
  1. 规则同船务「临近截单」：距截单≤24h 且未到点
  2. 截单时间只读订阅提单管理，本页不改截单
截单预警
一键通知 / 查验处置
  1. 进入报关查验页签后显示；与清关管理查验通知口径一致
查验通知
费用登记
  1. 勾≥1 票提单 → 弹窗一次添加多笔费用
  2. 字段对齐船务费用登记口径
费用登记
无本页入口
  1. 推送报关行、预录审核、上传资料、收取正式件、委托回传核对、改单/改配登记
  2. 无「发 AMS」；无品牌授权比对
工具栏

3.3 弹窗 · 查验 / 放行 / 舱单 / 分单号

功能点说明原型
报关查验
  1. #11 本期不对接 API，手动登记查验通知/开始/放行轨迹
  2. 弹窗必填买单/单证（单选，对齐国内表「买单还是单证」）
  3. 查验报表国内进度「买单/单证」取登记时的选择
  4. 支持一键通知客户查验、查验处置（天数/开船前提醒）
  5. 测：不选买单/单证拦住；选定后保存成功
报关查验
买单/单证
  1. 报关查验弹窗内单选：买单 / 单证
  2. 写入查验登记，供查验报表国内进度列出数
查验登记
退运运单
  1. 报关侧勾选/登记退运运单；查验报表运单维度对应行从此出数
  2. 与清关退运（国外）分流：国内报关退运票走本条
  3. 测：勾选退运运单后查验报表运单维可见
子表勾选
报关放行
  1. 登记报关放行轨迹；可多选本柜暂扣运单（扣货标）
报关放行
上海舱单 / ISF 弹窗
  1. 舱单：按现网「新增上海舱单」货物数据列；保存草稿不打标
  2. ISF：按现网「新增ISF」；服务商在标题栏右上角（信号旗 / 海管家，默认信号旗），不进基本信息网格；发舱单时隐藏服务商
  3. 预填来源见 §3.5 报文预填（弹窗内不展示来源说明）
报文
分单号规则
  1. 绑定提单后按船司×港口自动生成；未绑主单不生成
  2. 维护页：分单号规则配置
  3. 子表「推送同步」按客户单号，与分单号是否已生成无关
规则

3.4 费用登记

功能点说明原型
费用登记
  1. 勾≥1 票提单 → 工具栏「费用登记」
  2. 弹窗可一次添加多笔（类型/大类/金额/币种/说明），可增删行
  3. 字段对齐船务提单管理费用登记（大类国内/国外、归属、柜预估等）
  4. 落业务数据统计，无供应商台账
费用登记
