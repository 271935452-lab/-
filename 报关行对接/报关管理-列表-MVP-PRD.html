预录单整合进报关管理列表

与现有报关管理主列表同一页；预录阶段与申报/放行阶段共用表格，通过页签过滤。

页顶说明（已收入 PRD，不占主列表）

  • 委托（#12）：已对接报关行 →「委托查询」按客户名称 + 报关行拉取电子委托状态并回写子表；未对接 →「委托标记」催办/已委托 + 截图归档。无委托不可报关。见 关务方案 · 委托。
  • 客户授权同步：按附件类型＝品牌授权书从客户附件同步；子表比对报关资料抬头 vs 客户授权抬头；不一致或缺授权时硬拦推送报关行。见 关务方案 · 授权抬头。
  • 报关查验：「一键通知客户查验」或「查验处置」；行内展示查验天数、提醒/处置状态。与 清关管理 · 查验通知 口径一致。入口：页签「报关查验」或 ?tab=check。
  • 合并报关 · 再分票：客户可合并为 1 票；关务实操再拆为 N 票（例 10→3）。标记时选同柜优先或分柜装（分柜装须风险确认）。见 关务方案 §⑦。

与提前报关的关系

  • 本页为报关执行（已排柜 · 提单号）；下单后提前推送见提前报关列表。
  • 从提前报关「关联提单」进入本页时，沿用已推送/预录进度，行上展示「来自提前报关」；不重推资料。
  • 未走提前报关的票：排柜后仍可直接进入本页推送（原流程保留）。

页签与阶段（双区展示）

  • 预录阶段（紫色区）：全部、待推送 → 报关行处理中 → 预录待复审；「全部」聚合预录三态，申报前无报关单号。
  • 申报/放行（蓝色区）：全部、待放行、报关查验、报关放行、查验放行；允许报关之后，含报关单号回传。「报关中」仅作行内状态，不设独立页签。报关查验（#11）本期不对接，模块保留，手动维护。
  • 工具栏预录按钮仅在预录阶段页签可用。

页签说明

  • 全部（预录）：聚合待推送、报关行处理中、预录待复审；不含已允许报关及之后记录。
  • 待推送：操作：自动生成分单号（NEW）、绑定分单号（保留手填）、上传报关资料；尚无预录单号。
  • 报关行处理中：已推送，等待报关行回传预录单附件；无操作。
  • 预录待复审：报关行已回传预录单，待审附件；操作：预录审核、收取正式件（#08）；此阶段无海关报关单号。
  • 全部（申报）：含预录与申报/放行各状态全量视图。
  • 待放行：完成「收取正式件」（#08）后进入；等待海关放行。不走报关行对接的线下单亦可能直接进入此态。
  • 报关查验：本期不对接 API（#11），业务手动登记查验通知、更新状态；支持一键通知客户查验与查验处置（登记处置动作、开船前提醒、查验天数）。
  • 报关放行：未布控查验、海关已正常放行；抓到放行资料（#10）后系统自动进入此页签。
  • 查验放行：经海关查验后放行。

评审结论（#01–#12）

  • #01 推送报关资料附件 → 传附件 + 分单号；若子表「备注」有内容，推送报关行时一并传给报关行（标记：自动生成分单号、绑定分单号、推送报关行、上传资料；分单号、备注见子表）
  • #02 推送报关资料信息 → 不处理
  • #03 报关资料修改 → 修改分单号、附件或备注后触发再次推送；货物调整导致分单号重算后必须重推（标记：推送同步=待重推）
  • #04 预录单附件回传 → 保存附件、审附件（标记：预录审核、预录单号列）
  • #05 预录单信息回传 → 不处理
  • #06 预录单修改 → 线下沟通
  • #07 线上沟通 → 线下沟通
  • #08 正式件收取 → 列表点击「收取正式件」时，调用报关行接口抓取该票最新预录单信息，保存为「报关正式件」（标记：工具栏紫色 #08）；保存成功后进入待放行。Webhook 推送时走同一保存逻辑
  • #09 报关单号回传 → 增加字段（标记：报关单号列）
  • #10 放行资料回传 → 接收 + 抓取（标记：放行资料抓取）
  • #11 报关查验回传 → 本期不对接，模块保留，手动处理
  • #12 电子委托状态查询 → 按客户名称 + 报关行查询，返回委托状态/内容并回写子表电子委托、委托内容；工具栏「委托查询」。未对接另增「委托标记」（催客户 + 截图归档）；无委托不可报关

页内对本期对接功能（#01 #04 #08 #09 #10 #12）做彩色编号标记；#08 为预录阶段紫色标记。

新增列

  • 预录单号、报关单号（#09）、放行资料（#10）、最近抓取、推送时间、预录回传。
  • 报关单号与预录单号区分：预录单号为报关行预录阶段编号；报关单号为海关正式报关单号，申报受理后由报关行 API / webhook 写入，预录阶段为空。
  • 展开子表字段（与线上一致）：客户、电子委托（#12）、委托内容（#12）、商品材质、商检报告资料、业务员、打单号、客户单号、件数、总体积、总重量、标记、附加服务、主品名、分单号、报关编号、报关资料、报关资料抬头、客户授权（按附件类型「品牌授权书」从客户附件同步，不按文件名）、客户授权抬头、是否一致、备注（有值时随 #01 推送报关行）、FBA单号、REFERENCE ID、放行资料、托盘号、装柜扫描时间、更新时间、操作（报关资料，末列）。
  • 授权同步口径：用附件类型识别客户授权（类型＝品牌授权书），文件名仅展示；列表比对「报关资料抬头 vs 客户授权抬头」，结果：一致 / 不一致 / 缺授权 / 未比对。筛选区支持「抬头是否一致」。硬拦：推送报关行（#01）前校验子表，不一致或缺授权时弹窗阻断，不可硬过。

分单号自动生成 NEW

  • 按船司 × 港口规则自动生成（规则表：美森/合德/以星/COSCO·OOCL/WHL/EMC/华南）。
  • 入口：工具栏「自动生成分单号」；待推送行操作列；保留「绑定分单号」手填兜底（申请类：以星上海、WHL 上海）。
  • 规则维护：分单号规则配置（船司×港口→模板 T1–T7/T0；可试算）。
  • 货物调整：新增/删除/改序后整组按新序重算；顺序可错，号必须对舱单。
  • 子表新增「推送同步」：未推送 / 已同步 / 待重推。

推送报关行（#01）与重推（#03）

  • 推送内容：报关资料附件、分单号（按展开子表分单/运单行）。
  • 备注：若子表「备注」字段有内容，推送报关行时同时传给报关行；无备注则不传或传空（以报关行接口字段为准）。
  • 重推：修改分单号、附件或备注后（#03），或以货物调整触发分单号重算后，再次推送；以最新分单号 + 备注为准。
  • 阻断建议：同步=待重推时，「收取正式件」前应先完成 #03 重推，避免报关行侧分单号与舱单不一致导致改运抵。

收取正式件（#08）

  • 入口：报关管理列表工具栏「收取正式件」（预录待复审 / 预录全部页签；对勾选记录操作）。
  • 点击后：调用报关行 #08 接口，抓取报关行侧该票最新预录单信息（以报关行当前有效版本为准）。
  • 保存：抓取成功后，将返回内容保存为「报关正式件」，挂载至提单详情 · 清报关附件（附件类型：报关正式件；可与既有报关预录件并存）。
  • 状态：保存成功后，记录退出预录阶段，进入申报/放行区「待放行」页签；失败则提示错误，状态不变、不落正式件。
  • Webhook：报关行主动推送正式件/最新预录单时，执行相同抓取保存逻辑，成功后自动进入待放行（若已订阅 #08）。

页内说明（原筛选下提示条 · 已收入 PRD）

  • 委托（#12）：已对接报关行 →「委托查询」按客户名称 + 报关行拉取电子委托状态并回写子表；未对接 →「委托标记」登记催办/已委托并上传截图。无委托不可报关。见关务方案 · 委托。
  • 客户授权同步：按附件类型＝品牌授权书从客户附件同步；子表比对报关资料抬头 vs 客户授权抬头；不一致或缺授权时硬拦推送报关行。见关务方案 · 授权抬头。
  • 报关查验：页签「报关查验」下可「一键通知客户查验」「查验处置」；行内展示查验天数、提醒/处置状态。与清关管理 · 查验通知口径一致。入口 ?tab=check。
  • 合并报关 · 再分票：客户可合并为 1 票；关务再拆为 N 票实际报关单（例 10→3）。标记须选同柜优先或分柜装（分柜装须风险确认）。见关务方案 §⑦。

新增能力

  • 改配登记（NEW）：工具栏「改配」→ 登记改配场景（①舱单前改资料 / ②已发舱单改配 / ③装柜后改配）、可改字段、必通知客服/海外/仓库；保存后写提单备注并示意通知。详见改配三类场景 · 轨迹与同步。

工具栏

  • 工具栏按阶段分组配色：通用（灰）/预录（紫）/合并报关（青）/查验（橙）/申报放行（蓝绿）；随页签显隐，预录阶段灰显放行按钮。
  • 待推送页签：自动生成分单号（NEW）、绑定分单号、上传报关资料；报关行处理中：无操作；预录待复审/全部（预录）：推送报关行、预录审核、收取正式件（#08）。
  • 委托查询（#12）：按客户名称 + 报关行调用接口 → 展示返回的委托状态（及委托内容）→ 回写匹配客户行的子表电子委托列。
  • 委托标记（NEW）：未对接报关行时人工标记「未委托 / 已催办 / 已标记·催客户 / 已委托」，可上传截图、通知业务员；用于催客户补委托。
  • 一键通知客户查验（NEW）：进入「报关查验」页签后显示；勾选查验提单 → 生成通知文案 → 发送/复制给业务员或客户。与清关管理查验通知口径一致（国内出口查验）。
  • 合并报关标记（NEW）：勾选提单 → 将组内运单标记为客户「合并报关 1 组」（生成合并组号、指定报关员）；主行/子表可见合并标记。须选择同柜优先或分柜装（分柜装须勾选风险确认）。取消合并标记可清除。
  • 合并后再分票（NEW）：客户已合并为 1 票后，关务将组内运单再分配到 N 票实际报关单（例：10→3）。子表「标记」列展示「报关票1/2/3」；主行展示「再分票 N」。筛选项「合并报关」可按已合并 / 已再分票过滤。
  • 改配（NEW）：勾选提单 → 登记改配场景与可改字段 → 必通知客服/海外/仓库；保存写备注。
  • 发 AMS / 发 ISF（NEW）：勾选提单后打「已发」，回写提单管理业务标记。船务列表只展示、可筛，无打标按钮。本期只做标记与回写，报文自动发送未拍板。
  • 筛选项「委托状态」可按子表委托态过滤（示意）。
  • 预录阶段「报关放行」「报关查验」「放行资料抓取」灰显不可用。

状态自动流转

  • 收取正式件 → 待放行：列表点击「收取正式件」→ 调用 #08 抓取报关行最新预录单信息 → 保存为报关正式件 → 进入「待放行」。Webhook 推送时同样处理。
  • 放行资料抓取 → 报关放行：通过 #10 接口/webhook 抓到放行资料且判定齐全后，系统自动将状态更新为「报关放行」（未布控查验场景），并同步资料至运单/柜子。

操作列

  • 预录态 → 提单详情 · 清报关；预录待复审 → 列表工具栏 收取正式件（#08）；待放行 → 报关放行 / 抓取（#10）；已允许报关 → 抓取。
