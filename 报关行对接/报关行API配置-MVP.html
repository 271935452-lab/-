报关行 API 配置

参考服务商渠道「新增数据」弹窗布局：上方基本信息 + 下方 Tab（API 配置 / 对接能力 / Webhook 回调）。为报关管理列表多报关行对接提供主数据与适配参数。

列表

  • 按报关行、API 服务商、对接状态筛选；支持新增、编辑、启用/停用、连通性测试。
  • 「本期对接能力」展示评审编号芯片（#01 #04 #08 #09 #10 #12 等）。

基本信息

  • 关联已有报关行主数据；编码系统唯一。
  • 停用后该报关行新单不走 API，历史单只读。

API 配置（参考渠道 API 配置 Tab）

  • API 服务商：选择适配器（港兴 / 云报关 / 华商 / 自定义），切换时加载字段模板。
  • 字段映射表：序号、字段、字段值（必填）、备注；支持增删行。常见字段：基础地址、AppKey、AppSecret、海关编码、环境、Token 刷新间隔等。
  • 密钥类字段加密存储；保存前可做连通性测试。

对接能力

  • 按评审结论 #01–#12 列出能力项；「本期」列标识对接 / 不做 / 手动。
  • 仅「本期对接」项可启用开关；#02 #05 #11 等默认禁用。
  • 启用项与业务流程图节点、列表工具栏能力一致。

Webhook 回调

  • 系统生成每报关行唯一回调 URL，供报关行配置出站推送。
  • 可订阅：预录单附件回传（#04）、正式件收取（#08）、报关单号（#09）、放行资料就绪（#10）、电子委托（#12）。
  • 正式件收取（#08）→ 抓取最新预录单信息、保存报关正式件 → 待放行；放行资料齐全 → 自动 报关放行。

与业务联动

  • 列表「报关供应商」命中本配置后，按启用能力调用对应接口。
  • 未配置或停用的报关行由头程发放协作链接上传资料，头程在供应商上传审核确认（等同 #04/#08 线下通道）。
