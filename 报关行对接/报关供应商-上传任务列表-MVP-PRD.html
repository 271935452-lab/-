工作台链接 · 待办列表

与头程报关管理、供应商上传审核分域部署；报关行不进入 ERP，仅通过链接访问本协作站。

链接类型

  • 工作台链接（本页）：?token=…&scope=workspace · 有效期建议 7 天 · 可见该报关行全部待办。
  • 任务链接（直达上传页）：?token=…&scope=task&task=material&taskId=… · 有效期建议 72h · 仅单票操作。

鉴权（示意）

  • Token 为签名 JWT 或一次性随机串；服务端校验：未过期、报关行 ID 匹配、任务状态允许、API 未启用。
  • 校验通过后写 HttpOnly Cookie（会话 2h），同浏览器内可跳转任务详情无需重复带 token。
  • 失败跳转链接失效页；已启用 API 的报关行返回 reason=api。

生命周期

  • 过渡方案：未对接 API 报关行使用链接协作。
  • 报关行 API 启用后：停止发链，旧链立即失效，与 #01/#04/#08 全量对接。
