URL 参数

  • token — 签名令牌，绑定 brokerId + taskId + task 类型 + exp。
  • scope=task — 单任务模式；不展示 ERP 侧链；可选隐藏「返回待办列表」。
  • task=material|preentry|formal — 决定开放的上传区块。
  • readonly=1 — 已提交只读查看。

  • 写入头程「供应商上传审核」待确认队列；可选将任务链接标记 used 或缩短为只读。
  • 退回时头程生成新 token 再发链接，旧链失效。
