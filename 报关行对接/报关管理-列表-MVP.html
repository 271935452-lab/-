PRD · 报关管理列表

预录单整合进报关管理列表

与现有报关管理主列表同一页；预录阶段与申报/放行阶段共用表格，通过页签过滤。

页签与阶段（双区展示）

  • 预录阶段（紫色区）：全部、待推送 → 报关行处理中 → 预录待复审；「全部」聚合预录三态，申报前无报关单号。
  • 申报/放行（蓝色区）：全部、待放行、报关查验、报关放行、查验放行；允许报关之后，含报关单号回传。「报关中」仅作行内状态，不设独立页签。报关查验（#11）本期不对接，模块保留，手动维护。
  • 工具栏预录按钮仅在预录阶段页签可用。

页签说明

  • 全部（预录）：聚合待推送、报关行处理中、预录待复审；不含已允许报关及之后记录。
  • 待推送：操作：绑定分单号、上传报关资料；尚无预录单号。
  • 报关行处理中：已推送，等待报关行回传预录单附件；无操作。
  • 预录待复审：报关行已回传预录单，待审附件；操作：预录审核、收取正式件（#08）；此阶段无海关报关单号。
  • 全部（申报）：含预录与申报/放行各状态全量视图。
  • 待放行：确认收到正式件后进入（报关行接口回传正式件自动确认，或在列表操作）；等待海关放行。不走报关行对接的线下单亦可能直接进入此态。
  • 报关查验：本期不对接 API，业务手动登记查验通知、更新状态。
  • 报关放行：未布控查验、海关已正常放行；抓到放行资料（#10）后系统自动进入此页签。
  • 查验放行：经海关查验后放行。

评审结论（#01–#12）

  • #01 推送报关资料附件 → 传附件 + 分单号（标记：绑定分单号、推送报关行、上传资料；分单号见子表）
  • #02 推送报关资料信息 → 不处理
  • #03 报关资料修改 → 修改分单号或附件后触发再次推送，不设按钮标记
  • #04 预录单附件回传 → 保存附件、审附件（标记：预录审核、预录单号列）
  • #05 预录单信息回传 → 不处理
  • #06 预录单修改 → 线下沟通
  • #07 线上沟通 → 线下沟通
  • #08 正式件回传 → 收取 / 确认正式件（标记：列表工具栏「收取正式件」，紫色 #08）；接口回传可自动确认，或用户在列表手动点击
  • #09 报关单号回传 → 增加字段（标记：报关单号列）
  • #10 放行资料回传 → 接收 + 抓取（标记：放行资料抓取）
  • #11 报关查验回传 → 本期不对接，模块保留，手动处理
  • #12 电子委托状态查询 → 子表增加电子委托、委托内容字段（均标记 #12）；按分单/运单行展示，#12 接口回写

页内对本期对接功能（#01 #04 #08 #09 #10 #12）做彩色编号标记；#08 为预录阶段紫色标记。

新增列

  • 预录单号、报关单号（#09）、放行资料（#10）、最近抓取、推送时间、预录回传。
  • 报关单号与预录单号区分：预录单号为报关行预录阶段编号；报关单号为海关正式报关单号，申报受理后由报关行 API / webhook 写入，预录阶段为空。
  • 展开子表字段（与线上一致）：客户、电子委托（#12）、委托内容（#12）、商品材质、商检报告资料、业务员、打单号、客户单号、件数、总体积、总重量、标记、附加服务、主品名、分单号、报关编号、报关资料、备注、FBA单号、REFERENCE ID、放行资料、托盘号、装柜扫描时间、更新时间、操作（报关资料，末列）。

工具栏

  • 待推送页签：绑定分单号、上传报关资料；报关行处理中：无操作；预录待复审/全部（预录）：推送报关行、预录审核、收取正式件（#08，紫色）。
  • 预录未完成时「报关放行」灰显。

状态自动流转

  • 收取正式件 → 待放行：报关行 #08 正式件回传由系统自动确认，或用户在报关管理列表工具栏点击「收取正式件」后，记录退出预录阶段，进入申报/放行区「待放行」页签。
  • 放行资料抓取 → 报关放行：通过 #10 接口/webhook 抓到放行资料且判定齐全后，系统自动将状态更新为「报关放行」（未布控查验场景），并同步资料至运单/柜子。

操作列

  • 预录态 → 提单详情 · 清报关；预录待复审 → 列表工具栏 收取正式件（#08）；待放行 → 报关放行 / 抓取（#10）；已允许报关 → 抓取。
