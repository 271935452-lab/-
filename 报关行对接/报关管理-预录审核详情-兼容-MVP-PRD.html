提单详情 · 整合预录审核

与线上一致：提单详情为统一入口；预录审核不再单独开页，在「清报关信息」Tab 内审附件。从报关管理列表进入（预录态带 ?tab=customs）。

布局（对齐提单详情）

  • 顶部四色信息卡 + 货代提单号 / 船名航次。
  • Tab 顺序：清报关信息（默认）、运单信息、轨迹信息、箱单信息、提单附件、操作日志。
  • 右侧状态栏：订舱 / 报关 / 离港 / 清关时间轴，可隐藏。

清报关信息

  • 子 Tab：清报关数据、做资料分票核准（NEW）（买单轧差 + 双通道）、清报关附件（#04，默认打开）。
  • 清报关附件：表格列 — 勾选、附件信息（缩略图 + 文件名）、运单号/分单号、类型、备注信息、操作（下载 / 删除）；右上角「批量下载」。备注展示来源、回传/收取时间或业务说明（只读）。
  • 附件类型：报关预录件（报关行 #04 回传预录单）、报关正式件（#08 列表「收取正式件」时抓取最新预录单信息并保存）；与线上提单详情「清报关附件」一致。
  • 商品明细放在「箱单信息」Tab。
  • 列表「预录审核」链至本页并打开清报关 Tab。

与旧版差异

  • 本期不做线上沟通；改单、预录单补传不走系统流程。
  • 收取正式件（#08，紫色）在报关管理列表工具栏操作：点击后抓取报关行最新预录单信息，保存为「报关正式件」并出现在本页清报关附件；完成后进入列表「待放行」。详情页仅展示附件，不提供收取按钮。
