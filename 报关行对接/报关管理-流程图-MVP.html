报关管理业务流程图

与报关管理列表页签、状态标签对齐，用于评审整体流转口径。

预录阶段

  1. 待推送 → 绑定分单号（#01）→ 推送报关行（附件 + 分单号 + 备注（有则传），#01；结构化信息不推，#02）。
  2. 报关行处理中 → 预录单附件回传（#04）。
  3. 预录待复审 → 审附件（#04）；字段对比示意保留但不对接（#05）。
  4. 收取正式件（#08，列表工具栏）→ 抓取报关行最新预录单信息，保存为「报关正式件」（复审通过 / 进入申报的前置条件）。
  5. 复审通过 / 允许报关 → 进入申报阶段。

申报 / 放行

  1. 收取正式件（#08：抓取最新预录单 → 保存正式件；或 Webhook 同等逻辑）→ 进入待放行。
  2. 报关中（行内状态）→ 报关单号回传（#09）。
  3. 分支：未查验 → 报关放行；布控查验 → 报关查验 → 查验放行（#11 本期手动维护，不对接）。
  4. 放行资料抓取（#10）齐全 → 自动进入报关放行，并同步至运单/柜子。

本期调整

  • 已移除预录单改单、预录单补传分支。
  • 复审通过前新增收取正式件节点。
  • 报关查验（#11）本期不对接 API，模块保留，业务手动维护。

预录阶段节点

  • 待推送 — 绑定分单号后推送附件（#01）
  • 报关行处理中 — 等待预录单附件回传（#04）
  • 预录待复审 — 审附件；字段对比不做（#05）
  • 收取正式件 — #08：列表点击抓取最新预录单信息，保存为报关正式件；或 Webhook 自动同等处理
  • 复审通过 — 下发允许报关

申报 / 放行节点

  • 待放行 — 收取正式件（#08）完成后进入
  • 报关中 — 海关申报，报关单号回传（#09）
  • 报关放行 — 未布控正常放行；抓到放行资料（#10）后自动进入
  • 报关查验 → 查验放行 — 手动维护（#11 不对接）
  • 放行资料齐全 → 同步 — 抓取资料（#10），挂载至运单/柜子

手动操作

  • 不走报关行对接 → 待放行 → 手动报关放行 → 同步

本期不含

  • 预录单改单、预录单补传、线上沟通改单流转、报关查验 API 对接（#11）。
