资料员做资料 · 分票 + 买单 + 双通道

落点：报关管理 / 提单详情 · 清报关下「做资料分票核准」。方案对齐双核准通道与关务问题汇总「买单=合计−报关件」。

NEW

  • 分票表：报关件 + 最后一票买单（固定末行）。
  • 报关件数据取报关行预录结构化（通道②优先）；通道①附件识别辅助。
  • 终配总件/总重/总方支持调整并写日志；买单件数/毛重/方数自动轧差。
  • 支持增删报关件、调整顺序（买单始终沉底）、重算买单。
  • 核准标记：「已核准」是本页标记，资料岗点「核准通过」写入。报关执行不设核准状态，仅入口进本页。已标记后分票锁定；「退回修改」仍可用以解除锁定、继续编辑。本页工具栏不提供「分单号自动生成」入口（分单号在绑定提单后于报关列表/规则配置维护）。

双通道

  • 通道①：客户报关附件识别。
  • 通道②：报关行预录回传结构化（优先）。页头不展示「进数来源（双通道）」卡。本页工具栏不放「打开预录附件 #04」；#04 附件在本页通道①列表或提单详情「清报关附件」查看。
  • 报关件以预录为准做核对；比对基准 = 报关资料（不是下单资料）；字段含品名/HS/件毛体/申报金额/报关方式（信息比对不含抬头）。
  • 分票表无「比对」操作列。点击报关件行即刷新右侧字段比对；买单行不比对预录。
  • 本页不设「差异处置」表（无采纳/统一方式等操作）。差异只在字段比对中展示。核准通过时若仍有不一致，弹确认后仍可写入已核准。买单轧差为负不可核准。

品牌授权比对（已移除）

  • 查货侧已提前确认侵权；预录/做资料侧整段删除授权比对与硬卡，核准通过不依赖授权书。
  • 预录字段比对仍不含抬头。

进口商 / 清关行（绑定后展示）

  • 页头只读带出船务已绑定的进口商（名称 · 编码）与清关行。本页不改绑。
  • 未绑定显示 —。清关行列名与清关管理一致（目录：精准 / 02B / 赛因 / 关关通 / 人人数智 / 帝成）。

与推送报关行

  • 分单号在绑定提单之后按规则联动自动生成；买单分单号通常为末票规则（如 COSCO 宁波末票 Z）。
  • 核准通过后进入舱单链；分票/买单调整后按规则重算分单号（对舱单）。报关行侧按报关编号，不因分单号重推。
