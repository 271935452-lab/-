资料员做资料 · 分票 + 买单 + 双通道

落点：报关管理 / 提单详情 · 清报关下「做资料分票核准」。方案对齐双核准通道与关务问题汇总「买单=合计−报关件」。

取数口径（件数 / 重量 / 终配） 2026-09-05 定稿

  • 报关件 · 件数：取报关单表头「件数」（结构化 pcs）。例：出口报关单件数 = 35。不取商品行成交数量合计、不取终配件数。
  • 报关件 · 重量：取报关单表头「毛重(千克)」（结构化 grossWt）。例：毛重 = 580.66。不取净重、不取商品行法定重量合计、不取终配出货重作为报关件重量。
  • 终配舱带出：本页「终配合计」取终配舱的出货重与方数（可调、写日志）。重量合计列展示/轧差基准 = 出货重；方数合计 = 终配方数。
  • 买单轧差：末票件数 / 重量(出货重口径) / 方数 = 终配合计 − Σ报关件（报关件件数、毛重按上两条取报关单）。轧差为负不可核准。
  • 右侧字段比对中的「件数 / 毛重」同样按报关单件数、毛重与预录对照（比对基准仍=报关资料）。

NEW

  • 分票表：报关件 + 最后一票买单（固定末行）。
  • 报关件数据取报关行预录结构化（通道②优先）；通道①附件识别辅助；其中件数/重量按上节取报关单件数、毛重。
  • 终配合计：自终配舱带出出货重、方数（及若有则带出总件数），支持调整并写日志；买单件数/重量/方数自动轧差。
  • 支持增删报关件、调整顺序（买单始终沉底）、重算买单。
  • 核准标记：「已核准」是本页标记，资料岗点「核准通过」写入。报关执行不设核准状态，仅入口进本页。已标记后分票锁定；「退回修改」仍可用以解除锁定、继续编辑。本页工具栏不提供「分单号自动生成」入口（分单号在绑定提单后于报关列表/规则配置维护）。
  • 退回修改 → 改单标记（NEW）：点「退回修改」弹出改单标记窗。字段：适用提单（只读）、改单说明；同窗合并费用录入（旁支）：费用大类 / 类型 / 金额 / 币种 / 费用说明（金额选填）。确认后解除已核准锁定、清空资料员，并写入改单标（回写报关管理业务标记）；若填了金额一并登记费用留痕。测：已核准态点退回必出弹窗；确认后可再编辑分票；填金额确认后操作日志可见费用。
  • 资料员（NEW）：报关管理列表新增「资料员」字段。取值 = 在做资料分票页点击「核准通过」的当前登录人；核准成功后回写该提单/票维度。未核准显示空/—；「退回修改」清空资料员，再次核准按新操作人覆盖。可筛选。

双通道

  • 通道①：客户报关附件识别。
  • 通道②：报关行预录回传结构化（优先）。页头不展示「进数来源（双通道）」卡。本页工具栏不放「打开预录附件 #04」；#04 附件在本页通道①列表或提单详情「清报关附件」查看。
  • 报关件以预录为准做核对；比对基准 = 报关资料（不是下单资料）；字段含品名/HS/件数（报关单件数）/毛重（报关单毛重）/方数/申报金额/报关方式（信息比对不含抬头）。
  • 分票表无「比对」操作列。点击报关件行即刷新右侧字段比对；买单行不比对预录。
  • 本页不设「差异处置」表（无采纳/统一方式等操作）。差异只在字段比对中展示。核准通过时若仍有不一致，弹确认后仍可写入已核准。买单轧差为负不可核准。

品名 · 多商品行展示

  • 同一报关件（预录票）下若有多条商品行（结构化 decMergeList[] / 报关资料商品明细），分票清单「品名」列与右侧字段比对「品名」均按商品行顺序逗号拼接只读展示。
  • 分隔符：英文逗号 ,（无空格）。例：两行品名为「帽子」「女装连衣裙」→ 展示 帽子,女装连衣裙。
  • 空品名跳过不拼；仅 1 行时原样展示、不加逗号。买单行仍为「综合（轧差）」，不拼商品行。
  • 拼接仅用于本页展示与品名字段一致比对；件毛体 / HS / 金额等仍按票级汇总或逐字段规则，不因品名拼接改变。HS 等多值字段本期不在本条强制逗号拼接（有需要另开）。
  • 测：预录含 2 商品行时，分票「品名」= 帽子,女装连衣裙；点该行比对「品名」两侧同文案且一致；删至 1 行后只显示单品名。

品牌授权比对（已移除）

  • 查货侧已提前确认侵权；预录/做资料侧整段删除授权比对与硬卡，核准通过不依赖授权书。
  • 预录字段比对仍不含抬头。

进口商 / 清关行（绑定后展示）

  • 页头只读带出船务已绑定的进口商（名称 · 编码）与清关行。本页不改绑。
  • 未绑定显示 —。清关行列名与清关管理一致（目录：精准 / 02B / 赛因 / 关关通 / 人人数智 / 帝成）。

与推送报关行

  • 分单号在绑定提单之后按规则联动自动生成；买单分单号通常为末票规则（如 COSCO 宁波末票 Z）。
  • 核准通过后进入舱单链；分票/买单调整后按规则重算分单号（对舱单）。报关行侧按报关编号，不因分单号重推。
